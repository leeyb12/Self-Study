# ThisIsJava

이것이 자바다 교재 기반의 Java 예제를 정리한 Eclipse 워크스페이스 성격의 폴더입니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `chap02/` | 변수, 타입, 연산, 문자열 비교 등 Java 기초 |
| `chap05/` | 배열과 참조 타입 실습 |
| `.metadata/` | Eclipse 워크스페이스 메타데이터 |

## 실행

Java 소스 파일은 IDE에서 실행하거나 `javac`, `java` 명령으로 컴파일/실행합니다. 패키지 선언이 있는 파일은 패키지 구조를 유지해야 합니다.
