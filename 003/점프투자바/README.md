# 점프투자바

점프 투 자바 교재 예제를 Eclipse Java 프로젝트 형태로 정리한 폴더입니다.

## 폴더 구조

```text
점프투자바/
├─ src/
│  ├─ s0103/
│  │  └─ HelloWorld.java
│  ├─ s0301/
│  │  ├─ Sample0301_01.java
│  │  ├─ Sample0301_02.java
│  │  └─ Sample0301_03.java
│  └─ module-info.java
├─ bin/
├─ .classpath
└─ .project
```

## 학습 내용

| 위치 | 내용 |
| --- | --- |
| `src/s0103/HelloWorld.java` | Java 기본 출력 예제 |
| `src/s0301/` | 3장 기본 문법 예제 |

## 정리 기준

- 실제 소스는 `src/` 아래에서 확인합니다.
- `bin/`은 Eclipse 컴파일 산출물이므로 학습 내용 설명에서는 보조 정보로만 다룹니다.
- 새 예제가 추가되면 패키지 번호와 파일명을 README에 함께 기록합니다.
