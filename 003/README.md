# 003 - Java

`점프투자바` 교재의 Java 문법 예제를 정리한 폴더입니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `점프투자바/` | Eclipse 기반 점프 투 자바 예제 |
| `점프투자바/src/s0103` | HelloWorld 기본 실행 예제 |
| `점프투자바/src/s0301` ~ `s0311` | 3장 자료형 예제: 숫자, 문자열, 배열, 컬렉션, 형 변환 |
| `점프투자바/src/s0401` ~ `s0405` | 4장 제어문 예제: 조건문과 반복문 |
| `점프투자바/src/s0501` ~ `s0503` | 5장 클래스, 객체, 메서드 예제 |

## 학습 범위

- Java 기본 문법
- 변수와 타입
- 문자열 비교와 처리
- 배열 생성과 사용
- 리스트, 맵, 집합, 열거형과 형 변환
- 조건문과 반복문
- 클래스, 객체와 메서드
- 패키지 단위 예제 구성
- Eclipse 기반 실습 흔적

## 관리 메모

`.metadata/`는 Eclipse 워크스페이스 메타데이터입니다. `bin/`은 컴파일 산출물이며, 학습 소스는 `점프투자바/src`에서 확인합니다.
