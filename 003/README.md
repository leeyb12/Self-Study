# 003 - Java

Java 교재 예제와 문법 실습을 정리한 폴더입니다. `ThisIsJava`와 `점프투자바` 예제를 함께 관리합니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `ThisIsJava/` | 이것이 자바다 교재 기반 예제 |
| `ThisIsJava/chap02/` | 변수, 타입, 문자열 등 Java 기초 |
| `ThisIsJava/chap05/` | 배열과 참조 타입 관련 실습 |
| `점프투자바/` | Eclipse 기반 점프 투 자바 예제 |
| `점프투자바/src/s0103` | HelloWorld 기본 실행 예제 |
| `점프투자바/src/s0301` | 3장 기본 문법 예제 |

## 학습 범위

- Java 기본 문법
- 변수와 타입
- 문자열 비교와 처리
- 배열 생성과 사용
- 패키지 단위 예제 구성
- Eclipse 기반 실습 흔적

## 관리 메모

`.metadata/`는 Eclipse 워크스페이스 메타데이터입니다. `bin/`은 컴파일 산출물이며, 소스 코드와 직접 관련된 학습 내용은 주로 `ThisIsJava/chap*`, `점프투자바/src` 폴더에서 확인합니다.
