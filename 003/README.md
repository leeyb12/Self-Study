# 003 - Java 실습

`이것이 자바다` 교재의 장별 Eclipse Java 프로젝트와 예제 소스를 보관합니다.

## 현재 구조

```text
003/
├─ .gitignore
└─ 이것이 자바다/
   ├─ .metadata/              # Eclipse 워크스페이스 설정
   ├─ chap02/
   │  └─ src/exam02_char/
   │     └─ CharExample.java
   └─ chap05/
      └─ src/
         ├─ sec05/exam01_string_equals/
         └─ sec06/
```

## 핵심 개념

- Java 소스(`.java`)는 컴파일 후 바이트코드(`.class`)가 되며 JVM 위에서 실행됩니다.
- 기본 타입은 값을 직접 저장하고, 배열과 문자열 같은 참조 타입 변수는 객체를 가리키는 참조를 저장합니다.
- 배열은 같은 타입의 값을 고정된 길이로 묶으며 인덱스는 `0`부터 시작합니다.
- 문자열 내용 비교에는 참조를 비교하는 `==`보다 `equals()`를 사용합니다.

## 현재 상태

| 프로젝트 | 현재 학습 내용 |
| --- | --- |
| `chap02` | `char` 타입과 문자 표현 예제 |
| `chap05` | 문자열 동등 비교, 배열 선언과 생성, 배열 길이, 명령행 인수, 다차원 배열 |

각 장은 별도의 Eclipse Java 프로젝트이며 `src/`에서 학습 소스를 확인합니다. `bin/`은 컴파일 산출물이고 `.metadata/`는 Eclipse 워크스페이스 설정입니다.
