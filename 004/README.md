## 핵심 개념 연결

- CPU는 실행할 명령어와 데이터를 메모리에서 읽으며, 캐시는 CPU와 주기억장치의 속도 차이를 줄입니다.
- 운영체제는 프로세스, 메모리, 파일과 입출력 장치를 관리해 프로그램이 하드웨어를 안전하게 사용하도록 합니다.
- 네트워크 계층은 복잡한 통신 과정을 역할별로 나누며 각 계층은 정해진 프로토콜로 데이터를 교환합니다.
- 데이터베이스는 스키마로 데이터 구조를 정의하고 SQL로 조회·변경하며, 트랜잭션으로 작업의 일관성을 지킵니다.
- 교착 상태는 여러 프로세스가 서로 필요한 자원을 기다려 진행하지 못하는 상태입니다.
