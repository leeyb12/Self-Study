# 004 - Computer Science Notes

컴퓨터 구조, 운영체제, 네트워크, 디자인 패턴 등 CS 전공 지식을 Markdown으로 정리한 폴더입니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `면접을 위한 CS 전공지식 노트/` | 디자인 패턴, 네트워크, 운영체제 면접 대비 정리 |
| `소프트웨어 세상을 여는 컴퓨터 과학/` | 컴퓨터 과학 개론 정리 |
| `쉽게 배우는 데이터 통신과 컴퓨터 네트워크/` | 데이터 통신과 네트워크 기초 |
| `혼자 공부하는 컴퓨터 구조 + 운영체제/` | 컴퓨터 구조와 운영체제 교재 정리 |

## 학습 범위

- 컴퓨터 구조와 명령어
- CPU 동작 원리와 성능 향상 기법
- 운영체제와 메모리
- 네트워크 기초, TCP/IP, HTTP
- 디자인 패턴과 프로그래밍 패러다임

## 작성 방식

각 장 또는 절 단위로 Markdown 파일을 나누어 정리합니다. 새 내용을 추가할 때는 기존 번호 체계와 파일명 형식을 맞추는 것을 권장합니다.
