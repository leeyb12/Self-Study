# 혼자 공부하는 컴퓨터 구조 + 운영체제

컴퓨터 구조와 운영체제 교재 내용을 장별 Markdown 노트로 정리한 폴더입니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `01. 컴퓨터 구조 시작하기/` | 컴퓨터 구조를 배우는 이유와 큰 그림 |
| `02. 데이터/` | 0과 1로 숫자/문자를 표현하는 방법 |
| `03. 명령어/` | 소스 코드, 명령어, 명령어 구조 |
| `04. CPU의 작동 원리/` | ALU, 제어장치, 레지스터, 인터럽트 |
| `05. CPU 성능 향상 기법/` | 빠른 CPU 설계, 병렬 처리, CISC/RISC |

## 작성 메모

장별 폴더와 파일 번호를 유지해 학습 순서가 보이도록 관리합니다.
