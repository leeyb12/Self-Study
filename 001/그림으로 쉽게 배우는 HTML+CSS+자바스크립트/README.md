# 그림으로 쉽게 배우는 HTML+CSS+자바스크립트

HTML, CSS, JavaScript 기초를 장별 예제로 실습하는 교재 폴더입니다.

## 폴더 구조

```text
그림으로 쉽게 배우는 HTML+CSS+자바스크립트/
├─ ch02/
├─ ch03/
├─ ch04/
├─ ch05/
└─ ch06/
```

## 학습 내용

| 폴더 | 내용 |
| --- | --- |
| `ch02/` | 개발 환경과 HTML 파일 작성 기초 |
| `ch03/` | HTML 태그, 속성, 이미지, 레이아웃 기초 |
| `ch04/` | 텍스트, 이미지 링크, 목록, 표, 멀티미디어, 폼 |
| `ch05/` | CSS 작성 방식, 외부 CSS 연결, 선택자 |
| `ch06/` | 텍스트 스타일, 배경, 박스 모델, float 레이아웃 |

## 핵심 개념

- 블록 요소와 인라인 요소의 기본 배치 차이를 이해하면 레이아웃 문제를 찾기 쉽습니다.
- 박스 모델은 콘텐츠, 안쪽 여백, 테두리, 바깥 여백으로 요소의 실제 크기를 계산합니다.
- 폼 요소는 사용자의 값을 입력받으며 `label`과 함께 사용하면 접근성이 좋아집니다.
- `float` 기반 레이아웃은 요소가 일반 문서 흐름에서 달라지는 방식을 확인하는 데 의미가 있습니다.

## 확인 방법

각 장의 `.html` 파일을 브라우저에서 열어 결과를 확인합니다.

## 정리 기준

- 교재 장 번호는 `chNN` 폴더로 유지합니다.
- 절 번호 폴더 안에 HTML, CSS, 이미지, 미디어 파일을 함께 둡니다.
- 새 장을 추가하면 이 README의 폴더 구조와 학습 내용을 갱신합니다.
