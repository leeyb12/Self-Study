# HTML-CSS-JavaScript1

HTML, CSS, JavaScript 기초 예제를 챕터별로 정리한 폴더입니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `02/`, `03/`, `04/` | HTML/CSS 기본 예제와 결과물 |
| `15/` | JavaScript 파일 분리와 기본 동작 실습 |
| `19/` | DOM, NodeList, 이미지/상품 UI 예제 |
| `pr/` | 실습 프로젝트와 결과물 |

## 확인 방법

브라우저에서 HTML 파일을 직접 열어 결과를 확인합니다. CSS, JS, 이미지 파일은 각 예제 폴더 안의 상대 경로를 기준으로 연결되어 있습니다.
