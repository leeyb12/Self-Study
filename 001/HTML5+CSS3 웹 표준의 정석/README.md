# HTML5+CSS3 웹 표준의 정석

HTML5와 CSS3 웹 표준 기초 예제를 장별로 정리하는 폴더입니다.

## 폴더 구조

```text
HTML5+CSS3 웹 표준의 정석/
├─ 01/
│  ├─ basic.html
│  ├─ first-result.html
│  ├─ web.html
│  ├─ web.txt
│  └─ images/
└─ 02/
   ├─ colgroup.html
   ├─ dl.html
   ├─ index-table-result.html
   ├─ css/
   └─ images/
```

## 학습 내용

| 폴더 | 내용 |
| --- | --- |
| `01/` | HTML 문서 기본 구조, 텍스트 문서, 이미지 자료 연결 |
| `02/` | 목록, 설명 목록, 표, CSS 파일 연결 실습 |

## 핵심 개념

- 표는 행과 열의 관계를 표현하며 `caption`, `thead`, `tbody`를 사용하면 의미가 선명해집니다.
- `colgroup`은 표의 열 단위 스타일을 묶어 적용할 때 사용합니다.
- HTML과 CSS를 분리하면 콘텐츠 구조를 유지하면서 디자인만 교체하기 쉬워집니다.

## 확인 방법

각 장의 `.html` 파일을 브라우저에서 열어 결과를 확인합니다.

## 정리 기준

- 장 번호 폴더를 유지합니다.
- HTML, CSS, 이미지 파일은 예제에서 사용하는 상대 경로를 유지합니다.
- 새 장이 추가되면 폴더 구조와 학습 내용 표를 함께 갱신합니다.
