# Do it! HTML+CSS+자바스크립트 웹 표준의 정석

HTML, CSS, JavaScript 웹 표준 기초 예제를 챕터별로 정리한 폴더입니다. HTML 구조 작성, CSS 스타일링, 멀티미디어 요소, JavaScript 기초 문법, DOM 조작, 간단한 웹 페이지 프로젝트를 함께 다룹니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `02/`, `03/`, `04/` | HTML/CSS 기본 예제와 결과물 |
| `15/` | JavaScript 파일 분리와 기본 동작 실습 |
| `19/` | DOM, NodeList, 이미지/상품 UI 예제 |
| `pr/` | 실습 프로젝트와 결과물 |

## 학습 포인트

- HTML 문서 구조와 시맨틱 태그 사용
- 이미지, 오디오, 비디오, PDF 같은 미디어 연결
- CSS 파일 분리와 폼/주문 화면 스타일링
- JavaScript 기본 입출력, 확인창, 프롬프트, 외부 스크립트 연결
- DOM 선택, NodeList, 이미지 UI, 상품 UI 조작

## 개념 연결

- 시맨틱 HTML은 화면 모양과 별개로 콘텐츠의 의미와 문서 계층을 전달합니다.
- CSS 선택자는 스타일 적용 대상을 결정하며, 구체성과 상속은 최종 스타일 계산에 영향을 줍니다.
- DOM 이벤트는 사용자 동작을 감지하고 화면을 다시 그리는 JavaScript의 출발점입니다.
- 상대 경로는 현재 문서 위치를 기준으로 계산되므로 파일 이동 시 CSS, JS, 이미지 연결을 함께 확인합니다.

## 확인 방법

브라우저에서 HTML 파일을 직접 열어 결과를 확인합니다. CSS, JS, 이미지 파일은 각 예제 폴더 안의 상대 경로를 기준으로 연결되어 있습니다.
