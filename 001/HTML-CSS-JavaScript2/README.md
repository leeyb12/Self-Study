# HTML-CSS-JavaScript2

JavaScript를 HTML에서 분리해 사용하는 방식과 기본 DOM 조작을 연습하는 폴더입니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `01/` | 외부 JavaScript, CSS 파일 연결 실습 |
| `02/` | 추가 JavaScript 예제 |

## 핵심 개념

- 외부 CSS와 JavaScript 파일을 사용하면 여러 HTML 문서에서 코드를 재사용할 수 있습니다.
- DOM은 HTML 문서를 JavaScript 객체처럼 탐색하고 변경할 수 있게 표현한 구조입니다.
- 스크립트 실행 시점에 따라 요소를 찾지 못할 수 있으므로 `defer` 또는 문서 로드 이후 실행을 이해해야 합니다.

## 확인 방법

각 `.html` 파일을 브라우저에서 열고, 필요하면 개발자 도구 Console 탭에서 동작을 확인합니다.
