# HTML-CSS-JavaScript3

JavaScript 예제, 연습문제, 퀴즈, 미니 프로젝트를 모아 둔 폴더입니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `01/` - `05/` | 챕터별 JavaScript 예제 |
| `미니프로젝트/` | 작은 웹 기능을 완성하는 프로젝트 |
| `연습문제/` | 복습용 문제 풀이 |
| `퀴즈/` | 퀴즈 형식 실습 |

## 확인 방법

HTML 파일을 브라우저에서 열어 화면과 이벤트 동작을 확인합니다. 이미지가 있는 예제는 폴더 구조를 유지해야 정상 표시됩니다.
