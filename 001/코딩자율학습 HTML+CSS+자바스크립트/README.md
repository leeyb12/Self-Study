# 코딩자율학습 HTML+CSS+자바스크립트

HTML/CSS/JavaScript를 스스로 따라 하며 익히는 교재 실습 폴더입니다. 기본 태그와 JavaScript 문법부터 DOM, 포트폴리오형 웹 페이지 구성까지 이어서 정리합니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `03/`, `04/`, `05/` | 챕터별 웹 예제 |
| `09/` | 변수, 상수, 배열, 불리언 등 JavaScript 기본 자료형 실습 |
| `12/` | DOM 기본 조작 예제 |
| `13/` | 완성본 중심의 웹 페이지 실습 |

## 학습 포인트

- HTML 인용문과 기본 태그 사용
- JavaScript 변수, 상수, 배열, 불리언 타입
- DOM 기본 선택과 조작
- 섹션별 HTML/CSS 분리와 포트폴리오 페이지 구성
- 스크롤, 텍스트 효과, 이동 효과 같은 화면 인터랙션

## 확인 방법

각 예제의 HTML 파일을 브라우저에서 열어 확인합니다.
