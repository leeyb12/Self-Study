# 009 - Python 교재 실습

Python 교재 예제와 문제 풀이를 정리하는 폴더입니다.

`000/`이 Day 단위 코딩테스트 풀이 중심이라면, `009/`는 교재별 Python 문법 실습과 Notebook 풀이를 보관합니다.

## 폴더 구조

```text
009/
├─ 점프투파이썬/
│  ├─ 01-2/
│  ├─ 01-6/
│  └─ 02-2/

   ├─ 02. 파이썬 변수/
   └─ 03. 파이썬 문자열/
```

| 폴더 | 내용 |

## 실행 방법

Python 파일은 터미널에서 실행합니다.

```powershell
python "009\점프투파이썬\01-2\simple.py"
```

Notebook 파일은 Jupyter 환경에서 열어 실행합니다.

```powershell
cd "009\초보자를 위한 파이썬 300제"
jupyter notebook
```
