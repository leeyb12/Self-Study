# 009 - Python 교재 실습

Python 교재 예제와 문제 풀이를 정리하는 폴더입니다.

`000/`이 Day 단위 코딩테스트 풀이 중심이라면, `009/`는 교재별 Python 문법 실습과 Notebook 풀이를 보관합니다.

## 폴더 구조

```text
009/
├─ 점프투파이썬/
│  ├─ 01-2/
│  ├─ 01-6/
│  └─ 02-2/
└─ 초보자를 위한 파이썬 300제/
   ├─ 01. 파이썬 시작하기/
   ├─ 02. 파이썬 변수/
   └─ 03. 파이썬 문자열/
```

## 학습 내용

| 폴더 | 내용 |
| --- | --- |

| `점프투파이썬/01-6` | 에디터 실행과 간단한 출력 예제 |
| `점프투파이썬/02-2` | 문자열 기본 예제 |
| `초보자를 위한 파이썬 300제/01. 파이썬 시작하기` | 001~010번 Notebook 풀이 |
| `초보자를 위한 파이썬 300제/02. 파이썬 변수` | 011~020번 Notebook 풀이 |
| `초보자를 위한 파이썬 300제/03. 파이썬 문자열` | 021~040번 Notebook 풀이 |

## 핵심 개념

- Python 변수는 객체를 가리키는 이름이며 값의 타입은 실행 시 결정됩니다.
- 문자열은 불변이므로 변경처럼 보이는 연산은 새로운 문자열을 만듭니다.
- 작은 문제를 반복해서 풀 때는 정답뿐 아니라 입력 조건과 예외 상황을 함께 확인합니다.
- Notebook은 설명과 결과를 함께 남기기 좋지만 셀 실행 순서가 재현 가능하도록 관리해야 합니다.

## 실행 방법

Python 파일은 터미널에서 실행합니다.

```powershell
python "009\점프투파이썬\01-2\simple.py"
```

Notebook 파일은 Jupyter 환경에서 열어 실행합니다.

```powershell
cd "009\초보자를 위한 파이썬 300제"
jupyter notebook
```
