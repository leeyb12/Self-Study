# 모던 자바스크립트 Deep Dive

JavaScript 핵심 개념을 깊게 정리하는 교재 학습 폴더입니다.

## 폴더 구조

```text
모던 자바스크립트 Deep Dive/
└─ 03.md
```

## 학습 내용

| 파일 | 내용 |
| --- | --- |
| `03.md` | 3장 내용 정리 |

## 학습 관점

- JavaScript가 코드를 평가하고 실행하는 과정을 중심으로 개념을 연결합니다.
- 용어의 정의와 함께 실제 코드에서 나타나는 결과와 이유를 기록합니다.
- 암묵적 타입 변환, 스코프, 호이스팅처럼 예상과 다른 동작은 비교 예제를 만들어 확인합니다.

## 정리 기준

- 장별 Markdown 파일로 정리합니다.
- 개념 설명, 예제 코드, 헷갈리는 포인트를 함께 남깁니다.
- 새 장을 추가하면 `NN.md` 형식으로 파일명을 맞춥니다.
