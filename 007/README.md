# 007 - 포트폴리오 정리

프로젝트를 진행하며 배운 점, 문제 해결 과정, 기술 선택 이유를 정리하는 폴더입니다.

단순한 코드 보관보다 "무엇을 만들었고, 어떤 문제를 만났고, 어떻게 해결했는지"를 남기는 것을 목표로 합니다.

## 폴더 구조

```text
007/
├─ 프로젝트 회고/
│  ├─ Music.md
│  ├─ Note.md
│  └─ Game.md
├─ 트러블슈팅/
│  ├─ Spring.md
│  ├─ React.md
│  ├─ Database.md
│  └─ GitHub.md
├─ 학습 로드맵.md
└─ README.md
```

## 정리 주제

| 구분 | 내용 |
| --- | --- |
| `프로젝트 회고/` | 프로젝트별 구현 기능, 어려웠던 점, 개선 방향 정리 |
| `트러블슈팅/` | 개발 중 만난 오류와 해결 과정을 기술별로 정리 |
| `학습 로드맵.md` | 앞으로 보완할 학습 주제와 프로젝트 개선 계획 정리 |

## 작성 기준

- 문제 상황은 에러 메시지나 현상을 먼저 적습니다.
- 원인과 해결 방법을 분리해서 정리합니다.
- 다시 봤을 때 바로 따라 할 수 있도록 명령어, 파일 경로, 설정명을 남깁니다.
- 프로젝트 회고는 기능 나열보다 배운 점과 개선 방향을 중심으로 작성합니다.
