## 책형 뷰어

`모던 자바스크립트 프로그래밍의 정석/index.html`은 예제를 책처럼 볼 수 있도록 만든 학습 뷰어입니다.

- 왼쪽 페이지: HTML/CSS/JS 코드
- 오른쪽 페이지: 실제 구현 화면
- 이전/다음 페이지 이동
- 예제 선택 메뉴
- 브라우저 위치 권한 기반 현재 위치와 날씨 정보 표시

위치와 날씨 기능은 브라우저 보안 정책 때문에 로컬 서버에서 실행하는 것이 안정적입니다.

```powershell
cd "007\모던 자바스크립트 프로그래밍의 정석"
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765/index.html`로 접속합니다.

## 정리 기준

- 교재별 폴더를 만들고 장 번호로 예제를 나눕니다.
- HTML 예제와 연결되는 CSS/JS 파일은 같은 장 폴더 안의 `css`, `js` 하위에 둡니다.
- 개념 정리 중심 자료는 장 번호 Markdown 파일로 관리합니다.
- 새 예제가 추가되면 책형 뷰어의 예제 목록에도 함께 반영합니다.
