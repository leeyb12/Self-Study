# 러닝스쿨! 자바스크립트 첫걸음

JavaScript 입문 교재 실습을 정리하기 위한 폴더입니다.

## 현재 상태

아직 실습 파일은 추가되지 않았고, JavaScript 입문 교재 예제를 장별로 모으기 위한 준비 폴더입니다. 이후 파일이 추가되면 HTML/CSS/JS 예제와 개념 메모를 함께 관리합니다.

## 예정 구조

```text
러닝스쿨! 자바스크립트 첫걸음/
├─ 01/
├─ 02/
└─ README.md
```

## 정리 기준

- 장별 폴더를 만들고 예제 HTML/CSS/JS 파일을 함께 보관합니다.
- 개념 정리는 필요하면 장별 Markdown 파일로 분리합니다.
- 실습 파일이 추가되면 상위 `007/README.md`에도 범위를 반영합니다.
