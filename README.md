## 학습 폴더

### `000/` Python 코딩테스트

`000/python 00`에는 Day 01부터 Day 25까지 프로그래머스 스타일의 기초 문제 풀이가 들어 있습니다. Day 01-24는 각 5개, Day 25는 4개 풀이 파일이 있습니다.

주요 학습 내용:

- 입출력과 산술 연산
- 조건문과 반복문
- 문자열 인덱싱/슬라이싱
- 리스트 조작과 배열 문제 풀이
- 함수와 메서드 활용
- 2차원 리스트 다루기

### `001/` HTML/CSS/JavaScript

HTML 문서 구조, CSS 레이아웃과 스타일링, JavaScript 기본 문법, DOM 조작, 퀴즈와 미니 프로젝트를 단계별로 정리합니다.

### `002/` 혼공 시리즈

Python 기초, JavaScript 문법, 데이터 분석, 머신러닝/딥러닝 실습, 단어 노트와 이미지 자료를 교재별로 정리합니다.

### `003/` Java

`ThisIsJava` 교재 예제를 중심으로 기본 타입, 문자열 비교, 배열 생성과 사용 등을 실습합니다.

### `004/` CS / SQL 이론 노트

컴퓨터 구조, 운영체제, 네트워크, HTTP, 메모리, 디자인 패턴, SQL과 데이터베이스 기초를 Markdown으로 정리합니다.

### `005/` 웹 교재 실습

HTML/CSS 중심의 웹 기초 교재 예제, 장별 `index.html`, CSS 파일, 이미지 자산을 관리합니다.

### `006/` 머신러닝 교재 실습

`머신 러닝 교과서 3판`의 장별 Jupyter Notebook 실습을 정리합니다. 사이킷런 기반 분류, 전처리, 차원 축소, 모델 평가, 앙상블, 텍스트 데이터 처리 등을 다룹니다.

### `007/` JavaScript 교재 실습

`Do it! 자바스크립트 기초`, `Do it! 자바스크립트 입문`, `모던 자바스크립트 프로그래밍의 정석` 예제를 정리합니다.

`모던 자바스크립트 프로그래밍의 정석`은 01~07장과 18장 예제가 들어 있으며, `index.html`은 예제를 실제 책처럼 볼 수 있는 학습 뷰어입니다. 왼쪽에는 코드, 오른쪽에는 실행 화면을 표시하고, 브라우저 위치 권한을 허용하면 현재 위치와 날씨 정보를 읽어옵니다.

### `008/` Spring 실습 정리

Spring Boot 실습 자료를 정리하기 위한 공간입니다. 현재는 `README.md`만 있으며, 이후 Spring 실습 프로젝트나 개념 정리 파일을 추가할 때 구조를 갱신합니다.

## 실행 방법

프로젝트마다 DB, 포트, 환경 변수가 다를 수 있습니다. 실행 전 각 프로젝트의 `README.md`, `application.properties`, SQL 파일을 먼저 확인합니다.

### Spring Boot Backend

```powershell
cd project\<프로젝트명>\Backend
.\gradlew.bat bootRun
```

`Game` 프로젝트는 백엔드 폴더명이 소문자입니다.

```powershell
cd project\Game\backend
.\gradlew.bat bootRun
```

### React Frontend

Vite 프로젝트:

```powershell
cd project\<프로젝트명>\Frontend
npm install
npm run dev
```

Music 프로젝트는 Create React App 기반입니다.

```powershell
cd project\Music\Frontend
npm install
npm start
```

`Game` 프로젝트는 프론트엔드 폴더명이 소문자입니다.

```powershell
cd project\Game\frontend
npm install
npm run dev
```

### 정적 HTML 예제

HTML 예제는 브라우저에서 직접 열 수 있습니다. 단, `007/모던 자바스크립트 프로그래밍의 정석/index.html`처럼 코드 불러오기나 위치 권한을 사용하는 화면은 로컬 서버에서 실행하는 편이 안정적입니다.

```powershell
cd "007\모던 자바스크립트 프로그래밍의 정석"
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765/index.html`로 접속합니다.

## 관리 기준

- 학습 파일은 주제별 폴더와 Day/Chapter 단위로 정리합니다.
- 문제 풀이 파일은 문제 이름을 파일명으로 사용해 다시 찾기 쉽게 관리합니다.
- 프로젝트는 가능하면 `Backend`, `Frontend`, `sql`, `docs`, `uploads`처럼 역할이 드러나는 폴더로 구분합니다.
- `node_modules/`, `build/`, `.gradle/`, `dist/`, `bin/` 같은 생성물은 Git 관리 대상에서 제외하는 것을 권장합니다.
- DB 비밀번호, JWT secret, API key 같은 민감 정보는 운영 환경에서 환경 변수로 분리하는 것을 권장합니다.
