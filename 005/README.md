# 005 - 웹 교재 실습

HTML/CSS 중심의 웹 기초 교재 예제와 웹 페이지 제작 실습을 정리하는 폴더입니다.

## 폴더 구조

```text
005/
├─ HTML5 웹프로그래밍 입문/
│  ├─ Chapter 02/
│  └─ Chapter 03/
├─ HTML+CSS 실전입문서/
│  ├─ 02장/
│  ├─ 03장/
│  └─ 04장/
├─ 러닝스쿨! 한 권으로 끝내는 HTML + CSS 웹 디자인 입문/
│  └─ WCBCafe/
│     ├─ css/
│     ├─ images/
│     ├─ contact.html
│     └─ index.html
└─ 최신 표준 HTML5+CSS3 디자인/
   ├─ 1-3/
   ├─ 2-1/
   ├─ 2-2/
   └─ 2-3/
```

## 학습 내용

| 폴더 | 내용 |
| --- | --- |
| `HTML5 웹프로그래밍 입문/` | HTML 문서 구조, CSS/JavaScript 연결, 텍스트와 링크 태그 실습 |
| `HTML+CSS 실전입문서/` | 장별 `index.html` 예제를 통한 HTML/CSS 기본 구성 실습 |
| `러닝스쿨! 한 권으로 끝내는 HTML + CSS 웹 디자인 입문/` | WCBCafe 페이지 제작, CSS 분리, 이미지 자산 활용 실습 |
| `최신 표준 HTML5+CSS3 디자인/` | HTML5/CSS3 레이아웃, 이미지 자산, 장별 웹 페이지 예제 |

## 핵심 개념

- 시맨틱 태그는 콘텐츠의 역할을 브라우저와 보조 기술에 전달합니다.
- CSS 레이아웃은 일반 문서 흐름, 박스 모델, 위치 지정 방식의 영향을 함께 받습니다.
- 반응형 페이지는 고정된 화면 크기를 가정하지 않고 상대 단위와 미디어 쿼리로 변화에 대응합니다.
- 이미지 자산은 적절한 형식과 크기, 대체 텍스트를 선택해야 성능과 접근성을 함께 확보할 수 있습니다.

## 정리 기준

새 장이나 예제를 추가할 때는 교재명 아래에 장별 폴더를 만들고, 예제 실행 진입점은 가능한 `index.html`로 맞춥니다.
