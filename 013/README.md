## 개념 흐름

Java 소스는 `javac`로 바이트코드로 컴파일되고 JVM에서 실행됩니다. JDK는 컴파일러와 실행 도구를 포함하며, `JAVA_HOME`과 `Path`는 터미널이 설치된 도구를 찾도록 돕습니다. 개발 환경을 준비한 뒤 변수, 기본 타입과 메모리 표현을 학습하는 순서로 노트를 연결합니다.
