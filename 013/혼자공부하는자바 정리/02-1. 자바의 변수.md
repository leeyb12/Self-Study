## 변수의 개념과 역할
"변수는 값을 저장할 수 있는 메모리의 특정 번지에 붙여진 이름이다."
- 컴퓨터 메모리는 수많은 번지(주소)로 구성되어 있음.
- 데이터를 저장할 메모리 위치를 이름으로 지정하지 않으면 프로그래밍이 어려움
- 변수는 메모리 번지에 붙인 이름으로, 데이터를 저장하거나 읽을 때 사용
- 변수 한 개는 하나의 값을 저장함 (예: 변수 x에 정수 10 저장)
- 변수는 다양한 데이터 타입(정수, 실수 등)을 저장할 수 있음

## 변수 선언과 초기화
"변수 선언은 변수 이름과 저장할 데이터 타입을 결정하는 과정이다."
- 변수 선언 시, 어떤 타입의 데이터를 저장할지 지정 필요
- 예시: <mark>int age;</mark> (정수형 변수 age 선언), <mark>float value;</mark> (실수형 변수 value 선언)
- 한 줄에 같은 타입 변수 여러 개를 콤마로 선언 가능: <mark>int x, y, z;</mark>
- 변수 이름 규칙 (Java 기준)
  - 첫 글자는 문자 또는 달러($) 또는 언더스코어(_) 가능, 숫자로 시작 불가
  - 예약어(Java 예약어)는 변수 이름으로 사용할 수 없음 (컴파일 에러 발생)
  - 대소문자 구분 (ex. <mark>Total</mark>과 <mark>total</mark>은 다른 변수)
  - 관례: 소문자로 시작, 단어가 연결될 때는 카멜케이스(camelCase) 사용 (예: <mark>firstName</mark>)
  - 문자 수 제한 없음
- 변수 초기화
  - 초기화는 변수 선언 후 처음 값을 저장하는 것
  - 초기화하지 않은 변수는 메모리에 값이 없어서 읽기/연산 불가
  - 예: <mark>int score = 90;</mark> (선언과 동시에 초기화)
- 대입 연산자(=)로 값을 변수에 저장함
  - 수학에서 '='는 등호지만, 프로그래밍에서는 대입을 의미

| 구분 | 예시 | 설명 |
|------|------|------|
| 변수 선언 | <mark>int age;</mark> | 정수형 변수 age 선언 |
| 변수 초기화 | <mark>int score = 90;</mark> | 선언과 동시에 값 90 초기화 |
| 여러 변수 선언 | <mark>int x, y, z;</mark> | 같은 타입 변수 여러 개 선언 |
| 변수 이름 규칙 | <mark>firstName, _value</mark> | 문자 또는 $, _로 시작 |
| 예약어 사용 | <mark>int class;</mark> | 컴파일 에러 발생 |

## 변수 사용과 연산
- 변수 사용은 변수에 저장된 값을 읽거나 변경하는 것
- 변수는 출력문, 연산식 등 다양한 곳에서 사용 가능
- 예시: <mark>System.out.println(score);</mark> -> 변수 score 값 출력 
- 변수끼리 연산 가능 (단, 타입에 맞는 값이어야 함)
- 연산 결과를 다른 변수에 저장 가능

```java
int a = 3;
int b = 5;
int total = a + b;  // total은 8 
```

- 변수 값 교환 시 임시 변수 사용 필요
  - 예) x와 y 값 교환
    1. temp = x 
    2. x = y
    3. y = temp

| 예제 코드 | 설명 |
|-----------|------|
| <mark>int x = 3; int y = 5;</mark> | 변수 선언 및 초기화 |
| <mark>int temp = x; x = y; y = temp;</mark> | x와 y의 값 교환 |
| <mark>System.out.println(x + "시간" + y + "분");</mark> | 변수 값 출력 (문자열 결합) |

## 변수의 범위(Scope)와 로컬 변수
- 변수는 자신이 선언된 블록 내에서만 사용 가능 (변수의 유효 범위(scope))
- 블록: 중괄호 <mark>{}</mark>로 묶인 코드 영역 (예: 메소드, if문, for문)
- 로컬 변수 (local variable)
  - 메소드나 특정 블록 내부에서 선언된 변수
  - 해당 블록이 끝나면 메모리에서 제거되고, 더 이상 사용 불가
- 예시

| 블록 위치 | 변수 선언 위치 | 변수 사용 가능 여부 |
|-----------|----------------|---------------------|
| 메인 메소드 블록 | 변수 v1 | 메인 블록 내 전체에서 사용 가능 |
| if 블록 내부 | 변수 v2 | if 블록 내부에서만 사용 가능 |
| for 블록 내부 | 변수 v3 | for 블록 내부에서만 사용 가능 |

- 중첩 블록에서의 변수 사용
  - 상위 블록에서 선언된 변수는 하위 블록에서 사용 가능
  - 하위 블록에서 선언된 변수는 상위 블록 또는 다른 블록에서 사용 불가

| 선언 위치 | 사용 가능 위치 | 사용 불가 위치 |
|-----------|----------------|----------------|
| if 블록 | if 블록 내부, 하위 블록 | if 블록 밖, 다른 블록 |
| 상위 블록 | 상위 블록, 하위 블록 | 다른 블록 |

- 변수 사용 범위를 고려하여 필요한 위치에 변수를 선언하는 것이 중요

## 실습 예시: 변수 선언과 사용
- 프로젝트 생성 및 패키지, 클래스 설정 후 메인 메소드에 변수 선언 및 초기화
- 변수 선언 예
```java
int value = 10;  // 정수형 변수 선언 및 초기화
System.out.println(value);  // 출력: 10
```

- 변수 연산 및 출력 예
```java
int a = 3;
int b = 5;
int total = a * 60 + b;  // 총 분 계산
System.out.println("총 분: " + total);
```

- 변수 값 교환 예
```java
int x = 3;
int y = 5;
int temp = x;
x = y;
y = temp;
System.out.println("x = " + x + ", y = " + y);
```

- 코딩 스타일 권장사항
  - 들여쓰기는 탭 사용 권장 (스페이스 사용 가능하지만 일관성 중요)
  - 변수 이름은 소문자로 시작, 카멜케이스 사용 권장
  - 연산자는 한 칸 띄워서 사용
  - 문자열 결합 시 숫자가 문자열로 변환됨 주의

## 요약: 변수의 핵심 개념과 사용법
| 항목 | 내용 |
|------|------|
| 변수 정의 | 값을 저장할 수 있는 메모리 위치에 붙인 이름 |
| 변수 선언 | 타입과 이름을 정하는 과정 (<mark>int age;</mark>) |
| 변수 초기화 | 변수에 처음 값을 저장 (<mark>int score = 90;</mark>) |
| 변수 이름 규칙 | 문자 또는 $, _로 시작, 예약어 사용 불가, 대소문자 구분 |
| 변수 사용 | 저장된 값을 읽거나 변경, 출력문과 연산식에서 활용 |
| 변수 범위 | 선언된 블록 내에서만 사용 가능, 메소드 내부 변수는 로컬 변수 |
| 값 교환 | 임시 변수를 사용하여 두 변수의 값을 서로 바꿈 |

변수는 메모리 내 데이터를 이름으로 관리하며, 선언과 초기화를 통해 타입에 맞는 값을 저장한다. 변수의 범위는 선언된 블록 내로 제한되며, 변수 간 연산과 출력에 활용된다. 변수의 값 교환 시 임시 변수를 활용하여 데이터 손실 없이 값을 바꾼다.
