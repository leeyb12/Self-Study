## 핵심 개념

- 변수는 값을 저장하는 메모리 공간을 코드에서 식별하는 이름입니다.
- 선언은 타입과 이름을 정하고 초기화는 처음 값을 저장하는 과정입니다.
- 지역 변수는 선언된 블록 안에서만 사용할 수 있으며 사용 전에 초기화해야 합니다.
- 정수 타입은 크기마다 표현 범위가 다르고, 범위를 벗어난 값은 저장할 수 없습니다.
