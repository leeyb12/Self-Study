## 기본 타입과 변수 선언
"변수 타입에 따라 변수에 저장되는 값의 종류와 허용 범위가 달라진다."
- 자바는 기본 타입으로 총 8개를 제공한다. 
  - 정수 타입 5종: <mark>byte</mark>, <mark>short</mark>, <mark>char</mark>, <mark>int</mark>, <mark>long</mark>
  - 실수 타입 2종: <mark>float</mark>, <mark>double</mark>
  - 논리 타입 1종: <mark>boolean</mark>
- 타입별 허용 범위는 메모리 크기에 따라 결정된다. 
- 변수 선언 시 타입에 맞는 값을 저장해야 하며, 허용 범위를 벗어나면 컴파일 오류가 발생한다.

## 메모리와 데이터 저장 구조
- 메모리는 0과 1로 구성된 저장소이며, 1비트(bit)는 0 또는 1을 나타낸다. 
- 8비트 = 1바이트(byte), 4바이트 = 32비트
- 각 기본 타입은 사용하는 바이트 수가 다르며, 이에 따라 저장 가능한 값의 범위가 다름

| 타입  | 메모리 크기(바이트) | 허용 범위 (10진수) | 비고 | 
|-------|---------------------|--------------------|------|
| byte | 1 | -128 ~ 127 | 8비트, 최상위 비트는 부호 |
| short | 2 | -32,768 ~ 32,767 | 16비트 |
| char | 2 | 0 ~ 65,535 | 유니코드 문자 저장용 (음수 없음) |
| int | 4 | -2,147,483,648 ~ 2,147,483,647 | 32비트 |
| long | 8 | 매우 큰 범위 | 64비트 |

- **부호 있는 정수**는 최상위 비트로 양/음 구분 (0: 양수, 1: 음수)
- <mark>char</mark>는 음수가 아니며, 유니코드 숫자값만 저장

## 정수 타입 상세
- byte 타입
  - 1바이트(8비트)
  - 허용 범위: -128부터 127까지
  - 최상위 비트 1개는 부호 비트로 사용
  - 하드웨어 제어나 메모리 절약 목적으로 사용
- short 타입
  - 2바이트(16비트)
