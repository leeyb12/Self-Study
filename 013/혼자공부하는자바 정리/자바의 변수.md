## 변수의 개념과 역할
"변수는 값을 저장할 수 있는 메모리의 특정 번지에 붙여진 이름이다."
- 컴퓨터 메모리는 수많은 번지(주소)로 구성되어 있음.
- 데이터를 저장할 메모리 위치를 이름으로 지정하지 않으면 프로그래밍이 어려움
- 변수는 메모리 번지에 붙인 이름으로, 데이터를 저장하거나 읽을 때 사용
- 변수 한 개는 하나의 값을 저장함 (예: 변수 x에 정수 10 저장)
- 변수는 다양한 데이터 타입(정수, 실수 등)을 저장할 수 있음

## 변수 선언과 초기화
"변수 선언은 변수 이름과 저장할 데이터 타입을 결정하는 과정이다."
- 변수 선언 시, 어떤 타입의 데이터를 저장할지 지정 필요
- 예시: <mark>int age;</mark> (정수형 변수 age 선언), <mark>float value;</mark>
