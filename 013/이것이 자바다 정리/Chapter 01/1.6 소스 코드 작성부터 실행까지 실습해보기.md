## 자바 프로젝트 폴더 구조 및 파일 생성
> "폴더 구조를 체계적으로 구성하면 소스 코드 관리, 컴파일 결과 관리 및 실행이 용이해진다."
- 템프(temp) 폴더: 사용자 홈 디렉토리 내에 생성하는 임시 작업 폴더
- src 폴더: 소스 코드(.java 파일)를 저장하는 디렉토리 (source의 약자)
- bin 폴더: 컴파일된 바이트코드(.class 파일)를 저장하는 디렉토리 (binary의 약자)
- 하위 폴더는 프로젝트 단위로 구성하며, 예) <mark>chapter01/section06</mark>
- 하위 폴더는 **패키지 디렉토리(package directory)**로 불리며, 패키지 선언과 일치해야 함

| 폴더명 | 역할 | 비고 |
|--------|------|------|
| temp | 작업용 임시 폴더 | 사용자 홈 아래 생성 |
| src | 소스 파일 저장 | <mark>.java</mark> 파일 저장 |
| bin | 컴파일 결과 저장 | <mark>.class</mark> 바이트코드 파일 저장 |
| chapter01/section06 | 패키지 구조 반영 폴더 | 패키지 선언과 경로 일치 필요 |

## 자바 소스 파일 작성 및 저장
- 확장자 <mark>.java</mark>를 반드시 붙여야 하며, 예: <mark>Hello.java</mark>
- 대소문자 구분 엄격, 클래스명과 파일명은 일치해야 함
- 메모장 등 간단한 텍스트 편집기로 작성 가능하나, VS Code 같은 코드 에디터 사용 권장
  - 코드 에디터는 키워드별 색상 구분, 편리한 코드 작성 지원
- 파일 확장자 표시 설정 필요 (윈도우 탐색기: 보기 -> 파일 확장명 체크)

### 자바 소스 파일 기본 코드 구조 예
```java
package chapter01.section06;

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}
```
- package 선언: 소스 파일이 속한 패키지(폴더) 경로를 명시
- 클래스 선언: <mark>public class Hello</mark>
- main 메서드: 자바 프로그램의 시작점이며, <mark>public static void main(String[] args)</mark>로 작성
- 출력문: <mark>System.out.println("출력할 문자열")</mark>

## 컴파일과 바이트코드 생성
- 컴파일 명령어: <mark>javac -d bin src/chapter01/section06/Hello.java</mark>
  - <mark>-d bin</mark>: 컴파일 결과를 <mark>bin</mark> 폴더에 저장
  - 소스 파일 경로는 실제 저장된 경로를 <mark>/</mark>로 구분하여 지정
- 컴파일 성공 시 에러 메시지 없이 조용히 종료
- 컴파일 실패 시 에러 메시지 출력 -> 내용 확인 후 수정, 저장 후 재컴파일

| 단계 | 명령어 예시 | 설명 |
|------|-------------|------|
| 컴파일 | <mark>javac -d bin src/chapter01/section06/Hello.java</mark> | 소스 파일을 바이트코드로 변환, bin 폴더에 저장 |
| 결과 확인 | 탐색기에서 <mark>bin/chapter01/section06/Hello.class</mark> 확인 | 컴파일된 <mark>.class</mark> 파일 생성 확인 |

## 자바 프로그램 실행
- 실행 명령어: <mark>java -cp bin chapter01.section06.Hello</mark>
  - <mark>-cp bin</mark>: 클래스패스(classpath) 지정, 바이트코드 위치가 <mark>bin</mark> 폴더임을 알림
  - <mark>chapter01.section06.Hello</mark>: 실행할 클래스 이름, 패키지 경로를 <mark>.</mark>(점)으로 구분하여 작성
- 실행 시 출력 결과: <mark>Hello Java</mark>
- 주의: 실행할 때는 <mark>.class</mark> 확장자 없이 클래스의 전체 이름(패키지 포함)을 사용

| 단계 | 명령어 예시 | 설명 |
|------|-------------|------|
| 실행 | <mark>java -cp bin chapter01.section06.Hello</mark> | 컴파일된 클래스 실행 |

## 패키지와 디렉토리 구조 연결 이해
- 소스 파일은 <mark>src</mark> 폴더 내 패키지 구조와 일치하는 폴더에 위치해야 함
- 컴파일 시 <mark>-d</mark> 옵션으로 컴파일 결과가 저장되는 <mark>bin</mark> 폴더 내에도 동일한 패키지 구조가 생성됨
- 패키지 이름과 폴더 이름은 완전히 일치해야 하며, 자바는 대소문자를 구분함
- 실행 시에는 패키지 경로를 점(<mark>.</mark>)으로 구분하여 전체 클래스 이름으로 지정

| 구분 | 소스 파일 경로 (파일 시스템) | 실행 시 클래시 이름 (패키지명 포함) | 
|------|------------------------------|-------------------------------------|
| 예: Hello.java | <mark>src/chapter01/section06/Hello.java</mark> |<mark>chapter01.section06.Hello</mark> | 

## 주의사항 및 팁
| 주의사항 및 팁 | 설명 |
|----------------|------|
| 파일명과 클래스명은 반드시 일치해야 한다 | 예: 클래스 <mark>Hello</mark> -> 파일명 <mark>Hello.java</mark> | 
| 대소문자를 정확히 맞춰 작성해야 함 | <mark>System</mark>, <mark>String</mark>, <mark>main</mark> 등은 대소문자 구분 |
| 파일 확장자 <mark>.java</mark>를 꼭 붙여야 함 | 확장자 누락 시 컴파일 불가 |
| 컴파일 후 바이트코드 위치 정확히 확인 | <mark>bin</mark> 폴더 내 패키지 구조대로 생성되는지 확인 |
| 실행 시 패키지 경로를 점(<mark>.</mark>)으로 구분하여 정확히 입력 | 잘못 입력하면 클래스 못 찾는 오류 발생 |
| 메모장 대신 VS Code 같은 에디터 사용 권장 | 키워드 하이라이트, 자동 완성, 디버깅 등 편리 기능 지원|

자바 소스 파일의 작성부터 컴파일, 실행까지의 전 과정을 폴더 구조와 명령어 사용법에 맞춰 체계적으로 관리해야만 오류를 줄이고 효율적인 개발 환경을 만들 수 있다. 패키지 이름과 폴더 구조를 일치시키는 것은 자바 컴파일러와 실행 환경이 코드를 올바르게 인식하는 데 필수적이며, 컴파일 시 <mark>-d</mark> 옵션을 활용해 바이트코드 저장 위치를 지정하면 관리가 편리해진다. 실행 시에는 클래스패스 지정과 패키지명을 정확히 입력해야 하며, 이를 통해 자바 프로그램이 원하는 대로 실행되고 출력 결과를 얻을 수 있다.
