## 이클립스(Eclipse) 설치 및 실행 방법
> "이클립스는 자바 개발에 널리 사용되는 오픈 소스 통합 개발 환경(IDE)으로, 무료로 사용 가능하며 생산성 향상에 도움을 준다."

## 1. 통합 개발 환경(IDE)의 중요성
- IDE: 통합 개발 환경(Integrated Development Environment)
- 자바 프로그램 개발 시 편리한 기능 제공으로 생산성 향상
- 기업에서 주로 사용하는 IDE: 이클립스(Eclipse), 인텔리제이(IntelliJ)
  - 이클립스: 오픈 소스, 무료
  - 인텔리제이: 학생은 무료, 현업은 유료

## 2. 이클립스 다운로드 방법
| 단계 | 설명 |
|------|------| 
| 1 | 브라우저를 열고 이클립스 공식 사이트 접속 |
| 2 | 우측 상단의 다운로드(Download) 버튼 클릭 |
| 3 | 최신 버전(예: 2022년 06월 버전) 설치 파일 다운로드 | 
| 4 | 운영체제별 맞는 설치 파일 선택(윈도우, macOS, Linux) | 
| 5 | 설치 버전과 압축 버전 선택 가능 | 
| 6 | 압축 버전 다운로드 시, 아래쪽 "다운로드 패키지(Download Packages)" 링크 클릭 |

- macOS의 경우 인텔 칩용(x86_64)과 M1 칩용 별도 제공
- 윈도우 압축 파일은 <mark>.zip</mark> 확장자, macOS는 <mark>.dmg</mark> 확장자

## 3. 이클립스 압축 파일 설치 (윈도우 기준)
- 다운로드한 압축 파일을 적절한 위치(예: <mark>Program Files</mark>)에 압축 해제
  - 관리자 권한 필요할 수 있음, 권한 요청 시 승인
- 압축 해제 후 <mark>eclipse.exe</mark> 실행 파일 더블 클릭하여 실행
- 실행 편의를 위해 바로가기 만들기 권장
  - 바탕화면 또는 작업 표시줄에 바로가기 복사 가능

## 4. macOS에서 이클립스 설치
- <mark>.dmg</mark> 파일 더블 클릭 후, 이클립스 아이콘을 <mark>Applications</mark> 폴더로 드래그 앤 드롭
- 설치 완료 후 런치패드에서 이클립스 아이콘 실행
- 최초 실행 시 보안 경고 창에서 열기(Open) 선택 필요
- 인텔 칩용과 M1 칩용 별도 설치 파일 구분에 유의

## 5. 이클립스 실행 시 워크스페이스(Workspace) 설정
- 워크스페이스: 프로젝트가 저장되는 작업 공간 디렉토리
- 윈도우 예시 경로: <mark>C:\this is Java second edition\workspace</mark>
- macOs 예시 경로: <mark>/Users/사용자계정/this is Java second edition/workspace</mark>
- 실행 시 워크스페이스 경로 지정 후 런치(Launch) 버튼 클릭
- "다시 묻지 않기" 체크박스는 처음에는 체크하지 말 것 (향후 편리하게 설정 가능)
- 실행 후 웰컴 탭은 닫아도 무방

## 6. 윈도우용과 macOS 이클립스 사용법 차이점
| 구분 | 윈도우용 | macOS용 |
|------|----------|---------|
| 설치 파일 | <mark>.zip</mark> 압축 파일 | <mark>.dmg</mark> 설치 파일 |
| 설치 방법 | 압축 해제 후 <mark>eclipse.exe</mark> 실행 | <mark>.dmg</mark> 더블 클릭 후 드래그 앤 드롭 | 
| 워크스페이스 경로 | <mark>C:\this is Java second edition\workspace</mark> | /Users/사용자계정/this is Java second edition/workspace |

- 두 OS 모두 이클립스 실행 및 사용법은 동일 

이클립스 설치 절차는 운영체제별 파일 형식과 설치 방법의 차이가 있으나, 기본적으로 공식 사이트에서 최신 버전의 설치 파일을 받아 워크스페이스 경로를 지정하여 실행한다. 워크스페이스 설정은 프로젝트 관리의 핵심이며, 관리자 권한과 칩셋 별 설치 파일 구분에 주의해야 한다. 윈도우와 macOS 모두 비슷한 방식으로 실행되므로 두 환경에서 유사한 개발 환경을 구축할 수 있다.
