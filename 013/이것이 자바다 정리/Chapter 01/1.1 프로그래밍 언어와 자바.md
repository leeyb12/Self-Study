## 1. 프로그래밍 언어 분류 및 역할
- 기계어 (Machine Language)
  - 0과 1로 구성된 이진 코드
  - 컴퓨터가 직접 이해하지만 사람에게 매우 어려움
- 프로그래밍 언어 (Programming Language)
  - 사람과 컴퓨터 사이의 다리 역할
  - 사람이 이해하기 쉬운 형태의 언어를 고급 언어(High-level language)라 함
  - 고급 언어는 컴파일러를 통해 기계어로 변환되어 실행됨
- 어셈블리어 (Assembly Language)
  - 기계어에 가까우나 알파벳과 숫자로 구성
  - 사람이 이해하기 어려움

| 구분 | 특징 | 예시 |
|------|------|------|
| 기계어 | 0과 1로 구성, 컴퓨터 직접 이해 | 없음 |
| 어셈블리어 | 기계어에 가까움, 알파벳과 숫자 사용 | 어셈블리어 |
| 고급 언어 | 사람에게 친숙, 컴파일 과정 필요 | 자바, C, C++, 파이썬 |

## 2. 자바의 컴파일 및 실행 과정
- 자바 컴파일 과정 특징
  1. 소스 파일(.java) 작성 -> **바이트코드 파일(.class)** 생성 (기계어가 아님)
  2. 자바 가상 머신 (JVM)이 바이트코드를 해석하여 실행
    - 이 과정 덕분에 자바는 운영체제에 독립적인 실행이 가능
- 타 언어와의 비교

| 언어 | 컴파일러 동작 방식 | 실행 파일 유형 | 실행 방식 |
|------|--------------------|----------------|-----------|
| C/C++ | 소스 -> 컴파일러 -> 기계어 파일 | 기계어 파일 | 운영체제에서 직접 실행 |
| 자바 | 소스 -> 컴파일러 -> 바이트코드 | 바이트코드 파일 | JVM이 해석하여 실행 |
| 파이썬 | 소스 -> 인터프리터가 한 줄씩 해석 실행 | 기계어 파일 없음 | 인터프리터가 소스 직접 실행 |

## 3. 자바 언어 개요 및 특징
- 개발 역사
  - 1995년 선 마이크로시스템즈에서 발표
  - 현재 오라클(Oracle)에서 라이선스 및 개발 도구 제공
- 자바 활용 분야
  - 안드로이드 앱 개발 (코틀린과 함께 사용)
  - 웹 애플리케이션 개발 (주요 언어 중 하나)
  - 데스크톱 애플리케이션 (주로 C++가 속도 때문에 선호됨)
  - 운영체제 독립적인 애플리케이션 개발 가능
- 자바 주요 특징

| 특징 | 설명 |
|------|------|
| 운영체제 독립성 | 한 번 컴파일된 바이트코드로 윈도우, 맥, 리눅스 등 다양한 OS에서 실행 가능 |
| 객체 지향 프로그래밍 | 완전한 객체 지향 언어로 코드 재사용성과 유지 보수성 향상 |
| 자동 메모리 관리 | 개발자가 직접 메모리를 관리할 필요 없이 JVM이 가비지 컬렉션 등 자동 처리 | 
| 풍부한 무료 라이브러리 | 다양한 기능이 오픈소스로 제공되어 개발 기간 단축과 편의성 제공 |

## 4. 자바 개발 환경 구축 및 기본 흐름
- JDK 설치
  - Windows, Mac 등 운영체제별 설치 방법 존재
  - 환경 변수 설정으로 자바 명령어 쉽게 실행 가능
- 기본 작업 흐름
  1. 텍스트 에디터 또는 이클립스(Eclipse) IDE에서 소스 코드 작성
  2. 컴파일러(javac)로 소스 파일을 바이트코드(.class)로 변환
  3. JVM(java 명령어)로 바이트코드 실행
- 이클립스 IDE 활용
  - 코드 작성과 실행을 통합된 환경에서 편리하게 수행
  - 초보자에게 적합한 개발 도구

## 5. 프로그래밍 언어 용어 및 문법 기본
- 코드 용어 이해 
  - 소스 파일: 프로그래밍 언어로 작성된 코드 파일
  - 실행문: 프로그램 내에서 실행되는 명령문
  - 세미콜론(;): 실행문 구분자, 한 문장이 끝남을 표시
- 코드 주석 처리
  - 코드 내 설명을 위해 사용
  - 실행에 영향을 미치지 않음

## 6. 비유를 통한 이해: 자바의 바이트코드와 JVM
- 비유 
  - 바이트코드는 **영어 원서**와 같고, JVM은 이 영어 원서를 상황에 맞게 해석해 주는 **통역사**와 같다. 
  - 그래서 같은 영어 원서를 가지고도 어느 나라(운영체제)에서든 해석하여 이해할 수 있다. 

### 자바 시작하기 핵심 정리
- 자바는 **운영체제 독립적인 고급 프로그래밍 언어**로, 소스 코드를 한 번 작성 후 어디서든 실행 가능하다.
- 바이트코드와 자바 가상 머신(JVM)을 통해 다양한 플랫폼에서 동일한 실행 결과를 보장한다.
- 객체 지향 프로그래밍 특징과 자동 메모리 관리, 풍부한 라이브러리로 개발 효율성을 높인다. 
- JDK 설치, 환경 변수 설정, 이클립스 IDE 활용을 통해 자바 개발 환경을 구축한다. 
- 컴파일 과정과 실행 과정의 차이를 이해하는 것이 중요하며, 기본 프로그래밍 언어 용어와 문법에 익숙해져야 한다.
