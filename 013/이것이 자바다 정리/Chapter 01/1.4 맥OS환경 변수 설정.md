# macOS에서 JDK 환경변수 설정하기
macOS에 JDK가 설치되면 기본적으로 JDK 경로가 지정되어 있어 별도의 환경변수 설정 없이 사용할 수 있다. 다만 여러 버전의 JDK가 설치되어 있을 경우 어떤 버전을 사용할지 명시적으로 설정해야 한다.

## 1. JDK 설치 위치 확인
- Finder에서 Macintosh HD > Library > Java > JavaVirtualMachines 경로로 이동
- 이 폴더 내에 설치된 JDK 버전들이 각각 폴더 형태로 존재
- 단일 JDK 버전이 설치된 경우 별도의 환경변수 설정이 필요 없음

## 2. JDK 버전 확인 명령어
- 터미널에서 다음 명령어로 현재 사용 중인 JDK 버전 확인 가능
- 예: <mark>java version "17.0.x"</mark>와 같이 출력되면 해당 버전을 사용 중임

## 3. 환경변수 설정이 필요한 경우
- JDK 폴더 내에 여러 버전이 공존할 때
- 특정 JDK 버전을 고정해서 사용하고 싶을 때

## 4. 환경변수 설정 절차

| 단계 | 설명 |
|------|------|
| 1 | 사용자 홈 디렉토리에서 숨김 파일 <mark>.zshrc</mark> 또는 <mark>.bash_profile</mark> 확인 및 생성 |
| 2 | 텍스트 편집기로 <mark>.zshrc</mark>  (또는 <mark>.bash_profile</mark>) 열기 |
| 3 | 다음과 같이 <mark>JAVA_HOME</mark>과 <mark>PATH</mark> 환경변수 설정 추가 | 
| 4 | 설정 파일 저장 후 터미널에서 <mark>source ~/.zshrc</mark> 명령어로 적용 또는 재부팅 | 

## 5. <mark>.zshrc</mark> 파일 예시
```shell
export JAVA_HOME = /Library/Java/JavaVirtualMachines/jdk-17.jdk/Contents/Home
export PATH = $JAVA_HOME/bin:$PATH
```
- <mark>JAVA_HOME</mark>에 원하는 JDK 경로를 지정
- <mark>PATH</mark>에 <mark>$JAVA_HOME/bin</mark>을 추가하여 JDK 명령어를 우선 사용하도록 설정

## 6. 숨김 파일 보기 및 편집 팁
- Finder에서 홈 폴더 내 숨김 파일은 기본적으로 보이지 않음
- <mark>Command + Shift + .</mark> 키를 눌러 숨김 파일을 표시 가능
- <mark>.zshrc</mark> 또는 <mark>.bash_profile</mark> 파일이 없으면 새로 생성하여 설정 추가

## 7. 설정 적용 방법
- 터미널에서 source ~/.zshrc 명령어를 실행하면 현재 터미널 세션에 설정 적용
- 또는 macOS 재부팅 시 자동 적용

## 8. 요약: 환경변수 설정 필요 여부 판단 기준
| 설치된 JDK 버전 수 | 환경변수 설정 필요성 |
|--------------------|----------------------|
| 1개 | 필요 없음 (기본 JDK 자동 사용) |
| 2개 이상 | 원하는 JDK 버전을 명확히 지정하기 위해 필요 |
