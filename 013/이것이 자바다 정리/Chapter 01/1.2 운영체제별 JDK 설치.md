## JDK 설치와 종류 이해하기
> "자바 SE의 구현체인 JDK를 설치해야 자바 프로그램을 개발하고 실행할 수 있다."
- JDK (Java Development Kit): 자바 SE(스탠다드 에디션, Java Standard Edition) 스펙을 구현한 개발 도구와 라이브러리 모음
- 자바 SE는 자바 언어의 표준 사양 (Specification)을 의미 
- JDK 설치는 자바 개발 및 실행의 필수 조건

### JDK의 주요 종류
| 구분 | 오픈 JDK | 오라클 JDK | 
|------|----------|------------|
| 라이선스 | GNU 라이선스 (오픈소스) | 오라클 별도 라이선스 |
| 사용료 | 무료 | 개발/학습용 무료, 상업용 유료 |
| 개발 소스 공개 의무 | 없음 | 없음 |
| 성능 차이 | 거의 없음, 점차 안정화 중 | 약간 더 안정적, 미묘한 성능 우위 |
| 사용 권장 | 상업용 비용 부담 시 추천 | 상업용 프로젝트 시 비용 발생 가능 |

- 개발/학습 목적일 경우 둘 다 사용 가능
- 상업용 프로젝트는 오픈 JDK 사용 추천 (비용 절감 목적)
- 오라클 JDK는 오픈 JDK 기반으로 만들어져 성능 차는 미미함

## JDK 다운로드 및 LTS 버전 선택
> "LTS(Long-Term Support) 버전은 장기간 버그 픽스와 기술 지원을 받을 수 있는 안정적인 버전이다."
- JDK 다운로드 사이트 
  - 오픈 JDK: 여러 사이트(예: Eclipse Adoptium)
  - 오라클 JDK: 오라클 공식 사이트
- LTS 버전 권장 이유
  - 장기간 버그 픽스, 보안 업데이트 제공
  - 안정적인 개발 환경 보장
- 현재 주요 LTS 버전: JDK 8, 11, 17 (가장 널리 사용)
- 최신 LTS 예정: JDK 21 (2023년 9월 예정)
- 비LTS 버전은 테스트 용도 적합, 실제 프로젝트에는 적합하지 않음

## 운영체제별 JDK 설치 방법와 아키텍처
| 운영체제 | 아키텍처 종류 | 설치 파일 유형 | 특징 및 유의점 |
| Windows | x64 (인텔 CPU 기반) | MSI(설치형), ZIP(압축 해제 후 사용) | MSI는 더블클릭 설치, ZIP은 압축해제 후 바로 사용 가능 |
| macOS (인텔 CPU) | x64 | PKG 설치 파일 | 인텔 기반 맥북은 x64 버전 설치 |
| macOS (애플 M 칩) | ARM64 (aarch64) | PKG 설치 파일 | 최신 맥북은 ARM64 버전 설치 필수 | 

- 아키텍처 선택 중요: CPU 종류에 맞는 버전 다운로드 필수
- WIndows MSI 설치 시 기본 경로는 <mark>C:\Program Files\Java\jdk<버전></mark>
- macOS 설치는 사용자 인증 필요, 설치 경로는 <mark>/Library/Java/JavaVirtualMachines/jdk<버전>.jdk</mark>

## macOS에서 오픈 JDK 17 설치 절차
1. Eclipse Adoptium 사이트에서 macOS용 JDK 17 설치 파일 다운로드 (x64 또는 ARM64 선택)
2. 다운로드한 PKG 파일 더블클릭 실행
3. 설치 위치: <mark>/Library/Java/JavaVirtualMachines/jdk-17.jdk</mark>
4. 설치 과정 중 라이선스 동의 및 관리자 암호 입력 필수
5. 설치 완료 후 터미널에서 <mark>java-version</mark> 명령어로 설치 확인

- Intel 기반 맥북은 x64, Apple M 칩 (ARM64) 기반 맥북은 ARM64 아키텍처 선택 필수

## 환경변수 설정 및 설치 경로 
| 환경 변수 | 용도 | 설정 시점 및 방법 |
|-----------|------|-------------------|
| PATH | 자바 실행 명령어(<mark>java</mark>, <mark>javac</mark>) 인식 | 설치 시 자동 추가 권장, 수동 추가 가능 |
| JAVA_HOME | JDK 설치 경로를 가리키는 변수 | 수동 설정 필요 (특히 빌드 도구 사용 시 중요) | 

- Windows 설치 시 PATH 추가 옵션 기본 활성화 권장
- JAVA_HOME은 보통 <mark>C:\Program Files\Java\jdk-17.0.x</mark> 또는 <mark>/Library/Java/JavaVirtualMachines/jdk-17.jdk/Contents/Home</mark>
- 환경변수 설정 후 터미널/명령 프롬프트 재시작 필요

### 요약
자바 개발을 위해서는 자바 SE 스펙을 구현한 JDK 설치가 필수이며, 오픈 JDK와 오라클 JDK 중 목적에 맞게 선택할 수 있다. 상업용 프로젝트에서는 비용과 라이선스 문제로 오픈 JDK가 권장된다. 안정성과 장기 지원을 위해 LTS 버전(JDK 8, 11, 17)을 사용하며, 최신 LTS인 JDK 17을 학습용으로 권장한다. 운영체제와 CPU 아키텍처에 맞는 설치 파일을 다운로드하여 설치하고, 환경변수(PATH, JAVA_HOME)를 적절히 설정해야 자바 개발 환경이 정상적으로 구축된다. Windows는 MSI 설치 파일, macOS는 PKG 설치 파일을 사용하며, 설치 경로와 환경변수 설정이 개발 도구와 연동에 중요하다.
