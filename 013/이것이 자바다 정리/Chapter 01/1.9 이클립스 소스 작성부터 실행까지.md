## Eclipse에서 자바 소스 코드 작성 및 실행
> "Eclipse에서는 소스 파일 저장 시 자동으로 컴파일되어 바이트코드 파일이 생성되며, 실행 버튼 또는 Run As 메뉴를 통해 프로그램을 바로 실행할 수 있다."

### 1. Package Explorer 뷰와 패키지 생성
- Package Explorer: 프로젝트 내 폴더 및 파일을 탐색하는 뷰
- <mark>src</mark> 폴더 선택 후 우클릭 -> New -> Package 선택
- 패키지 이름 입력 예
  - <mark>chapter01.section09</mark>
  - <mark>chapter01.section11</mark>
- 마침(Finish) 클릭 시 패키지 생성 완료
- 패키지 이름의 점(.)은 하위 패키지 구분자 (예: <mark>chapter01</mark>이 상위 패키지, <mark>section09</mark>가 하위 패키지)

### 2. 패키지 계층 구조 보기 설정
- 기본적으로 패키지가 flat(평면) 스타일로 보임
- 상위 패키지와 하위 패키지를 계층적으로 보고 싶을 경우
  - Package Explorer 우측 상단 뷰 메뉴 클릭
  - <mark>Package Presentation</mark> → <mark>Hierarchical</mark>로 변경
- 결과: <mark>chapter01</mark> 아래 <mark>section09</mark>, <mark>section11</mark> 하위 패키지로 표시

### 3. 소스 파일(클래스) 생성
- 생성된 패키지(예: <mark>section09</mark>) 선택 → 우클릭 → New → Class 선택
- 클래스 이름 입력 (예: <mark>Hello</mark>) — 반드시 첫 글자 대문자
- <mark>public static void main(String[] args)</mark> 메인 메서드 추가 옵션 체크
- Finish 클릭하면 기본 템플릿 포함된 소스 파일 생성
- 생성 후 소스 코드 편집 가능

### 4. 소스 코드 작성 및 수정
- 기본 생성된 코드 삭제 후 아래 예시 코드 입력
```java
System.out.println("Hello, Java");
```
- 수정한 파일 탭 제목에 <mark>*</mark> 표시: 저장하지 않은 변경 있음 의미
- 저장 필수 (Ctrl + S 또는 메뉴에서 저장)

### 5. 자동 컴파일과 바이트코드 파일 생성
- Eclipse는 별도 컴파일 명령 없이 저장 시 자동 컴파일 수행
- 저장하면 <mark>.class</mark> 확장자의 바이트코드 파일이 생성됨
- 자동 컴파일 덕분에 편리하게 개발 가능

### 6. 프로그램 실행 방법
| 실행 방법 | 설명 |
|-----------|------|
| 툴바의 실행 버튼 클릭 | 현재 열려 있는 자바 소스 파일을 컴파일 후 실행 |
| Package Explorer에서 우클릭 -> Run As -> Java Application 선택 | 현재 선택한 자바 소스 파일의 바이트코드 실행 | 

- 두 방법 모두 동일한 실행 결과를 낳음
- 실행 결과는 Eclipse 하단의 Console 뷰에 출력됨

### 7. 바이트코드 파일 위치 확인 
- 프로젝트 폴더 구조
| 폴더명 | 설명 |
|--------|------|
| <mark>src</mark> | 자바 소스 파일(.java)이 위치하는 폴더 |
| <mark>bin</mark> | 컴파일된 바이트코드 파일(.class)이 위치하는 폴더 |

- <mark>bin</mark> 폴더는 Package Explorer에서 기본적으로 숨김 처리됨
- 실제 파일 탐색기(Windows Explorer 등)에서 직접 확인 가능
- 예: <mark>bin/chapter01/section09/Hello.class</mark> 위치에 바이트코드 존재

### 8. 폰트 크기 조절 방법
- 메뉴: Window -> Preferences -> General -> Appearance -> Colors and Fonts -> Basic -> Text Font 선택
- Edit 버튼 클릭 후 원하는 폰트 크기로 변경
- Apply and Close 클릭하여 변경 사항 적용

Eclipse는 패키지와 소스 파일을 직관적으로 생성하고 관리할 수 있도록 하며, 저장 시 자동으로 자바 컴파일러(javac)를 실행해 바이트코드를 생성한다. 이 바이트코드는 <mark>bin</mark>  폴더에 저장되어, 실행 버튼이나 Run As 메뉴를 통해 즉시 실행 가능하다. 패키지 탐색기에서 계층적 구조로 패키지를 확인하며, 폰트 설정을 통해 코드 편집 환경을 사용자화할 수 있다. 이러한 절차와 기능은 개발 효율성 향상과 오류 방지에 중대한 역할을 한다.
