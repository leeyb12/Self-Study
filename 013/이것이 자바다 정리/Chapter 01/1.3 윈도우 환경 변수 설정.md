## JDK 설치 후 환경변수 설정의 중요성
> "환경변수는 운영체제가 관리하는 데이터로, 프로그램들이 필요할 때 이 데이터를 참조하여 실행에 필요한 정보를 얻는다."
- JDK 설치 후 가장 먼저 해야 할 작업은 **환경변수 설정**이다. 
- 환경변수는 운영체제에서 프로그램 실행 시 참조하는 정보 저장소 역할을 한다.
- JDK 관련 주요 환경변수는 JAVA_HOME과 PATH이다. 
| 환경 변수 | 역할 및 의미 |
|-----------|--------------|
| JAVA_HOME (자바 홈) | JDK가 설치된 위치(디렉토리 경로)를 저장하는 변수 |
| PATH (패스) | JDK 내 개발 도구(예: java.exe, javac.exe)가 위치한 경로를 포함 |

## Windows에서 환경변수 설정 방법
- Windows 검색창에 "시스템 환경 변수 편집"을 입력하여 시스템 속성 창 실행
- 시스템 속성 창 -> 오른쪽 하단의 **환경변수** 버튼 클릭 -> 환경변수 창 실행
- JAVA_HOME **변수 생성 과정**
  1. 시스템 변수 영역에서 **새로 만들기** 클릭
  2. 변수 이름에 JAVA_HOME 입력 (관례적으로 대문자 사용)
  3. 변수 값에 JDK가 설치된 경로 지정 (예: <mark>C:\Program Files\Java\jdk-17</mark>)
- PATH **변수 편집 과정**
  1. 시스템 변수 영역에서 PATH 변수 선택 후 **편집** 클릭
  2. 새 항목 추가 -> <mark>JAVA_HOME</mark> 하위 <mark>bin</mark> 폴더 경로 추가 (예: <mark>%JAVA_HOME%\bin</mark>)
  3. 만약 JDK를 압축 파일로 설치했다면 자동 추가가 안 되므로 수동으로 추가해야 함.
  4. 경로는 가장 위쪽에 위치시키는 것이 우선순위 확보에 중요
- 경로 추가 시 <mark>%JAVA_HOME%\bin</mark> 형태로 변수 참조를 사용하는 것이 유지보수에 유리함

## 환경변수 변경 시 주의점과 권장사항
- 환경변수 수정 후 기존 명령 프롬프트(CMD) 창은 변경 사항을 인식하지 못하므로 반드시 새로 열어 테스트해야 한다. 
- 여러 JDK 버전을 사용할 경우, **JAVA_HOME 변수만 변경**하면 되므로 편리하다.
  - PATH 변수는 <mark>%JAVA_HOME%\bin</mark>으로 참조하므로 별도 수정 불필요
- 경로는 항상 상단에 위치시켜 우선권을 확보해야 한다. 

## 환경변수 설정 정상 확인 방법
- 명령 프롬프트(CMD) 또는 PowerShell 실행 후 다음 명령어로 확인
| 명령어 | 기능 및 설명 |
|--------|--------------|
| <mark>java -version</mark> | 현재 설정된 자바 버전 확인 |
| <mark>javac -version</mark> | JDK 컴파일러 버전 확인 |

- 정상 출력 예시: <mark>openjdk version "17.0.x"</mark> 형태로 설치된 JDK 버전이 표시됨
- 만약 다른 버전이 나오거나 오류가 발생하면 환경변수 설정이 잘못된 것임

## 환경변수 설정의 기술적 의미
- 운영체제는 명령어 실행 시 PATH 환경변수에 등록된 경로에서 실행파일을 탐색함
- <mark>javac</mark> 등 JDK 제공 도구들이 포함된 경로가 PATH에 포함되어야 자바 명령어를 어디서든 실행 가능
- JAVA_HOME 환경변수는 JDK 설치 경로를 대표하는 변수로, 여러 설정에서 참조 가능하여 관리 편의성 증대

| 환경변수 이름 | 변수 값 예시 | 설명 | 
|---------------|--------------|------|
| JAVA_HOME | <mark>C:\Program Files\Java\jdk-17</mark> | JDK 설치 경로를 지정 |
| PATH | <mark>%JAVA_HOME%\bin</mark> | JDK 실행 도구 경로를 포함 (우선순위 상단 위치 권장) |

## 비유: 환경변수의 역할
- 환경변수는 **프로그램 실행 시 필요한 주소록**과 같음
- JAVA_HOME은 JDK라는 회사의 본사 위치를 가리키고 PATH는 그 회사 내 각 부서(개발 도구)가 어디에 위치하는지 알려줌
- 주소록이 정확해야 원하는 부서에 바로 연락할 수 있듯, 환경변수가 정확해야 명령어가 제대로 실행됨

## 요약 및 핵심
- JDK 설치 후 JAVA_HOME과 PATH 환경변수를 반드시 설정해야 정상적인 개발 환경 구성이 가능하다. 
- 환경변수 설정 시 경로를 정확히 지정하고, PATH 내 위치는 우선순위를 고려햐 상단 배치해야 한다. 
- 환경변수 수정 후에는 반드시 새로운 명령 프롬프트 창을 열어 변경 사항을 반영해야 한다. 
- JAVA_HOME 변수 사용으로 JDK 버전 변경 시 편리하게 관리할 수 있다. 

환경변수는 프로그램 실행에 필요한 필수 정보를 운영체제에 제공하며, 정확한 설정은 개발 도구가 정상 작동하는 기반이 된다. JDK 설치 경로를 JAVA_HOME에 지정하고 PATH에 이를 연동함으로써 다양한 자바 실행 및 컴파일 도구가 원활히 호출되며, 환경변수 우선순위 조정은 실행파일 충돌 방지와 일관된 버전 관리를 가능하게 한다.
