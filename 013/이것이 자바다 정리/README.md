## 핵심 개념

- JDK는 Java 개발 도구 모음이며 JRE와 컴파일러 같은 도구를 포함합니다.
- JVM은 운영체제에 맞게 바이트코드를 실행해 Java의 플랫폼 독립성을 지원합니다.
- LTS 버전은 장기간 지원되는 배포판으로 학습 및 운영 환경에서 안정적인 기준이 됩니다.
- `JAVA_HOME`은 JDK 설치 위치를, `Path`는 명령어를 검색할 경로를 알려 줍니다.
