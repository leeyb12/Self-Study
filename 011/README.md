# 011 - LLM / AI 애플리케이션

LLM을 활용한 실전 AI 애플리케이션 개발 학습 내용을 Jupyter Notebook으로 정리하는 폴더입니다.

## 폴더 구조

```text
011/
└─ LLM을 활용한 실전 AI 애플리케이션 개발/
   ├─ 02장/
   │  └─ chapter_2_transformer_with_code.ipynb
   └─ 03장/
      └─ chapter_3.ipynb
```

## 학습 내용

| 위치 | 내용 |
| --- | --- |
| `02장/chapter_2_transformer_with_code.ipynb` | Transformer 구조와 코드 실습 |
| `03장/chapter_3.ipynb` | LLM 기반 AI 애플리케이션 개발 실습 |

## 실행 방법

```powershell
cd "011\LLM을 활용한 실전 AI 애플리케이션 개발"
jupyter notebook
```

## 정리 기준

- 장별 폴더 안에 Notebook을 보관합니다.
- 모델 구조, 입력/출력 흐름, 실습 결과를 Markdown 셀로 함께 정리합니다.
- 외부 API key나 토큰이 필요한 실습은 코드에 직접 저장하지 않고 환경 변수로 분리합니다.
