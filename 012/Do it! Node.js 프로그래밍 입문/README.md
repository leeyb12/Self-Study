# Do it! Node.js 프로그래밍 입문

Node.js 기본 문법과 서버 개발 입문 예제를 정리하는 교재 폴더입니다.

## 폴더 구조

```text
Do it! Node.js 프로그래밍 입문/
└─ basics/
   └─ 01/
      └─ hello.js
```

## 학습 내용

| 폴더 | 내용 |
| --- | --- |
| `basics/01/` | `hello.js` 함수 선언과 콘솔 출력 예제 |

## 첫 예제에서 확인할 개념

- 함수 선언은 동작을 이름으로 묶어 재사용할 수 있게 합니다.
- `console.log()`는 표준 출력으로 값을 전달해 실행 결과를 확인합니다.
- `node hello.js` 명령은 Node.js 런타임이 파일을 읽고 최상위 코드를 실행하도록 합니다.

## 실행 방법

```powershell
cd "012\Do it! Node.js 프로그래밍 입문\basics\01"
node hello.js
```
