# 012 - Node.js 교재 실습

`Do it! Node.js 프로그래밍 입문` 교재의 Node.js 예제를 정리하는 폴더입니다.

## 폴더 구조

```text
012/
└─ Do it! Node.js 프로그래밍 입문/
   └─ basics/
      └─ 01/
         └─ hello.js
```

## 학습 내용

| 위치 | 내용 |
| --- | --- |
| `basics/01/hello.js` | 함수 선언과 문자열 출력으로 확인하는 Node.js 첫 실행 예제 |

## 실행 방법

```powershell
cd "012\Do it! Node.js 프로그래밍 입문\basics\01"
node hello.js
```

## 정리 기준

- 기본 문법 예제는 `basics/` 아래에 장 또는 절 번호로 구분합니다.
- Node.js 실행 예제는 실행 명령을 함께 기록합니다.
- 서버, 라우팅, 파일 처리처럼 주제가 커지면 별도 하위 폴더로 분리합니다.
