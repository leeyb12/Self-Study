## 구성

| 폴더/파일 | 내용 |
| --- | --- |
| `01-2/`, `01-3/` | Python 시작과 출력 예제 |
| `02-1/` | 문자열 연산 예제 |
| `02-3/` | 숫자형, 입력, 형 변환 예제 |

| `img/`, `image*.png` | 노트에 사용한 이미지 |

## 실행
