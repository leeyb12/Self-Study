# 002 - 혼공 시리즈

혼자 공부하는 시리즈 교재 기반의 예제 코드, 노트, 이미지 자료를 정리한 폴더입니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `혼공파이썬/` | Python 기초 문법 예제와 단어 정리 |
| `혼공첫프With파이썬/` | 처음 프로그래밍을 배우는 Python 예제 |
| `혼공데With파이썬/` | Python 데이터 분석 학습 자료 |
| `혼공머신러닝+딥러닝/` | 머신러닝/딥러닝 Jupyter Notebook과 이미지 노트 |
| `혼공자바스크립트/` | JavaScript 문법 예제와 개념 노트 |

## 학습 범위

- Python 기본 문법, 자료형, 문자열, 숫자 처리
- JavaScript 기본 문법과 브라우저 예제
- 데이터 분석과 머신러닝 기초
- Jupyter Notebook 기반 실습
- `wordnote.md`와 이미지 파일을 활용한 개념/단어 정리

## 실행 방법

Python 파일은 `python` 명령으로 실행하고, HTML 파일은 브라우저에서 열어 확인합니다. Notebook 파일은 Jupyter 환경에서 실행합니다.
