# 혼공첫프With파이썬

처음 프로그래밍을 배우는 관점에서 Python 기본 예제를 정리한 폴더입니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `ch01/` | Hello World와 시작 예제 |
| `ch02/` | 진법, 실수, 기본 수 처리 예제 |

## 핵심 개념

- 프로그램은 작성한 명령을 위에서 아래로 실행하며, 출력은 현재 상태를 확인하는 가장 기본적인 방법입니다.
- 2진수는 컴퓨터가 데이터를 표현하는 기반이고, 10진수와의 변환을 통해 값 표현 방식을 이해할 수 있습니다.
- 부동소수점은 실수를 근삿값으로 저장하므로 일부 계산에서 작은 오차가 발생할 수 있습니다.

## 실행

```powershell
python "ch01\hello-world.py"
```
