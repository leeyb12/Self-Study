# 혼공머신러닝+딥러닝

머신러닝과 딥러닝 기초 실습을 Jupyter Notebook과 이미지 노트로 정리한 폴더입니다.

## 구성

| 파일/폴더 | 내용 |
| --- | --- |
| `1-3.ipynb`, `2-*.ipynb`, `3-*.ipynb` | 장별 머신러닝 실습 Notebook |
| `wordnote.md` | 용어와 개념 정리 |
| `image*.png`, `image/` | 노트에 사용한 이미지 자료 |

## 핵심 개념

- 특성은 모델의 입력이고 타깃은 예측하려는 정답입니다.
- 훈련 세트는 모델을 학습시키고 테스트 세트는 보지 못한 데이터에 대한 성능을 평가합니다.
- 과대적합과 과소적합을 구분하려면 훈련 점수와 검증 점수를 함께 비교해야 합니다.
- 전처리 기준은 훈련 데이터에서 학습한 뒤 검증·테스트 데이터에 동일하게 적용합니다.

## 실행

Jupyter 환경에서 Notebook 파일을 열어 셀 단위로 실행합니다.

```powershell
jupyter notebook
```
