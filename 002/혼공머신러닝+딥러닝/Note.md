## 1강 인공지능과 머신러닝, 딥러닝
### 인공지능과 머신러닝 개요
- 인공지능(AI)은 컴퓨터가 인간처럼 사고, 학습, 문제 해결을 하는 기술을 의미
- 머신러닝은 AI의 하위 분야로, 컴퓨터가 데이터에서 패턴을 학습하여 자동으로 작업 수행 능력을 개선하는 알고리즘 집합
- 최근 10~20년 사이 머신러닝이 AI 분야에서 큰 비중을 차지하며 거의 동의어처럼 사용됨

### 인공지능의 역사와 발전 단계
| 시기 | 주요 사건 및 특징 |
|------|-------------------|
| 1940 ~ 50년대 | - MCP 뉴런 모델(1943, 월터 피츠, 워런 맥컬러)<br> - 튜링 테스트 제안(1950)<br> - 인공지능 용어 최초 등장(1956, 다트머스 AI 컨퍼런스) |
| 1957년 | 퍼셉트론 알고리즘 발표 (프랑크 로젠블라트) | 
| 1959년 | 시각 피질 연구 (데이비드 허블, 토르스텐 비젤) |
| 1974 ~ 80년대 | 첫 번째 AI 겨울 (기대감 감소, 투자 축소) |
| 1980년대 | 전문가 시스템 붐, 일시적 AI 부흥 |
| 2차 AI 겨울 | 전문가 시스템 한계와 실용성 의문 제기로 인한 관심 저하 |
| 1990년대 후반 | 인공신경망 재부흥 (루멜하트 박사) |
| 2012년 | 알렉스넷(AlexNet) 딥러닝으로 이미 지넷 대회 우승 |
| 2015년 | 텐서플로(TensorFlow) 공개 |
| 2016년 | 알파고(AlphaGo) 한국에서 딥러닝 기반 바둑 AI 대성공 | 

- AI 겨울: 기대감이 과대했던 시기에 기술적 한계로 인해 관심과 투자가 급격히 감소한 시기
- 전문가 시스템: 특정 분야의 규칙 기반 문제 해결 시스템, 한계로 인해 2차 AI 겨울 촉발

### 강인공지능(AGI)과 약인공지능(ANI) 구분
| 구분 | 설명 | 사례 및 특징 |
|------|------|--------------|
| 강인공지능 | 사람과 동등한 인지 능력을 가진 AI, 자율 학습 및 인간과 교감 가능 | 영화 속 AI(터미네이터, Her) 수준 현재는 실현되지 않음 |
| 약인공지능 | 특정 작업에 특화된 AI, 제한된 영역에서 인간을 돕고 편리하게 함 | 자율주행 자동차, 음성 비서(시리, 빅스비 등) | 

- 현재 대부분 AI 시스템은 약인공지능에 해당
- 강인공지능은 아직 요원하지만, LLM(대규모 언어 모델)과 같은 최근 기술이 강인공지능으로 가는 길을 밝히고 있음

### 머신러닝과 딥러닝
| 구분 | 설명 | 주요 라이브러리 및 알고리즘 | 
|------|------|-----------------------------|
| 머신러닝 | 컴퓨터가 데이터에서 패턴을 학습하여 특정 작업을 자동화하는 알고리즘 집합 | 사이킷런(scikit-learn): 선형 회귀, 로지스틱 회귀, 결정 트리, 랜덤 포레스트 등 |
| 딥러닝 | 인공신경망(ANN)을 기반으로 한 머신러닝 하위 분야, 여러 층(layer)을 통해 복잡한 데이터 표현 학습 | 텐서플로(TensorFlow), 파이토치(PyTorch), 케라스(Keras) |

- 인공신경망은 본래 머신러닝 알고리즘 중 하나였으나, 복잡한 문제 해결 능력이 뛰어나 딥러닝으로 확장됨
- 딥러닝은 여러 층을 쌓아 깊게 학습하는 방식이며, 이를 통해 복잡한 특징을 추출 가능
- 케라스는 텐서플로와 파이토치를 감싸는 고수준 API로, 사용 편의성 제공

### 인공신경망의 주요 구조
| 구조명 | 설명 | 특징 및 역할 |
|--------|------|--------------|
| 합성곱 신경망(CNN) | 이미지 및 공간 데이터 처리에 특화된 신경망 구조 | 이미지 분류, 객체 인식 등에 활용 |
| 순환 신경망(RNN) | 시퀀스(연속 데이터) 처리에 적합한 구조 | 자연어 처리, 음성 인식 등에 활용 | 
| 트랜스포머 | 병렬 처리 기반의 시퀀스 모델, 대규모 언어 모델(LLM) 개발에 핵심 구조 | BERT, GPT 등 LLM에 사용 |

- 트랜스포머는 대규모 데이터 처리에 매우 효율적이며, 최근 AI 분야에서 혁신을 주도하고 있음

### 머신러닝 학습 환경과 자료
- 저자는 머신러닝과 딥러닝 관련 다수의 책 저술 및 번역 경험 보유
- 최신 코드와 라이브러리 업데이트는 저자 블로그에서 확인 가능 (광고성 메일 없음)
- GitHub에 공개된 예제 코드를 통해 실습 가능
- 구글 코랩(Google Colab)을 활용한 학습 환경 설정 방법 강의 예정
- 강의 슬라이드에는 저자가 직접 손으로 그린 그림 사용, 책에는 전문 작가가 재구성한 그림 수록

### 요약 - 핵심 개념 및 연결
- 인공지능은 다양한 하위 분야를 포함하며, 머신러닝은 그 중 데이터 기반 학습 자동화에 초점
- 인공지능 역사는 기술적 성취와 기대감, 그리고 AI 겨울을 반복하며 발전
- 현재 대부분 AI는 특정 문제 해결에 최적화된 약인공지능이며, 강인공지능은 연구 및 개발 단계
- 딥러닝은 인공신경망을 여러 층으로 확장해 복잡한 문제에 강력한 성능 발휘
- 트랜스포머 구조는 최근 AI 발전의 핵심으로, 특히 대규모 언어 모델(LLM)에서 중심적 역할
- 학습 자료와 환경은 저자 블로그, GitHub, 구글 코랩을 통해 지속적으로 업데이트 및 제공

인공지능은 다양한 학문과 기술이 융합된 복잡한 체계로, 역사적 도전과 혁신을 거쳐 지금의 딥러닝 중심 패러다임에 도달했으며, 이 과정에서 구조적 발전과 도구 개발이 AI의 적용 가능성과 성능을 획기적으로 확장했다.

## 2강 코랩과 주피터 노트북
### 구글 코랩(Google Colab)과 주피터 노트북(Jupyter Notebook) 사용법
> "구글 코랩은 클라우드 기반 주피터 노트북 환경으로, 로컬 환경 설치 없이 동일한 환경에서 편리하게 머신러닝 실습을 할 수 있다."

#### 1. 구글 코랩과 주피터 노트북 개념 및 차이점
| 구분 | 구글 코랩 (Colab) | 주피터 노트북 (Jupyter Notebook) | 
|------|-------------------|----------------------------------|
| 환경 | 구글 클라우드 서버에서 실행 | 로컬 컴퓨터에서 직접 실행 |
| 설치 여부 | 별도 설치 필요 없음, 웹 브라우저만 있으면 사용 가능 | 로컬에 설치 필요 (Python, Jupyter 등) | 
| 실행 주체 | 구글 클라우드 컴퓨팅 인스턴스에서 코드 실행 | 사용자의 PC CPU/GPU에서 코드 실행 |
| GPU 지원 | 구글에서 무료로 P4 GPU 제공 | 로컬 PC에 GPU 장착 시에만 가능 |
| 환경 통일성 | 모든 사용자가 동일한 환경에서 작업 가능 | 환경(운영체제, 파이썬 버전 등)마다 다름 |
| 문제 발생 시 지원 | 동일 환경이므로 문제 재현 및 해결 쉬움 | 환경 차이로 인한 문제 해결 어려움 | 

#### 2. 코랩 사용 기본 흐름 
- 구글 계정으로 로그인 후 [colab.research.google.com](https://colab.research.google.com) 접속
- 기존 작업 노트북 열기 또는 새 노트북 생성
- 코드 셀 생성 및 파이썬 코드 작성 가능
- 코드 실행은 로컬이 아닌 구글 클라우드 서버에서 이루어짐
- 실행 결과만 사용자 브라우저에 출력됨

#### 3. 코랩 런타임 연결과 자원 할당
- 코드를 실행하려면 구글 클라우드 컴퓨팅 인스턴스(런타임)와 연결 필요
- 연결 버튼 클릭 시 무료 컴퓨팅 자원(예: CPU, RAM, GPU)을 할당받음
- 할당받은 런타임 사양 예시
  - Python 3 버전
  - RAM 약 12GB
  - 디스크 용량 약 100GB
- 일정 시간 사용하지 않거나 명시적으로 연결 해제하면 인스턴스 반환
- 반환 후에는 변수, 메모리 상태 모두 초기화됨

#### 4. 코드 셀 단위 실행 구조
- 주피터 노트북과 코랩 모두 코드 셀 단위로 실행됨
- 셀에 여러 줄 또는 한 줄의 파이썬 코드를 작성 가능
- 실행 순서에 따라 변수 상태가 변함
- 런타임 연결 해제 후 재연결 시 이전 변수 상태는 모두 사라짐
- 따라서 재실행 시에는 처음부터 순서대로 셀을 실행해야 함

#### 5. 저장과 파일 관리
- 작성한 노트북 파일(.ipynb) 및 실행 결과(출력 포함)는 구글 드라이브에 저장 가능
- 코드 + 실행 결과가 함께 저장되어 재실행 없이도 결과 확인 가능
- GitHub 저장소에 예제 노트북을 올려놓아 바로 코랩에서 열어 실행할 수 있음
- GitHub 링크에서 "Open in Colab" 클릭 시 자동으로 구글 런타임에 연결되어 실행 가능

#### 6. 오류 발생 시 대응 방법
- 오류 발생 시 가장 먼저 할 일
  1. GitHub 저장소에서 동일 예제 노트북 다운로드 또는 열기
  2. 해당 노트북을 코랩에서 실행해 동일 오류 발생 여부 확인
  3. 본인이 작성한 코드와 비교하여 차이점 확인
- 환경 문제나 라이브러리 버전 차이로 인한 문제를 줄일 수 있음
- 최신 버전 예제는 GitHub에 업데이트되므로 항상 최신 노트를 활용하는 것이 좋음

#### 7. 에라타(Errata) 페이지 활용
- 출간된 책이나 온라인 자료에 대한 오류 및 수정 사항을 모아서 제공하는 페이지
- 라이브러리 버전 변경에 따른 코드 수정 사항도 포함됨
- 학습 중 혼동을 줄이고 최신 내용을 반영하기 위해 주기적으로 확인 권장
- 저자의 공식 블로그 또는 책 관련 웹사이트에서 확인 가능

## 3강 마켓과 머신러닝 | k-최근접 이웃 알고리즘
### 머신러닝과 마켓 예제 이해
- 머신러닝 프로그램은 사람이 규칙을 직접 작성하지 않고, 데이터를 통해 스스로 규칙을 학습하는 프로그램이다. 
- 전통적 프로그래밍은 사람이 명확한 규칙(명세)을 먼저 정하고 코드를 작성하지만, 머신러닝은 많은 샘플 데이터를 제공하여 규칙을 찾아내게 한다. 
- 책에서 소개한 가상의 "한빛 마켓"은 생선 판매 쇼핑몰이며, 생선 종류 구분 문제를 머신러닝으로 해결하는 시나리오이다. 

### 생선 데이터와 분류 문제
- 도미와 빙어 두 종류 생선 데이터를 예로 든다. 
- 각 생선 샘플은 두 가지 특성(Feature)을 가진다. **길이(length)**와 무게(weight).
- 이 문제는 두 클래스(도미, 빙어)를 구분하는 이진 분류(binary classification) 문제이다. 
- 분류 문제는 대상 객체를 여러 카테고리(클래스)로 나누는 작업이며, 이진 분류는 두 개의 클래스만 구분하는 경우이다. 

### 데이터 시각화: 산점도(Scatter Plot)
- 각 생선 샘플의 길이와 무게를 2차원 좌표상에 점으로 표시하는 그래프를 산점도라고 한다.
- 파이썬의 Matplotlib 라이브러리의 <mark>scatter</mark> 함수를 사용하여 산점도를 그린다. 
- 도미는 길이와 무게가 큰 쪽에, 빙어는 작고 가벼운 쪽에 분포되어 있어 시각적으로 쉽게 구분 가능하다. 
- 산점도를 통해 데이터의 분포와 특성을 직관적으로 이해할 수 있다. 

| 용어 | 설명 | 
|------|------|
| 산점도 | 두 개의 특성을 가진 데이터를 2차원 점으로 표현한 그래프 |
| Matplotlib(멧플롯립) | 파이썬에서 널리 사용하는 시각화 라이브러리 | 

### 데이터 준비: 리스트와 리스트 묶음
- 도미와 빙어의 길이, 무게를 각각 별도의 리스트로 저장한다. 
- 머신러닝 라이브러리인 scikit-learn(사이킷런)은 각 샘플을 여러 특성의 리스트(벡터)로 묶어서 입력받는다.
- 파이썬의 <mark>zip</mark> 함수를 이용해 길이와 무게를 묶어 <mark>[[길이1, 무게1], [길이2, 무게2],...]</mark> 형식의 리스트로 변환한다. 
- 샘플 데이터 개수: 도미 35개, 빙어 14개.

### 타겟 데이터(Target)와 이진 레이블링
- 타겟은 각 샘플이 어떤 클래스인지 알려주는 정답 데이터이다. 
- 도미를 1, 빙어를 0으로 레이블링하여 이진 분류 문제에 맞게 만든다. 
- 파이썬 리스트 곱셈 연산으로 쉽게 반복된 값의 리스트를 생성 가능하다.
- 타겟 값은 머신러닝 모델 학습 시 정답 역할을 한다. 

| 클래스 | 타겟 값 |
|--------|---------|
| 도미 | 1 |
| 빙어 | 0 |

### 머신러닝 모델: K-최근접 이웃 (K-Nearest Neighbors, KNN)
- 사이킷런 라이브러리의 <mark>KNeighborsClassifier</mark> 클래스를 사용하여 KNN 분류 모델을 만든다. 
- KNN은 새로운 샘플의 클래스를 주변에 가장 가까운 K개의 샘플을 참조해 다수결로 결정한다.
- 기본 K값은 5이며, 주변 샘플 5개 중 다수 클래스가 예측 결과가 된다.
- KNN은 훈련 시 단순히 데이터를 저장하며, 실제 예측은 근접 이웃 탐색으로 이루어진다.

| 과정 | 설명 |
|------|------|
| 모델 생성 | <mark>KNeighborsClassifier()</mark> 객체 생성 |
| 훈련(Fit) | <mark>fit(X_train, y_train)</mark> 메서드로 데이터 학습 |
| 예측(Predict) | <mark>predict(X_test)</mark> 메서드로 새로운 샘플 분류 |

### 모델 평가: 정확도(Accuracy)와 스코어 메서드
- 훈련된 모델에 다시 훈련 데이터(X_train, y_train)를 넣어 평가할 수 있다. 
- <mark>score</mark> 메서드는 정확도(accuracy)를 반환하여, 1.0은 완벽한 분류를 의미한다.
- 예제에서는 100% 정확도를 보여주었으나, 이는 훈련 데이터에 한정된 결과이다.
- K값을 크게 변경하면(예: 49개 모두 참조) 정확도가 떨어질 수 있다. 이는 주변 이웃의 클래스 비율에 좌우된다.

| K값 | 정확도 (score) | 설명 |
|-----|----------------|------|
| 5 | 1.0 | 기본값, 완벽한 분류 |
| 49 | 약 0.717 | 모든 샘플 참조, 다수 클래스 쏠림 발생 |

### KNN 예측 과정 이해
- 새로운 생선 샘플(예: 길이 30cm, 무게 600g)을 입력하면 KNN 모델이 주변 5개 샘플을 찾아 가장 많은 클래스에 따라 예측한다.
- 예측 결과는 1(도미)이며, 산점도에서 주변에 도미 샘플이 많아 자연스러운 결과이다.
- KNN은 직관적으로 이해하기 쉬운 알고리즘으로, 주변 샘플의 분포가 예측 성능에 큰 영향을 미친다.

# Ch02. 데이터 다루기
## 4강 훈련 세트와 테스트 세트
### 머신러닝의 훈련 세트와 테스트 세트 분할
> "훈련 세트와 테스트 세트를 나누는 이유는 모델이 학습한 데이터뿐 아니라 새로운 데이터에 대해서도 잘 예측할 수 있는지 평가하기 위함이다."

#### 1. K-최근접 이웃(K-Nearest Neighbors, KNN) 알고리즘 복습
- KNN은 새로운 샘플 주변에 있는 K개의 훈련 샘플 중 다수 클래스에 속하는 클래스로 예측
- 훈련 데이터 전체를 저장하며, 예측 시 가장 가까운 이웃을 찾는 방식
- 예시: 도미 35마리, 빙어 14마리를 모두 맞춤 (k=5 사용)
- 훈련 데이터에 있는 샘플을 평가하면 100% 정확도가 나옴 -> 훈련 데이터로 평가하면 과적합(overfitting)이 발생할 수 있음

#### 2. 훈련 세트와 테스트 세트의 필요성
- 훈련 데이터로 모델을 학습한 후, 같은 데이터로 평가하면 100% 정확도를 얻는 것이 당연함
- 실제 상황에서는 학습하지 않은 새로운 데이터(시험 문제)로 평가해야 모델의 진짜 성능을 알 수 있음
- 따라서 데이터를 훈련 세트와 테스트 세트로 나누어야 함
- 테스트 세트는 모델 학습에 사용하지 않고, 학습 후 성능을 평가하는 용도

#### 3. 머신러닝의 세 가지 학습 유형
| 학습 유형 | 설명 | 예시 |
|-----------|------|------|
| 지도 학습 (Supervised Learning) | 입력과 정답(타겟)이 모두 주어져 학습함 | KNN, 선형 회귀, 의사결정나무 |
| 비지도 학습 (Unsupervised Learning) | 정답 없이 데이터의 구조나 패턴을 찾는 학습 | 군집화, 차원 축소 |
| 강화 학습 (Reinforcement Learning) | 환경과 상호작용하며 보상을 최대화하는 방향으로 학습 | 알파고, 로봇 제어 |

- 본 강의에서는 주로 지도 학습과 비지도 학습을 다룸
- 강화 학습은 복잡하여 별도의 전문 도서를 권장

#### 4. 훈련 세트와 테스트 세트 구성 예시
- 데이터: 생선 49마리 (도미 35마리, 빙어 14마리)
- 입력 특성: 길이, 무게 (2차원 입력 데이터)
- 타겟 값: 도미(1), 빙어(0)
- 데이터 분할 예시
  - 훈련 세트: 앞 35개 샘플 (도미만)
  - 테스트 세트: 뒤 14개 샘플 (빙어만)
- 문제점: 훈련 세트에 도미만 있어 빙어 예측 불가능 -> 테스트 결과 0% 정확도

#### 5. 데이터 분할 시 주의사항: 샘플링 편향 (Sampling Bias)
| 문제 상황 | 결과 |
|-----------|------|
| 훈련 세트에 한 클래스만 포함 | 모델이 다른 클래스 예측 불가능, 성능 저하 |
| 테스트 세트에 다른 클래스만 포함 | 평가 시 모든 예측 실패 |
| 적절히 섞이지 않은 데이터 분할 | 모델 성능 평가 불공정, 신뢰도 하락 |

- 데이터는 클래스별로 골고루 섞여야 함
- 그래야 훈련 시 다양한 클래스 샘플을 학습하고, 테스트 시 다양한 클래스 예측 가능

#### 6. 넘파이(Numpy)를 이용한 데이터 분할 및 셔플링
- 넘파이: 파이썬의 고성능 다차원 배열 처리 라이브러리
- 리스트와 달리 배열 내 데이터 타입이 동일해야 함 (숫자, 문자열 등 혼합 불가)
- 배열 차원 예시
  - 1차원 배열: 단일 축 (예: 타겟 리스트)
  - 2차원 배열: 행(샘플 수)과 열(특성 수) (예: 입력 특성 배열)
  - 3차원 배열: 깊이(예: 이미지 데이터)

#### 7. 데이터 섞기(Shuffling) 방법
| 방법 | 설명 | 
|------|------|
| 전체 배열 셔플링 | 입력과 타겟 배열을 동일하게 섞어야 함 (복잡성 및 메모리 부담) |
| 인덱스 배열 셔플링 | 0부터 N-1까지 인덱스 배열을 무작위로 섞고, 이 인덱스로 입력/타겟 선택 |

- 인덱스 배열 생성: <mark>np.arange(49)</mark> -> 0부터 48까지 정수 배열 생성
- 인덱스 배열 섞기: <mark>np.random.shuffle(index_array)</mark>
- 섞인 인덱스 배열을 이용해 훈련 세트와 테스트 세트 분할
  - 예: 처음 35개 인덱스 -> 훈련 세트, 나머지 14개 인덱스 -> 테스트 세트
- 입력과 타겟 데이터 모두 인덱스로 선택해 일관성 유지 (입력과 타겟이 엇갈리지 않도록)

#### 8. 넘파이 배열 인덱싱과 슬라이싱
| 구분 | 예시 및 설명 |
|------|--------------|
| 슬라이싱 | <mark>array[0:35]</mark> -> 0번부터 34번까지 선택 |
| 전체 선택 | <mark>array[:]</mark> 또는 <mark>array[0:]</mark> -> 모든 행 선택 |
| 2차원 배열 행/열 지정 | <mark>array[:, 0]</mark> -> 모든 행의 0번째 열 선택 (길이) |
| 인덱스 배열 지정 | <mark>array[[1, 3, 5]]</mark> -> 1, 3, 5번째 행 선택 |

- 2차원 배열은 행과 열을 콤마로 구분해 지정함
- 인덱스 배열로 특정 샘플을 쉽게 선택 가능

#### 9. 데이터 시각화와 검증
- 훈련 세트와 테스트 세트가 잘 섞였는지 산점도로 확인
- 색깔 분리(예: 푸른색: 훈련 세트, 주황색: 테스트 세트)
- 두 세트 모두 도미와 빙어가 적절히 분포하는지 확인 가능

#### 10. 최종 모델 훈련 및 평가
- 섞인 훈련 세트로 KNN 모델 재훈련
- 테스트 세트로 평가 시 100% 정확도 달성 (도미와 빙어 모두 잘 분류)
- 올바른 데이터 분할과 섞기가 모델 성능 평가에 필수임을 확인

#### 11. 정리: 훈련 세트와 테스트 세트 분할의 중요성
- 훈련 데이터와 테스트 데이터는 분리되어야 하며, 테스트는 모델 평가 전용
- 데이터는 클래스별로 균등하게 섞어야 편향 없는 학습과 평가 가능
- 넘파이 배열과 인덱스 셔플링 기법은 효율적이고 안정적으로 데이터 분할을 수행함
- 올바른 분할과 평가로 모델의 일반화 능력을 객관적으로 측정할 수 있음

### KNN 모델과 데이터 분할의 상호작용
K-최근접 이웃 알고리즘은 주변 샘플의 클래스를 참조하기 때문에, 훈련 세트와 테스트 세트가 섞이지 않고 한쪽에만 특정 클래스가 몰리면 테스트 시 모든 이웃이 같은 클래스가 되어 예측이 잘못된다. 따라서 훈련 및 테스트 세트 내에 다양한 클래스가 골고루 분포해야 KNN의 거리 기반 특성이 제대로 발휘되어 정확한 예측이 가능하다. 넘파이의 인덱스 배열 셔플링 기법은 데이터 전체를 섞지 않고도 효율적으로 훈련용과 평가용 데이터를 무작위로 분배함으로써, 샘플링 편향 문제를 해결하고 모델의 진정한 성능을 평가할 수 있게 한다. 이 과정은 데이터 특성에 맞는 올바른 샘플링과 평가가 모델의 일반화 능력을 담보한다는 점에서 머신러닝 실무의 핵심 절차임을 보여 준다.

## 5강 데이터 전처리
### 데이터 전처리와 K-최근접 이웃(KNN) 문제 사례
- 25cm 길이에 150g 무게인 생선 데이터를 KNN 모델에 넣었더니 직관과 달리 도미가 아닌 빙어로 예측하는 문제 발생
- 문제 원인은 두 특성(길이, 무게)의 스케일 차이 때문
  - 길이: 10~40 범위
  - 무게: 0~1 범위 내 작은 값
- KNN 알고리즘은 거리 기반으로 예측 -> 거리 계산 시 스케일 차이가 크면 큰 값에 영향력 집중 -> 왜곡된 이웃 선택 발생 

### 넘파이 배열 결합: column_stack과 concatenate
| 함수명 | 동작 방식 | 결과 형태 | 용도 및 특징 |
|--------|-----------|-----------|--------------|
| <mark>np.column_stack</mark> | 1차원 배열 두 개를 열 방향으로 나란히 붙임 | 2차원 배열 (행, 열) | 입력 데이터를 2차원 배열로 묶어 머신러닝 입력 형태에 맞춤 |
| <mark>np.concatenate</mark> | 1차원 배열 두 개를 단순 연결 | 1차원 배열 | 여러 1차원 배열을 연결해 하나의 긴 벡터로 만듦 | 

- <mark>column_stack</mark>은 각 리스트가 하나의 열이 되어 2차원 배열 생성
- <mark>concatenate</mark>는 배열을 단순 이어 붙임

### 훈련세트와 테스트세트 분할: train_test_split 함수
- <mark>train_test_split</mark> 함수는 여러 배열을 함께 섞어 훈련/테스트 세트로 분리
- <mark>random_state</mark> 매개변수로 무작위 섞기 시드 고정 가능 -> 반복 실행 시 같은 결과 보장 (예: 42) 
- <mark>stratify</mark> 매개변수에 타깃 레이블 배열을 넣으면, 원본 데이터의 클래스 비율을 유지하며 분할
  - 예) 도미:빙어 = 2:1 비율 -> 훈련/테스트 세트 모두 이 비율 유지
- 클래스 비율이 매우 불균형할 때 <mark>stratify</mark> 사용 권장

### K-최근접 이웃(KNN) 알고리즘과 주변 이웃 선택
- KNN은 예측 시 주변 샘플 다섯 개(기본값)의 거리와 인덱스를 반환 가능
- 문제 생선(25cm, 150g)의 주변 샘플을 보면 빙어가 4개, 도미가 1개로 다수인 빙어로 분류됨
- 거리 계산에서 특성별 스케일 차이로 인해 멀리 떨어진 빙어가 가까운 샘플로 잘못 선택됨

### 특성 스케일 문제와 해결: 표준화(Standardization)
- 특성별 범위가 달라 거리 계산에 치우침 발생 -> 모든 특성 값들의 스케일을 맞춰야 함
- 표준화: 각 특성에서 평균을 빼고 표준편차로 나누어 **표준 점수(z-score)**로 변환
  - 공식: $z = \frac{x - \mu}{\sigma}$
- 결과: 평균 0, 표준편차 1인 분포로 변환 -> 두 특성 값의 범위가 비슷해짐
- 넘파이 <mark>mean()</mark>과 <mark>std()</mark> 함수에 <mark>axis=0</mark> 지정 시 각 열별(특성별) 평균과 표준편차 계산 가능
- 브로드캐스팅 기능으로 2차원 배열 각 행에 평균과 표준편차 연산을 자동 적용 가능(반복문 불필요)
- 특성 스케일이 동일해지면 KNN 거리 계산이 왜곡 없이 정상 동작

### 표준화 적용 후 결과 확인
- 훈련 데이터와 테스트 데이터 모두 훈련 데이터의 평균과 표준편차를 이용해 표준화 진행
  - 새 데이터(문제 생선)도 훈련 데이터 기준으로 변환해야 함
- 변환 후 산점도에서 문제 생선 주변에 도미 샘플들이 적절히 선택됨
- KNN 모델 재학습 시 100% 정확도 달성
- KNN, 선형회귀, 로지스틱 회귀, 인공신경망 등 거리나 특성 스케일에 민감한 알고리즘에서는 반드시 전처리 필요
- 트리 기반 알고리즘(랜덤 포레스트, 결정 트리 등)은 스케일 영향 받지 않음 -> 5장에서 상세 설명 예정

### 데이터 전처리 요약

| 문제점 | 해결책 | 적용 효과 |
|--------|--------|-----------|
| 특성별 스케일 차이로 거리 왜곡 | 표준화(평균 제거 + 표준편차 나누기) | 거리 계산 공정성 확보 -> 정확한 이웃 선택 |
| 테스트/새로운 데이터 변환 미적용 | 훈련 데이터 평균, 표준편차 이용 변환 | 일관성 있는 입력 데이터 분포 유지 |
| 무작위 분할 시 클래스 불균형 가능 | <mark>stratify</mark> 옵션 사용 분할 | 훈련/테스트 세트 클래스 비율 유지 |

### 추가 설명: 브로드캐스팅 개념
- 브로드캐스팅은 넘파이 배열 간 크기가 다를 때 자동으로 작은 배열을 큰 배열 크기에 맞게 확장하여 연산하는 기능
- 예) (2차원 배열) - (1차원 배열) 연산 시 1차원 배열이 행마다 자동으로 반복 적용

### 중요 개념 정리
- KNN은 거리를 기준으로 이웃 판단 -> 특성 스케일 일치 필수
- 훈련 데이터 기준으로 전처리 기준(평균, 표준편차) 산출 -> 테스트/새 데이터에도 동일 적용
- <mark>train_test_split</mark> 활용해 편리하게 데이터 분할 가능, <mark>random_state</mark>, <mark>stratify</mark> 활용으로 재현성 및 클래스 비율 유지 가능
- 데이터 전처리 과정은 모델 성능과 신뢰성에 직접적인 영향 -> 반드시 숙지하고 활용해야 함
 
전처리는 특성 간 스케일 차이가 거리 기반 판단에 미치는 왜곡을 제거하며, 훈련 데이터의 통계치를 기준으로 변환함으로써 모델 입력의 일관성을 유지한다. 이 과정은 K-최근접 이웃과 같이 거리 개념이 핵심인 알고리즘에서 필수적이며, 테스트 세트 및 새 데이터에도 동일한 변환 기준을 적용함으로써 예측의 정확성과 신뢰성이 보장된다. 데이터 분할 시에는 클래스 비율을 유지하는 stratify 옵션과 재현성을 위한 random_state 설정이 모델 평가의 객관성을 높인다.

# Ch03. 회귀 알고리즘과 모델 규제
## 6강 k-최근접 이웃 회귀
### 회귀(Regression)의 개념과 배경
> "회귀란 임의의 실수값을 예측하는 문제이며, 분류와 달리 타깃이 정수 레이블이 아닌 연속적인 실수값이다."
- 회귀 정의
  - 임의의 실수값(예: 농어의 무게) 예측 문제
  - 분류(classification)는 클래스 레이블을 예측(0, 1, 2 등 정수)
  - 회귀는 클래스가 아닌 연속적인 실수값을 예측
- 용어의 유래
  - 19세기 통계학자 프랜시스 골턴(Francis Galton)이 키의 유전적 회귀 연구에서 처음 사용
  - '회귀' 용어는 두 변수 사이 상관관계 분석에 사용
  - 영어로는 "regression"
- 용어 혼동 주의
  - "로지스틱 회귀(logistic regression)"는 분류 알고리즘이며, 회귀(임의 실수 예측)와 다름
  - 회귀라는 단어에 너무 얽매이지 않고 "임의 실수 예측 문제"로 이해 권장

### 농어 무게 예측 문제 사례
- 농어 데이터에 대해 다음 3가지 특성 보유: 길이(length), 높이(height), 두께(thichness)
- 이번 예에서는 길이만 사용하여 농어 무게 예측
  - 길이가 길수록 무게가 늘어나는 직관적 관계
  - 구체적 관계는 모델이 학습하여 예측
- 여러 특성을 쓸 수도 있으나, 시각화 및 설명 편의를 위해 단일 특성 사용
- 회귀 문제이므로 y축에 실수값(무게)을 표시하고, x축에 특성(길이) 표시하여 산점도 작성

### K-최근접 이웃 회귀 알고리즘(KNN Regression)
- K-최근접 이웃(KNN)은 분류와 회귀 모두에 적용 가능
- 동작 방식
  - 관심 샘플 $X$ 주변의 $k$개 이웃 샘플 선택
  - 이웃 샘플들의 타깃값(실수)을 평균(또는 가중평균)하여 예측값 산출
- 예시
  - 주변 이웃 3개 샘플 무게 평균으로 예측
- 장점: 매우 직관적이고 간단함
- 코드 흐름
  1. <mark>KNeighborsRegressor</mark> 클래스 객체 생성
  2. <mark>fit()</mark> 메서드로 훈련 데이터 입력 및 학습
  3. <mark>predict()</mark>로 테스트 데이터 예측
  4. <mark>score()</mark>로 모델 평가

| 분류 KNN | 회귀 KNN |
|----------|----------|
| 다수 클래스 레이블로 예측 | 이웃 타깃값 실수들의 평균으로 예측 |
| 예: 다수 클래스 결정 | 예: 이웃 농어 무게 평균 계산 |
| <mark>KNeighborsClassifier</mark> 사용 | <mark>KNeighborsRegressor</mark> 사용 |

### 데이터 전처리 및 배열 차원 조정
- 회귀 문제에서 입력 특성은 2차원 배열 형태여야 함
  - 예: (샘플 수, 특성 수) = (n, 1)
- 원래 1차원 배열(예: [1, 2, 3])을 2차원 배열(예: [[1], [2], [3]])로 변환 필요
- 변환 방법 중 하나: NumPy의 <mark>reshape(-1, 1)</mark> 사용
  - <mark>-1</mark>은 알맞은 행 수 자동 계산
  - <mark>1</mark>은 열 수 지정 (특성이 하나임을 의미)
- 타깃값은 1차원 배열로도 무방

#### 예시 코드
```python
train_input = train_input.reshape(-1, 1)
```

### 모델 평가 지표: 결정계수(R², R-squared)
- 회귀 모델 성능 평가는 얼마나 타깃값에 근접하게 예측했는지 측정
- 대표 지표: 결정계수(R², 결정 계수, coefficient of determination)
- 공식 <br>
  $R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$
- $y_i$: 실제 타깃값
- $\hat{y}$: 모델 예측값
- $\bar{y}$: 타깃값 평균
- 해석
  - $R^2$ = 1: 완벽 예측
  - $R^2$ = 0: 예측이 단순히 평균값 수준
  - $R^2$ < 0: 모델이 평균보다 못한 예측
- 일반적으로 $0 \leq R^2 \leq 1$ 사이 값이 많음
- 사이킷런 <mark>score()</mark> 메서드는 기본적으로 이 값을 반환
- 모델 평가 시 높은 값일수록 좋은 모델

### 추가 평가 지표: 평균 절댓값 오차 (MAE, Mean Absolute Error)
- 절댓값 평균 오차는 예측과 실제값 차이의 절댓값 평균
- 공식 <br>
  $MAE = \frac{1}{n} \sum |y_i - \hat{y}_i|$
- 단위가 원 데이터 단위와 같아 해석이 직관적임
  - 예: 농어 무게 예측에서 MAE가 19g이면 평균 오차가 19g임을 의미
- 사이킷런 <mark>metrics</mark> 모듈에서 <mark>mean_absolute_error</mark> 함수로 계산 가능
- 보완적 평가 지표로 활용

### 과대적합(Overfitting)과 과소적합(Underfitting)

| 구분 | 설명 | 특징 |
|------|------|------|
| 과대적합 (Overfitting) | 모델이 훈련 데이터에 너무 치중하여 새로운 데이터 일반화 실패 | 훈련 세트 점수 매우 높음, 테스트 세트 점수 낮음 |
| 과소적합 (Underfitting) | 모델이 충분히 학습하지 못하여 데이터 패턴을 제대로 학습하지 못함 | 테스트 세트 점수가 훈련 세트 점수보다 더 높게 나올 수 있음 |

- 일반적으로
  - 훈련 세트 점수가 테스트 세트 점수보다 높아야 정상
  - 반대 경우 과소적합 가능성 있음
- 과대적합/과소적합 문제는 모델 성능 저하의 주요 원인
- KNN에서 이웃 수 $k$ 조절이 과대적합과 과소적합에 영향
  - 작은 $k$ (예: 1): 과대적합 가능성 증가
  - 큰 $k$ (예: 전체 샘플 수): 과소적합 가능성 증가

### KNN 모델의 이웃 개수 (k) 조절에 따른 영향

| 이웃 개수 $k$ | 모델 특성 | 그래프 형태 및 학습 정도 |
|---------------|-----------|--------------------------|
| $k$ = 1 | 가장 최근접 샘플만 참조 | 매우 불규칙하고 훈련 데이터에 과도하게 맞춤 (과대적합) |
| $k$ = 3 | 근접 이웃 3개 참조 | 훈련과 테스트 점수가 모두 높고, 두 점수 차이 적음 (적절한 학습) |
| $k$ = 42 | 훈련 데이터 전체를 참조 | 모든 샘플 평균값으로 예측, 과소적합 발생 (단순한 수평선) |

- $k$ 값이 작을수록 모델 복잡도 높아져 과대적합 증가
- $k$ 값이 클수록 모델 단순해져 과소적합 증가
- 적절한 $k$ 선택이 중요하며, 검증 과정을 통해 결정

### 회귀 모델 훈련과 평가 코드 개요

| 단계 | 설명 |
|------|------|
| 1. 데이터 분리 | <mark>train_test_split</mark> 함수로 훈련 세트와 테스트 세트 분리 (stratify 불필요) |
| 2. 데이터 전처리 | 입력 특성 1차원 배열 -> 2차원 배열 변환 (reshape 사용) |
| 3. 모델 생성 | <mark>KNeighborsRegressor</mark> 클래스 객체 초기화 |
| 4. 모델 학습 | <mark>fit(train_input, train_target)</mark> 호출 |
| 5. 예측 및 평가 | <mark>predict(test_input)</mark>, <mark>score(test_input, test_target)</mark>로 결정계수 확인 |
| 6. 추가 평가 | <mark>mean_absolute_error(test_target, prediction)</mark>로 MAE 계산 |

- <mark>score()</mark> 메서드는 결정계수(R²) 반환
- <mark>mean_absolute_error</mark>는 예측 오차의 직관적 평가
- 훈련 세트와 테스트 세트 점수 비교로 과대/과소 적합 판단 가능

### 모델 성능 해석 예시

| 평가 데이터 | 결정계시(R²) | 해석 |
|-------------|--------------|------|
| 훈련 세트 점수 | 0.98 | 훈련 데이터에 대해 매우 좋은 예측 |
| 테스트 세트 점수 | 0.97 | 새로운 데이터에 대해서도 좋은 예측 |
| MAE (테스트 세트) | 약 19 (그램) | 평균 19g 정도 오차로 무게 예측 가능 |

- 훈련 점수와 테스트 점수가 모두 높고 차이가 크지 않으면 모델이 적절하게 학습됨
- MAE로 실제 단위 기준 오차 크기 표현 가능
- 지나치게 큰 점수 차이가 나면 과대적합 또는 과소적합 가능성 존재

### 정리
회귀 문제는 임의의 실수를 예측하는 문제로, 농어 무게 예측 사례를 통해 단일 특성 기반 회기 모델을 구축하였다. K-최근접 이웃 알고리즘을 활용해 주변 이웃의 타깃값 평균을 계산하여 예측하는 방식이 직관적이며, 데이터 전처리 과정에서 2차원 배열 형태로 입력 특성을 변환하는 것이 필수적이다. 결정계수(R²)를 중심으로 모델 성능을 평가하며, 평균 절댓값 오차(MAE)를 통해 예측 오차의 실질적 크기를 파악한다. 과대적합과 과소적합 문제는 모델 일반화 능력에 영향을 미치며, KNN에서는 이웃 수 조절로 이를 완화할 수 있다. 훈련 세트와 테스트 세트 점수의 균형이 모델의 적절한 학습 상태를 반영한다.

## 7강 선형 회귀
### k-최근접 이웃(k-NN) 한계와 선형 회귀 개념
- **k-최근접 이웃(k-NN)**은 데이터 포인트 주변의 k개의 인접한 샘플을 참고해 예측하는 방식
- 하지만 고차원 데이터나 복잡한 패턴에서는 성능 저하 및 계산 비용 증가 문제 존재
- **선형 회귀(linear regression)**는 독립 변수들과 종속 변수 간 선형 관계를 가정한 모델
- 선형 회귀는 간단한 1차 함수 형태를 기반으로 하며, 데이터의 추세선을 찾는 데 적합

### 선형 회귀(linear regression) 모델 이해
> "선형 회귀는 입력 변수 $x$와 출력 변수 $y$ 사이의 관계를 직선 방정식 $y = wx + b$ 형태로 모델링하는 알고리즘이다."
- 여기서 $w$는 기울기(가중치, weight), $b$는 절편(바이어스, bias)
- 목표는 주어진 데이터에 가장 잘 맞는 직선을 찾는 것
- 오차의 제곱합(Residual Sum of Squares, RSS)을 최소화하는 $w$와 $b$를 찾음
- 선형 회귀는 회귀 문제에 널리 사용되는 기본적인 알고리즘

| 용어 | 설명 |
|------|------|
| $w$ | 독립변수 $x$의 기울기 |
| $b$ | 절편, $y$축과의 교차점 |
| RSS | 잔차 제곱 합, 오차를 제곱해 합산한 값 |

### LinearRegression 클래스 활용법
- Python의 사이킷런(sklearn) 라이브러리에서 제공하는 LinearRegression 클래스는 선형 회귀 모델 구현을 쉽게 해줌
- 주요 메서드와 속성

| 메서드/속성 | 설명 |
|-------------|------|
| <mark>fit(X, y)</mark> | 입력 데이터 $X$와 타깃 $y$로 모델 학습 |
| <mark>predict(X)</mark> | 학습된 모델로 입력 데이터에 대한 예측 수행 |
| <mark>coef_</mark> | 학습된 기울기 $w$ 값 |
| <mark>intercept_</mark> | 학습된 절편 $b$ 값 |

- 학습 후 <mark>predict</mark> 메서드로 새로운 입력에 대한 결과를 구할 수 있음
- 학습한 직선을 시각화해 데이터와 모델의 적합도를 확인 가능

### 학습한 직선 그리기 및 다항 회귀 소개
- 선형 회귀 결과는 2차원 그래프로 직선을 그려 시각적으로 확인 가능
- 데이터 분포와 선형 모델의 적합 정도를 쉽게 파악할 수 있음
- 단순 직선 모델로는 표현하기 어려운 곡선 관계를 다루기 위해 다항 회귀(polynomial regression) 도입
- 다항 회귀는 입력 변수를 다항식으로 변환하여 선형 모델을 적용하는 방법

| 회귀 종류 | 모델 형태 | 설명 |
|-----------|-----------|------|
| 선형 회귀 | $y = wx + b$ | 1차 함수 형태, 직선 모델 |
| 다항 회귀 | $y = w_0 + w_1 + w_2x^2 + ...$ | 고차항을 추가하여 곡선 형태 모델링 가능 |

- 다항 회귀는 과적합 위험도 있지만, 복잡한 데이터 패턴에 대한 표현력 증가

### 모델 재훈련과 성능 개선 절차
- 모델 학습 후 새로운 데이터나 변형된 특성을 반영해 모델을 다시 훈련할 수 있음
- 재훈련 과정에서 파라미터가 업데이트되어 모델의 예측 정확도가 향상됨
- 학습한 직선을 다시 그려 변화된 모델 상테와 데이터 적합도를 비교 분석 가능

| 단계 | 설명 | 
|------|------|
| 초기 학습 | 원본 데이터로 모델 학습 |
| 재훈련 | 새로운 데이터 또는 변형된 특성 반영해 재학습 |
| 시각화 비교 | 학습 전후 직선 그래프 비교로 모델 변화 확인 |

- 이러한 반복 학습 과정을 통해 모델 성능을 점진적으로 개선 

### 개념 정리 및 학습 포인트

| 개념 | 핵심 내용 |
|------|-----------|
| k-최근접 이웃 한계 | 고차원 및 복잡 데이터에 적합하지 않음 |
| 선형 회귀 모델 | $y = wx + b$ 형태로 데이터의 선형 관계를 모델링 |
| LinearRegression 클래스 | sklearn에서 제공하는 선형 회귀 구현 도구, <mark>fit</mark>과 <mark>predict</mark> 핵심 메서드 | 
| 다항 회귀 | 다항식 변환으로 곡선 형태 모델링, 단순 선형 회귀의 확장 |
| 모델 재훈련 | 데이터 변화 반영해 파라미터 업데이트, 성능 향상 목적 |

- 선형 회귀는 머신러닝에서 가장 기본적이고 직관적인 회귀 기법으로, 데이터와 모델 간 관계를 명확히 이해하는 데 필수적이다. 
- 다항 회귀와 모델 재훈련을 통해 단순 선형 모델의 한계를 극복하고 다양한 데이터 패턴에 대응하는 능력을 키울 수 있다.

## 8강 특성 공학과 규제
### 다중 회귀와 특성 공학 (Feature Engineering)
> "다중 회귀는 특성(Feature)이 여러 개인 회귀 모델을 뜻하며, 특성 공학은 기존 특성들을 조합하거나 변형하여 새로운 특성을 만드는 작업이다."

#### 다중 회귀 (Multiple Regression)
- 특성이 한 개인 단일 회귀와 달리, 여러 개의 특성을 독립 변수로 사용하는 회귀 모델
- 특성 개수가 2개일 경우, 선형 회귀 모델은 평면(2차원 이상 공간에서 초평면)으로 표현됨
- 특성이 3개 이상이면 시각적 평가가 어려워 R² 점수 등 수치적 평가를 사용함

#### 특성 공학 (Feature Engineering)
- 기존 특성을 제곱하거나 서로 곱하는 등 조합하여 새로운 특성을 생성하는 작업
- 예: 길이, 높이, 두께 특성이 있을 때, 각각의 제곱항, 곱셈항을 추가해 특성 확장
- 특성 공학을 통해 모델의 표현력을 높이고 복잡한 패턴 학습 가능

### 판다스(Pandas)와 데이터 프레임
> "판다스는 파이썬 기반 데이터 처리 라이브러리로, 행과 열로 구성된 2차원 데이터 구조인 데이터 프레임을 제공한다."

| 특징 | 설명 |
|------|------|
| 데이터 구조 | 2차원 배열 형태, 엑셀 스프레드시트와 유사 | 
| 연산 기능 | 통계 함수, 수학 함수, 그래프 그리기 지원 |
| 넘파이와 차이점 | 넘파이는 다차원 배열 지원, 판다스는 2차원 데이터에 특화 |

- CSV 파일은 <mark>pd.read_csv()</mark>로 읽어 데이터 프레임 생성
- <mark>head()</mark> 메소드는 데이터 프레임의 상위 5개 행을 출력하여 데이터 구조 확인 가능

### 데이터 분할과 사이킷런(Scikit-learn) 연동 
- 판다스 데이터 프레임을 직접 사이킷런 모델에 사용할 수 있음 (변환 필요 없음)
- <mark>train_test_split</mark> 함수를 활용해 훈련 세트와 테스트 세트로 데이터를 나눔
- 데이터 분할 시 훈련 세트에서 만든 변환기(Transformer)를 테스트 세트에도 동일하게 적용해야 함

### 다항 특성 생성: PolynomialFeatures 클래스

| 메소드 | 기능 |
|--------|------|
| <mark>fit(X)</mark> | 입력 데이터의 특성 개수와 조합 파악 |
| <mark>transform(X)</mark> | 다항 특성(제곱, 곱 등)으로 변환된 데이터 생성 |

- 기본적으로 2차항까지 생성 (각 특성의 제곱 + 특성 간 곱)
- 절편항(상수항) 포함 여부는 <mark>include_bias</mark> 매개변수로 조절 가능
- 출력 특성 이름은 판다스 데이터 프레임 열 이름 유지. 직관적 이해에 도움

### 특성 표준화 (Standardization)
- 선형회귀 모델에서 특성의 스케일 차이가 크면 계수 산출에 영향을 줌(특히 규제 모델에서 민감)
- 표준화는 각 특성의 평균을 0, 표준편차를 1로 변환하는 작업
- 사이킷런의 <mark>StandardScaler</mark> 클래스로 손쉽게 구현 가능
- 훈련 세트의 평균과 표준편차로 테스트 세트를 변환해야 함(데이터 누수 방지)

### 규제(Regularization) 개념과 목적
> "규제는 모델이 훈련 세트에 과도하게 적합하는 과대적합을 방지하기 위해 계수의 크기를 제한하는 방법이다."
- 자유도가 높은 모델(특성 수가 많음)은 훈련 데이터에 너무 정확히 맞춰져 과대적합 발생
- 규제는 계수(기울기)를 작게 만들어 모델을 완만하게 만듦
- 특성 스케일 조정 후에 규제를 적용하는 것이 효과적

### 릿지(Ridge) 회귀: L2 규제
- <mark>Ridge</mark> 클래스 사용 (사이킷런 <mark>linear_model</mark> 모듈)
- 가중치의 제곱합을 벌칙으로 사용 -> 큰 계수에 페널티 부여
- L2 규제라고도 불림
- 매개변수 <mark>alpha</mark>가 규제 강도 조절 (큰 값일수록 규제 강함)
- 알파 값에 따른 훈련 및 테스트 성능 변화로 최적 값 탐색 가능
- 과대적합 감소, 테스트 세트 성능 향상 효과

### 라쏘(Lasso) 회귀: L1 규제
- <mark>Lasso</mark> 클래스 사용 (사이킷런 <mark>linear_model</mark> 모델)
- 가중치 절댓값의 합을 벌칙으로 사용 -> 일부 계수를 0으로 만듦
- L1 규제라고도 불림
- 특성 선택 효과: 불필요한 특성의 계수를 0으로 만들어 모델 단순화
- 다중 회귀에서 많은 특성(예: 55개) 중 약 40개 특성 계수를 0으로 만듦
- 실제 적용 시 릿지보다 덜 사용되나 특성 선택에 유용

### 하이퍼파라미터(Hyperparameter)와 최적화
- 규제 강도 <mark>alpha</mark>는 모델이 자동으로 결정하지 못하고 사람이 설정해야 함
- 적절한 <mark>alpha</mark> 값 탐색은 모델 성능에 매우 중요
- 일반적으로 로그 스케일(예: 0.001, 0.01, 0.1, 1, 10, 100)로 탐색 후 세분화 진행
- 이후 교차 검증, 그리드 서치 등으로 최적값 찾는 방법 학습

### 표: 주요 개념과 메소드 비교

| 개념 | 클래스/메소드 | 주요 역할 | 비고 |
|------|---------------|-----------|------|
| 다항 특성 생성 | <mark>PolynomialFeatures</mark> | 기존 특성의 제곱, 곱 등 조합 생성 | <mark>fit()</mark>, <mark>transform()</mark> 사용 |
| 특성 표준화 | <mark>StandardScaler</mark> | 평균 0, 표준편차 1로 변환 | 훈련 세트 기준 변환 필수 |
| 규제: 릿지 회귀 | <mark>Ridge</mark> | L2 규제, 계수 제곱 벌칙 적용 | <mark>alpha</mark>로 규제 강도 조절 |
| 규제: 라쏘 회귀 | <mark>Lasso</mark> | L1 규제, 계수 절댓값 벌칙, 특성 선택 가능 | 일부 계수 0으로 만듦 |

### 모델 학습 및 평가 절차 요약
1. 데이터 준비: 농어 데이터셋 불러오기 (길이, 높이, 두께)
2. 다항 특성 생성: <mark>PolynomialFeatures</mark>로 2차항 이상 특성 확장
3. 데이터 분할: 훈련 세트와 테스트 세트로 나누기
4. 특성 표준화: <mark>StandardScaler</mark>로 특성 스케일 맞추기
5. 모델 훈련: <mark>Ridge</mark> 또는 <mark>Lasso</mark> 클래스에 데이터 입력 후 <mark>fit()</mark> 실행
6. 평가: 훈련 세트와 테스트 세트에서 <mark>score()</mark>로 R² 점수 확인
7. 하이퍼파라미터 튜닝: <mark>alpha</mark> 값 변화시켜 성능 곡선 분석 후 최적 값 선택

### 데이터 차원과 모델 복잡성 관계
- 특성 개수가 훈련 샘플 수보다 많을 경우, 모델이 훈련 데이터를 완벽히 맞출 수 있음 (과대적합)
- 예: 42개 샘플 vs 55개 특성 -> 자유도 과다 -> 훈련 세트에서 매우 높은 점수, 테스트 세트에서 낮은 점수
- 규제는 이런 자유도를 제한하여 일반화 성능 개선

### 용어 정리

| 용어 | 설명 |
|------|------|
| 특성 (Feature) | 모델 입력 변수 (ex. 길이, 높이, 두께) |
| 다중 회귀 (Multiple Regression) | 여러 특성을 사용하는 회귀 분석 |
| 특성 공학 (Feature Engineering) | 특성을 변형/조합해 새로운 특성을 만드는 과정 |
| 규제 (Regularization) | 모델 복잡성을 제한해 과적합 방지하는 방법 |
| 하이퍼파라미터 (Hyperparameter) | 학습 과정에서 외부에서 설정하는 매개변수 (ex. alpha) |
| 트랜스포머 (Transformer) | 데이터를 변환하는 객체 (ex. PolynomialFeatures, StandardScaler) |

특성 공학은 기존 특성 간의 조합과 변환을 통해 모델의 표현력을 확장하며, 다중 회귀 모델은 이를 활용해 복잡한 관계를 학습한다. 판다스 데이터 프레임을 이용해 데이터를 효율적으로 다루고, 사이킷런의 변환기와 회귀 클래스를 통해 다항 특성 생성과 규제를 적용한다. 규제는 모델의 자유도를 제한하여 과대적합을 방지하며, 적절한 하이퍼파라미터 튜닝을 통해 훈련 세트와 테스트 세트에서 균형 잡힌 성능을 도출한다. 특성 스케일 표준화는 규제 모델의 안정성을 높이며, 라소 규제는 불필요한 특성의 계수를 0으로 만들어 모델 단순화에 기여한다.

# Ch04. 다양한 분류 알고리즘
## 9강 로지스틱 회귀
### K-최근접 이웃 알고리즘 (K-Nearest Neighbors, KNN)
> "K-최근접 이웃 알고리즘은 관측값 주변의 이웃 샘플들의 클래스 비율을 이용해 예측하는 분류 방법이다."
- 개념
  - 주어진 샘플 주변의 K개의 이웃 샘플 중 다수 클래스가 예측 결과가 됨
  - 예: 이웃 10개 중 3개가 네모, 5개가 세모, 2개가 동그라미 -> 각각 30%, 50%, 20% 확률로 분류 가능
- 데이터 예시
  - 입력 특성: 무게(weight), 길이(length), 대각선길이(diagonal), 두께(width)
  - 타겟: 생선 종류 (7개 클래스)
- 모델 훈련 및 예측
  - pandas <mark>read_csv</mark>로 데이터 불러오기 -> 데이터프레임 변환
  - 입력과 타겟 분리하여 KNN 모델에 학습
  - <mark>predict()</mark> 메서드로 클래스 예측
  - <mark>predict_proba()</mark> 메서드로 각 클래스별 확률 예측 (확률은 이웃 중 해당 클래스 비율에 해당)
- 특징
  - 확률값은 이웃 개수에 따라 결정되어, 0, 0.33, 0.5 등 이산적인 값만 가짐
  - 확률이 자연스럽게 연속적으로 변화하지 않음 -> 확률적 해석에 한계 존재

### 로지스틱 회귀 (Logistic Regression)
> "로지스틱 회귀는 선형 방정식을 기반으로 출력값을 0과 1 사이 확률로 변환하여 분류 문제를 해결하는 대표적인 알고리즘이다."

#### 기본 원리
- 선형 방정식 형태 <br>
  $z = a \cdot x_1 + b \cdot x_2 + c \cdot x_3 + \cdots + \text{intercept}$ <br>

여기서 $x_i$는 특성값, 계수 $a, b, c$는 학습되는 파라미터
- $z$ 값은 임의의 실수값으로, 그대로는 분류에 쓸 수 없으므로 0~1 사이 확률로 변환 필요
- 확률 변환 함수: 시그모이드 함수 (또는 로지스틱 함수) <br>
  $\sigma(z) = \frac{1}{1 + e^{-z}}$

- 시그모이드 함수 특징
  - $z \to -\infty$일 때 $\sigma(z) \to 0$
  - $z \to +\infty$일 때 $\sigma(z) \to 1$
  - $z = 0$일 때 $\sigma(0) = 0.5$
- 분류 기준
  - $\sigma(z) \geq 0.5$ -> 양성 클래스 (positive)
  - $\sigma(z) < 0.5$ -> 음성 클래스 (negative)
  - 또는 $z \geq 0$ -> 양성, $z < 0$ -> 음성으로도 분류 가능

#### 예시
- $z값: -0.4x - 0.57y + \cdots$ 형태로 계수 학습
- 시그모이드 함수로 확률 계산하여 예측
- <mark>predict()</mark>는 $z$ 값을 기준으로 클래스 예측
- <mark>predict_proba()</mark>는 시그모이드 함수 적용 후 확률 반환
- <mark>decision_function()</mark> 메서드로 $z$값 자체를 확인 가능

#### 다중 클래스 분류
- 로지스틱 회귀는 기본적으로 다중 클래스 분류 지원
- 각 클래스마다 하나의 선형 방정식 계수 집합이 학습됨 (One-vs-Rest 방식에 근접)
- 예측 시 각 클래스별 $z$ 값을 계산하고, 소프트맥스 함수로 확률 변환
- 소프트맥스 함수 <br>
  $\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}$
- 다중 클래스 확률 분포로 결과 표현

#### 규제 (Regularization)
- <mark>C</mark> 매개변수로 규제 정도 조절 (작으면 강한 규제, 크면 약한 규제)
- 규제는 과적합 방지 및 모델 일반화에 도움
- 로지스틱 회귀에서는 L2 규제가 기본이며, L1 규제도 선택 가능
- <mark>max_iter</mark>로 최대 반복 횟수 지정, 미수렴 시 경고 발생

### 로지스틱 회귀 실습 주요 단계

| 단계 | 설명 및 함수 |
|------|--------------|
| 데이터 준비 | pandas <mark>read_csv()</mark> -> 데이터프레임 생성 |
| 특성 선택 | 입력: 무게, 길이, 대각선, 높이, 두께 (5개 특성) |
| 타겟 설정 | 생선 종류 (7개 클래스 중 선택 또는 이진 분류용 필터링) |
| 모델 생성 | <mark>LogisticRegression()</mark> 임포트 및 객체 생성 |
| 모델 훈련 | <mark>fit(X_train, y_train)</mark> |
| 예측 | <mark>predict(X_test)</mark> | 
| 확률 예측 | <mark>predict_proba(X_test)</mark> |
| 결정 함수 값 확인 | <mark>decision_function(X_test)</mark> |
| 계수 확인 | <mark>coef_</mark> (각 특성별 계수), <mark>intercept_</mark> (절편) |
| 규제 조절 | <mark>C</mark> 매개변수로 조절 (기본 L2 규제) |

### 용어 및 개념 정리

| 용어 | 정의 및 설명 |
|------|--------------|
| 시그모이드 함수 | 실수 입력을 0 ~ 1 사이 확률로 변환하는 함수 |
| 소프트맥스 함수 | 다중 클래스 확률 분포를 계산하는 함수 |
| $z$값 (결정 함수) | 선형 방정식을 통해 계산된 실수값, 분류의 기준이 됨 |
| 규제 (Regularization) | 모델 과적합 방지 목적으로 가중치 크기를 제한하는 기법 | 
| 이진 분류 | 두 개 클래스 (양성/음성) 중 하나를 예측하는 작업 |
| 다중 클래스 분류 | 세 개 이상 클래스를 구분하는 분류 문제 |

### 예측 확률과 결정 함수 관계
- 결정 함수 $z$값은 선형 방정식 결과
- 시그모이드 함수 $\sigma(z)$는 $z$를 확률로 변환
- 확률 0.5 기준이 $z$ = 0과 일치
- <mark>predict()</mark>는 $z$ 기준으로 클래스 예측
- <mark>predict_proba()</mark>는 시그모이드 함수 값 반환 
- 다중 클래스는 소프트맥스로 변환하여 각 클래스 확률 산출

### 시그모이드 함수 그래프 특징
- $z$축은 $-\infty$부터 $+\infty$까지 확장
- 함수값은 0과 1 사이에 부드럽게 수렴
- $z$ = 0에서 함수값 0.5 (경계)
- 양성 클래스는 0.5 이상 확률 구간
- 음성 클래스는 0.5 미만 확률 구간

### 로지스틱 회귀와 선형 회귀의 차이점

| 구분 | 선형 회귀 | 로지스틱 회귀 |
|------|-----------|---------------|
| 출력값 | 실수 (연속값) | 0 ~ 1 사이 확률 |
| 문제 유형 | 예측 (regression) | 분류 (classification) |
| 모델 출력 | 선형 방정식 결과 $z$ | 시그모이드 함수 적용한 확률 | 
| 목적 | 연속적인 숫자 예측 | 클래스 구분 및 확률 예측 |

- 이름에 '회귀'가 붙어도 로지스틱 회귀는 엄연한 분류 알고리즘임
- 회귀(regression)와 분류(classification)는 문제 종류 구분 용어임

### 비유: 시그모이드 함수는 물리적 '압축기'와 같음
- 선형 방정식의 출력값 $z$가 아무 숫자(무한대까지 가능)라고 생각
- 시그모이드 함수는 이 값을 0 ~ 1 사이로 '압축'하는 기계
- 이 압축기를 통과한 값은 확률로 해석 가능하여, 분류 기준이 됨

### 추가 설명: 불리언 인덱싱을 통한 이진 분류 데이터 생성
- 전체 7개 클래스 중 2개 클래스(예: 브림, 스멜트)만 선택하여 이진 분류 데이터셋 만듦
- numpy/pandas 불리언 인덱싱 사용
- 이렇게 생성된 데이터로 로지스틱 회귀 이진 분류 실습 가능

### 사이킷런 로지스틱 회귀 주요 메서드 요약

| 메서드 | 기능 |
| <mark>fit(X, y)</mark> | 모델 학습 |
| <mark>predict(X)</mark> | 클래스 예측 |
| <mark>predict_proba(X)</mark> | 클래스별 확률 예측 |
| <mark>decision_function(X)</mark> | 선형 방정식 결과 $z$값 반환 |
| <mark>coef_</mark> | 특성별 계수 (가중치) |
| <mark>intercept_</mark> | 절편 (bias) |

### 다중 클래스 로지스틱 회귀 특징
- 각 클래스마다 하나의 선형 함수 학습 -> $z_1, z_2, \dots, z_k$ 계산
- 소프트맥스로 각 클래스 확률 계산
- 가장 높은 확률 클래스가 최종 예측 결과
- 각 클래스별 5개 특성 계수와 절편 존재 (예: 7개 클래스 -> 7세트 계수)

### 규제 파라미터 <mark>C</mark>의 역할
- <mark>C</mark> 값이 크면 규제 완화 (과적합 가능성 증가)
- <mark>C</mark> 값이 작으면 규제 강화 (과적합 감소, 과소적합 위험)
- 선형 회귀 및 로지스틱 회귀에 모두 적용 가능
- 사이킷런 설계 철학에 따라 <mark>C</mark>는 규제 강도의 역수임

### 종합 
로지스틱 회귀는 선형 모델의 출력값을 시그모이드 함수로 압축하여 확률적 분류 결과를 제공하며, 다중 클래스 문제에서는 소프트맥스 함수를 이용해 각 클래스별 확률을 계산한다. 규제 매개변수를 활용해 모델 복잡도를 조절하며, <mark>decision_function</mark>으로 선형 방정식의 원시 점수도 확인 가능하다. K-최근접 이웃과는 달리, 로지스틱 회귀는 연속 확률값을 생성하여 더 자연스러운 확률 해석을 제공한다.

## 10강 확률적 경사 하강법
### 확률적 경사 하강법 (SGD; Stochastic Gradient Descent)
> "확률적 경사 하강법은 특정 모델에 국한되지 않고, 최적화 문제를 해결하는 범용적인 방법이다. 특히 데이터가 많거나 해석적으로 해를 구하기 어려운 경우에 효과적이다."

#### 개념 및 특징

| 항목 | 설명 |
|------|------|
| 확률적 | 무작위로 샘플(또는 소수 배치)을 선택하여 경사를 계산한다는 의미. |
| 경사(Gradient) | 함수의 기울기, 즉 손실 함수의 변화율을 의미하며, 최적화 방향을 결정하는 기준. |
| 에포크(epoch) | 전체 훈련 데이터 세트를 한 번 모두 사용하여 경사 하강법을 수행한 한 사이클. |
| 온라인 학습 | 데이터가 점진적으로 도착할 때, 기존 모델을 재학습하지 않고 추가 학습하는 전략. |

- SGD는 모델 파라미터를 손실 함수의 경사를 따라 조금씩 갱신하여 최적점을 찾아가는 방법이다.
- 딥러닝을 포함한 다양한 머신러닝 문제에서 주로 사용된다. 
- 미니배치 경사 하강법(mini-batch gradient descent)은 샘플 여러 개를 묶어 경사를 계산하는 방식으로, 딥러닝에서 가장 흔히 쓰임.
- 배치 경사 하강법(batch gradient descent)은 전체 데이터를 한꺼번에 사용하여 경사를 계산하는 방식.

### 손실 함수와 경사 하강법의 산
- 손실 함수(loss function)는 모델 예측과 실제 값 간 차이를 수치화하는 함수이며, 이 함수의 값을 최소화하는 것이 훈련의 목표이다. 
- 손실 함수는 회귀 문제와 분류 문제에서 다르게 정의된다.

| 문제 유형 | 손실 함수 예시 | 설명 |
|-----------|----------------|------|
| 회귀 | 평균 제곱 오차(MSE; Mean Squared Error) | 타깃과 예측값 차이의 제곱 평균, 연속적이고 부드러운 함수 |
| 분류 | 로지스틱 손실 함수 (이진 크로스 엔트로피) | 정확도 대신 사용할 수 있는 대리 손실 함수, 연속적이고 미분 가능하도록 설계됨 |

- 정확도(accuracy)는 0과 1 사이의 불연속적 값이므로 손실 함수로 사용하기 어렵다. 
- 손실 함수는 부드럽고 연속적으로 변화하여 경사 하강법이 원활히 작동할 수 있도록 해야 한다. 

### 로지스틱 손실 함수 (이진 크로스 엔트로피)
- 이진 분류 문제에서 주로 사용한다. 
- 정의 
  - 타깃 $y = 1$일 때 손실: $-\log(p)$, 여기서 $p$는 모델이 예측한 클래스 1일 확률
  - 타깃 $y = 0$일 때 손실: $-\log(1 - p)$
- 예시

| 타깃 $y$ | 예측 확률 $p$ | 손실 계산 방법 | 손실 값 해석 |
|----------|---------------|----------------|--------------|
| 1 | 0.9 | $-\log(0.9)$ | 낮은 손실 (좋은 예측) |
| 1 | 0.3 | $-\log(0.3)$ | 높은 손실 (나쁜 예측) |
| 0 | 0.8 | $-\log(1-0.8) = -\log(0.2)$ | 매우 높은 손실 (잘못된 예측) |
| 0 | 0.2 | $-\log(1-0.2) = -\log(0.8)$ | 낮은 손실 (좋은 예측) |

- 손실 함수가 작을수록 모델 예측이 실제 타깃에 가까움을 의미한다.

### 확률적 경사 하강법 훈련 과정
- 훈련 데이터에서 샘플을 무작위로 하나씩 꺼내어 경사를 계산하고 모델 파라미터를 갱신한다. 
- 한 번 모든 샘플을 다 사용하면 한 에포크가 완료되고, 다시 데이터를 채워 여러 에포크 동안 반복 훈련한다. 
- 미니배치 경사 하강법은 여러 샘플을 묶어 경사를 계산하며, 딥러닝에서 주로 사용된다.
- 이렇게 하면 매번 전체 데이터를 사용하는 배치 경사 하강법보다 계산 비용이 줄고, 새로운 데이터가 점진적으로 도착하는 온라인 학습에도 적합하다. 

### 온라인 학습과 점진적 학습
- 데이터가 점차 추가될 때 매번 처음부터 전체 모델을 재훈련하는 대신, 기존 모델에 새 데이터를 이용해 추가 학습한다. 
- 확률적 경사 하강법은 온라인 학습에 적합하며, 새로운 데이터에 빠르게 적응 가능하다. 
- <mark>partial_fit</mark> 메서드를 통해 추가 학습(점진적 학습)을 구현할 수 있다. 

### 사이킷런(Sklearn)에서 SGDClassifier 사용법

| 단계 | 설명 |
|------|------|
| 임포트 | <mark>from sklearn.linear_model import SGDClassifier</mark> |
| 객체 생성 | <mark>clf = SGDClassifier(loss='log', max_iter=10)</mark> <br> - loss='log'는 로지스틱 손실 함수 사용 <br>- max_iter는 최대 에포크 수 지정 |
| 모델 학습 | <mark>clf.fit(X_train, y_train)</mark> |
| 추가 학습 | <mark>clf.partial_fit(X_new, y_new)</mark> |
| 평가 | <mark>clf.score(X_test, y_test)</mark> |

- <mark>SGDClassifier</mark>는 분류 문제에 확률적 경사 하강법을 적용한 클래스이다. 
- <mark>loss</mark> 파라미터로 손실 함수를 선택할 수 있으며, 로지스틱 회귀를 원하면 <mark>'log'</mark>로 설정.
- 에포크 수가 많아질수록 훈련 세트 정확도는 증가하지만, 과대적합(overfitting)에 주의해야 한다. 

### 에포크 수와 과적합 관계
- 에포크가 증가할수록 훈련 세트 정확도는 상승한다.
- 일정 시점 이후에는 테스트 세트 정확도가 오히려 떨어지는 과대적합 현상이 발생한다. 
- 적절한 에포크 수는 과소적합과 과대적합 사이의 균형점(절충점)이다. 
- 그래프 예시

| 에포크 수 | 훈련 정확도 | 테스트 정확도 | 해석 |
|-----------|-------------|---------------|------|
| 0 ~ 100 | 상승 중 | 상승 중 | 점진적 학습 진행 |
| 100 이상 | 계속 상승 | 정체 또는 하락 | 과대적합 발생 가능성 높음 |

- 실제 실험에서 약 100 에포크가 절충점으로 관찰됨.

## 11강 결정 트리
### 결정 트리(Decision Tree)의 개요 및 중요성
- 결정 트리는 전통적인 머신러닝 알고리즘 중 하나로, 딥러닝과 구분되는 핵심 모델
- 머신러닝에서 가장 중요한 앙상블 모델(ensemble model)의 기초가 되는 알고리즘
- 로지스틱 회귀(Logistic Regression)와 달리, 이해하기 쉽고 시각화가 용이하여 직관적인 모델 해석 가능

### 와인 데이터셋을 이용한 문제 설정 및 데이터 전처리
- 문제: 레드 와인과 화이트 와인 중 어떤 종류인지 분류 (레이블링이 없는 상태에서 예측) 
- 데이터셋 크기: 6,497개 샘플, 누락된 값 없음 (null 카운트 0)
- 데이터프레임 메서드 활용
  - <mark>info()</mark>: 각 컬럼 데이터 타입, 누락 값 확인 
  - <mark>describe()</mark>: 카운트, 평균, 표준편차, 4분위수 등 기본 통계량 확인
- 누락된 값 처리 방법 예시
  - 연속형 변수: 평균값 대체
  - 이산형 변수: 최빈값(most frequent) 대체
  - 행 삭제 가능성도 있음
- 전처리 시 주의사항: 훈련 데이터에서 계산한 평균 등 전처리 기준은 테스트 데이터에도 동일하게 적용해야 함

### 로지스틱 회귀 모델과 결정 트리 모델 비교

| 구분 | 로지스틱 회귀 | 결정 트리 |
|------|---------------|-----------|
| 모델 유형 | 선형 모델 | 비선형, 분할 기반 모델 |
| 해석력 | 계수 값으로 설명 가능하나 직관적 이해 어려움 | 플로우 차트 형태로 매우 직관적 |
| 전처리 필요성 | 스케일 조정(표준화) 필수 | 스케일 조정 불필요 | 
| 성능 (와인 데이터) | 훈련 세트 약 0.78, 테스트 세트 약 0.77 | 훈련 세트 약 0.99, 테스트 세트 약 0.85 (과대적합 가능성) |
| 계수 예시 | 알콜 0.5, 슈가 1.6, pH -0.6 등 | 특성 중요도로 해석 가능 |

- 로지스틱 회귀는 계수 밑에 입력 특성을 곱하는 방식이나, 왜 그 계수가 중요한지 이해하기 어려움(블랙박스 문제)
- 결정 트리는 플로우 차트와 유사한 구조로, 각 노드의 조건에 따라 분류가 이루어져 설명력 우수

### 결정 트리 모델 구조 및 작동 원리
- 트리의 시작점은 루트 노드(root node), 끝점은 리프 노드(leaf node)
- 각 노드는 하나의 특성(feature)과 임계값(threshold)을 기준으로 데이터를 두 그룹으로 분할 
- 분할은 이진 트리(binary tree) 구조로 이루어지며, 노드는 2개의 가지(branch)를 가짐
- 예시: "당도가 -0.239보다 작은가?" -> 예: 왼쪽 가지, 아니오: 오른쪽 가지
- 리프 노드에는 한 클래스(양성 혹은 음성)만 남도록 분할을 계속 진행

#### 불순도(Impurity) 개념

| 용어 | 설명 |
|------|------|
| 지니 불순도(Gini impurity) | $1 - (p_{\text{음성}}^2 + p_{\text{양성}}^2)$ 형태로 계산, 0에 가까울수록 순수한 노드 |
| 순수 노드 | 한 클래스만 포함하는 노드, 지니 불순도 0에 해당 |
| 불순도 최대 | 음성, 양성 클래스가 50%씩 섞인 경우, 지니 불순도 최대 (0.5) |

- 부모 노드의 불순도와 자식 노드들의 가중 평균 불순도 차이가 최대화되도록 분할하여 트리를 성장
- 불순도 차이가 클수록 노드가 순수해짐

### 결정 트리 시각화 및 해석
- 사이킷런(sklearn)의 <mark>plot_tree</mark> 함수로 트리 시각화 가능
- 각 노드에 다음 정보 표시
  - 분할 기준(예: "당도가 -0.238보다 작은가?")
  - 샘플 수 및 클래스별 샘플 분포(예: 음성 100개, 양성 1745개)
  - 불순도 지표
- 시각화 색상으로 클래스 비율 표현
  - 양성 클래스가 많은 노드는 짙은 파란색
  - 음성 클래스가 많은 노드는 붉은색 계열
  - 섞여 있으면 연한 색상으로 표시
- 깊이를 제한하여 트리의 일부만 시각화 가능(예: <mark>max_depth=1</mark>)

### 가지치기(Pruning)와 과대적합 조절
- 결정 트리는 데이터를 지나치게 분할하여 과대적합(overfitting)이 발생하기 쉬움
- 가지치기(pruning): 트리의 깊이나 분할을 제한하여 과대적합 완화
- 대표적인 매개변수
  - <mark>max_depth</mark>: 트리 최대 깊이 제한 (예: 3층까지만 성장)
  - 기타 분할 조건 관련 파라미터 존재 (책 참고)
- 가지치기 적용 시 훈련 세트와 테스트 세트의 점수 차이가 줄어듦 (과대적합 완화 효과)

### 결정 트리의 전처리 장점과 특성 중요도(feature importance)
- 결정 트리는 각 노드에서 하나의 특성만을 사용해 분할하므로,
  - 특성 간 스케일(단위) 차이를 맞출 필요 없음
  - 원본 데이터 그대로 사용 가능
- 특성 중요도 산출 가능
  - 각 노드 분할에 사용된 특성의 지니 불순도 감소 기여도를 누적하여 계산
  - <mark>feature_importances_</mark> 속성으로 확인 가능

| 특성 | 중요도 예시 (와인 데이터) |
|------|---------------------------|
| 알콜 | 가장 중요 |
| 당도 | 두 번째로 중요 |
| pH | 세 번째 |

- 특성 중요도는 모델 해석과 변수 선택에 유용

### 결정 트리 예측 과정 간단 설명
- 입력 샘플이 루트 노드에서 시작해 각 노드의 조건에 따라 좌우 가지로 이동
- 최종 도달한 리프 노드에 존재하는 클래스가 예측 결과
- 예: 당도 < -0.239 -> 왼쪽 이동 -> 리프 노드에 음성 클래스만 존재 -> 음성 클래스로 예측

### 요약
결정 트리는 데이터의 특성별 임계값으로 이진 분할을 반복하여 노드를 구성하는 모델이다. 각 분할은 지니 불순도 기준으로 가장 순수한 집단을 만들도록 조정되며, 최종 리프 노드는 한 클래스만 포함하게 된다. 트리 모양이 플로우 차트처럼 명확하여 해석이 쉽고, 원본 데이터 스케일 조정이 불필요하며, 특성 중요도 분석을 통해 변수의 영향력을 직관적으로 파악할 수 있다. 반면, 깊이 제한 등 가지치기를 통해 과대적합을 조절해야 모델 성능이 균형을 이룰 수 있다. 이 과정에서 분할 기준과 불순도 계산이 모델의 핵심 메커니즘을 구성하며, 시각화를 통해 결정 과정을 쉽게 추적할 수 있다.

## 23강 순차 데이터와 순환 신경망
### 순차 데이터와 순환 신경망 개념
순차 데이터는 시간적 또는 순서적 관계가 있는 데이터로, 대표적으로 텍스트 데이터나 시계열 데이터(온도, 센서 데이터 등)가 있다.
- 순차 데이터(Sequential data): 시간 또는 순서에 따라 데이터가 나열된 형태
- 타임스텝(Time step): 순차 데이터에서 데이터가 발생하는 각 간격 단위
- 시계열 데이터(Time-series data): 일정 시간 간격으로 수집되는 데이터(예: 온도, 센서 신호)
- 기존 완전 연결 신경망(fully connected neural networks), **합성곱 신경망(CNN)**은 순차 데이터 처리에 적합하지 않음
- 순차 데이터 특성을 반영한 모델로 **순환 신경망(RNN, Recurrent Neural Network)**이 고안됨

### 순환 신경망 구조와 동작 원리
- 기본 인공신경망과 달리, 순환 신경망은 자기 자신에게 출력을 다시 입력하는 순환 고리를 가짐
- 이 순환 고리는 이전 타임스텝의 출력을 다음 타임스텝의 입력 처리에 재사용함으로써 순차적 의존성을 학습 가능케 함
- 타임스텝별 데이터 $a$, $b$, $c$가 순서대로 입력될 때, 
  - 첫 번째 타임스텝 $a$에서 출력 $h_a$ 생성
  - 두 번째 타임스텝 $b$ 처리 시 이전 출력 $h_a$이 재사용됨
  - 세 번째 타임스텝 $c$ 처리 시 이전 출력 $h_b$가 재사용됨
- 이전 타임스텝의 영향은 시간이 지날수록 점차 희미해지며, 최근 데이터의 영향이 더 큼

| 타임스텝 | 입력 데이터 | 출력 데이터 | 재사용된 이전 출력      |
|----------|-------------|-------------|-------------------------|
| 1        | $a$         | $h_a$       | 없음 (초기값 0)         |
| 2        | $b$         | $h_b$       | $h_a$                   |
| 3        | $c$         | $h_c$       | $h_b$ (내포 $h_a$ 포함) |

- 순환층은 여러 뉴런이 모여 하나의 셀(cell) 단위로 표현됨
- 순환층의 출력은 일반 신경망에서의 특성맵 대신 **은닉 상태(hidden state, $h$)**라 부름

### 활성화 함수: 하이퍼볼릭 탄젠트 함수 (tanh)
- 순환 신경망에서 주로 사용되는 활성화 함수는 tanh 함수 (하이퍼볼릭 탄젠트)
- tanh 함수의 역할
  - 입력 값을 -1에서 1 사이로 압축
  - 비선형성을 부여하여 복잡한 패턴 학습 가능
- tanh 함수는 로지스틱 함수(시그모이드)와 유사하지만 출력 범위가 다름 표현:
  > $$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$

### 순환층의 시간에 따른 펼침 (Time Unrolling)
- 순환 신경망의 순환 구조는 시간에 따라 펼쳐서 표현 가능
- 타임스텝별 은닉 상태 $h_1$, $h_2$, $h_3$, ... 가 순서대로 계산됨
- 각 타임스텝에 동일한 가중치 행렬 $W_x$, $W_h$가 공유됨 (가중치는 변하지 않음)

| 구성 요소 | 설명                                  |
|-----------|---------------------------------------|
| $x_t$     | 타임스텝 $t$에서의 입력 벡터          |
| $h_t$     | 타임스텝 $t$에서의 은닉 상태 출력     |
| $W_x$     | 입력에 곱해지는 가중치 행렬           |
| $W_h$     | 이전 은닉 상태에 곱해지는 가중치 행렬 |

- 펼친 그림에서 각 타임스텝이 독립적으로 그려졌지만, 실제로는 모든 타임스텝에 동일한 가중치가 사용됨
- 순환층은 하나의 층(Layer)이며, 여러 층을 쌓아 심층 순환 신경망을 구성 가능

### 순환층 내부 뉴런의 상호 연결
- 순환층 내 뉴런(유닛)들은 서로 완전 연결되어 있음
- 각 뉴런 출력은 자기 자신뿐 아니라 모든 다른 뉴런에게도 전달됨
- 입력층의 각 특성도 뉴런 전체에 전달되는 구조와 유사함
- 복잡한 연결을 단순화하기 위해 순환층을 하나의 셀로 표현함

### 순차 데이터의 입력과 차원 구조
- 일반 인공신경망은 샘플 하나가 특성 벡터 형태
- 합성곱 신경망은 2차원(높이, 너비) 또는 3차원(깊이 포함) 배열 입력
- 순환 신경망은 3차원 배열 입력:
  - 첫 번째 차원: 샘플 개수
  - 두 번째 차원: 시퀀스 길이(타임스텝 수)
  - 세 번째 차원: 각 타임스텝의 특성 벡터 크기
예) 텍스트 샘플 "I am boy"
| 단어 | 특성 벡터 크기 | 설명 |
|------|----------------|------|
| I | 3 | 단어 "I"를 3차원 벡터로 표현 |
| am | 3 | 단어 "am"을 3차원 벡터로 표현 |
| boy | 3 | 단어 "boy"를 3차원 벡터로 표현 |

- 입력 데이터 형태: (샘플 수, 시퀸스 길이, 특성 크기)
- 예: (1,5,3) -> 1개 샘플, 5 타임스텝, 3차원 특성 벡터

### 순환층 출력 구조와 다층 RNN
| 특징 | 설명 |
|------|------|
| 출력 차원 | 시퀀스 길이와 무관, 뉴런 개수(은닉 상태 크기)만큼 출력됨
| 다층 순환 신경망 (Stacked RNN) | 첫 번째 층은 모든 타임스텝에서 은닉 상태를 출력하고, 두 번째 층은 마지막 타임스텝 출력만 생성 가능 |
| 출력 연결 | 순환층 출력 -> 완전 연결(Dense) 층 -> 최종 분류/회귀 결과 생성 |

- 타임스텝별 은닉 상태 전체를 출력하려면 첫 번째 층에서 <mark>return_sequences=True</mark> 설정 필요
- 마지막 층은 보통 최종 타임스텝 출력만 반환하여 분류 등에 사용

### 순차 데이터 순서 중요성
- 일반 신경망과 달리 순환 신경망은 입력 데이터 순서가 매우 중요
- 순서가 섞이면 의미 왜곡 발생 (예: 텍스트 "I love you" -> 무작위 섞임 -> 의미 상실)
- 따라서 데이터의 순서 유지가 필수적임

### 정리: 순환 신경망의 핵심 특징과 처리 방식
| 구분 | 설명 |
|------|------|
| 데이터 유형 | 순서가 중요한 순차 데이터 (텍스트, 시계열 등) |
| 구조 | 자기 자신으로 출력을 되돌리는 순환 고리 존재 |
| 입력 차원 구조 | (샘플 수, 시퀀스 길이, 특성 크기)의 3차원 텐서 |
| 은닉 상태 | 각 타임스텝별로 계산되며 이전 은닉 상태가 재사용됨 |
| 가중치 공유 | 모든 타임스텝에서 동일한 가중치 행렬 $W_x$, $W_h$ 사용 |
| 활성화 함수 | 하이퍼볼릭 탄젠트(tanh)함수 주로 사용 |
| 다층 구성 | 여러 순환층을 쌓아 심층 RNN 구성 가능 |
| 출력 처리 방식 | 마지막 타임스텝 출력 혹은 모든 타임스텝 출력 선택 가능 |
| 순서 중요성 | 데이터 순서 유지 필수, 순서 섞이면 의미 왜곡 |

순환 신경망은 순차 데이터의 시간적 특성을 내재한 구조를 통해 각 시점의 입력과 이전 은닉 상태를 통합적으로 처리함으로써 순서에 따른 정보 흐름과 기억을 가능하게 한다. 가중치 공유와 은닉 상태의 반복적 계산은 시간 축을 따라 동일한 변환을 수행하여 데이터의 순차적 패턴을 효과적으로 학습한다. 또한 다층으로 확장하면 더욱 복잡한 시퀀스 패턴을 포착할 수 있으며, 순서가 유지되는 입력 설계가 모델 성능의 핵심이 된다.

## 24강 순환 신경망으로 IMDB 리뷰 분류하기
### IMDB 리뷰 분류를 위한 순환 신경망 모델링
IMDB 리뷰 데이터셋을 활용하여 순환 신경망(RNN)으로 영화 리뷰의 긍정/부정을 분류하는 과정과 관련 용어, 데이터 전처리, 인코딩 및 임베딩 방법을 학습한다.

#### 1. IMDB 리뷰 데이터셋 개요
- IMDB 데이터셋
  - 영화 리뷰 텍스트가 담긴 데이터셋
  - 긍정적 리뷰 25,000개, 부정적 리뷰 25,000개로 구성
  - 각 단어는 고유 정수 인덱스로 매핑되어 있음 (케라스가 토큰화 및 인덱싱 처리 완료)
- 용어 설명 
  - 토큰화 (Tokenization): 텍스트 데이터를 분석 가능한 최소 단위(토큰)로 나누는 과정입니다. 
  - 어휘사전 (Vocabulary): 데이터셋에 등장하는 고유 단어들의 집합으로, 각 단어는 고유한 인덱스로 매핑됩니다.
  - 패딩(Padding): 서로 길이가 다른 텍스트 시퀀스를 동일한 길이로 맞추기 위해 특정 값(보통 0)을 추가하여 길이를 통일하는 기술입니다.
  - 임베딩(Embedding): 단어를 고차원의 희소 벡터가 아닌, 의미를 내포한 저차원의 밀집된 실수 벡터로 표현하는 방법입니다.
  - 시그모이드 함수 (Sigmoid Function): 입력값을 0과 1 사이의 확률값으로 변환해 주는 활성화 함수로, 주로 이진 분류 문제의 출력층에서 사용됩니다.
  - 과적합 (Overfitting): 모델이 훈련 데이터에 너무 과도하게 맞춰져서, 새로운 데이터에 대한 성능이 떨어지는 현상입니다.

#### 2. 데이터셋 구조 및 특징
- 케라스 IMDB 데이터셋은 이미 토큰화 및 인덱싱이 완료된 정수 시퀀스로 제공됨
- 리뷰 길이 다양성: 리뷰마다 길이가 다름
- 데이터 형태 
  - 훈련 입력: 파이썬 리스트(서로 길이가 다름)
  - 타겟(정답): 0 또는 1 (부정/긍정) 이진 분류 문제
- 리뷰 길이 통계
  - 평균 약 200 토큰
  - 중앙값 178 토큰
  - 분포는 짧은 리뷰가 많고 긴 리뷰는 적은 편(우측 치우침)

#### 3. 시퀀스 길이 맞추기: 패딩 (Padding)
- 이유: RNN 입력은 3차원 텐서로, 각 배치 샘플의 시퀀스 길이가 동일해야 함
- 처리 방법
  - 긴 리뷰는 자름 (max length 초과 시)
  - 짧은 리뷰는 0으로 패딩 (제로 패딩)
  - 패딩 위치는 시퀀스 앞부분에 채우는 pre-padding 방식 사용
    - 이유: RNN의 마지막 타임스텝 출력이 중요 -> 실제 텍스트가 뒤쪽에 위치하도록 하기 위함
- 케라스 함수 <mark>pad_sequences</mark> 사용
  - 예: <mark>pad_sequences(train_input, maxlen=100, padding='pre')</mark>
  - 결과: 모든 시퀀스 길이가 100으로 통일됨 (2만 개 샘플 x 100 타임스텝)

#### 4. 순환 신경망 모델 구성 (케라스 활용)

| 구성 요소           | 설명                                                                                                   |
|---------------------|--------------------------------------------------------------------------------------------------------|
| 입력층(Input layer) | 시퀀스 길이 100, 각 타임스텝은 단어 인덱스(정수)로 표현                                                |
| 임베딩 차원         | 단어마다의 벡터 크기(초기에는 무작위 실수로 초기화, 학습을 통해 단어 의미를 담은 임베딩 벡터로 최적화) |
| RNN 층 (SimpleRNN)  | 유닛 수 8, 순환층으로 시퀀스 처리                                                                      |
| 출력층              | 뉴런 1개, 활성화 함수 시그모이드 -> 이진 분류 결과 출력                                                |

- 모델은 <mark>Sequential</mark> API 또는 함수형 API로 구성 가능
- 출력값은 긍정(1) / 부정(0) 확률로 해석 가능

#### 5. 텍스트 데이터 인코딩 방법 
##### 5-1. 원-핫 인코딩 (One-hot encoding)
- 각 단어를 고유 인덱스에 대응하는 벡터로 변환
- 벡터 크기 = 어휘사전 크기 (예: 200)
- 단어가 인덱스 10이라면 10번째 위치만 1이고 나머지는 0인 200차원 벡터 생성
- 결과 텐서 크기: (샘플 수) x (시퀀스 길이) x (어휘 크기)
- 단점: 매우 큰 메모리 사용, 희소 벡터(sparse vector) 발생
- 케라스 함수: <mark>to_categorical</mark> 사용

##### 5-2. 임베딩 (Embedding)
- 단어를 고정 크기 실수 벡터로 표현하는 방법
- 예: 500개의 단어를 16차원 벡터로 매핑 -> 500x16 크기의 임베딩 행렬
- 임베딩 벡터는 학습 과정에서 최적화
- 단어 간 의미적 유사도(예: <mark>cat</mark>과 <mark>dog</mark> 벡터가 가깝게 위치)를 계산 가능
- 메모리 효율이 높고, 단어 의미 표현에 효과적
- 케라스의 <mark>Embedding</mark> 층 사용
- 초기 임베딩 행렬은 랜덤 초기화되고 학습에 따라 개선됨

#### 6. 인코딩과 임베딩 비교 및 활용
| 구분        | 원-핫 인코딩                          | 임베딩                                | 
|-------------|---------------------------------------|---------------------------------------|
| 벡터 형태   | 희소 벡터 (0과 1만 존재)              | 밀집된 실수 벡터                      |
| 차원 수     | 어휘 크기만큼 (예: 200)               | 임베딩 차원 수 (예: 16~200) 선택 가능 |
| 메모리 사용 | 매우 큼                               | 상대적으로 작음                       |
| 의미 표현력 | 단어 간 관계 반영 불가                | 단어 의미 유사도 반영 가능            |
| 구현 방법   | <mark>to_categorical</mark> 함수 사용 | 케라스 <mark>Embedding</mark> 층 사용 |

#### 7. 모델 훈련 및 평가
- 옵티마이저, 손실 함수 설정
  - 이진 분류이므로 손실 함수는 <mark>binary_crossentropy</mark> 사용 
- 콜백 함수로 조기 종료(Early Stopping) 적용 가능
- 훈련 과정에서 검증 세트를 분리하여 과적합 여부 확인
- 임베딩 층을 사용하면 메모리 효율이 좋아지고, 성능 향상 가능
- 훈련 후 정확도 및 손실 곡선으로 모델 성능 평가

#### 8. 자연어 처리와 순환 신경망의 역사적 맥락
- NLP 분야에서 과거에는 순환 신경망이 대표적인 텍스트 처리 방법이었음
- 10장 이후 트랜스포머 모델이 등장하면서 NLP의 주류가 크게 변화됨
- 임베딩 기술은 트랜스포머 모델의 근간을 이루는 핵심 개념임
- 초기에는 이러한 계산적 접근법이 기존 언어학적 전통과 달라 저항이 있었으나, 뛰어난 실용성과 성능을 바탕으로 점차 인정받게 됨

#### 9. 핵심 키워드 정리

|-----------------------|---------------------------------------------------|

| 데이터 전처리         | 패딩, 시퀀스 길이, pre-padding                    |
| 모델 구성             | 순환 신경망, SimpleRNN, 시그모이드                |

## 25강 LSTM과 GRM 셀
### LSTM 셀 구조와 작동 원리
"LSTM(Long Short-Term Memory)"은 긴 텍스트에서 앞쪽 정보를 기억하지 못하는 문제를 해결하기 위해 단기 기억을 늘려 주는 순환 신경망 셀이다."

#### LSTM 셀의 주요 특징
|    구분     |                                         설명                                          |
|-------------|---------------------------------------------------------------------------------------|
| 상태(state) | 은닉 상태(hidden state)와 셀 상태(cell state) 두 가지 상태를 가짐                     |
|  입력 처리  | 입력과 이전 타임스텝 은닉 상태를 하나로 묶은 가중치에 곱하여 새로운 은닉 상태 계산    |
| 활성화 함수 | 시그모이드 함수와 탄젠트 함수(tanh)를 사용하여 게이트 출력을 조절                     |
|    출력     | 은닉 상태는 외부(다음 층 혹은 모델 출력)로 전달되지만, 셀 상태는 내부 순환에만 사용됨 |

#### LSTM 셀 내부 게이트
|       게이트 이름        | 역할 설명                                                              | 수학적 처리                                                   |
|--------------------------|------------------------------------------------------------------------|---------------------------------------------------------------|
| 삭제 게이트(forget gate) | 이전 셀 상태에서 어떤 정보를 잊을지 결정 (정보 삭제 역할)              | 시그모이드 함수 출력과 이전 셀 상태의 곱                      |
| 입력 게이트(input gate)  | 현재 입력으로부터 어떤 정보를 셀 상태에 추가할지 결정 (정보 추가 역할) | 시그모이드 함수 출력과 탄젠트 함수 출력을 곱해 셀 상태에 더함 |
| 출력 게이트(output gate) | 은닉 상태를 생성하여 모델의 다음 층 혹은 결과로 내보낼 출력을 결정     | 시그모이드 함수 출력과 탄젠트 함수 출력을 곱해 은닉 상태 생성 |

- 각 게이트는 서로 다른 가중치(WF, WI, WJ, WO 등)를 사용해 더 복잡한 패턴과 정보를 저장 가능
- 게이트의 구체적 역할은 모델 훈련 과정에서 자동 학습되므로 사전 정의가 어렵다. 

#### LSTM 셀 작동 흐름
1. 이전 은닉 상태와 현재 입력을 하나의 벡터로 묶어 가중치와 곱함.
2. 시그모이드 및 탄젠트 함수를 통해 게이트별 출력을 만듦.
3. 삭제 게이트 출력을 이전 셀 상태와 곱하여 일부 정보를 제거.
4. 입력 게이트 출력을 새로운 후보 셀 상태와 곱해 추가할 정보 결정.
5. 위 두 결과를 더해 새로운 셀 상태 생성.
6. 출력 게이트 출력을 셀 상태의 탄젠트 함수값과 곱해 은닉 상태 생성.
7. 은닉 상태가 다음 층 또는 출력으로 전달됨.

### LSTM 모델 구현과 학습
- 케라스(Keras)의 <mark>LSTM</mark> 층을 사용해 간단히 구현 가능
- 심플 RN(Simple RNN)과 비교 시 파라미터 수가 약 4배 증가 (예: 200 -> 800)
  - 이유: LSTM은 네 개의 서로 다른 가중치 벡터를 사용하기 때문
- 과대적합 문제 발생시 <mark>dropout</mark>과 <mark>recurrent_dropout</mark> 매개변수로 규제 가능
- 다중 순환층 연결 시, 마지막 층을 제외한 앞선 층에서는 <mark>return_sequences=True</mark> 설정 필요
  - 그래야 각 타임스텝별 은닉 상태를 다음 층으로 전달 가능
- 모델 학습은 기존 순환 신경망과 동일한 방식으로 진행

### GRU 셀 구조와 작동 원리
"GRU(Gated Recurrent Unit)는 LSTM 셀보다 구조가 단순하지만 비슷한 목적을 가진 순환 셀로, 게이트를 통해 정보를 제어한다."

#### GRU 셀의 주요 특징 및 게이트
| 게이트 이름        | 역할 설명                                                  | 수학적 처리 요약                                                               |
|--------------------|------------------------------------------------------------|--------------------------------------------------------------------------------|
| 업데이트 게이트(z) | 현재 상태를 얼마나 유지할지 결정 (LSTM의 삭제 게이트 유사) | 입력과 은닉 상태를 가중치와 곱해 시그모이드 함수 적용 후 원래 은닉 상태에 곱함 |
| 리셋 게이트(r)     | 이전 은닉 상태 정보를 얼마나 반영할지 조절                 | 입력과 은닉 상태를 가중치와 곱해 시그모이드 함수 적용                          |
| 후보 은닉 상태     | 리셋 게이트에 의해 조절된 은닉 상태와 입력을 바탕으로 계산 | 탄젠트 함수 적용                                                               |

- GRU는 LSTM보다 게이트 수가 적어 파라미터 수가 적음
- 실제 구현 시 입력과 은닉 상태에 곱해지는 가중치를 분리하여 효율적으로 처리
- 파라미터 수는 심플 RN 대비 약 3배 이상 증가 (예: 200 -> 약 624)
- 게이트 역할 역시 훈련 과정에서 학습되어 명확한 역할 구분이 어려움

### GRU 모델 구현과 학습
- 케라스의 <mark>GRU</mark>층으로 쉽게 구현 가능
- LSTM과 마찬가지로 기존 순환 신경망 학습 방식과 동일
- 파라미터 수 계산 시 절편(bias) 추가로 인해 단순 곱셈보다 약간 더 많음
- 인터넷 및 논문에서 보통 왼쪽에 GRU 게이트 구조 그림으로 설명됨

# Ch10. 언어 모델을 위한 신경망
## 26강 어텐션 메커니즘과 트랜스포머
### 인코더-디코더 신경망과 시퀀스투시퀀스 모델
- 인코더-디코더 신경망: 입력 시퀀스를 받고 출력 시퀀스를 생성하는 두 개의 신경망으로 구성됨
- 예시: 한국어 입력 -> 영어 출력 (번역, 요약 작업에 활용)
- 시퀀스투시퀀스 모델: 입력과 출력이 모두 시퀀스인 모델
- 인코더는 입력 토큰을 시간 순서대로 처리 (타임스텝별)
- 디코더는 마지막 인코더 은닉 상태를 받아 타임스텝별로 출력 생성
- 디코더는 이전 출력 토큰을 참조(자기회귀 모델)하여 다음 토큰 생성

### 순환 신경망(RNN)의 한계와 어텐션 메커니즘 등장 배경
- 긴 텍스트를 하나의 은닉 상태에 모두 압축하는 것은 어려움
- LSTM, GRU 셀도 긴 시퀀스 정보를 저장하는 데 한계 존재
- 어텐션 메커니즘: 인코더의 모든 타임스텝 은닉 상태를 디코더가 참조
- 각 인코더 은닉 상태에 어텐션 가중치(α)를 곱해 적절히 조합
- 어텐션 가중치는 학습 과정에서 자동으로 최적화됨
- 단점: 은닉 상태를 모두 저장하고 참조하기 때문에 메모리 사용량 증가, 입력 길이 제한 발생

| 기존 RNN 구조                    | 어텐션 메커니즘 적용 구조               |
|----------------------------------|-----------------------------------------|
| 마지막 은닉 상태만 디코더에 전달 | 모든 타임스텝 은닉 상태를 디코더가 참조 |
| 긴 문장 정보 압축 어려움         | 가중치로 중요한 부분에 집중 가능        | 
| 입력 길이 제한 없음              | 메모리 제한으로 입력 길이 제한 존재     | 

### 트랜스포머(Transformer) 모델 개요
- 2017년 구글 연구팀이 개발한 모델
- 순환 신경망(RNN) 완전 제거, 어텐션 구조만 사용
- 인코더-디코더 구조 유지
- 인코더는 입력 시퀀스를 동시에 처리 (병렬 처리 가능 -> 속도 향상)
- 디코더는 자기회귀 구조 유지하며 타임스텝별 토큰 생성
- 인코더 출력은 은닉 상태 대신 **단어 벡터(임베딩 벡터)**로 표현 
- 각 입력 토큰마다 벡터 생성 -> 어텐션 가중치로 조합 (셀프 어텐션)

| 구분           | RNN 기반 인코더-디코더     | 트랜스포머 인코더-디코더        |
|----------------|----------------------------|---------------------------------|
| 입력 처리 방식 | 타임스텝별 순차 처리       | 모든 토큰 동시 처리 (병렬)      |
| 출력 처리 방식 | 타임스텝별 생성 (자기회귀) | 타임스텝별 생성 (자기회귀 유지) |
| 은닉 상태 용어 | 은닉 상태                  | 단어 벡터(임베딩 벡터)          | 
| 속도           | 느림                       | 빠름                            |

### 셀프 어텐션(Self-Attention) 메커니즘
- 입력 토큰 각각에 대해 Query (Q), Key (K), Value (V) 벡터 생성 (밀집층 사용)
- 어텐션 가중치 계산: Q와 K의 곱을 통해 각 토큰이 다른 토큰에 얼마나 주목하는지 결정
- 어텐션 가중치에 따라 V 벡터를 가중합하여 최종 은닉 벡터 생성
- 입력 토큰 개수만큼 최종 은닉 벡터 생성 (입력과 출력 벡터 개수 일치)
- 모델이 스스로 중요한 토큰에 집중할 수 있는 구조 

| 용어 | 역할 |
|------|------|
| Query (Q) | 현재 토큰이 주목할 대상 토큰을 찾는 질문 벡터 |
| Key (K) | 각 토큰이 가진 정보의 특징 벡터 |
| Value (V) | 실제로 가중합되어 최종 결과에 반영되는 정보 벡터 |
| 어텐션 가중치 | $Q$, $K$의 내적 결과로 계산, 중요도 반영 |

### 멀티헤드 어텐션(Multi-Head Attention)
- 단일 어텐션 헤드로는 제한된 패턴 학습 가능성 존재
- 여러 개의 어텐션 헤드를 병렬로 실행하여 다양한 패턴 추출
- 각 헤드는 독립적으로 Q, K, V 계산 -> 개별 결과 생성
- 모든 헤드 출력 결과를 연결(concatenate) 후 밀집층 통과 -> 최종 벡터 생성
- 최종 벡터 차원은 입력 단어 벡터 차원과 동일 유지

| 멀티헤드 어텐션 구성 요소 | 설명 |
|---------------------------|------|
| 여러 개 어텐션 헤드 | 병렬로 Q, K, V 계산, 다양한 시각으로 주목 |
| 연결 (Concatenate) | 각 헤드 결과를 이어 붙임 |
| 밀집층 (Dense layer) | 연결된 결과를 다시 원래 차원으로 변환 |

### 정규화와 잔차 연결(Residual Connection)
| 용어 | 역할 및 특징 |
|------|--------------|
| 층 정규화(Layer Normalization) | 각 토큰별로 입력 벡터를 정규화하여 학습 안정성 및 속도 향상. 순차 데이터에 적합한 정규화 방식. |
| 배치 정규화(Batch Normalization) | 샘플 채널별 정규화. 합성곱 신경망에 주로 사용. 텍스트 시퀀스 데이터에는 부적합할 수 있음. |
| 잔차 연결(Residual Connection) | 입력을 출력에 더해 원소별 덧셈 수행. 매우 깊은 네트워크에서도 효과적으로 훈련 가능하게 함. 입력과 출력 차원 동일해야 함. |
|
- 잔차 연결은 ResNet에서 최초 도입된 기법
- 트랜스포머 모델에서 반복적으로 층을 쌓을 때 훈련 안정성에 기여
- 정규화 위치는 모델마다 다를 수 있음 (기존 트랜스포머는 잔차 연결 후, 최신 모델은 잔차 연결 전)
- 드롭아웃(dropout)도 잔차 연결과 정규화 사이에 적용 가능 (모델에 따라 다름)

### 위치별 완전 연결 신경망 (Position-wise Feed-Forward Network)
- 인코더/디코더 블록 내 두 개의 밀집층(Dense layer)이 연속으로 존재
- 첫 번째 밀집층은 단어 벡터 차원의 4배 크기로 확장 (정보 저장력 증가)
- 활성화 함수로 ReLU 사용 -> 비선형 변환 수행
- 두 번째 밀집층에서 다시 원래 크기로 차원 축소
- 드롭아웃과 잔차 연결, 층 정규화와 함께 사용
- 최종 출력 벡터 크기는 입력과 동일하여 다음 층으로 전달 가능

| 구성 요소 | 기능 및 역할 |
|-----------|--------------|
| 첫 번째 밀집층 | 차원 확장(보통 4배) 및 비선형 변환 |
| ReLU 활성화 함수 | 비선형성 부여 |
| 두 번째 밀집층 | 차원 축소(원래 크기로 복원) |
| 드롭아웃 | 과적합 방지 |
| 잔차 연결 및 층 정규화 | 학습 안정화 및 깊은 네트워크 지원 |

### 인코더와 디코더 블록 구조 비교
| 구성 요소 | 인코더 블록 | 디코더 블록 |
|-----------|-------------|-------------|
| 셀프 어텐션 | 멀티헤드 셀프 어텐션 | 마스크드 멀티헤드 셀프 어텐션 (미래 토큰 가림) |
| 크로스 어텐션 | 없음 | 인코더 출력(키, 값)와 디코더 입력(쿼리) 연결 |
| 피드포워드 네트워크 | 두 개의 밀집층 + ReLU + 드롭아웃 + 잔차 연결 | 동일 |
| 층 정규화 | 각 주요 단계 전후에 적용 | 동일 | 
| 잔차 연결 | 입력과 출력 벡터 크기 동일 유지 | 동일 |

- 디코더는 미래 토큰을 보지 못하도록 마스킹하여, 학습 시 다음 토큰 예측 오류 방지
- 크로스 어텐션은 디코더가 인코더 출력을 참조하여 번역 등 문맥 반영 가능하게 함
- 인코더 블록 여러 개가 쌓여 단어 벡터를 점차 정교하게 추출
- 디코더 블록도 여러 개 쌓여 점진적으로 출력 토큰 생성

### 요약 핵심 개념 표 
| 개념 | 설명 | 주요 특징 및 역할 |
|------|------|-------------------|
| 인코더-디코더 신경망 | 입력 시퀀스 -> 출력 시퀀스 생성하는 쌍으로 된 신경망 | 번역, 요약 등 시퀀스투시퀀스 작업에 필수 | 
| 어텐션 메커니즘 | 인코더 모든 타임스텝 은닉 상태에 가중치 곱해 참조 | 긴 문장 처리 성능 향상, 메모리 제한 있음 |
| 트랜스포머 | RNN 제거, 어텐션만 활용, 인코더는 병렬 처리 | 속도 빠름, 대규모 언어 모델 근간 | 
| 셀프 어텐션 | 입력 토큰 스스로 어떤 토큰에 집중할지 결정 | Query, Key, Value 벡터 사용 |
| 멀티헤드 어텐션 | 여러 어텐션 헤드 병렬 처리로 다양한 패턴 학습 | 패턴 다양성 증가 | 
| 잔차 연결 | 입력을 출력에 더해 깊은 네트워크 학습 안정화 | ResNet 기법, 차원 동일 유지 필수 | 
| 층 정규화 | 각 토큰별 벡터 정규화하여 학습 안정성 및 속도 향상 | 배치 정규화와 달리 시퀀스 데이터에 적합 |
| 위치별 피드포워드 네트워크 | 두 개 밀집층 + ReLU 활성화, 차원 확장 후 축소 | 정보 저장력 증가, 비선형 변환 |
| 디코더 마스킹 | 미래 토큰을 보지 못하도록 가림 | 올바른 자기회귀 학습 구조 유지 | 

트랜스포머 모델은 입력 시퀀스의 모든 토큰을 병렬로 처리하며, 셀프 어텐션 메커니즘을 통해 각 토큰이 문맥 내에서 중요한 부분에 집중할 수 있도록 한다. 멀티헤드 어텐션은 다양한 의미적 패턴을 병렬로 포착하고, 잔차 연결과 층 정규화는 모델이 깊어져도 안정적인 학습을 가능하게 한다. 위치별 피드포워드 네트워크는 비선형 변환과 정보 저장을 담당하며, 디코더는 마스크드 어텐션으로 미래 정보를 차단해 정확한 다음 토큰 예측을 수행한다. 이러한 구성 요소들이 복합적으로 작동해 대규모 언어 모델의 성능과 효율성을 극대화한다.

## 27강 트랜스포머로 상품 설명 요약하기
### 트랜스포머 모델 기반 상품 설명 요약
> "트랜스포머 모델은 인코더, 디코더, 그리고 인코더-디코더 결합 구조로 발전해 왔으며, 각 구조는 언어 처리 작업에 특화되어 있다."

#### 트랜스포머 모델의 분류와 특징
| 모델 유형              | 주요 특징                                               | 대표 모델 예시        | 활용 분야                        |
|------------------------|---------------------------------------------------------|-----------------------|----------------------------------|
| 비트랜스포머 초기 모델 | 언어 모델 초기, 단어 임베딩 벡터 생성에 기여            | -                     | 단어 임베딩 생성                 |
| 인코더 기반 모델       | 입력 텍스트를 임베딩 벡터로 변환, 분류·개체명 인식 특화 | BERT, ALBERT, RoBERTa | 텍스트 분류, 개체명 인식         |
| 인코더-디코더 모델     | 입력과 출력 모두 시퀀스, 번역·요약·질문 답변에 강점     | T5, BART              | 번역, 요약, 질문답변             |
| 디코더 기반 모델       | 텍스트 생성 특화, 미세 튜닝 가능                        | GPT-3, ChatGPT        | 텍스트 생성, 챗봇, 요약, 번역 등 |

- 오픈소스 vs 독점 모델
  - 바탕색 모델: 오픈소스
  - 하얀 박스 모델: 독점/유료 모델
  - 2022~2023년부터 메타의 LLaMA 모델을 중심으로 오픈소스 모델 재부상

### 전이학습(Transfer Learning)과 트랜스포머
- 전이학습: 사전 훈련된 모델을 새로운 작업에 적용하는 기술.
- 컴퓨터 비전에서 이미지넷 기반 전이학습이 주로 사용됨.
- 자연어처리에서는 순환 신경망(RNN)의 한계로 전이학습이 어려웠으나, 트랜스포머 등장 이후 적용 가능. 
- 대규모 텍스트 데이터(인터넷, 책)로 사전 훈련 후, 미세 튜닝(fine-tuning)하여 다양한 NLP 작업에 활용.
- 미세 튜닝은 일부 층만 파인튜닝하거나 전체 모델을 조정하는 방식으로 수행.

#### BART 모델과 구조
- 메타에서 2019년 공개한 인코더-디코더 트랜스포머 모델
- 파라미터 수:
  - Base 모델 약 1억 2천만 개
  - Large 모델 약 4억 개
- 구조:
  1. 토큰 임베딩 -> 인코더 모듈(연속 통과) -> 디코더 모듈에 전달
  2. 인코더와 디코더 모두 위치 임베딩 사용 (랜덤 초기화 후 학습 가능)
  3. 인코더, 디코더는 모두 층 정규화, 드롭아웃, 잔차 연결 포함
  4. 디코더는 크로스 어텐션을 통해 인코더 출력과 상호작용
- 최종 출력은 768차원 벡터 -> 5,265개 토큰 확률로 변환하기 위해 밀집충(Dense) 사용 
- 임베딩층 가중치(weight)와 출력층 가중치 공유(가중치 행렬 회전 활용)하여 학습 효율 향상 

| 구성 요소          | 설명                                                                  |
|--------------------|-----------------------------------------------------------------------|
| 토큰 임베딩 층     | 입력 토큰을 768차원 벡터로 변환                                       | 
| 위치 임베딩 층     | 토큰 순서 정보를 벡터에 주입 (삼각 함수 방식 또는 학습 가능한 임베딩) |
| 인코더 블록        | 멀티헤드 어텐션, 피드포워드 네트워크, 층 정규화, 드롭아웃 포함        |
| 디코더 블록        | 마스크드 셀프 어텐션, 크로스 어텐션, 피드포워드 네트워크 포함         |
| 밀집 출력층(Dense) | 768차원 -> 5,265차원 토큰 확률 분포 변환                              |
| 임베딩 가중치 공유 | 입력 임베딩과 출력층 가중치를 회전하여 공유                           |

#### GRLU 활성 함수
- BART 모델에서 피드포워드 네트워크 활성화 함수로 사용
- 공식적으로는 Gaussian Error Linear Unit (GELU)
- 수식 개념:
  > 
  ```
  GELU(x)=x⋅Φ(x)
  ```
여기서 Φ(x)는 표준 정규 분포의 누적분포함수(CDF)
- ReLU와 달리 미분 가능하며, 부드러운 곡선 형태를 가짐
- 계산 효율을 위해 근사식 사용

#### 활성함수 비교
| 함수명 | 형태 및 특징                             |
|--------|------------------------------------------|
| ReLU   | f(x)=max(0,x), 비선형, 비미분점 존재     |
| GELU   | x에 확률밀도 함수 곱, 부드럽고 미분 가능 |

#### KoBART 모델과 활용법
- 한국어에 특화된 BART 기반 모델
- SKT에서 공개. 허깅페이스(Hugging Face) 트랜스포머 라이브러리로 사용 가능
- 파이프라인(pipeline) 함수로 간단하게 요약 작업 수행 가능
  - 예) <mark>pipeline(task="summarization", model="skt/kobart")</mark>
- 입력: 요약할 긴 텍스트
- 출력: 간결하게 요약된 텍스트

#### 활용 예시
| 과정            | 설명                                         |
|-----------------|----------------------------------------------|
| 모델 로드       | 허깅페이스 모델 리포지토리에서 불러오기      | 
| 파이프라인 생성 | <mark>summarization</mark> 태스크 지정       |
| 텍스트 입력     | 원본 문장 또는 문서 입력                     |
| 요약 결과 출력  | 자동으로 핵심 내용 요약                      |

#### 토크나이저(Tokenization) 및 토크나이징 방식
- 토크나이저는 텍스트를 토큰 단위로 분할하고 정수 인덱스로 변환하는 별도 프로그램/모델
- LM(Large Model) 내부가 아닌 독립적으로 존재
- 어휘 사전(vocabulary)과 토큰-정수 매핑 포함
- 토크나이징 방식 종류 및 특징

| 방식                     | 설명                                           | 용도 및 장점                              | 
|--------------------------|------------------------------------------------|-------------------------------------------|
| 공백 기반                | 단순히 공백으로 토큰 분리                      | 가장 단순, 하지만 어미 변화 문제          |
| WordPiece                | 단어를 부분 단어(Subword) 단위로 분해          | 어휘 수 감소, 희귀 단어 처리 가능         |
| Byte Pair Encoding (BPE) | 자주 출현하는 문자 쌍을 병합하여 토큰 생성     | 어휘 효율적 관리, 다양한 언어에 적용 가능 |
| SentencePiece            | 언어 독립적, 유니코드 기반 서브워드 토크나이저 | 공백 없는 언어에도 적합                   |

- 복잡한 어미 변화, 언어 특성에 대응하기 위해 부분 단어 토크나이징이 주류
- 토크나이저는 모델 입력의 정수 시퀀스를 생성하며, 이 시퀀스가 임베딩 층으로 전달됨

#### 트랜스포머 모델 요약 작업 과정
1. 입력 텍스트 토크나이징 -> 토큰 ID 시퀀스 생성
2. 인코더 입력 -> 토큰 임베딩 + 위치 임베딩 -> 인코더 블록 통과
3. 인코더 출력 -> 디코더에 크로스 어텐션 키/값으로 전달
4. 디코더 입력 -> 이전 생성 토큰에 대한 임베딩 + 위치 임베딩
5. 디코더 블록 통과 -> 다음 토큰 확률 분포 생성 (밀집층 통해)
6. 다음 토큰 선택 및 반복 -> 자동 회귀 방식으로 요약문 생성

#### 참고 사항
- 트랜스포머 모델의 발전과 다양성은 2023년까지 엄청난 속도로 진행되어오며, 2024년 이후는 모델 수 급증으로 시각화가 어려움.
- 미세 튜닝 관련 상세 내용은 10장 3절과 별도 추천 도서 참고.
- 트랜스포머 기반 자연어처리 모델 사용 시, 사전 훈련된 모델과 토크나이저를 함께 활용하는 것이 필수.
- 실제 구현 시 허깅페이스 트랜스포머 라이브러리 활용이 매우 편리함.

## 28강 대규모 언어 모델(LLM)로 텍스트 생성하기
### 대규모 언어 모델(LLM)과 텍스트 생성
"대규모 언어 모델(LLM)은 텍스트 생성에 혁신을 가져왔으며, 다양한 오픈소스와 독점 모델들이 활발히 연구 및 활용되고 있다."

#### 1. 대규모 언어 모델 개요 및 주요 모델 소개
- 대규모 언어 모델(LLM): 텍스트 생성에 특화된 트랜스포머 디코더 기반 모델로, 최근 많은 인기를 누림.
- 대표 오픈소스 LLM
  - 메타(Meta)의 LLaMA (라마): 오픈소스 대구모 모델로 주목받음.
  - 구글의 Gemma (젬마) 모델
  - 마이크로소프트의 Pi (파이) 모델: 경량화와 높은 성능으로 유명.
- 소규모 언어 모델 (SLM, Small Language Model)
  - 중국 기업 모델: 알리바바의 Qwen(큐원), 딥스피크(DeepSeek) 등. 
- 한국 오픈소스 모델
  - LG AI 연구소의 X1 (엑사1원)
  - 네이버의 HyperCLOVA X (하이퍼클로바 X)
  - 카카오의 오픈소스 LRM
- 독점 유료 LLM 
  - OpenAI의 GPT 시리즈 (GPT-4.5 포함)
  - 앤트로픽의 Claude (클로드)
  - 구글의 Gemini (제미나이) 등

#### 2. LLM 리더보드 및 평가
| 리더보드 명칭                     | 특징 및 현황                                                                                                                                   |
|-----------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| Hugging Face Open LLM 리더보드    | 2년간 인기, 다양한 모델 성능 비교 가능, 2025년 5월 경 중단 및 아카이브됨. 최신 모델 간 성능 차이 평가 어려움, 추론 및 에이전트 성능 반영 한계. |
| LM Arena (이전 LMSYS 챗봇 아레나) | 사람 개입 평가 포함, 현재도 유용하게 사용됨.                                                                                                   |

- 리더보드는 모델 성능을 비교하는 데 참고 자료로 유용하지만, 최신 LLM의 다양한 능력과 특성을 완벽히 반영하지는 못함.

#### 3. 엑사1원(X1) 모델 구조 및 특징
- 버전: 3.5 (24억 파라미터 모델 기준)
- 파라미터 규모: 24억, 78억, 320억 파라미터 버전 존재
- 은닉 벡터 차원: 2560
- 어텐션 헤드: 32개 (그룹 쿼리 어텐션 사용)
  - 키와 값 헤드: 8개
  - 쿼리 헤드: 32개
- 밀집층: 어텐션 헤드 결과를 모아 2560차원으로 복원
- 정규화: RMS 정규화 (RMSNorm) 사용
- 피드포워드 네트워크: 
  - 입력 차원 2560 -> 확장 7168 (두 개 밀집층)
  - 활성화 함수로 실루(SiLU, Switch-GELU 계열) 적용
  - 두 밀집층 출력 곱셈(element-wise multiplication) 후 다시 2560 차원으로 축소
- 디코더 블록: 30개 반복 구조
- 입력/출력 흐름: 입력 임베딩 -> 드롭아웃 -> 30개 디코더 블록 -> RMS 정규화 -> 출력 밀집층 -> 토큰 확률 벡터 (약 102,400 크기)

#### 4. 주요 기술 설명
| 기술명                                   | 설명                                                                              | 특징 및 역할                                                    |
|------------------------------------------|-----------------------------------------------------------------------------------|-----------------------------------------------------------------|
| 멀티 쿼리 어텐션 (Multi-Query Attention) | 쿼리 헤드 여러 개 유지, 키와 값은 하나만 유지하여 효율성 증대                     | 캐싱된 키/값 재사용으로 계산 및 메모리 효율 향상                |
| 그룹 쿼리 어텐션 (Group Query Attention) | 쿼리 헤드를 몇 개 그룹으로 나누어 각 그룹이 키/값을 공유                          | 멀티 헤드와 멀티 쿼리 어텐션의 중간 형태, 효율성과 표현력 균형. |
| 실루 함수 (SiLU, SwiGLU)                 | 입력값과 시그모이드 함수를 곱한 활성화 함수, 글루 (GLU) 함수 변형                 | 기존 GELU 대비 성능 개선, X1 모델 활성화 함수로 사용            |
| RMS 정규화 (RMSNorm)                     | 층 정규화 변형. 평균을 빼지 않고 분산 계산 시 각 원소 제곱 평균으로 표준편차 산출 | 계산 효율적, 평균 제거 없이 정규화, 대규모 LLM에서 인기         |

#### 5. RMS 정규화 상세 설명
- 일반 층 정규화는 각 원소에서 평균을 빼고 분산(제곱평균)을 구함.
- RMS 정규화는 평균을 빼지 않고, 원소들의 제곱 평균으로 분산 추정.
- 표준 편차는 제곱근으로 구함.
- 정규화 시 평균 제거 과정을 생략하여 계산량 감소.
- 모델 성능 저하 없이 더 빠른 계산 가능.

#### 6. 텍스트 생성 및 디코딩 전략
- 토큰 확률 분포에서 토큰 선택 문제
  - 단순 최고 확률 토큰 선택 시 텍스트가 단조롭고 부자연스러움.
- 주요 디코딩 기법
| 기법                           | 설명                                                                          | 역할 및 효과                                     |
|--------------------------------|-------------------------------------------------------------------------------|--------------------------------------------------|
| 온도 파라미터 (Temperature)    | 확률 분포 차이를 완화, 확률이 높은 토큰과 낮은 토큰 간 차이 줄임              | 다양성 증가, 보다 자연스러운 텍스트 생성         |
| 탑 K (Top-K) 선택              | 확률 상위 K개 토큰만 후보로 선택 후 확률에 따라 랜덤 선택                     | 확률이 낮은 토큰 배제, 다양성 유지               |
| 탑 P (Top-P, Nucleus Sampling) | 누적 확률이 p 이상이 될 때까지 토큰 선택, 선택된 토큰 확률 재정규화 후 샘플링 | 동적 후보군 설정, 보다 자연스러운 확률 분포 반영 |

- 통상 탑 K를 먼저 적용 후 탑 P 적용하는 방식이 효율적.

#### 7. 엑사1원 모델 실습 및 활용
- Hugging Face Transformers 라이브러리 사용 가능.
- 텍스트 생성 파이프라인에서 <mark>task='text-generation'</mark> 설정.
- 시스템 역할과 사용자 역할 메시지를 JSON 스타일로 전달 가능. 
  - 예) 시스템 롤: "쇼핑몰 Q&A 봇", "답변 전에 친절한 안내 포함"
  - 사용자 롤: 실제 질문 텍스트 입력
- 출력 예시: 친절하고 자연스러운 답변, 정확한 답변을 위해 시간이 필요함을 안내하는 문장 등.
- 24억 파라미터 규모임에도 매우 자연스러운 텍스트 생성 가능.

#### 8. OpenAI GPT 모델 활용법
- OpenAI API를 통해 GPT-4.5 Mini 모델 등 사용 가능.
- API 키 발급 후 OpenAI 패키지에서 <mark>OpenAI</mark> 클라이언트 생성.
- 메시지 포맷은 엑사1원과 동일한 JSON 리스트 딕셔너리 형태.
- 컴플리션 호출 시 다수 응답 가능하지만 기본 1개로 설정. 
- 출력 결과 자연스럽고 실무에서 Q&A 업무에 활용 가능.
