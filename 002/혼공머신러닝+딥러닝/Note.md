## 23강 순차 데이터와 순환 신경망
### 순차 데이터와 순환 신경망 개념
순차 데이터는 시간적 또는 순서적 관계가 있는 데이터로, 대표적으로 텍스트 데이터나 시계열 데이터(온도, 센서 데이터 등)가 있다.
- 순차 데이터(Sequential data): 시간 또는 순서에 따라 데이터가 나열된 형태
- 타임스텝(Time step): 순차 데이터에서 데이터가 발생하는 각 간격 단위
- 시계열 데이터(Time-series data): 일정 시간 간격으로 수집되는 데이터(예: 온도, 센서 신호)
- 기존 완전 연결 신경망(fully connected neural networks), **합성곱 신경망(CNN)**은 순차 데이터 처리에 적합하지 않음
- 순차 데이터 특성을 반영한 모델로 **순환 신경망(RNN, Recurrent Neural Network)**이 고안됨

### 순환 신경망 구조와 동작 원리
- 기본 인공신경망과 달리, 순환 신경망은 자기 자신에게 출력을 다시 입력하는 순환 고리를 가짐
- 이 순환 고리는 이전 타임스텝의 출력을 다음 타임스텝의 입력 처리에 재사용함으로써 순차적 의존성을 학습 가능케 함
- 타임스텝별 데이터 $a$, $b$, $c$가 순서대로 입력될 때, 
  - 첫 번째 타임스텝 $a$에서 출력 $h_a$ 생성
  - 두 번째 타임스텝 $b$ 처리 시 이전 출력 $h_a$이 재사용됨
  - 세 번째 타임스텝 $c$ 처리 시 이전 출력 $h_b$가 재사용됨
- 이전 타임스텝의 영향은 시간이 지날수록 점차 희미해지며, 최근 데이터의 영향이 더 큼

| 타임스텝 | 입력 데이터 | 출력 데이터 | 재사용된 이전 출력      |
|----------|-------------|-------------|-------------------------|
| 1        | $a$         | $h_a$       | 없음 (초기값 0)         |
| 2        | $b$         | $h_b$       | $h_a$                   |
| 3        | $c$         | $h_c$       | $h_b$ (내포 $h_a$ 포함) |

- 순환층은 여러 뉴런이 모여 하나의 셀(cell) 단위로 표현됨
- 순환층의 출력은 일반 신경망에서의 특성맵 대신 **은닉 상태(hidden state, $h$)**라 부름

### 활성화 함수: 하이퍼볼릭 탄젠트 함수 (tanh)
- 순환 신경망에서 주로 사용되는 활성화 함수는 tanh 함수 (하이퍼볼릭 탄젠트)
- tanh 함수의 역할
  - 입력 값을 -1에서 1 사이로 압축
  - 비선형성을 부여하여 복잡한 패턴 학습 가능
- tanh 함수는 로지스틱 함수(시그모이드)와 유사하지만 출력 범위가 다름 표현:
  > $$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$

### 순환층의 시간에 따른 펼침 (Time Unrolling)
- 순환 신경망의 순환 구조는 시간에 따라 펼쳐서 표현 가능
- 타임스텝별 은닉 상태 $h_1$, $h_2$, $h_3$, ... 가 순서대로 계산됨
- 각 타임스텝에 동일한 가중치 행렬 $W_x$, $W_h$가 공유됨 (가중치는 변하지 않음)

| 구성 요소 | 설명                                  |
|-----------|---------------------------------------|
| $x_t$     | 타임스텝 $t$에서의 입력 벡터          |
| $h_t$     | 타임스텝 $t$에서의 은닉 상태 출력     |
| $W_x$     | 입력에 곱해지는 가중치 행렬           |
| $W_h$     | 이전 은닉 상태에 곱해지는 가중치 행렬 |

- 펼친 그림에서 각 타임스텝이 독립적으로 그려졌지만, 실제로는 모든 타임스텝에 동일한 가중치가 사용됨
- 순환층은 하나의 층(Layer)이며, 여러 층을 쌓아 심층 순환 신경망을 구성 가능

### 순환층 내부 뉴런의 상호 연결
- 순환층 내 뉴런(유닛)들은 서로 완전 연결되어 있음
- 각 뉴런 출력은 자기 자신뿐 아니라 모든 다른 뉴런에게도 전달됨
- 입력층의 각 특성도 뉴런 전체에 전달되는 구조와 유사함
- 복잡한 연결을 단순화하기 위해 순환층을 하나의 셀로 표현함

### 순차 데이터의 입력과 차원 구조
- 일반 인공신경망은 샘플 하나가 특성 벡터 형태
- 합성곱 신경망은 2차원(높이, 너비) 또는 3차원(깊이 포함) 배열 입력
- 순환 신경망은 3차원 배열 입력:
  - 첫 번째 차원: 샘플 개수
  - 두 번째 차원: 시퀀스 길이(타임스텝 수)
  - 세 번째 차원: 각 타임스텝의 특성 벡터 크기
예) 텍스트 샘플 "I am boy"

## 24강 순환 신경망으로 IMDB 리뷰 분류하기
### IMDB 리뷰 분류를 위한 순환 신경망 모델링
IMDB 리뷰 데이터셋을 활용하여 순환 신경망(RNN)으로 영화 리뷰의 긍정/부정을 분류하는 과정과 관련 용어, 데이터 전처리, 인코딩 및 임베딩 방법을 학습한다.

#### 1. IMDB 리뷰 데이터셋 개요
- IMDB 데이터셋
  - 영화 리뷰 텍스트가 담긴 데이터셋
  - 긍정적 리뷰 25,000개, 부정적 리뷰 25,000개로 구성
  - 각 단어는 고유 정수 인덱스로 매핑되어 있음 (케라스가 토큰화 및 인덱싱 처리 완료)
- 용어 설명 
  - 토큰화 (Tokenization): 텍스트 데이터를 분석 가능한 최소 단위(토큰)로 나누는 과정입니다. 
  - 어휘사전 (Vocabulary): 데이터셋에 등장하는 고유 단어들의 집합으로, 각 단어는 고유한 인덱스로 매핑됩니다.
  - 패딩(Padding): 서로 길이가 다른 텍스트 시퀀스를 동일한 길이로 맞추기 위해 특정 값(보통 0)을 추가하여 길이를 통일하는 기술입니다.
  - 임베딩(Embedding): 단어를 고차원의 희소 벡터가 아닌, 의미를 내포한 저차원의 밀집된 실수 벡터로 표현하는 방법입니다.
  - 시그모이드 함수 (Sigmoid Function): 입력값을 0과 1 사이의 확률값으로 변환해 주는 활성화 함수로, 주로 이진 분류 문제의 출력층에서 사용됩니다.
  - 과적합 (Overfitting): 모델이 훈련 데이터에 너무 과도하게 맞춰져서, 새로운 데이터에 대한 성능이 떨어지는 현상입니다.

#### 2. 데이터셋 구조 및 특징
- 케라스 IMDB 데이터셋은 이미 토큰화 및 인덱싱이 완료된 정수 시퀀스로 제공됨
- 리뷰 길이 다양성: 리뷰마다 길이가 다름
- 데이터 형태 
  - 훈련 입력: 파이썬 리스트(서로 길이가 다름)
  - 타겟(정답): 0 또는 1 (부정/긍정) 이진 분류 문제
- 리뷰 길이 통계
  - 평균 약 200 토큰
  - 중앙값 178 토큰
  - 분포는 짧은 리뷰가 많고 긴 리뷰는 적은 편(우측 치우침)

#### 3. 시퀀스 길이 맞추기: 패딩 (Padding)
- 이유: RNN 입력은 3차원 텐서로, 각 배치 샘플의 시퀀스 길이가 동일해야 함
- 처리 방법
  - 긴 리뷰는 자름 (max length 초과 시)
  - 짧은 리뷰는 0으로 패딩 (제로 패딩)
  - 패딩 위치는 시퀀스 앞부분에 채우는 pre-padding 방식 사용
    - 이유: RNN의 마지막 타임스텝 출력이 중요 -> 실제 텍스트가 뒤쪽에 위치하도록 하기 위함
- 케라스 함수 <mark>pad_sequences</mark> 사용
  - 예: <mark>pad_sequences(train_input, maxlen=100, padding='pre')</mark>
  - 결과: 모든 시퀀스 길이가 100으로 통일됨 (2만 개 샘플 x 100 타임스텝)

#### 4. 순환 신경망 모델 구성 (케라스 활용)

| 구성 요소           | 설명                                                                                                   |
|---------------------|--------------------------------------------------------------------------------------------------------|
| 입력층(Input layer) | 시퀀스 길이 100, 각 타임스텝은 단어 인덱스(정수)로 표현                                                |
| 임베딩 차원         | 단어마다의 벡터 크기(초기에는 무작위 실수로 초기화, 학습을 통해 단어 의미를 담은 임베딩 벡터로 최적화) |
| RNN 층 (SimpleRNN)  | 유닛 수 8, 순환층으로 시퀀스 처리                                                                      |
| 출력층              | 뉴런 1개, 활성화 함수 시그모이드 -> 이진 분류 결과 출력                                                |

- 모델은 <mark>Sequential</mark> API 또는 함수형 API로 구성 가능
- 출력값은 긍정(1) / 부정(0) 확률로 해석 가능

#### 5. 텍스트 데이터 인코딩 방법 
##### 5-1. 원-핫 인코딩 (One-hot encoding)
- 각 단어를 고유 인덱스에 대응하는 벡터로 변환
- 벡터 크기 = 어휘사전 크기 (예: 200)
- 단어가 인덱스 10이라면 10번째 위치만 1이고 나머지는 0인 200차원 벡터 생성
- 결과 텐서 크기: (샘플 수) x (시퀀스 길이) x (어휘 크기)
- 단점: 매우 큰 메모리 사용, 희소 벡터(sparse vector) 발생
- 케라스 함수: <mark>to_categorical</mark> 사용

##### 5-2. 임베딩 (Embedding)
- 단어를 고정 크기 실수 벡터로 표현하는 방법
- 예: 500개의 단어를 16차원 벡터로 매핑 -> 500x16 크기의 임베딩 행렬
- 임베딩 벡터는 학습 과정에서 최적화
- 단어 간 의미적 유사도(예: <mark>cat</mark>과 <mark>dog</mark> 벡터가 가깝게 위치)를 계산 가능
- 메모리 효율이 높고, 단어 의미 표현에 효과적
- 케라스의 <mark>Embedding</mark> 층 사용
- 초기 임베딩 행렬은 랜덤 초기화되고 학습에 따라 개선됨

#### 6. 인코딩과 임베딩 비교 및 활용
| 구분        | 원-핫 인코딩                          | 임베딩                                | 
|-------------|---------------------------------------|---------------------------------------|
| 벡터 형태   | 희소 벡터 (0과 1만 존재)              | 밀집된 실수 벡터                      |
| 차원 수     | 어휘 크기만큼 (예: 200)               | 임베딩 차원 수 (예: 16~200) 선택 가능 |
| 메모리 사용 | 매우 큼                               | 상대적으로 작음                       |
| 의미 표현력 | 단어 간 관계 반영 불가                | 단어 의미 유사도 반영 가능            |
| 구현 방법   | <mark>to_categorical</mark> 함수 사용 | 케라스 <mark>Embedding</mark> 층 사용 |

#### 7. 모델 훈련 및 평가
- 옵티마이저, 손실 함수 설정
  - 이진 분류이므로 손실 함수는 <mark>binary_crossentropy</mark> 사용 
- 콜백 함수로 조기 종료(Early Stopping) 적용 가능
- 훈련 과정에서 검증 세트를 분리하여 과적합 여부 확인
- 임베딩 층을 사용하면 메모리 효율이 좋아지고, 성능 향상 가능
- 훈련 후 정확도 및 손실 곡선으로 모델 성능 평가

#### 8. 자연어 처리와 순환 신경망의 역사적 맥락
- NLP 분야에서 과거에는 순환 신경망이 대표적인 텍스트 처리 방법이었음
- 10장 이후 트랜스포머 모델이 등장하면서 NLP의 주류가 크게 변화됨
- 임베딩 기술은 트랜스포머 모델의 근간을 이루는 핵심 개념임
- 초기에는 이러한 계산적 접근법이 기존 언어학적 전통과 달라 저항이 있었으나, 뛰어난 실용성과 성능을 바탕으로 점차 인정받게 됨

## 25강 LSTM과 GRM 셀
### LSTM 셀 구조와 작동 원리
"LSTM(Long Short-Term Memory)"은 긴 텍스트에서 앞쪽 정보를 기억하지 못하는 문제를 해결하기 위해 단기 기억을 늘려 주는 순환 신경망 셀이다."

#### LSTM 셀의 주요 특징
|    구분     |                                         설명                                          |
|-------------|---------------------------------------------------------------------------------------|
| 상태(state) | 은닉 상태(hidden state)와 셀 상태(cell state) 두 가지 상태를 가짐                     |
|  입력 처리  | 입력과 이전 타임스텝 은닉 상태를 하나로 묶은 가중치에 곱하여 새로운 은닉 상태 계산    |
| 활성화 함수 | 시그모이드 함수와 탄젠트 함수(tanh)를 사용하여 게이트 출력을 조절                     |
|    출력     | 은닉 상태는 외부(다음 층 혹은 모델 출력)로 전달되지만, 셀 상태는 내부 순환에만 사용됨 |

#### LSTM 셀 내부 게이트
|       게이트 이름        | 역할 설명                                                              | 수학적 처리                                                   |
|--------------------------|------------------------------------------------------------------------|---------------------------------------------------------------|
| 삭제 게이트(forget gate) | 이전 셀 상태에서 어떤 정보를 잊을지 결정 (정보 삭제 역할)              | 시그모이드 함수 출력과 이전 셀 상태의 곱                      |
| 입력 게이트(input gate)  | 현재 입력으로부터 어떤 정보를 셀 상태에 추가할지 결정 (정보 추가 역할) | 시그모이드 함수 출력과 탄젠트 함수 출력을 곱해 셀 상태에 더함 |
| 출력 게이트(output gate) | 은닉 상태를 생성하여 모델의 다음 층 혹은 결과로 내보낼 출력을 결정     | 시그모이드 함수 출력과 탄젠트 함수 출력을 곱해 은닉 상태 생성 |

- 각 게이트는 서로 다른 가중치(WF, WI, WJ, WO 등)를 사용해 더 복잡한 패턴과 정보를 저장 가능
- 게이트의 구체적 역할은 모델 훈련 과정에서 자동 학습되므로 사전 정의가 어렵다. 

#### LSTM 셀 작동 흐름
1. 이전 은닉 상태와 현재 입력을 하나의 벡터로 묶어 가중치와 곱함.
2. 시그모이드 및 탄젠트 함수를 통해 게이트별 출력을 만듦.
3. 삭제 게이트 출력을 이전 셀 상태와 곱하여 일부 정보를 제거.
4. 입력 게이트 출력을 새로운 후보 셀 상태와 곱해 추가할 정보 결정.
5. 위 두 결과를 더해 새로운 셀 상태 생성.
6. 출력 게이트 출력을 셀 상태의 탄젠트 함수값과 곱해 은닉 상태 생성.
7. 은닉 상태가 다음 층 또는 출력으로 전달됨.

### LSTM 모델 구현과 학습
- 케라스(Keras)의 <mark>LSTM</mark> 층을 사용해 간단히 구현 가능
- 심플 RN(Simple RNN)과 비교 시 파라미터 수가 약 4배 증가 (예: 200 -> 800)
  - 이유: LSTM은 네 개의 서로 다른 가중치 벡터를 사용하기 때문
- 과대적합 문제 발생시 <mark>dropout</mark>과 <mark>recurrent_dropout</mark> 매개변수로 규제 가능
- 다중 순환층 연결 시, 마지막 층을 제외한 앞선 층에서는 <mark>return_sequences=True</mark> 설정 필요
  - 그래야 각 타임스텝별 은닉 상태를 다음 층으로 전달 가능
- 모델 학습은 기존 순환 신경망과 동일한 방식으로 진행

### GRU 셀 구조와 작동 원리
"GRU(Gated Recurrent Unit)는 LSTM 셀보다 구조가 단순하지만 비슷한 목적을 가진 순환 셀로, 게이트를 통해 정보를 제어한다."

#### GRU 셀의 주요 특징 및 게이트
| 게이트 이름        | 역할 설명                                                  | 수학적 처리 요약                                                               |
|--------------------|------------------------------------------------------------|--------------------------------------------------------------------------------|
| 업데이트 게이트(z) | 현재 상태를 얼마나 유지할지 결정 (LSTM의 삭제 게이트 유사) | 입력과 은닉 상태를 가중치와 곱해 시그모이드 함수 적용 후 원래 은닉 상태에 곱함 |
| 리셋 게이트(r)     | 이전 은닉 상태 정보를 얼마나 반영할지 조절                 | 입력과 은닉 상태를 가중치와 곱해 시그모이드 함수 적용                          |
| 후보 은닉 상태     | 리셋 게이트에 의해 조절된 은닉 상태와 입력을 바탕으로 계산 | 탄젠트 함수 적용                                                               |

- GRU는 LSTM보다 게이트 수가 적어 파라미터 수가 적음
- 실제 구현 시 입력과 은닉 상태에 곱해지는 가중치를 분리하여 효율적으로 처리
- 파라미터 수는 심플 RN 대비 약 3배 이상 증가 (예: 200 -> 약 624)
- 게이트 역할 역시 훈련 과정에서 학습되어 명확한 역할 구분이 어려움

### GRU 모델 구현과 학습
- 케라스의 <mark>GRU</mark>층으로 쉽게 구현 가능
- LSTM과 마찬가지로 기존 순환 신경망 학습 방식과 동일
- 파라미터 수 계산 시 절편(bias) 추가로 인해 단순 곱셈보다 약간 더 많음
- 인터넷 및 논문에서 보통 왼쪽에 GRU 게이트 구조 그림으로 설명됨

## 26강 어텐션 메커니즘과 트랜스포머
### 인코더-디코더 신경망과 시퀀스투시퀀스 모델
- 인코더-디코더 신경망: 입력 시퀀스를 받고 출력 시퀀스를 생성하는 두 개의 신경망으로 구성됨
- 예시: 한국어 입력 -> 영어 출력 (번역, 요약 작업에 활용)
- 시퀀스투시퀀스 모델: 입력과 출력이 모두 시퀀스인 모델
- 인코더는 입력 토큰을 시간 순서대로 처리 (타임스텝별)
- 디코더는 마지막 인코더 은닉 상태를 받아 타임스텝별로 출력 생성
- 디코더는 이전 출력 토큰을 참조(자기회귀 모델)하여 다음 토큰 생성

### 순환 신경망(RNN)의 한계와 어텐션 메커니즘 등장 배경
- 긴 텍스트를 하나의 은닉 상태에 모두 압축하는 것은 어려움
- LSTM, GRU 셀도 긴 시퀀스 정보를 저장하는 데 한계 존재
- 어텐션 메커니즘: 인코더의 모든 타임스텝 은닉 상태를 디코더가 참조
- 각 인코더 은닉 상태에 어텐션 가중치(α)를 곱해 적절히 조합
- 어텐션 가중치는 학습 과정에서 자동으로 최적화됨
- 단점: 은닉 상태를 모두 저장하고 참조하기 때문에 메모리 사용량 증가, 입력 길이 제한 발생

| 기존 RNN 구조                    | 어텐션 메커니즘 적용 구조               |
|----------------------------------|-----------------------------------------|
| 마지막 은닉 상태만 디코더에 전달 | 모든 타임스텝 은닉 상태를 디코더가 참조 |
| 긴 문장 정보 압축 어려움         | 가중치로 중요한 부분에 집중 가능        | 
| 입력 길이 제한 없음              | 메모리 제한으로 입력 길이 제한 존재     | 

### 트랜스포머(Transformer) 모델 개요
- 2017년 구글 연구팀이 개발한 모델
- 순환 신경망(RNN) 완전 제거, 어텐션 구조만 사용
- 인코더-디코더 구조 유지
- 인코더는 입력 시퀀스를 동시에 처리 (병렬 처리 가능 -> 속도 향상)
- 디코더는 자기회귀 구조 유지하며 타임스텝별 토큰 생성
- 인코더 출력은 은닉 상태 대신 **단어 벡터(임베딩 벡터)**로 표현 
- 각 입력 토큰마다 벡터 생성 -> 어텐션 가중치로 조합 (셀프 어텐션)

| 구분           | RNN 기반 인코더-디코더     | 트랜스포머 인코더-디코더        |
|----------------|----------------------------|---------------------------------|
| 입력 처리 방식 | 타임스텝별 순차 처리       | 모든 토큰 동시 처리 (병렬)      |
| 출력 처리 방식 | 타임스텝별 생성 (자기회귀) | 타임스텝별 생성 (자기회귀 유지) |
| 은닉 상태 용어 | 은닉 상태                  | 단어 벡터(임베딩 벡터)          | 
| 속도           | 느림                       | 빠름                            |

### 셀프 어텐션(Self-Attention) 메커니즘
- 입력 토큰 각각에 대해 Query (Q), Key (K), Value (V) 벡터 생성 (밀집층 사용)
- 어텐션 가중치 계산: Q와 K의 곱을 통해 각 토큰이 다른 토큰에 얼마나 주목하는지 결정
- 어텐션 가중치에 따라 V 벡터를 가중합하여 최종 은닉 벡터 생성
- 입력 토큰 개수만큼 최종 은닉 벡터 생성 (입력과 출력 벡터 개수 일치)
- 모델이 스스로 중요한 토큰에 집중할 수 있는 구조

### 전이학습(Transfer Learning)과 트랜스포머
- 전이학습: 사전 훈련된 모델을 새로운 작업에 적용하는 기술.
- 컴퓨터 비전에서 이미지넷 기반 전이학습이 주로 사용됨.
- 자연어처리에서는 순환 신경망(RNN)의 한계로 전이학습이 어려웠으나, 트랜스포머 등장 이후 적용 가능. 
- 대규모 텍스트 데이터(인터넷, 책)로 사전 훈련 후, 미세 튜닝(fine-tuning)하여 다양한 NLP 작업에 활용.
- 미세 튜닝은 일부 층만 파인튜닝하거나 전체 모델을 조정하는 방식으로 수행.

#### BART 모델과 구조
- 메타에서 2019년 공개한 인코더-디코더 트랜스포머 모델
- 파라미터 수:
  - Base 모델 약 1억 2천만 개
  - Large 모델 약 4억 개
- 구조:
  1. 토큰 임베딩 -> 인코더 모듈(연속 통과) -> 디코더 모듈에 전달
  2. 인코더와 디코더 모두 위치 임베딩 사용 (랜덤 초기화 후 학습 가능)
  3. 인코더, 디코더는 모두 층 정규화, 드롭아웃, 잔차 연결 포함
  4. 디코더는 크로스 어텐션을 통해 인코더 출력과 상호작용
- 최종 출력은 768차원 벡터 -> 5,265개 토큰 확률로 변환하기 위해 밀집충(Dense) 사용 
- 임베딩층 가중치(weight)와 출력층 가중치 공유(가중치 행렬 회전 활용)하여 학습 효율 향상 

| 구성 요소          | 설명                                                                  |
|--------------------|-----------------------------------------------------------------------|
| 토큰 임베딩 층     | 입력 토큰을 768차원 벡터로 변환                                       | 
| 위치 임베딩 층     | 토큰 순서 정보를 벡터에 주입 (삼각 함수 방식 또는 학습 가능한 임베딩) |
| 인코더 블록        | 멀티헤드 어텐션, 피드포워드 네트워크, 층 정규화, 드롭아웃 포함        |
| 디코더 블록        | 마스크드 셀프 어텐션, 크로스 어텐션, 피드포워드 네트워크 포함         |
| 밀집 출력층(Dense) | 768차원 -> 5,265차원 토큰 확률 분포 변환                              |
| 임베딩 가중치 공유 | 입력 임베딩과 출력층 가중치를 회전하여 공유                           |

#### GRLU 활성 함수
- BART 모델에서 피드포워드 네트워크 활성화 함수로 사용
- 공식적으로는 Gaussian Error Linear Unit (GELU)
- 수식 개념:
  > 
  ```
  GELU(x)=x⋅Φ(x)
  ```
여기서 Φ(x)는 표준 정규 분포의 누적분포함수(CDF)
- ReLU와 달리 미분 가능하며, 부드러운 곡선 형태를 가짐
- 계산 효율을 위해 근사식 사용

#### 활성함수 비교
| 함수명 | 형태 및 특징                             |
|--------|------------------------------------------|
| ReLU   | f(x)=max(0,x), 비선형, 비미분점 존재     |
| GELU   | x에 확률밀도 함수 곱, 부드럽고 미분 가능 |

#### KoBART 모델과 활용법
- 한국어에 특화된 BART 기반 모델
- SKT에서 공개. 허깅페이스(Hugging Face) 트랜스포머 라이브러리로 사용 가능
- 파이프라인(pipeline) 함수로 간단하게 요약 작업 수행 가능
  - 예) <mark>pipeline(task="summarization", model="skt/kobart")</mark>
- 입력: 요약할 긴 텍스트
- 출력: 간결하게 요약된 텍스트

#### 활용 예시
| 과정            | 설명                                         |
|-----------------|----------------------------------------------|
| 모델 로드       | 허깅페이스 모델 리포지토리에서 불러오기      | 
| 파이프라인 생성 | <mark>summarization</mark> 태스크 지정       |

| 요약 결과 출력  | 자동으로 핵심 내용 요약                      |

#### 토크나이저(Tokenization) 및 토크나이징 방식
- 토크나이저는 텍스트를 토큰 단위로 분할하고 정수 인덱스로 변환하는 별도 프로그램/모델
- LM(Large Model) 내부가 아닌 독립적으로 존재
- 어휘 사전(vocabulary)과 토큰-정수 매핑 포함
- 토크나이징 방식 종류 및 특징

| 방식                     | 설명                                           | 용도 및 장점                              | 
|--------------------------|------------------------------------------------|-------------------------------------------|
| 공백 기반                | 단순히 공백으로 토큰 분리                      | 가장 단순, 하지만 어미 변화 문제          |
| WordPiece                | 단어를 부분 단어(Subword) 단위로 분해          | 어휘 수 감소, 희귀 단어 처리 가능         |
| Byte Pair Encoding (BPE) | 자주 출현하는 문자 쌍을 병합하여 토큰 생성     | 어휘 효율적 관리, 다양한 언어에 적용 가능 |
| SentencePiece            | 언어 독립적, 유니코드 기반 서브워드 토크나이저 | 공백 없는 언어에도 적합                   |

- 복잡한 어미 변화, 언어 특성에 대응하기 위해 부분 단어 토크나이징이 주류
- 토크나이저는 모델 입력의 정수 시퀀스를 생성하며, 이 시퀀스가 임베딩 층으로 전달됨

#### 트랜스포머 모델 요약 작업 과정
1. 입력 텍스트 토크나이징 -> 토큰 ID 시퀀스 생성
2. 인코더 입력 -> 토큰 임베딩 + 위치 임베딩 -> 인코더 블록 통과
3. 인코더 출력 -> 디코더에 크로스 어텐션 키/값으로 전달
4. 디코더 입력 -> 이전 생성 토큰에 대한 임베딩 + 위치 임베딩
5. 디코더 블록 통과 -> 다음 토큰 확률 분포 생성 (밀집층 통해)
6. 다음 토큰 선택 및 반복 -> 자동 회귀 방식으로 요약문 생성

#### 참고 사항
- 트랜스포머 모델의 발전과 다양성은 2023년까지 엄청난 속도로 진행되어오며, 2024년 이후는 모델 수 급증으로 시각화가 어려움.
- 미세 튜닝 관련 상세 내용은 10장 3절과 별도 추천 도서 참고.
- 트랜스포머 기반 자연어처리 모델 사용 시, 사전 훈련된 모델과 토크나이저를 함께 활용하는 것이 필수.
- 실제 구현 시 허깅페이스 트랜스포머 라이브러리 활용이 매우 편리함.

## 28강 대규모 언어 모델(LLM)로 텍스트 생성하기
### 대규모 언어 모델(LLM)과 텍스트 생성
"대규모 언어 모델(LLM)은 텍스트 생성에 혁신을 가져왔으며, 다양한 오픈소스와 독점 모델들이 활발히 연구 및 활용되고 있다."

#### 1. 대규모 언어 모델 개요 및 주요 모델 소개
- 대규모 언어 모델(LLM): 텍스트 생성에 특화된 트랜스포머 디코더 기반 모델로, 최근 많은 인기를 누림.
- 대표 오픈소스 LLM
  - 메타(Meta)의 LLaMA (라마): 오픈소스 대구모 모델로 주목받음.
  - 구글의 Gemma (젬마) 모델
  - 마이크로소프트의 Pi (파이) 모델: 경량화와 높은 성능으로 유명.
- 소규모 언어 모델 (SLM, Small Language Model)
  - 중국 기업 모델: 알리바바의 Qwen(큐원), 딥스피크(DeepSeek) 등. 
- 한국 오픈소스 모델
  - LG AI 연구소의 X1 (엑사1원)
  - 네이버의 HyperCLOVA X (하이퍼클로바 X)
  - 카카오의 오픈소스 LRM
- 독점 유료 LLM 
  - OpenAI의 GPT 시리즈 (GPT-4.5 포함)
  - 앤트로픽의 Claude (클로드)
  - 구글의 Gemini (제미나이) 등

#### 2. LLM 리더보드 및 평가
| 리더보드 명칭                     | 특징 및 현황                                                                                                                                   |
|-----------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| Hugging Face Open LLM 리더보드    | 2년간 인기, 다양한 모델 성능 비교 가능, 2025년 5월 경 중단 및 아카이브됨. 최신 모델 간 성능 차이 평가 어려움, 추론 및 에이전트 성능 반영 한계. |
| LM Arena (이전 LMSYS 챗봇 아레나) | 사람 개입 평가 포함, 현재도 유용하게 사용됨.                                                                                                   |

- 리더보드는 모델 성능을 비교하는 데 참고 자료로 유용하지만, 최신 LLM의 다양한 능력과 특성을 완벽히 반영하지는 못함.

#### 3. 엑사1원(X1) 모델 구조 및 특징
- 버전: 3.5 (24억 파라미터 모델 기준)
- 파라미터 규모: 24억, 78억, 320억 파라미터 버전 존재
- 은닉 벡터 차원: 2560
- 어텐션 헤드: 32개 (그룹 쿼리 어텐션 사용)
  - 키와 값 헤드: 8개
  - 쿼리 헤드: 32개
- 밀집층: 어텐션 헤드 결과를 모아 2560차원으로 복원
- 정규화: RMS 정규화 (RMSNorm) 사용
- 피드포워드 네트워크: 
  - 입력 차원 2560 -> 확장 7168 (두 개 밀집층)
  - 활성화 함수로 실루(SiLU, Switch-GELU 계열) 적용
  - 두 밀집층 출력 곱셈(element-wise multiplication) 후 다시 2560 차원으로 축소
- 디코더 블록: 30개 반복 구조
- 입력/출력 흐름: 입력 임베딩 -> 드롭아웃 -> 30개 디코더 블록 -> RMS 정규화 -> 출력 밀집층 -> 토큰 확률 벡터 (약 102,400 크기)

#### 4. 주요 기술 설명
| 기술명                                   | 설명                                                                              | 특징 및 역할                                                    |
|------------------------------------------|-----------------------------------------------------------------------------------|-----------------------------------------------------------------|
| 멀티 쿼리 어텐션 (Multi-Query Attention) | 쿼리 헤드 여러 개 유지, 키와 값은 하나만 유지하여 효율성 증대                     | 캐싱된 키/값 재사용으로 계산 및 메모리 효율 향상                |
| 그룹 쿼리 어텐션 (Group Query Attention) | 쿼리 헤드를 몇 개 그룹으로 나누어 각 그룹이 키/값을 공유                          | 멀티 헤드와 멀티 쿼리 어텐션의 중간 형태, 효율성과 표현력 균형. |
| 실루 함수 (SiLU, SwiGLU)                 | 입력값과 시그모이드 함수를 곱한 활성화 함수, 글루 (GLU) 함수 변형                 | 기존 GELU 대비 성능 개선, X1 모델 활성화 함수로 사용            |
| RMS 정규화 (RMSNorm)                     | 층 정규화 변형. 평균을 빼지 않고 분산 계산 시 각 원소 제곱 평균으로 표준편차 산출 | 계산 효율적, 평균 제거 없이 정규화, 대규모 LLM에서 인기         |

#### 5. RMS 정규화 상세 설명
- 일반 층 정규화는 각 원소에서 평균을 빼고 분산(제곱평균)을 구함.
- RMS 정규화는 평균을 빼지 않고, 원소들의 제곱 평균으로 분산 추정.
- 표준 편차는 제곱근으로 구함.
- 정규화 시 평균 제거 과정을 생략하여 계산량 감소.
- 모델 성능 저하 없이 더 빠른 계산 가능.

#### 6. 텍스트 생성 및 디코딩 전략
- 토큰 확률 분포에서 토큰 선택 문제
  - 단순 최고 확률 토큰 선택 시 텍스트가 단조롭고 부자연스러움.
- 주요 디코딩 기법
| 기법                           | 설명                                                                          | 역할 및 효과                                     |
|--------------------------------|-------------------------------------------------------------------------------|--------------------------------------------------|
| 온도 파라미터 (Temperature)    | 확률 분포 차이를 완화, 확률이 높은 토큰과 낮은 토큰 간 차이 줄임              | 다양성 증가, 보다 자연스러운 텍스트 생성         |
| 탑 K (Top-K) 선택              | 확률 상위 K개 토큰만 후보로 선택 후 확률에 따라 랜덤 선택                     | 확률이 낮은 토큰 배제, 다양성 유지               |
| 탑 P (Top-P, Nucleus Sampling) | 누적 확률이 p 이상이 될 때까지 토큰 선택, 선택된 토큰 확률 재정규화 후 샘플링 | 동적 후보군 설정, 보다 자연스러운 확률 분포 반영 |

- 통상 탑 K를 먼저 적용 후 탑 P 적용하는 방식이 효율적.

#### 7. 엑사1원 모델 실습 및 활용
- Hugging Face Transformers 라이브러리 사용 가능.
- 텍스트 생성 파이프라인에서 <mark>task='text-generation'</mark> 설정.
- 시스템 역할과 사용자 역할 메시지를 JSON 스타일로 전달 가능. 
  - 예) 시스템 롤: "쇼핑몰 Q&A 봇", "답변 전에 친절한 안내 포함"
  - 사용자 롤: 실제 질문 텍스트 입력
- 출력 예시: 친절하고 자연스러운 답변, 정확한 답변을 위해 시간이 필요함을 안내하는 문장 등.
- 24억 파라미터 규모임에도 매우 자연스러운 텍스트 생성 가능.

#### 8. OpenAI GPT 모델 활용법
- OpenAI API를 통해 GPT-4.5 Mini 모델 등 사용 가능.
- API 키 발급 후 OpenAI 패키지에서 <mark>OpenAI</mark> 클라이언트 생성.
- 메시지 포맷은 엑사1원과 동일한 JSON 리스트 딕셔너리 형태.
- 컴플리션 호출 시 다수 응답 가능하지만 기본 1개로 설정. 
- 출력 결과 자연스럽고 실무에서 Q&A 업무에 활용 가능.
