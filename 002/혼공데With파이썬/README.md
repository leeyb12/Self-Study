# 혼공데With파이썬

Python 데이터 분석 학습 자료를 정리하기 위한 폴더입니다.

## 관리 메모

데이터 분석 예제, CSV/Excel 자료, Jupyter Notebook 등을 추가할 때 사용하는 공간입니다. 자료를 추가할 때는 데이터 파일의 출처와 실행 순서를 함께 남기는 것을 권장합니다.

## 기본 분석 흐름

1. 데이터의 출처, 행과 열의 의미를 확인합니다.
2. 결측치, 중복값과 자료형을 점검하고 필요한 전처리를 수행합니다.
3. 기초 통계와 시각화로 분포와 관계를 탐색합니다.
4. 분석 결과와 한계, 재현에 필요한 실행 환경을 함께 기록합니다.
