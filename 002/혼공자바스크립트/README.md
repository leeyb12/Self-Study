# 혼공자바스크립트

혼자 공부하는 자바스크립트 교재 기반의 HTML 예제와 개념 노트를 모아 둔 폴더입니다.

## 구성

| 폴더/파일 | 내용 |
| --- | --- |
| `01/` - `10/` | 장별 JavaScript 예제 |
| `WordNote.md` | 개념/단어 정리 |
| `image*.png` | 노트 이미지 |

## 핵심 개념

- JavaScript는 값의 자료형을 실행 중에 판단하는 동적 타입 언어입니다.
- 함수는 반복되는 동작을 묶고, 객체와 배열은 관련 데이터를 구조화합니다.
- 브라우저 예제에서는 JavaScript 언어 기능과 DOM·이벤트 같은 Web API를 구분해 살펴봅니다.

## 확인 방법

각 장의 `.html` 파일을 브라우저에서 열어 확인합니다. 콘솔 출력 예제는 개발자 도구 Console 탭을 함께 확인합니다.
