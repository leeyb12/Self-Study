## 흐름 제어 개념 및 역할
> "흐름 제어란 코드 실행 순서를 결정하는 것"
- 순차적 실행: 위에서 아래로 한 줄씩 실행
- 흐름 제어: 분기, 반복, 점프문으로 코드 실행 경로를 다양하게 조정

## 분기문 (Branch Statement)
### 분기란?
- 프로그램 실행 경로를 여러 갈래로 나누는 것
- 한 번에 하나의 경로만 실행 가능 (도로의 분기점, 기차의 선로 선택 비유)

### 주요 분기문 종류
| 분기문 종류 | 설명 | 특징 | 예시 |
|-------------|------|------|------|
| if문 | 조건이 참일 때 코드 실행 | 조건 충족 여부에 따라 코드 블록 분기 | 조건 만족 시 동작 수행 |
| else if문 | 이전 조건이 거짓일 때 추가 조건 평가 | 여러 조건 순차 평가 | 다중 조건 분기 |
| else문 | 위 조건 모두 거짓일 때 실행 | 선택 사항, 조건 없이 기본 실행 | 모든 조건 불충족 시 실행 |
| switch문 | 식의 결과와 여러 케이스 비교 | 각 케이스별 실행, break 필요 (중단용) | 값에 따른 다중 분기 |

### if문 예제 흐름
- $a$ 출력 -> 조건1 평가 (true면 $b_1$ 출력) -> 조건2 평가 (true면 $b_2$ 출력) -> 조건 모두 false면 $b_3$ 출력 -> $c$ 출력

### switch문 동작 원리
- 식 결과를 케이스와 비교
- 일치하는 케이스 코드 실행 후 break로 탈출
- 일치하는 케이스 없으면 default 코드 실행

### switch문 break 중요성
- break 없으면 다음 케이스 코드도 연속 실행됨 (fall-through 현상)
- break는 감옥 탈출하는 것(미드 '프리즌 브레이크' 비유)

## 반복문 (Loop Statement)
### 반복문 의미
- 조건이 참인 동안 특정 코드 블록을 반복 실행

### C# 반복문 종류
| 종류 | 실행 순서 및 조건 평가 | 특징 및 용도 |
|------|------------------------|--------------|
| while문 | 조건 평가 -> 조건 참이면 코드 실행 -> 다시 조건 평가 | 조건 만족 시 반복, 조건 먼저 검사 |
| do-while문 | 코드 실행 -> 조건 평가 -> 조건 참이면 반복 | 최소 1회 실행, 조건 나중에 검사 |
| for문 | 초기화 -> 조건 평가 -> 코드 실행 -> 증감 -> 반복 | 반복 횟수 제어용, 조건 변수 사용 |

### while문 흐름
- $a$ 출력 -> 조건 평가 -> 참이면 $b_1$, $b_2$ 출력 -> 조건 다시 평가 -> 조건 거짓 시 $c$ 출력

### do-while문 흐름
- $a$ 출력 -> $b_1$, $b_2$ 출력 -> 조건 평가 -> 조건 참 시 반복, 거짓 시 $c$ 출력

### for문 세부 구조
- 초기화: 반복 변수 선언 및 초기화($i$ = 0)
- 조건: 반복 수행 조건($i$ < 10)
- 증감: 반복 변수 증감($i++$)

### for문 예시 흐름
- $a$ 출력 -> $i$ = 0 초기화 -> $i$ < 10 조건 평가 -> 참이면 $b_1$, $b_2$ 출력 -> $i$ 증가 -> 조건 평가 반복 -> 조건 거짓 시 $c$ 출력

## 점프문 (Jump Statement)
### 점프문 개념
- 프로그램 흐름을 특정 위치로 즉시 이동

### C# 점프문 종류 및 기능
| 점프문 | 역할 | 주요 사용처 |
|--------|------|-------------|
| break | 반복문이나 switch 탈출 | 반복 중단, switch 분기 탈출 |
| continue | 반복문의 현재 반복 건너뜀 | 다음 반복으로 즉시 넘어감 |
| goto | 지정한 레이블로 이동 | 특정 위치로 무조건 점프 |

### break 예시
- while문 내 if 조건 충족 시 break -> 반복 즉시 종료 -> 이후 코드 실행

### continue 예시
- while문 내 if조건 충족 시 continue -> 아래 코드 건너뛰고 조건 평가로 돌아감 -> 반복 계속

### goto 예시
- 조건 충족 시 지정한 레이블로 점프 -> 해당 위치 코드 실행 -> 이전 코드 건너뜀

## 식(식별자)과 패턴 매칭
### 식 (Expression)
- 연산자와 피연산자의 조합으로 결과값 생성
- 반대로 문(statement)은 결과값 없이 동작 수행

### 패턴 매칭 개념
- 식의 결과가 특정 형태와 일치하는지 검사 (참/거짓 반환)
- 생산성 향상을 위해 C#에서 도입된 문법

### 주요 패턴 종류 및 설명 
| 패턴 종류 | 설명 | 예시 및 특징 |
|-----------|------|--------------|
| 선언 패턴 | 특정 형식과 일치하면 변수를 선언 | 변수 사용 가능, 스코프 내에서 유효 |
| 형식 패턴 | 특정 형식과 일치 검사, 변수 선언 없음 | 단순 타입 체크 |
| 상수 패턴 | 특정 상수와 일치 여부 검사 | switch 식 내 사용, 간단한 값 비교 |
| 프로퍼티 패턴 | 객체의 프로퍼티 값들과 패턴 일치 검사 | 복잡한 객체 조건 검사에 활용 |
| 관계 패턴 | 관계 연산자(>, <, == 등) 이용한 비교 | 범위 조건 판별 등에 활용 |
| 논리 패턴 | 복수 패턴을 논리 연산자(and, or, not)로 조합 | 복잡한 조건 결합 가능 |
| 괄호 패턴 | 패턴을 괄호로 묶음 | 가독성 향상 |
| 위치 패턴 | 튜플 등 분해 가능한 자료구조 요소별 패턴 검사 | 튜플, 레코드 등의 구조 분해 및 검사에 적합 |
| 변수 패턴 | 모든 식과 일치, 결과값을 변수에 할당 | 임시 변수 할당 후 추가 연산 가능 |
| 무시 패턴 | 모든 식과 일치하지만 값 무시 (언더스코어 사용) | 스위치식 등에서 특정 값 무시할 때 유용 |
| 목록 패턴 | 리스트 등 여러 요소에 대한 패턴 검사 | 다량 데이터 중 일부 조건만 검사 가능 |

## 패턴 매칭 예시 정리
| 패턴 종류 | 코드 기능 및 설명 |
|-----------|-------------------|
| 선언 패턴 | 식 결과가 int와 일치하면 변수 선언 후 사용 |
| 상수 패턴 | switch 식에서 변수와 특정 문자열("kr", "us") 일치 여부 검사 |
| 프로퍼티 패턴 | 객체의 특정 속성 값으로 조건 분기 (예: 자동차 모델과 생산년도 검사) |
| 관계 패턴 | 점수 범위에 따른 평가 (예: 90 이상 A, 60 이하 F 등) | 
| 논리 패턴 | 여러 패턴 조합 (예: or, and, not) |
| 위치 패턴 | 튜플 요소별 조건 검사 (첫 번째 요소 타입, 두 번째 요소 값 등) |
| 무시 패턴 | 특정 조건 검사 시 값 무시 (_ 기호 사용) |
| 목록 패턴 | 리스트 요소별 조건 검사 및 일부 요소만 일치 여부 확인 |

## 흐름 제어와 패턴 매칭의 상호작용
- 분기문(if, switch)과 패턴 매칭은 조건에 따른 코드 흐름 분기 핵심 도구
- 반복문은 조건 만족 시 코드 블록 반복 실행으로 동작 제어
- 점프문은 코드 흐름의 즉각적인 변경으로 복잡한 흐름 제어 가능
- 패턴 매칭은 복잡한 조건 분기와 데이터 검증을 간결하게 표현

## 흐름 제어 핵심 비교표
| 구분 | 용도 | 조건 평가 시점 | 특징 및 주의점 |
|------|------|----------------|----------------|
| if문 | 조건 분기 | 각 조건별로 순차 평가 | else if, else로 다중 조건 처리 가능 |
| switch문 | 값에 따른 다중 분기 | 한번의 식 평가 후 케이스 비교 | break를 써서 중단 필수 (fall-through 방지) |
| while문 | 조건 만족 시 반복 | 반복 시작 전 조건 평가 | 조건이 처음부터 거짓이면 반복 안 함 |
| do-while문 | 최소 1회 이상 반복 | 반복 후 조건 평가 | 최소 1회 실행 보장 | 
| for문 | 반복 횟수 제어 | 반복 시작 전 조건 평가 | 초기화, 조건, 증감문 필수 |
| break | 반복문 / switch 탈출 | 즉시 탈출 | 반복 또는 분기 종료용 |
| continue | 반복 현재 단계 건너뛰기 | 즉시 다음 반복으로 진행 | 반복 중 일부 코드 실행 생략 |
| goto | 지정 위치로 즉시 이동 | 조건에 따라 자유롭게 이동 | 코드 가독성 저하 가능, 신중 사용 필요 |

## 핵심 정리
분기문, 반복문, 점프문은 프로그램 실행 흐름을 세밀하게 조절하는 수단으로 각기 다른 역할과 특성을 가진다. 분기문은 조건에 따라 실행 경로를 나누고, 반복문은 특정 조건 동안 코드를 반복하며, 점프문은 흐름을 즉시 다른 위치로 전환한다. 패턴 매칭은 복잡한 조건 판별을 단순화하여 분기문의 조건식과 결합함으로써 코드의 가독성과 유지보수성을 높인다. 이러한 흐름 제어 요소들은 프로그램의 논리적 구조를 구성하고, 효율적이고 명확한 알고리즘 구현을 가능하게 한다.
