## 비주얼 스튜디오(Visual Studio) 설치 과정
> "Visual Studio 2022 Community 버전은 무료로 제공되며, 닷넷 데스크톱 개발 기능만 선택하여 설치할 수 있다."

### 설치 절차 요약
| 단계 | 세부 내용 |
|------|-----------|
| 1. 브라우저 접속 | 비주얼 스튜디오 공식 다운로드 사이트 주소 입력 |
| 2. 다운로드 | Visual Studio 2022 Community 무료 다운로드 버튼 클릭 -> 설치 파일 자동 다운로드 |
| 3. 설치 파일 실행 | 다운로드된 설치 파일 실행 |
| 4. 설치 옵션 선택 | 닷넷 데스크톱 개발(.NET Desktop Development) 항목만 선택 (필수) |
| 5. 설치 진행 | 선택한 항목만 설치, 나머지 옵션은 제거 가능 |
| 6. 완료 후 사용 | 설치 완료까지 기다림 |

### 핵심 유의점
- 닷넷 데스크톱 개발 항목만 설치해도 필요한 개발 환경 구축 가능
- 기타 옵션은 필요에 따라 설치하거나 제거해도 무방
- 설치 시간은 다소 소요될 수 있으니 인내심 필요

### 비유를 통한 이해
- 비주얼 스튜디오 설치는 마치 빵집에서 빵을 고르는 것과 같다. 여러 빵 종류(옵션) 중에서 자신이 필요한 '식빵(닷넷 데스크톱 개발)'만 골라 구매하면 된다. 나머지 빵들은 필요 없으면 그냥 두어도 된다.
