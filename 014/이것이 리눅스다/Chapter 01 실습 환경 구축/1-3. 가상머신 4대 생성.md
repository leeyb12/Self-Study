## 가상 머신 환경 구축 실습 (Windows 환경)
> "가상 머신은 실제 컴퓨터 내부에 만들어진 가상의 컴퓨터로, 여러 대의 서버와 클라이언트를 구성하여 실습 및 운영 환경을 구성할 수 있다."

### 1. 가상 머신 생성 준비 및 폴더 구성
- 실습용 가상 머신 4대 생성: 서버, 서버비(Server B), 클라이언트, 윈도우 클라이언트(Win Client)
- 각 가상 머신별 저장 폴더를 Window C 드라이브 아래 <mark>로키텐</mark> 폴더 내에 생성
  - 폴더명 예시: 서버, 서버비, 클라이언트, 윈도우 클라이언트 
- 가상 머신 파일 저장 위치를 각 폴더로 구분하여 관리

### 2. 가상 머신 생성 절차 (VMware 기준)
| 단계 | 주요 작업 및 설정 내용 |
|------|------------------------|
| 1. 새 가상 머신 생성 | "Create New Virtual Machine" 클릭 후 Typical 기본 설정 선택 |
| 2. OS 선택 | Linux -> Rocky Linux 64-bit 선택 (서버, 서버비, 클라이언트) <br> Windows -> Windows 11 64-bit 선택 (윈도우 클라이언트) |
| 3. 저장 위치 지정 | 각 가상 머신별로 준비한 폴더 지정 (예: C\로키텐\서버) |
| 4. 디스크 용량 설정 | 서버: 100GB SCSI 디스크 <br> 서버비: 80GB SCSI 디스크 <br> 클라이언트: 80GB 기본 디스크 (MVM 또는 SCSI 상관없음) <br> 윈도우 클라이언트: 60GB 기본 디스크 | 
| 5. 메모리 설정 | 설치 시 최소 4GB(4096MB)로 설정 권장 |
| 6. CPU 설정 | 기본값 유지 (성능 향상 크게 영향 없음) |
| 7. 가상 하드디스크 파일 | 싱글 파일(single file)로 생성 (가독성 및 관리 편리) |
| 8. 부가 장치 설정 | 사운드 카드, USB 컨트롤러는 필요에 따라 제거 (서버 및 서버비는 제거 권장) |
| 9. 디스플레이 설정 | 3D 그래픽 가속 기능 해제 (특히 Rocky Linux 설치 시 화면 충돌 방지) |
| 10. 네트워크 설정 | 기본 NAT 모드 유지 (인터넷 연결 가능) |

### 3. 디스크 용량 및 실제 파일 관리
- 가상 머신의 하드디스크는 실제로는 파일 형태로 존재함 (확장자. <mark>vmdk</mark>)
- 예: 서버 가상 머신의 100GB 디스크는 초기에는 약 10~12MB 크기의 파일로 시작하며, 실제 사용량에 따라 최대 100GB까지 확장 가능
- 가상 머신 생성 시 기본 설정된 20GB 디스크는 삭제 후 새로 설정한 크기로 교체
- 디스크 파일을 여러 개로 쪼개거나 하나로 운영햘 수 있으나, 일반적으로 관리 편의를 위해 하나의 파일로 설정

### 4. 가상 머신별 주요 설정 비교
| 가상 머신 | OS 종류 | 디스크 용량 | 디스크 타입 | 메모리 | 사운드 & USB | 3D 가속 설정 | 비고 | 
|-----------|---------|-------------|-------------|--------|--------------|--------------|------|
| 서버 | Rocky Linux 64bit | 100GB | SCSI | 4GB | 제거 | 3D 가속 OFF | 서버 전용 스펙 | 서버 전용 스펙 |
| 서버비 (Server B) | Rocky Linux 64bit | 80GB | SCSI | 4GB | 제거 | 3D 가속 OFF | 서버비 전용 스펙 |
| 클라이언트 | Rocky Linux 64bit | 80GB | 기본 (MVM) | 4GB | 활성화 | 3D 가속 OFF | 사운드 및 USB 유지 |
| 윈도우 클라이언트 | Windows 11 64bit | 60GB | 기본 (MVM) | 4GB | 제거 | 3D 가속 ON (기본) | 윈도우 환경 설정 |

### 5. 가상 머신 생성 후 관리 및 주의사항
- 가상 머신 생성 완료 후, 필요 없는 기본 장치(사운드카드, USB 컨트롤러 등)는 제거하여 자원 절약 및 안정성 확보
- VMware 버전 25H2 기준 Rocky Linux 설치 시 3D 그래픽 가속 기능을 반드시 꺼야 충돌 없이 작동
- 가상 머신 파일은 압축하여 공유하거나, 이미 만들어진 가상 머신 폴더를 그대로 복사 및 다운받아 사용 가능
- 생성된 가상 머신 폴더 내 <mark>.vmdk</mark> 파일이 가상 하드디스크의 실체이며, 이 파일 용량은 사용량에 따라 동적으로 증가

### 6. 실습 진행 흐름 요약
1. Windows 탐색기에서 <mark>C:\로키텐</mark> 폴더 생성 및 각 가상 머신별 하위 폴더 생성
2. VMware에서 새 가상 머신 생성 -> OS 및 버전 선택 -> 저장 위치 지정
3. 기본 디스크 삭제 -> SCSI 타입의 새 디스크 추가 (서버, 서버비 기준)
4. 메모리 4GB, CPU 기본값 설정
5. 사운드 카드, USB 컨트롤러 제거(필요 시 유지)
6. 3D 그래픽 가속 기능 끄기(리눅스 가상 머신에 한함)
7. 가상 머신 생성 완료 후 동일 작업 반복하여 4대 모두 생성
8. 생성된 가상 머신 폴더와 파일 구조 확인 및 불필요한 초기 디스크 파일 삭제

### 7. 가상 머신 네트워크 및 운영 준비
- 각 가상 머신은 기본 NAT 네트워크 설정으로 외부 인터넷 접속 가능 
- 가상 머신을 실제 서버실 책상 위에 여러 컴퓨터를 올려놓은 것과 같은 환경으로 이해
- 모든 하드웨어 가상화 및 네트워크 연결은 VMware에서 자동으로 관리
- OS 설치 및 추가 환경 설정은 가상 머신 생성 후 별도 진행
