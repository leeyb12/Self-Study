프로젝트 기술서
프로젝트명 Music Board & Player  (음악 게시판 & 플레이어)
개발 의도 개인 음악을 업로드 · 재생하고, 커뮤니티 게시판과 실시간 채팅으로 사용자 간 소통이 가능한 풀스택 음악 플랫폼 조성
활용기술
- Frontend : React 19, React Router, Axios, HTML5 Audio API, WebSocket, CSS Variables
- Backend : Spring Boot 4.1, Spring Data JPA, Spring Security, WebSocket, JWT(JJWT), Lombok
- Database : Oracle 11g XE
- Tool : Visual Studio Code, Gradle, Git
내용

▶ 개발 기간 : 2025.06.13 ~ 06.25 (13일)

▶ 팀 구성 : 1명 (개인 프로젝트 · 프론트엔드 / 백엔드 단독 개발)

▶ 기능 구성

  1. 회원가입 / 로그인  (JWT 인증, BCrypt 암호화)
  2. 음악 파일 업로드 및 5가지 디자인의 플레이어
  3. 나만의 앨범 보관함 관리 (큐 연속 재생)
  4. 커뮤니티 게시판 (파일 첨부 · 댓글 · 페이지네이션)
  5. 실시간 채팅 (공개방 / 1:1 개인 메시지)
  6. 가사 싱크 표시 및 10가지 테마(다크 모드 포함)
▶ 세부 구현
  • Spring Security + JWT 필터 기반 인증 / 인가, 리소스 소유자만 수정 · 삭제 가능
  • 음악 파일은 서버 로컬 스토리지(C:/music_storage/)에 저장, MP3 ID3 태그 자동 추출
  • HTML5 Audio API로 재생 / 셔플 / 반복, 재생 위치에 따른 가사 싱크 패널
  • WebSocket 핸드셰이크 단계에서 JWT 검증 → 발신자 신원 위조 방지
  • Controller → Service → Repository 계층 분리, GlobalExceptionHandler 중앙 예외 처리
  • React Context API(Auth / Theme / PlayerDesign)로 전역 상태 관리, CSS 변수로 테마 단일 관리
기능 로그인 / 회원가입 JWT 인증 기반 회원 관리 음악 플레이어 (5가지 디자인) wall · walkman · boombox · turntable · glass
가사 싱크 패널 재생 위치에 맞춘 실시간 가사 표시 앨범 보관함 앨범 생성 및 큐 연속 재생
커뮤니티 게시판 첨부파일 · 댓글 · 페이지네이션 테마 전환 (10종) 다크 모드 포함, localStorage 유지
