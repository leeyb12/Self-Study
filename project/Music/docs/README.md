# Music Docs

Music 프로젝트의 문서와 화면 자료를 보관하는 폴더입니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `screenshots/` | 프로젝트 화면 캡처 |

## 관리 메모

기능 설명, API 메모, 화면 설계 자료를 추가할 때 이 폴더에 정리합니다.

## 문서화 기준

- 화면 이미지는 기능명과 상태가 드러나는 파일명으로 저장합니다.
- API 문서는 요청 조건, 예시 본문, 성공 응답과 오류 응답을 함께 기록합니다.
- 화면 설계에는 사용자의 진입점, 주요 동작과 완료 결과를 설명합니다.
- 구조나 설정이 바뀌면 코드와 문서가 같은 내용을 가리키는지 함께 확인합니다.
