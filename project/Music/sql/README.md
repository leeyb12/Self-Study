# Music SQL

Music 프로젝트의 DB 스키마와 초기 데이터 SQL을 보관하는 폴더입니다.

## 관리 메모

SQL 파일을 추가할 때는 실행 순서가 보이도록 파일명에 번호나 목적을 포함하는 것을 권장합니다.

## 데이터베이스 개념

- 테이블은 엔티티의 속성을 열로 정의하고 기본 키로 각 행을 식별합니다.
- 외래 키는 회원, 곡, 게시글과 댓글 사이의 참조 무결성을 유지합니다.
- Oracle 시퀀스는 새로운 행의 식별자를 생성할 때 사용할 수 있습니다.
- 인덱스는 조회 속도를 높이지만 쓰기 비용과 저장 공간이 필요하므로 검색 조건을 기준으로 선택합니다.
- 스키마 변경 SQL과 테스트 데이터 SQL을 분리하면 운영 반영 순서를 관리하기 쉽습니다.
