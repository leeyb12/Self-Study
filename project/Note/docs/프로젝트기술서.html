프로젝트명 AI Note  (AI 노트 작성 · 관리 애플리케이션)
개발 의도 로컬 LLM(Ollama)을 활용해 마크다운 노트 작성 · 폴더 정리 · 파일 첨부와 함께 AI 요약 · 번역 · 교정 · 이어쓰기 · 채팅을 지원하는 풀스택 노트 플랫폼 조성
활용기술
- Frontend : React 19, TypeScript, Vite, marked(마크다운), DOMPurify(XSS 방지)
- Backend : Spring Boot 4.1, Spring Data JPA, Spring Security, JWT(JJWT), Bean Validation, Apache PDFBox, Lombok
- Database : MariaDB
- AI : Ollama 로컬 LLM (기본 모델 gemma)
- Tool : Visual Studio Code, Gradle, Git
내용

▶ 개발 기간 : 2025.06.13 ~ 06.25 (13일)

▶ 팀 구성 : 1명 (개인 프로젝트 · 프론트엔드 / 백엔드 단독 개발)

▶ 기능 구성

  1. 회원가입 / 로그인  (JWT 인증, Spring Security)
  2. 마크다운 노트 작성 · 조회 · 수정 · 삭제(CRUD) 및 폴더별 분류
  3. 노트별 파일 첨부 · 다운로드  (최대 25MB) / PDF 뷰어 · 텍스트 추출
  4. 휴지통  (소프트 삭제 · 복원 · 영구 삭제)
  5. AI 요약 / 번역 / 교정 / 이어쓰기
  6. AI 채팅  (Ollama LLM 대화) 및 다크 / 라이트 테마
▶ 세부 구현
  • Spring Security + JWT 필터 기반 인증 / 인가, 리소스 소유자만 노트 · 첨부파일 접근 가능
  • OllamaClient로 로컬 LLM 연동, 노트 본문 · PDF 내용을 요약 / 번역 / 교정 / 이어쓰기 / 채팅에 활용
  • 첨부파일은 서버 로컬 스토리지에 저장, Apache PDFBox로 PDF 텍스트 자동 추출
  • 소프트 삭제(deleted_at) 기반 휴지통 — 복원 및 영구 삭제, 휴지통 비우기 지원
  • Controller → Service → Repository 계층 분리, GlobalExceptionHandler 중앙 예외 처리
  • marked로 마크다운 렌더링 후 DOMPurify로 XSS 차단, 테마는 localStorage로 유지
