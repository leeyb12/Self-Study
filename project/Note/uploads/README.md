# Note Uploads

Note 프로젝트에서 첨부파일 업로드 자료를 보관하는 폴더입니다.

## 주의

실제 서비스에서는 업로드 파일을 Git으로 관리하지 않는 것이 좋습니다. 이 폴더는 로컬 개발과 테스트용 저장 위치로 사용합니다.

## 파일 저장 개념

- 사용자가 올린 원본 파일명과 서버의 실제 저장 파일명을 분리하면 이름 충돌과 경로 문제를 줄일 수 있습니다.
- 확장자만 믿지 않고 MIME 타입, 파일 크기와 허용 형식을 검사해야 합니다.
- 다운로드 요청에서는 현재 사용자가 해당 첨부파일에 접근할 권한이 있는지 확인합니다.
- 운영 환경에서는 객체 스토리지나 별도 볼륨을 사용하고 DB에는 파일 메타데이터와 위치를 저장합니다.
