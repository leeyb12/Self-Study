# 006 - 머신 러닝 교과서 3판

`머신 러닝 교과서 3판` 교재를 따라가며 Jupyter Notebook 실습을 정리하는 폴더입니다.

머신러닝 개념을 이론으로만 정리하지 않고, 장별 노트북을 통해 데이터 전처리, 모델 학습, 평가 과정을 직접 실행하며 확인하는 것을 목표로 합니다.

## 폴더 구조

```text
006/
├─ 머신 러닝 교과서 3판/
│  ├─ ch01.ipynb
│  ├─ ch02.ipynb
│  ├─ ch03.ipynb
│  └─ ch04.ipynb
└─ README.md
```

## 학습 내용

| 파일 | 내용 |
| --- | --- |
| `ch01.ipynb` | 머신러닝 기본 개념과 학습 흐름 |
| `ch02.ipynb` | 분류 알고리즘과 기초 모델 실습 |
| `ch03.ipynb` | 사이킷런 기반 분류 모델과 평가 |
| `ch04.ipynb` | 데이터 전처리와 특성 처리 |

## 정리 기준

- 각 Notebook은 장별 실습 흐름을 유지합니다.
- 중요한 개념은 Markdown 셀로 요약합니다.
- 모델 학습 결과는 실행 출력과 함께 남깁니다.
- 헷갈리는 개념은 별도 메모로 정리합니다.

## 실행 방법

Jupyter 환경에서 노트북을 열어 실행합니다.

```powershell
cd "006\머신 러닝 교과서 3판"
jupyter notebook
```
