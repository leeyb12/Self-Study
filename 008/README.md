# 008 - Spring 교재 자료

Spring Framework와 Spring Boot 교재의 장별 자료를 관리하는 폴더입니다.

`스프링 프레임워크 첫걸음 (개정판)`에는 텍스트 예제가 있습니다. `실전! 스프링 부트 3 & 리액트로 시작하는 모던 웹 애플리케이션 개발`에는 현재 컴파일 산출물만 남아 있습니다.

## 폴더 구조

```text
008/
├─ 스프링 프레임워크 첫걸음 (개정판)/
│  ├─ 예제/
│  │  ├─ 2장/
│  │  │  ├─ 2-1.txt
│  │  │  ├─ ...
│  │  │  └─ 2-11.txt
│  │  └─ 3장/
│  └─ README.md
├─ 실전! 스프링 부트 3 & 리액트로 시작하는 모던 웹 애플리케이션 개발/
│  ├─ Chapter 04/bin/
│  ├─ Chapter 05/bin/
│  └─ Chapter 06/bin/
└─ README.md
```

## 학습 내용

| 폴더 | 내용 |
| --- | --- |
| `스프링 프레임워크 첫걸음 (개정판)/예제/2장` | Spring Framework 2장 텍스트 예제 |
| `스프링 프레임워크 첫걸음 (개정판)/예제/3장` | 다음 장 예제를 이어서 보관할 폴더 |
| `실전! 스프링 부트 3 & 리액트로 시작하는 모던 웹 애플리케이션 개발/Chapter 04` ~ `Chapter 06` | `bin/main`, `bin/test`의 컴파일 산출물 보관. 현재 소스와 빌드 설정 파일은 없음 |

## 정리 기준

- 장별 실습은 `예제/N장/` 폴더로 구분합니다.
- Spring Boot 교재 폴더는 원본 소스와 빌드 설정이 확인되기 전까지 실행 가능한 예제로 안내하지 않습니다.
- `build/`, `.gradle/`, `bin/` 같은 생성물은 Git 관리 대상에서 제외하는 것을 권장합니다.
- 기능이 추가되면 실행 방법, 패키지 구조, 설정 파일 변경점을 README에 함께 기록합니다.
