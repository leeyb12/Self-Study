## 정리 방식

각 Chapter는 다음 흐름으로 정리합니다.

1. 핵심 개념
2. 주요 이론 / 학자
3. 검사 도구
4. 헷갈리는 개념
5. 기출 포인트

## 정리 기준

- 개념은 짧게 정의하고, 시험에 나오는 표현을 함께 적습니다.
- 이론은 학자, 핵심 주장, 키워드를 묶어서 정리합니다.
- 기출 포인트는 암기해야 하는 문장과 헷갈리는 선택지를 분리합니다.
