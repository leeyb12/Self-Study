# 008 - Spring / Spring Boot 교재 실습

Spring Framework와 Spring Boot 교재의 장별 예제와 개념 정리를 관리하는 폴더입니다.

현재는 `스프링 프레임워크 첫걸음 (개정판)`의 텍스트 예제와 `실전! 스프링 부트 3 & 리액트로 시작하는 모던 웹 애플리케이션 개발`의 Chapter 산출물을 함께 보관합니다.

## 폴더 구조

```text
008/
├─ 스프링 프레임워크 첫걸음 (개정판)/
│  ├─ 예제/
│  │  ├─ 2장/
│  │  │  ├─ 2-1.txt
│  │  │  ├─ ...
│  │  │  └─ 2-11.txt
│  │  └─ 3장/
│  └─ README.md
├─ 실전! 스프링 부트 3 & 리액트로 시작하는 모던 웹 애플리케이션 개발/
│  ├─ Chapter 04/
│  ├─ Chapter 05/
│  └─ Chapter 06/
└─ README.md
```

| `스프링 프레임워크 첫걸음 (개정판)/예제/3장` | 이후 3장 예제를 정리할 공간 |
| `실전! 스프링 부트 3 & 리액트로 시작하는 모던 웹 애플리케이션 개발/Chapter 04` | Spring Boot 교재 4장 컴파일 산출물 |
| `실전! 스프링 부트 3 & 리액트로 시작하는 모던 웹 애플리케이션 개발/Chapter 05` | Spring Boot 교재 5장 컴파일 산출물 |

## 정리 기준

- 장별 실습은 `예제/N장/` 폴더로 구분합니다.
- `build/`, `.gradle/`, `bin/` 같은 생성물은 Git 관리 대상에서 제외하는 것을 권장합니다.
- Spring Boot 교재 폴더는 현재 `bin/` 중심이므로 원본 `src/`, `build.gradle`, 설정 파일이 확보되면 실행 방법을 다시 정리합니다.
- 기능이 추가되면 실행 방법, 패키지 구조, 설정 파일 변경점을 README에 함께 기록합니다.
