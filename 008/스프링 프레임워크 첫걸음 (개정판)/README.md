# 스프링 프레임워크 첫걸음 (개정판)

Spring Framework 기초 개념을 장별 텍스트 파일로 정리하는 폴더입니다.

## 폴더 구조

```text
스프링 프레임워크 첫걸음 (개정판)/
└─ 예제/
   ├─ 2장/
   │  ├─ 2-1.txt
   │  ├─ ...
   │  └─ 2-11.txt
   └─ 3장/
```

## 학습 내용

| 폴더 | 내용 |
| --- | --- |
| `예제/2장/` | Spring Framework 2장 개념 정리 |
| `예제/3장/` | 3장 예제 정리 공간 |

## 정리 기준

- 장별 폴더를 만들고 절 번호별 텍스트 파일로 나눕니다.
- 개념, 용어, 예제 흐름을 짧게 정리합니다.
- 실습 프로젝트가 추가되면 실행 방법과 패키지 구조를 README에 함께 기록합니다.
