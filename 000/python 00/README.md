# python 00

Python 기초 문제를 Day 01부터 Day 25까지 순서대로 풀이한 폴더입니다.

## 구성

각 Day 폴더는 주제별 문제 파일을 담고 있습니다.

| 구간 | 주요 내용 |
| --- | --- |
| Day 01-03 | 출력과 기본 연산 |
| Day 04-08 | 조건문, 반복문, 문자열 기초 |
| Day 09-19 | 문자열과 리스트 문제 |
| Day 20-23 | 함수/메서드와 조건문 활용 |
| Day 24-25 | 반복문 활용과 2차원 리스트 |

## 실행

```powershell
python "Day 01 출력\문자열 출력하기.py"
```

문제 파일은 서로 독립적이므로 필요한 파일만 골라 실행하면 됩니다.
