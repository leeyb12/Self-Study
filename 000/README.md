# 000 - Python Coding Practice

프로그래머스 스타일의 Python 기초 문제 풀이를 Day 단위로 정리한 폴더입니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `python 00/` | Day 01부터 Day 25까지의 기초 문제 풀이 |
| `python 01/` | 사칙연산, 조건문, 배열 등 추가 Python 문제 풀이 |

## 학습 범위

- 출력, 입력, 사칙연산
- 조건문과 반복문
- 문자열 인덱싱, 슬라이싱, 변환
- 리스트와 2차원 리스트
- 함수와 메서드 활용

## 실행 방법

각 문제 파일은 독립 실행 가능한 `.py` 파일입니다.

```powershell
python "python 00\Day 01 출력\문자열 출력하기.py"
```

파일명에 공백이나 한글이 포함되어 있으므로 PowerShell에서는 경로를 따옴표로 감싸는 것을 권장합니다.
