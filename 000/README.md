## 핵심 개념

- 문제를 입력, 처리, 출력의 세 단계로 나누면 구현 순서를 정하기 쉽습니다.
- 조건문은 실행 경로를 선택하고 반복문은 같은 규칙을 여러 데이터에 적용합니다.
- 문자열과 리스트는 인덱스, 슬라이싱, 순회를 함께 익혀야 다양한 문제에 적용할 수 있습니다.
- 풀이 후에는 시간 복잡도와 불필요한 반복을 확인해 더 단순한 방법이 있는지 비교합니다.
