## 비트(bit)가 무엇인가요?
### 비트 (Bit)의 개념과 중요성
> "비트(bit)는 두 가지 상태를 나타내는 기본 단위이다."
- 비트(bit): binary digit의 약자로, 0과 1 두 가지 상태를 나타내는 정보의 최소 단위
- 컴퓨터에서 모든 정보는 비트 단위로 표현되고 저장됨
- 비트의 두 가지 상태 예시
  - 전구: 켜짐(1) / 꺼짐(0)
  - 스위치: 켜짐(1) / 꺼짐(0)
  - 자석: N극(0) / S극(1) 등

### 비트 조합에 의한 상태 표현
- 비트 1개: 2가지 상태 표현 가능 (예: 전구 1개 -> 켜짐, 꺼짐)
- 비트 2개: $2^2 = 4$가지 상태 표현 가능
- 비트 3개: $2^3 = 8$가지 상태 표현 가능
- 비트 4개: $2^4 = 16$가지 상태 표현 가능

| 비트 수 (n) | 표현 가능한 상태 수 ($2^n$) | 예시 (전구 상태) |
|-------------|-----------------------------|------------------|
| 1 | 2 | 꺼짐, 켜짐 |
| 2 | 4 | 00, 01, 10, 11 |
| 3 | 8 | 꺼꺼꺼, 꺼꺼켜, ... , 켜켜켜 (총 8가지) |
| 4 | 16 | 0000, 0001, ..., 1111 (총 16가지) |

- 상태 조합은 전구나 스위치가 나란히 있을 때의 켜짐/꺼짐 조합을 생각하면 이해가 쉬움
- 비트가 많아질수록 상태 수가 기하급수적으로 늘어나므로 직접 계산하기 어려움 → 지수 표현 사용

### 비트 상태 표현의 수학적 공식
- 비트가 $n$개일 때 표현 가능한 총 상태 수는 다음과 같음:

  $$\text{상태 수} = 2^n$$

- 예시
  - 비트 1개: $2^1 = 2$
  - 비트 3개: $2^3 = 8$
  - 비트 8개: $2^8 = 256$
- 실생활에서 전구 8개가 각기 켜짐/꺼짐을 표현하는 경우 총 256가지 조합이 가능함
- 컴퓨터 데이터 저장 단위에서 비트 8개를 묶은 것을 **바이트(byte)**라 부름

### 바이트(Byte)와 데이터 저장
- 1바이트 = 8비트
- 컴퓨터는 바이트 단위로 데이터를 저장하고 처리함
- 바이트 단위는 실질적인 데이터 표현 및 저장 단위로 사용됨

| 단위 | 비트 수 | 상태 표현 수 |
|------|---------|--------------|
| 1비트 | 1 | 2 |
| 1바이트 | 8 | $2^8 = 256$ |

- 바이트는 여러 비트를 묶어 복잡한 정보를 표현하기 위한 최소 단위임
- 데이터 저장 시 비트들을 바이트 단위로 모아 관리하는 이유는 효율적인 처리와 저장 공간 활용 때문

### 0과 1로 비트 상태를 표현하는 방법
- 비트 상태를 0과 1로 표시하는 이진법 사용
- 0: 꺼짐, 1: 켜짐으로 전구 상태를 표현 가능
- 예시: 4비트 전구 상태

| 전구 상태 | 이진 표현 |
|-----------|-----------|
| 모두 꺼짐 | 0000 |
| 오른쪽 1개 켜짐 | 0001 |
| 가운데 1개 켜짐 | 0100 |
| 모두 켜짐 | 1111 |

- 이진법을 이용하면 복잡한 상태 조합도 간단히 숫자로 나타낼 수 있음
- 이진수 4자리 -> $2^4=16$가지 상태 표현 가능

### 비트와 상태 조합 요약 표
| 비트 수 (n) | 상태 수 ($2^n$) | 설명 | 예시 (전구 개수) |
|-------------|-----------------|------|------------------|
| 1 | 2 | 한 개 비트로 두 상태 표현 | 꺼짐/켜짐 |
| 2 | 4 | 두 비트 조합 4가지 상태 | 2개 전구 켜짐/꺼짐 조합 |
| 3 | 8 | 세 비트 조합 8가지 상태 | 3개 전구 켜짐/꺼짐 조합 |
| 4 | 16 | 네 비트 조합 16가지 상태 | 4개 전구 켜짐/꺼짐 조합 |
| 8 | 256 | 8비트 = 1바이트, 256가지 상태 | 8개 전구 켜짐/꺼짐 조합 |

<br>
<hr>
비트는 두 가지 상태만을 나타내지만, 여러 개의 비트 조합을 통해 방대한 상태를 표현할 수 있다. 이진수 체계는 복잡한 상태를 간결하게 표현할 수 있도록 하며, 컴퓨터 데이터 저장의 기본 단위인 바이트는 8비트를 묶어 다양한 정보를 효율적으로 관리한다. 상태 수가 지수적으로 증가하는 특성은 정보 처리와 저장의 근간을 이루며, 비트와 바이트 단위의 개념은 컴퓨터 과학과 전자공학 등 다양한 분야에서 핵심적인 역할을 수행한다.
