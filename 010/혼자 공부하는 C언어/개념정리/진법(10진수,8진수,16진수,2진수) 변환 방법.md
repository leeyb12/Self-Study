## 진법(10진수, 8진수, 16진수, 2진수) 변환 방법
### 진법의 개념 및 종류
> "진법은 숫자를 표현하는 방법으로, 사용하는 단위 숫자의 개수에 따라 구분된다."
- 10진법 (Decimal): 숫자 0~9, 총 10개 단위 숫자 사용
- 2진수 (Binary): 숫자 0, 1 두 개 단위 숫자 사용
- 8진법 (Octal): 숫자 0~7,  총 8개 단위 숫자 사용
- 16진법 (Hexadecimal): 숫자 0~9와 알파벳 a~f(또는 A~F) 합쳐 총 16개 단위 숫자 사용

| 진법 | 단위 숫자 개수 | 단위 숫자 예시 |
|------|----------------|----------------|
| 10진법 | 10 | 0, 1, 2, ..., 9 | 
| 2진법 | 2 | 0, 1 |
| 8진법 | 8 | 0, 1, 2, ..., 7 |
| 16진법 | 16 | 0, 1, ..., 9, a, b, c, d, e, f |

### 진법별 가중치와 값 계산 방법
- 각 자리수는 오른쪽부터 왼쪽으로 가면서 가중치가 증가함
- 가중치는 진법의 밑(base)을 거듭제곱한 값으로 결정됨
  - 예: 10진법은  $10^0, 10^1, 10^2 ...$
  - 2진법은 $2^0, 2^1, 2^2 ...$
  - 8진법은 $8^0, 8^1, 8^2 ...$
  - 16진법은 $16^0, 16^1, 16^2 ...$

#### 10진법 예시 (1024)
- 각 자리의 숫자에 가중치를 곱해서 더함
- 계산식: $1 \times 10^3 + 0 \times 10^2 + 2 \times 10^1 + 4 \times 10^0 = 1000 + 0 + 20 + 4 = 1024$

#### 2진법 예시 (1011)
- 오른쪽부터 가중치 적용: $1 \times 2^3 + 0 \times 2^2 + 1 \times 2^1 + 1 \times 2^0 = 8 + 0 + 2 + 1 = 11$

#### 8진법 예시 (1703)
- 계산: $1 \times 8^3 + 7 \times 8^2 + 0 \times 8^1 + 3 \times 8^0 = 512 + 448 + 0 + 3 = 963$

#### 16진법 예시 (1a4)
- a = 10진수 10
- 계산: $1 \times 16^2 + 10 \times 16^1 + 4 \times 16^0 = 256 + 160 + 4 = 420$

| 진법 | 예시 수 | 자리별 계산식 | 10진수 값 |
|------|---------|---------------|-----------|
| 10진법 | 1024 | $1 \times 10^3 + 0 \times 10^2 + 2 \times 10^1 + 4 \times 10^0$ | 1024 |
| 2진법 | 1011 | $1 \times 8^3 + 7 \times 8^2 + 0 \times 8^1 + 3 \times 8^0$ | 11 |
| 8진법 | 1703 | $1 \times 8^3 + 7 \times 8^2 + 0 \times 8^1 + 3 \times 8^0$ | 963 | 
| 16진법 | 1a4 | $1 \times 16^2 + 10 \times 16^1 + 4 \times 16^0$ | 420 |

### 10진수를 다른 진법으로 변환하는 방법
- 나누기 연산을 반복하여 몫과 나머지를 구함
- 나머지를 밑(base)으로 하는 숫자로 변환된 자리수로 사용
- 몫이 0이 될 때까지 반복

#### 변환 절차 예시 (10진수 -> 2진수)
1. 10진수 숫자를 2로 나눈다.
2. 나머지를 기록한다.
3. 몫이 0이 될 때까지 2로 계속 나눈다.
4. 나머지들을 거꾸로 읽으면 2진수로 변환된 숫자가 된다.

#### 16진수, 8진수 변환도 같은 원리 적용
- 16진수 변환 시 16으로 계속 나누기
- 8진수 변환 시 8로 계속 나누기

| 10진수 | 진법 변환 방법 | 설명 |
|--------|----------------|------|
| 190 | 2진수로 변환 (나누기 2) | 몫과 나머지를 반복 계산 후 역순으로 읽기 |
| 190 | 16진수로 변환 (나누기 16) | 몫과 나머지를 반복 계산 후 역순으로 읽기 |
| 190 | 8진수로 변환 (나누기 8) | 몫과 나머지를 반복 계산 후 역순으로 읽기 |

### 2진수, 8진수, 16진수 간 변환의 효율적 방법
- 8진수 단위 숫자 1개는 2진수 3자리와 정확히 대응됨
- 16진수 단위 숫자 1개는 2진수 4자리와 정확히 대응됨

| 진법 간 변환 | 대응 단위 숫자 개수 | 설명 |
|--------------|---------------------|------|
| 8진수 -> 2진수 | 1 : 3 | 8진수 한 자리 = 2진수 3자리 |
| 16진수 -> 2진수 | 1 : 4 | 16진수 한 자리 = 2진수 4자리 |

- 예: 8진수 7은 2진수 111, 16진수 f는 2진수 1111
- 16진수는 2진수 4자리씩 끊어서 쉽게 변환 가능
- 8진수는 2진수 3자리씩 끊어서 변환 가능

#### 변환 예시
| 진법 | 숫자 | 2진수 표현 | 비고 |
|------|------|------------|------|
| 8진수 | 7 | 111 | 3자리 2진수 |
| 16진수 | f | 1111 | 4자리 2진수 |
| 16진수 | b | 1011 | 4자리 2진수 |

### 비트(Bit)와 상태 표현 
- 비트(bit): 두 가지 상태(0 또는 1)를 표현하는 단위
- 비트 수에 따른 표현 가능한 상태 수

| 비트 수 | 표현 가능한 상태 수 | 계산식 |
|---------|---------------------|--------|
| 1 | 2 | $2^1$ |
| 2 | 4 | $2^2$ |
| 3 | 8 | $2^3$ |
| 4 | 16 | $2^4$ |

- 8진수 숫자 하나는 3비트, 16진수 숫자 하나는 4비트와 대응됨

### 진수 변환 연습 시 유의점
- 앞에 0이 붙어도 전체 값에는 영향 없음
- 몫과 나머지 계산을 정확히 수행할 것
- 2진수 -> 8진수, 16진수 변환 시, 2진수를 3자리(8진수), 4자리(16진수)씩 끊어서 변환
- 10진수 -> 다른 진법 변환 시 몫이 0이 될 때까지 반복

### 진법 변환 요약 표
| 변환 방향 | 방법 설명 | 비고 |
|-----------|-----------|------|
| 진법 -> 10진법 | 각 자리수 x 진법의 가중치 합산 | 가중치는 진법의 자리수 거듭제곱 |
| 10진법 -> 진법 | 나누기 연산 반복 (몫과 나머지 이용) | 몫이 0이 될 때까지 반복 |
| 8진수 <-> 2진수 | 8진수 1자리 = 2진수 3자리 매핑 | 빠른 변환 가능 |
| 16진수 <-> 2진수 | 16진수 1자리 = 2진수 4자리 매핑 | 빠른 변환 가능 |

### 주요 예시 정리
| 문제 유형 | 예시 | 풀이 요점 |
|-----------|------|-----------|
| 10진수 -> 2진수 | 190 -> ? | 190을 2로 나누며 몫과 나머지 기록 후 역순 읽기 |
| 2진수 -> 10진수 | 1011 -> ? | 각 자리수 x 2의 거듭제곱 후 합산 |
| 8진수 -> 10진수 | 1703 -> ? | 각 자리수 x 8의 거듭제곱 후 합산 |
| 16진수 -> 10진수 | 1a4 -> ? | a = 10, 각 자리수 x 16의 거듭제곱 후 합산 |
| 10진수 -> 16진수 | 291 -> ? | 16으로 나누기 반복, 나머지 역순으로 배열 |
| 2진수 <-> 8진수, 16진수 | 1011(2진수) -> ? | 2진수 3자리씩(8진수), 4자리씩(16진수)로 묶어 변환 |

<hr>
진법 체계는 숫자를 표현하는 기본 구조를 제공하며, 각 자리의 가중치와 단위 숫자 개수에 따라 수의 값을 결정한다. 진법 간 변환은 몫과 나머지를 이용한 나누기 과정 또는 자리수 간 매핑을 통해 효율적으로 이루어진다. 비트 단위로 표현 가능한 상태 수와 진법 간 자리수 대응 관계는 컴퓨터 과학 및 전산학에서 수의 처리 방식을 이해하는 데 핵심적이다.
