## 10진수 형태의 실수를 2진수로 바꾸는 방법
### 10진수 실수를 2진수 실수(실수 형태)로 변환하는 방법
> "10진수 형태의 실수를 2진수 형태의 실수, 즉 실수 형태로 바꾸는 과정은 정수 부분과 소수 부분을 분리하여 각각 변환하는 방식으로 이루어진다."

#### 1. 정수 부분을 2진수로 변환하기
- 소수점 기준으로 정수 부분과 소수 부분을 분리한다.
- 정수 부분은 2로 나누면서 몫과 나머지를 기록한다.
- 몫이 0이 될 때까지 반복하며, 나머지를 밑에서부터 위로 읽으면 2진수 정수가 된다. 

| 예시: 9 (십진수) 정수 부분 변환 과정 | |
|--------------------------------------|-|
| 9 ÷ 2 = 4, 나머지 1 | 나머지 기록 |
| 4 ÷ 2 = 2, 나머지 0 | 나머지 기록 |
| 2 ÷ 2 = 1, 나머지 0 | 나머지 기록 |
| 1 ÷ 2 = 0, 나머지 1 | 나머지 기록 |
| 2진수 -> 밑에서 위로 읽으면 1001 |

- 결과: 9(십진수) -> 1001(2진수)

#### 2. 소수 부분을 2진수로 변환하기
- 소수 부분은 2를 곱하는 방식으로 변환한다.
- 각 곱셈 후 소수점 앞의 정수 부분(0 또는 1)을 차례대로 기록한다.
- 곱한 결과에서 소수점 앞 정수를 분리한 뒤, 남은 소수 부분으로 다시 2를 곱한다.
- 이 과정을 소수 부분이 0이 될 때까지 또는 원하는 정확도에 도달할 때까지 반복한다.

| | 예시: 0.625 (십진수) 소수 부분 변환 과정 |
|-|------------------------------------------|
| 0.625 x 2 = 1.25 | 정수 부분 1 기록 |
| 0.25 x 2 = 0.5 | 정수 부분 0 기록 |
| 0.5 x 2 = 1.0 | 정수 부분 1 기록 |
| 소수 부분 0이 되어 종료 | 2진수 소수 부분: 101 |

- 결과: 0.625(십진수) -> 0.101(2진수)

#### 3. 전체 실수 결합 
- 정수 부분과 소수 부분의 2진수 변환 결과를 '.'으로 구분하여 결합한다.
- 예: 9.625(십진수) -> 1001.101(2진수)

#### 4. 2진수 실수를 10진수 실수로 다시 변환
- 2진수 소수점 왼쪽 자리의 가중치는 $2^0, 2^1, 2^2, \dots$로 오른쪽에서 왼쪽으로 증가한다.
- 소수점 오른쪽 자리의 가중치는 $2^{-1}, 2^{-2}, 2^{-3}, \dots$로 왼쪽에서 오른쪽으로 감소한다.

| 2진수 자리 위치 | 가중치 | 예시 값(자리 숫자 x 가중치) | 
|-----------------|--------|-----------------------------|
| 정수 부분 (1001) | $2^3 = 8, 2^2 = 4, 2^1 = 2, 2^0 = 1$ | $1 \cdot 8 + 0 \cdot 4 + 0 \cdot 2 + 1 \cdot 1 = 9$ |
| 소수 부분 (0.101) | $2^{-1}=\frac{1}{2}, 2^{-2}=\frac{1}{4}, 2^{-3}=\frac{1}{8}$ | $1 \cdot \frac{1}{2} + 0 \cdot \frac{1}{4} + 1 \cdot \frac{1}{8} = 0.5 + 0 + 0.125 = 0.625$ |

- 결국 9 + 0.265 = 9.625로 원래 10진수 실수와 일치함을 확인할 수 있다.

#### 5. 정리 및 유의점
| 구분 | 변환 방법 | 주의점 |
|------|-----------|--------|
| 정수 부분 | 2로 나누며 몫과 나머지 기록 | 몫이 0이 될 때까지 반복 |
| 소수 부분 | 2를 곱하며 정수 부분 기록 | 소수 부분이 0이 되거나 원하는 정확도까지 반복 |
| 결합 | 정수 부분과 소수 부분을 '.'로 연결 | 소수 부분 변환은 무한 반복될 수 있음 (근사치 사용) |

- 소수 부분 변환에서 곱한 결과의 정수 부분을 차례대로 나열하는 것이 핵심이다.
- 정수 부분은 나머지를 위에서 아래로 읽는 것과 달리, 소수 부분은 곱셈 후 나온 정수 부분을 순서대로 나열한다.
