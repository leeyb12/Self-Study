## 연산자의 정의와 개념
> "연산자란 컴파일러에게 데이터 가공을 지시하는 기호이다."

| 구분 | 설명 |
|------|------|
| 연산자 기호 | \+, \-, \=, \!, \%, \| 등 다양한 기호 사용 |
| 역할 | 데이터에 대해 산술, 논리, 비교 등 연산 수행 |

- 연산자는 데이터 가공을 위한 컴파일러 지시 기호
- C#에서 여러 종류의 연산자 제공

## C#의 연산자 종류 
| 연산자 종류 | 설명 | 특징 및 예시 |
|-------------|------|--------------|
| 산술 연산자 | 덧셈(+), 뺄셈(-), 곱셈(*), 나눗셈(/), 나머지(%) | 두 개의 피연산자 필요 (2항 연산자) |
| 증가/감소 연산자 | 변수 값을 1씩 증가(++), 감소(--) | 단항 연산자(1항), 전위/후위 형태 존재 |
| 관계 연산자 | 크기 비교(<, >, <=, >=), 동등(==), 부등(!=) | 결과는 불타입(참/거짓) |
| 조건 연산자 | 조건식 ? 참일 때 값 : 거짓일 때 값 반환 | if문과 동일 기능, 삼항 연산자 |
| 논리 연산자 | 논리곱(&&), 논리합(\|\|), 부정(!) | 불대수 기반, 참/거짓 연산 수행 |
| 비트 연산자 | 이진수 단위로 연산 수행 (AND, OR, XOR, NOT, 시프트) | 비트 단위 데이터 가공 |
| 할당 연산자 | 변수에 값 할당, 복합 할당 가능 (+=, -=, <<= 등) | 오른쪽 피연산자 값을 왼쪽 변수에 할당 |

## 산술 연산자
- 정수형 및 부동소수점형 데이터에 사용
- 두 개의 피연산자 필요 (이항 연산자)
- 예시
  - <mark>3 + 4 = 7</mark>
  - <mark>15 / 3 = 5</mark>
- 친숙한 기호 사용

| 연산자 | 설명 |
|--------|------|
| + | 덧셈 |
| - | 뺄셈 | 
| * | 곱셈 |
| / | 나눗셈 |
| % | 나머지 |

## 증감 연산자 
- 변수 값을 1씩 증가 또는 감소시킴
- 단항 연산자(1항)
- 전위 연산자: ++a (먼저 증가 후 사용)
- 후위 연산자: a++ (먼저 사용 후 증가)
- 변수에만 적용 가능

| 형태 | 설명 | 예시 및 결과 |
|------|------|--------------|
| 전위 | 값을 먼저 증가/감소시킴 | <mark>int a = 10; int b = ++a;</mark> b는 11 |
| 후위 | 값을 먼저 사용 후 변경 | <mark>int a = 10; int b = a++;</mark> b는 10, a는 11 |

## 문자열 결합 연산자
- <mark>+</mark> 기호를 사용하지만 산술 덧셈과 다름
- 두 문자열을 연결하여 하나의 문자열 생성
- 예시
  <mark>"123" + "456" = "123456"</mark>
- 피연산자가 문자열일 때 동작

## 관계 연산자
- 두 피연산자의 크기 또는 동등성 비교
- 결과는 불(bool) 타입 (true 또는 false)
- 주요 연산자와 의미

| 연산자 | 의미 | 설명 |
|--------|------|------|
| < | 작다 | 왼쪽이 오른쪽보다 작으면 true | 
| > | 크다 | 왼쪽이 오른쪽보다 크면 true | 
| <= | 작거나 같다 | 작거나 같으면 true |
| >= | 크거나 같다 | 크거나 같으면 true |
| == | 같다 | 양쪽 값이 같으면 true |
| != | 다르다 | 양쪽 값이 다르면 true |

- 예시: <mark>3 < 4 -> true</mark>, <mark>3 == 4 -> false</mark>

## 논리 연산자 (Boolean 연산)
- 참(true)과 거짓(false)을 다루는 연산자
- 조지 부울(George Boole)의 이름에서 유래
- 주요 종류

| 연산자 | 의미 | 설명 |
|--------|------|------|
| && | 논리곱 (AND) | 두 피연산자가 모두 참일 때만 참 |
| \|\| | 논리합 (OR) | 두 피연산자 중 하나라도 참이면 참 |
| ! | 부정 (NOT) | 피연산자의 참/거짓 상태를 반대로 변경 |
| ^ | 배타적 논리합 (XOR) | 둘 중 하나만 참일 때 참, 둘 다 같으면 거짓 |

- 예시
  - <mark>true && false = false</mark>
  - <mark>true || false = true</mark>
  - <mark>!true = false</mark>

## 조건 연산자 (삼항 연산자)
- 구문: <mark>조건식 ? 참일 때 값 : 거짓일 때 값</mark>
- <mark>if</mark> 문과 같은 역할을 함
- 조건식을 평가해 참이면 <mark>?</mark> 뒤 값 반환, 거짓이면 <mark>:</mark> 뒤 값 반환
### 예시
```cs
int a = 30;
var result = (a == 30) ? 30 : 40;  // result는 30
```

## 비트 연산자
- 2진수 비트 단위로 데이터를 가공하는 연산자
- 데이터는 메모리 내 32비트(예: int)로 표현됨
- C# 비트 연산자 6종류 제공

| 연산자 | 설명 |
|--------|------|
| << | 왼쪽 시프트: 비트를 왼쪽으로 밀고 오른쪽 빈칸 0으로 채움 |
| >> | 오른쪽 시프트: 비트를 오른쪽으로 밀고 왼쪽 빈칸 0으로 채움 |
| & | 논리곱 (AND): 각 비트별로 1이면 1, 아니면 0 |
| \| | 논리합 (OR): 각 비트별로 하나라도 1이면 1 | 
| ^ | 배타적 논리합 (XOR): 서로 다르면 1, 같으면 0 |
| ~ | 보수 (NOT): 모든 비트 반전 |

- 예시 
  - <mark>240</mark> -> 이진수 <mark>11110000</mark>
  - <mark>240 << 2</mark> -> 1111000000 (왼쪽으로 2칸 시프트, 오른쪽 0 채움)

## 할당 연산자
- 변수 또는 상수에 값을 할당하는 연산자
- 기본 할당: <mark>a = b</mark>
- 복합 할당 연산자: 기존 값에 연산 후 재할당

| 연산자 | 의미 | 설명 |
|--------|------|------|
| = | 기본 할당 | 오른쪽 값을 왼쪽 변수에 할당 |
| += | 덧셈 후 할당 | <mark>a += b</mark>는 <mark>a = a + b</mark>와 같음 |
| -= | 뺄셈 후 할당 | <mark>a -= b</mark>는 <mark>a = a - b</mark>와 같음 | 
| *= | 곱셈 후 할당 | <mark>a *= b</mark>는 <mark>a = a * b</mark>와 같음 |
| /= | 나눗셈 후 할당 | <mark>a /= b</mark>는 <mark>a = a / b</mark>와 같음 |
| <<= | 왼쪽 시프트 후 할당 | <mark>a <<= b</mark>는 <mark>a = a << b</mark>와 같음 |

- 모든 복합 할당 연산자는 연산 후 왼쪽 변수에 재할당

## 연산자 우선순위
- 연산자마다 우선순위가 존재하여 계산 순서 결정
- C# 우선순위 (높은 순서부터)

| 순위 | 연산자 종류 | 설명 |
| 1 | 후위 증감 연산자 | <mark>a++</mark>, <mark>a--</mark> |
| 2 | 전위 증감 연산자 | <mark>++a</mark>, <mark>--a</mark> |
| 3 | 산술 연산자 | <mark>*</mark>, <mark>/</mark>, <mark>%</mark>, <mark>+</mark>, <mark>-</mark> | 
| 4 | 쉬프트 연산자 | <mark><<</mark>, <mark>>></mark> | 
| 5 | 관계 연산자 | <mark><</mark>, <mark>></mark>, <mark><=</mark>, <mark>>=</mark> |
| 6 | 비트 논리 연산자 | <mark>&</mark>, <mark>\|</mark>, <mark>^</mark> |
| 7 | 할당 연산자 | <mark>=</mark>, <mark>+=</mark>, <mark>-=</mark>, <mark><<=</mark> 등 | 

- 복잡한 우선순위 외우기보다 카테고리별 이해가 중요
- 경험과 코딩을 통해 자연스레 익힘

## 주요 예시 코드 정리
| 기능 | 코드 예시 | 설명 |
|------|-----------|------|
| 산술 덧셈 | <mark>int sum = 3 + 4;</mark> | 3과 4를 더해 7 저장 |
| 증감 연산자 (후위) | <mark>a = 10; int b = a++;</mark> | b는 10, a는 11 |
| 증감 연산자 (전위) | <mark>a = 10; int b = ++a;</mark> | b는 11, a도 11 | 
| 문자열 결합 | <mark>string s = "123" + "456";</mark> | s는 "123456"|
| 관계 연산자 | <mark>bool isLess = 3 < 4;</mark> | isLess는 true |
| 조건 연산자 | <mark>var result = (a == 30) ? 30 : 40</mark> | a가 30이면 30, 아니면 40 반환 |
| 비트 시프트 | <mark>int shifted = 240 << 2;</mark> | 240을 왼쪽으로 2비트 시프트 |
| 비트 논리곱 | <mark>int andResult = 9 & 10;</mark> | 9과 10의 비트 논리곱 결과 |
| 할당 복합 연산자 | <mark>a += b;</mark> | <mark>a = a + b</mark>와 동일 |

연산자는 컴파일러에게 데이터 처리 방법을 지시하는 도구로, 각 연산자가 다루는 데이터 유형과 연산 방식에 따라 구분된다. 산술 연산자는 수치형 데이터의 기본 계산을 담당하며, 증감 연산자는 변수 값을 간단히 수정한다. 문자열 결합 연산자는 문자열 데이터 처리에 특화되어 있으며, 관계 및 논리 연산자는 조건 판단과 불대수를 바탕으로 참거짓을 결정한다. 비트 연산자는 이진수 단위로 정밀한 데이터 조작을 가능하게 하고, 할당 연산자는 변수에 값을 저장하면서 연산 결과를 재할당한다. 각 연산자의 우선순위는 계산 흐름을 규정해, 복잡한 표현식 내에서 정확한 결과 도출을 보장한다.
