### 조건문과 반복문
| 구분 | 설명 | 예시 및 특징 |
|------|------|--------------|
| 조건문 | 조건이 참일 때만 코드 블록 실행 | if 조건문, 항상 true일 때 경고 발생 (IntelliJ) |
| for 반복문 | 초기화, 조건 검사, 증감식 포함 반복문 | 반복 변수 <mark>i</mark>를 0부터 배열 길이 미만까지 증가시키며 반복 실행 |
| while 반복문 | 조건 검사 후 반복 실행, 반복 변수 선언과 증감식은 반복문 밖 혹은 내부에 위치할 수 있음 | 조건이 true일 때 계속 반복, 특정 조건에 <mark>break</mark>로 반복 종료 가능 |

- for문은 반복 제어가 명확할 때 적합
- while문은 종료 조건이 복잡하거나 중간에 종료 브레이크가 필요할 때 적합
- 두 반복문의 내부 증감식 위치와 변수 선언 위치 차이가 있음

### 다형성 (Polymorphism)
- 다형성 정의: 하나의 객체가 여러 타입을 가질 수 있으며, 동일한 코드가 객체의 실제 타입에 따라 다른 동작 수행
- 겉보기에는 같은 타입(상위 타입 레퍼런스)이나 내부 객체 타입에 따라 다르게 동작
- 다형성 구현 방법: 상속과 인터페이스 활용
- 코드 예시 구성
  - <mark>Car</mark> 인터페이스
  - <mark>Sonata</mark>, <mark>K5</mark> 클래스가 <mark>Car</mark> 인터페이스 구현
  - <mark>Main</mark> 클래스에서 <mark>Car</mark> 타입 변수에 <mark>Sonata</mark>, <mark>K5</mark> 인스턴스 대입 가능
- 주의점: 하위 타입 인스턴스를 상위 타입 레퍼런스에 넣는 것 자체는 다형성의 기본 조건이며, 실제 다형성은 실행 시점에 서로 다른 동작을 실행하는 것임
- 다형성은 객체지향 프로그래밍에서 매우 중요한 개념이며, 차후 학습에서 점진적으로 이해도 향상

### 컬렉션: 리스트 (List)
- 리스트는 배열과 유사하며, 인덱스는 0부터 시작
- 예시
  - <mark>ArrayList\<Integer></mark> 생성 후, 1, 2, 3 저장
  - <mark>get(1)</mark> 호출 시 인덱스 1 위치의 값 2 반환
- 문자열 리스트 예시 
  - 문자열 3개 넣고 순회 출력
  - 리스트에서 요소 제거 (<mark>remove</mark>)
  - 특정 문자열 인덱스 찾기 (<mark>indexOf</mark>)
- 리스트는 데이터 저장과 순회에 편리하며, 배열보다 유연한 크기 조절 가능
- 다른 컬렉션(<mark>Set</mark>, <mark>Map</mark>)도 중요하며, 상황에 따라 적절한 컬렉션 선택 필요

### 동일성과 동등성
| 구분 | 비교 대상 | 설명 | 결과 예시 |
|------|-----------|------|-----------|
| 동일성 | 객체 인스턴스 자체 비교 | 두 레퍼런스가 같은 객체(인스턴스)인지 비교 <br> <mark>==</mark> 사용 | 서로 다른 인스턴스면 <mark>false</mark> |
| 동등성 | 객체의 내용(값) 비교 | 두 객체가 같은 내용을 갖는지 비교 <br> <mark>equals()</mark> 메서드 사용 | 내용이 같으면 <mark>true</mark> |

- <mark>String str1 = new String("세");</mark>, <mark>String str2 = new String("세");</mark> 비교 시
  - <mark>str1 == str2</mark> -> <mark>false</mark> (서로 다른 인스턴스) 
  - <mark>str1.equals(str2)</mark> -> <mark>true</mark> (내용 동일)
- 사용자 정의 클래스는 <mark>equals()</mark> 메서드를 오버라이딩 해야 동등성 비교 시 의미 있는 결과 도출 가능
- 동일성은 레퍼런스 주소 비교, 동등성은 객체 논리적 동등성 비교

### 요약 및 활용 포인트
| 주제 | 핵심 내용 | 활용 팁 |
|------|-----------|---------|
| 조건문/반복문 | 기본적인 흐름 제어 구문, 반복문 종류별 적합 상황 이해 | for문은 반복 횟수 명확, while문은 조건에 따라 유연 |
| 다형성 | 상위 타입 변수에 하위 타입 인스턴스 참조, 실행 시점 객체에 따라 다양한 동작 가능 | 다형성은 실행 시점 행동 변화에 집중, 차후 심화 학습 필요 |
| 컬렉션 | 리스트는 가변 배열, 인덱스 0부터 시작, 요소 추가/삭제/검색 가능 | 적절한 컬렉션 선택 시 코드 효율과 가독성 향상 |

다형성은 객체의 실제 타입에 따라 같은 코드가 서로 다르게 행동할 수 있도록 하며, 컬렉션은 데이터 구조에 따라 리스트, 셋, 맵의 특성을 이해하고 적합한 구조를 선택하는 능력을 요구한다. 동일성과 동등성 개념은 객체 비교 시 혼동을 방지하고, 사용자 정의 클래스의 비교 로직 구현에 핵심적이다.
