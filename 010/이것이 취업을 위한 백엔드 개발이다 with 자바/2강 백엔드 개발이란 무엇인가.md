# 백엔드 개발이란 무엇인가?
## 웹과 인터넷의 개념 이해
> "웹은 전 세계에 퍼져 있는 인터넷을 통해 정보를 공유하는 시스템이며, HTTP 프로토콜을 사용해 정보를 교환한다."

| 개념 | 정의 및 특징 |
|------|--------------|
| 인터넷 | 전 세계에 연결된 네트워크 망 자체. PC, 서버, 라우터, 스위치 등 네트워크 장비 포함.|
| 웹(Web) | 인터넷 위에서 HTTP 프로토콜로 동작하는 시스템. 월드와이드웹(WWW)의 줄임말. |
| HTTP | 웹에서 정보를 교환하는 프로토콜. 백엔드 개발에서 핵심 역할을 함. |

- WWW는 '월드와이드웹'의 약자로 도메인 주소의 'www'에 반영됨
- 인터넷은 더 넓은 개념이며, 웹은 인터넷 위에서 동작하는 서비스 중 하나
- 인터넷에는 HTTP 외에도 다양한 프로토콜이 존재함

## 프런트엔드와 백엔드의 구분 및 발전 과정

| 구분 | 역할 및 특징 |
|------|--------------|
| 프런트엔드 | 사용자에게 보이는 부분 (HTML 문서, JavaScript 코드 등) |
| 백엔드 | 사용자가 직접 보지 않는 서버 쪽 로직, 데이터 처리, 저장, API 제공 등 |

- 초기 웹 개발: 단순히 HTML 문서 전달, 프런트엔드·백엔드 구분 필요 없음
- 서비스 복잡화 → 데이터베이스 추가, 사용자별 맞춤 데이터 처리 필요성 대두 → 프런트엔드와 백엔드 구분
- 백엔드는 사용자의 요청을 받아 데이터 처리 후 응답하는 역할 수행
- 스마트폰 등장 이후 변화
  - 스마트폰 앱은 자체 UI를 가지고 있어 HTML 문서 전체가 필요하지 않음
  - HTML 문서 대신 데이터만 필요 → 백엔드에서 데이터만 주고받는 API 개발로 변화

### 프런트엔드 표기 주의
- 올바른 표기는 "프런트엔드" (프론트엔드가 아님)

## 스마트폰 등장과 API 중심 개발로의 전환
- 기존 백엔드 서버는 HTML 문서를 생성해 웹브라우저 사용자에게 전달
- 스마트폰 애플리케이션은 HTML 문서 대신 데이터만 필요 → HTML 파싱 작업 비효율적
- 백엔드 개발자는 웹브라우저용 HTML 생성 코드와 스마트폰용 데이터 생성 코드를 각각 작성 → 비효율
- 해결책
  - 웹브라우저와 스마트폰 모두 백엔드에서 데이터만 주고받는 API 사용
  - HTML 문서는 별도로 프런트엔드에서 처리
- 데이터 포맷: 주로 JSON 사용 (JSON은 자바스크립트 객체 표기법 기반의 데이터 교환 형식. 쉽게 읽고 쓸 수 있음)
- 서버 간 통신도 증가하며, HTTP 기반 API 사용이 표준화됨 (비HTTP 프로토콜도 존재하나 성능 고려 시)

## 개발자 도구를 통한 API 데이터 확인 실습
- 크롬 브라우저에서 F12 키를 눌러 개발자 도구 실행
- 상단 탭 중 '네트워크(Network)' 탭 선택
- 유튜브 접속 후 네트워크 요청 리스트 확인 가능
- 요청 중에서 JSON 형식의 요청과 응답을 찾아볼 수 있음
  - 요청 페이로드(payload)와 응답(response)이 JSON 문자열로 주고받는 형태
- JSON 데이터는 텍스트 기반으로 사람이 읽기 쉽도록 구성

참고: JSON 데이터 구조는 도서 후반부 및 추가 강의에서 더 자세히 다룸

## 백엔드 개발자의 역할과 영역

| 역할 구분 | 설명 |
|-----------|------|
| API 개발 | 웹브라우저, 스마트폰 등 클라이언트에 데이터를 주고받을 수 있는 인터페이스(API) 제작 |
| 요청 처리 및 로직 수행 | 클라이언트 요청에 따른 데이터베이스 조회/저장, 비즈니스 로직 처리 등 백엔드 서버 내부 작업 수행 |

- API(Application Programming Interface)
  - 프로그래밍적으로 사용할 수 있는 외부 인터페이스
  - 웹 개발에서는 HTTP를 통해 API를 제공
  - 자바의 코드 내 인터페이스와는 다른 개념임
- 백엔드 서버는 API를 통해 주로 JSON 데이터를 주고받음
- 데이터베이스 연동은 백엔드 개발의 핵심 작업 중 하나
- 백엔드 내부 로직은 서비스 요구사항에 따라 다양함

## 요약 핵심 개념

| 주제 | 핵심 내용 |
|------|-----------|
| 웹과 인터넷 | 인터넷은 광범위한 네트워크, 웹은 HTTP 기반 서비스 |
| 프런트엔드와 백엔드 | 프런트엔드는 사용자 인터페이스, 백엔드는 데이터 처리 및 비즈니스 로직 |
| API와 데이터 포맷 | API는 클라이언트와 서버 간 인터페이스, 주로 JSON 포맷 사용 |
| 스마트폰과 API 개발 | 스마트폰 앱 UI와 데이터 분리, API 중심 개발 구조 등장 |
| 백엔드 개발자 역할 | API 설계, 클라이언트 요청 처리, 데이터베이스 연동, 서버 로직 구현 |
| 개발자 도구 활용법 | 크롬 개발자 도구의 네트워크 탭에서 JSON 요청/응답 관찰 가능 |

<br>
<hr>

백엔드는 클라이언트와 서버 사이에서 데이터를 주고받는 API를 중심으로 동작하며, 이를 처리하기 위한 다양한 로직과 데이터베이스 연동을 담당한다. 웹과 인터넷의 관계, 프런트엔드와 백엔드의 구분, API의 중요성을 이해하면 복잡한 웹 서비스 구조를 명확히 파악할 수 있고, 스마트폰 등장으로 인한 개발 패러다임 변화가 백엔드 개발 방식에 큰 영향을 미쳤음을 알 수 있다. JSON 포맷과 개발자 도구를 통해 실시간 네트워크 데이터를 확인하는 경험은 실제 개발 현장을 이해하는 데 실질적인 도움이 된다.
