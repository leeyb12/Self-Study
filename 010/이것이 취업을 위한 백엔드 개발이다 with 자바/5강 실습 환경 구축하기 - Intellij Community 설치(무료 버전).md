# 5강 실습 환경 구축하기 | Intellij Community 설치(무료 버전)
## 인텔리제이 커뮤니티 버전 설치 및 실습 환경 구축
> "인텔리제이(IntelliJ)는 개발에 필요한 여러 기능을 통합하여 개발자가 효율적으로 코드를 작성하고 실행할 수 있도록 도와주는 통합 개발 환경(IDE, Integrated Development Environment)이다."

### 1. IDE(통합 개발 환경)의 의미와 주요 기능
| 기능명 | 설명 | 비고 | 
|--------|------|------|
| 소스코드 편집 | 코드 문법 검사, 문법 오류 하이라이트, 자동완성 기능 제공 | 메모장과 달리 강력한 편집기능 |
| 빌드 자동화 | 소스코드를 컴퓨터가 실행할 수 있는 기계어 형태로 변환하는 과정 자동 수행 | 컴파일, 링킹, 패키징 등 포함 |
| 디버거 | 애플리케이션 실행 중 특정 코드에서 멈추고 변수 값 확인, 한 줄씩 코드 실행 가능 | 버그 수정 및 프로그램 흐름 분석에 유용 |

- IDE는 여러 개발 도구를 하나로 통합해 개발자가 효율적으로 작업할 수 있도록 한다.
- 자동완성 기능은 함수명, 변수명 등을 추천해주어 코딩이 훨씬 편리하다. 
- 디버거는 코드 실행 중 상태를 상세히 들여다보며 문제점을 쉽게 파악할 수 있게 해준다. 

### 2. 인텔리제이 커뮤니티 버전 설치 과정
1. 인텔리제이 검색 및 다운로드
- 구글에 "인텔리제이" 검색 후 공식 사이트 접속
- 인텔리제이에는 크게 두 가지 버전 존재
  - 얼티밋 버전: 유료, 30일 무료 체험 가능
  - 커뮤니티 버전: 무료, 실습에 충분한 기능 제공
- 커뮤니티 버전의 <mark>.exe</mark> 파일 다운로드

2. 설치 진행
- 설치 파일 실행 후 <mark>Next</mark>를 눌러 진행
- 설치 완료 후 "인텔리제이 실행" 체크 후 마무리

3. 초기 설정
- 약간 동의 및 사용성 개선 정보 제공 동의 선택 가능 (사용자 선택)
- 테마 선택 가능 (밝은 테마 또는 어두운 테마)

### 3. 프로젝트 생성 및 JDK 설정
- 프로젝트 생성 절차
  - 인텔리제이 실행 후 <mark>New Project</mark> 클릭
  - 프로젝트 이름 입력 (예: <mark>BackendWorld</mark>)
  - 프로젝트 저장 경로 지정 (기본값 사용 가능)
- JDK 설정
  - JDK가 없으면 <mark>Download JDK</mark> 버튼을 눌러 설치
  - 권장 JDK 버전: 17버전 또는 21버전 중 선택 (17버전 권장, 최신 LTS 버전)
  - 벤더는 <mark>AdoptOpenJDK HotSpot</mark> 기본 선택 가능
- 샘플 코드 포함
  - <mark>Add sample code</mark> 체크 유지 후 프로젝트 생성
  - 기본 예제 코드가 포함되어 빠르게 실행 가능

| 항목 | 설명 |
|------|------|
| 프로젝트명 | 사용자가 지정 (예: BackendWorld) |
| JDK 버전 | 17 또는 21 (17 권장, 최신 LTS) |
| 벤더 | AdoptOpenJDK HotSpot 선택 |
| 샘플 코드 | 기본 예제 코드 포함하여 생성 |

### 4. 기본 코드 작성 및 실행 방법
- 코드 수정
  - 샘플 코드 중 불필요한 부분 삭제
  - <mark>System.out.println</mark> 구문을 사용해 <mark>"Hello World"</mark> 출력하도록 수정
- 실행 방법
  - 클래스 옆, 메인 메서드 옆, 또는 상단 재생 버튼 클릭 가능
  - 실행 시 <mark>Run 'Main.main()'</mark> 선택하면 콘솔에 출력 확인 가능
- 실행 결과
  - 콘솔 창에 <mark>Hello World</mark>

| 실행 방법 | 설명 |
|-----------|------|
| 클래스 옆 재생 버튼 클릭 | 해당 클래스 실행 |
| 메인 메서드 옆 재생 버튼 클릭 | 메인 메서드 기준 실행 |
| 상단 재생 버튼 클릭 | 프로젝트 전체 실행 |

### 5. 실습 환경 구성 시 주의점 및 팁 
| 항목 | 설명 |
|------|------|
| JDK 버전 선택 | 실습 문제 방지를 위해 책과 동일한 17버전 권장 |
| 테마 선택 | UI 익숙함에 따라 밝은 테마 또는 어두운 테마 선택 가능 |
| IDE 버전 | 커뮤니티 버전으로 충분, 얼티밋 버전은 유료 |
| 설치 후 실행 | 설치 완료 시 바로 IDE 실행 체크 권장 |

- 설치 시 나오는 UI는 버전 및 시점에 따라 다를 수 있으나 기본 절차는 동일함
- 사용성 개선 정보 전송 여부는 개인 선택 사항

인텔리제이 커뮤니티 버전은 소스코드 편집, 빌드 자동화, 디버깅 기능을 하나의 툴로 통합해 개발자가 복잡한 작업을 단순화하고 효율적으로 코드를 작성할 수 있도록 하며, JDK의 적절한 설치와 프로젝트 설정을 통해 안정적인 자바 개발 환경을 제공한다. 프로젝트 생성 시 선택한 JDK 버전과 샘플 코드 포함 여부가 개발 초기 작업을 원활하게 만들고, 실행 버튼을 통한 간편한 코드 실행은 개발 흐름의 빠른 확인과 실습 진행에 필수적인 역할을 한다.
