# 4강 백엔드 개발자가 되는 방법 | 서류 전형, 코딩&과제 테스트, 면접
## 백엔드 개발자 채용 프로세스
> "백엔드 개발자가 되기 위한 채용 절차는 대체로 서류 전형, 코딩 테스트/과제 테스트, 1차 면접, 2차 면접 순으로 진행된다."

| 단계 | 주요 내용 및 특징 |
|------|-------------------|
| 서류 전형 | - 지원자의 경력, 기술 스택, 프로젝트 경험 등을 기반으로 합격 여부 결정 <br> - 채용 공고 자격 조건과 맞지 않으면 합격 확률 낮음 <br> - 개인 프로젝트가 없는 경우 불리함 <br> - 성의 없는 이력서도 탈락 요인 <br> - 2023~24년 취업 시장 상황도 영향 |
| 코딩 테스트/과제 테스트 | - 코딩 테스트: 주로 알고리즘 문제 풀이, 짧은 시간 내 해결 <br> - 과제 테스트: 실제 애플리케이션 구현 과제, 코드 스타일 및 실무 능력 검증 <br> - 과제 테스트는 짧게 보는 유형과 장기간(일주일) 수행하는 유형으로 나뉨 |
| 1차 면접 | - 코딩 테스트/과제 테스트 결과 기반 검증 <br> - 컴퓨터 과학(CS) 기본 지식(운영체제, 네트워크, 데이터베이스, 알고리즘) 질문 <br> - 프로젝트 경험 및 시스템 설계 관련 질문 <br> - 협업 및 인성 관련 질문 포함 <br> - 반복 면접을 통해 자주 물어보는 질문 유형 파악 필요 |
| 2차 면접 | - 임원급(CTO, CEO 등) 참여 <br> - 1차 면접에서 미흡했던 부분 보완 질문 가능 <br> - 기업 고위직의 관점에서 지원자 평가 진행 |

### 서류 전형 상세
- 적합한 채용 공고 탐색: 자신의 경력과 능력에 맞는 공고를 골라 지원해야 합격 가능성 높음
- 경력 조건 미충족 시 불리: 예를 들어, 경력 3~5년 이상 요구 시 신원 지원자는 탈락 확률 높음
- 기술 스택 및 프로젝트 경험 부적합: 지원 공고와 맞지 않는 기술을 보유하거나 프로젝트 경험이 부족하면 서류 통과 어려움
- 개인 프로젝트 유무: 팀 프로젝트만 있을 경우 독립적 개발 역량 의심받음 -> 개인 프로젝트 진행 추천
- 이력서 완성도: 성의 없거나 부족한 이력서는 모든 직군에서 불리

### 코딩 테스트 vs 과제 테스트
| 구분 | 코딩 테스트 | 과제 테스트 |
|------|-------------|-------------|
| 목적 | 알고리즘 문제 풀이, 문제 해결 능력 평가 | 실제 코드 작성 능력, 코드 스타일, CS 지식 검증 |
| 기간 | 수 시간 내 단기 수행 | 수일 ~ 일주일 단위 긴 과제 가능 |
| 형태 | 플랫폼 기반 자동 채점 | 요구사항에 따른 실제 애플리케이션 구현 |
| 특징 | 짧고 집중된 문제, 빠른 판단 가능 | 실무 능력에 가까운 평가, 깊이 있는 코드 작성 |

### 면접 준비 포인트
- 코딩 테스트/과제 테스트 복기 필수 (면접 시 관련 질문 출제 가능)
- CS 기초 지식 철저히 학습: 운영체제, 네트워크, 데이터베이스, 알고리즘
- 프로젝트 경험: 사용 기술, 선택 이유, 성능 고려사항 등 상세히 설명 가능해야 함
- 협업 경험 및 갈등 해결 방법 준비
- 반복 면접 경험으로 주요 질문 유형 파악

## 자바를 선택해야 하는 이유
> "한국 IT 산업에서 개발자로 취업을 준비한다면 자바는 수요와 공급의 선순환 고리 때문에 나쁘지 않은 선택이다."
- 자바는 국내 IT 서비스 기업에서 여전히 높은 수요를 보임
- 자바 외에도 다양한 언어 학습 권장 (예: 자바스크립트, 코틀린)
- 자바스크립트: 웹 개발 및 크롤링에 유용하며, 문법이 자바와 유사해 배우기 쉽다
- 코틀린: JVM 기반 언어로 자바의 문제점을 보완, 실제로 코틀린을 사용하는 기업도 많음
- 데이터 분석 및 머신러닝 업무 협업을 위해 관련 지식도 일부 경험하면 좋음

| 언어 | 특징 및 활용 분야 |
|------|-------------------|
| 자바 | 국내 IT 기업에서 수요 많음, 안정적 백엔드 개발 언어 |
| 자바스크립트 | 웹 개발, 크롤링, 프론트엔드 개발에 필수적 |
| 코틀린 | JVM 기반, 자바의 단점 보완, 점점 채택 증가 |

## 추가 팁 및 조언
- 공개 채용과 상시 채용의 차이 이해
  - 상시 채용은 실무 경력자 위주, 코딩 테스트 난이도 낮음
  - 공개 채용은 신입도 경쟁, 코딩 테스트 난이도 상대적으로 높음
- 면접 시 부족했던 부분은 반드시 보완하고, 면접관의 피드백을 참고하여 준비 
- 여러 번 면접을 경험하면서 자신만의 답변 및 준비 방법을 체득할 것

자바를 중심으로 한 백엔드 개발자 채용 과정은 지원자의 경력과 기술 수준에 맞는 공고를 선별해 적극 지원하고, 코딩 및 과제 테스트를 철저히 준비하며 CS 기초와 프로젝트 경험을 자신 있게 설명할 수 있는 능력을 요구한다. 1차 면접에서 발견된 약점을 2차 면접 전에 보완해 기업 임원진에게 신뢰를 줄 수 있어야 하며, 자바는 한국 IT 시장에서 안정적인 취업 기회를 제공하는 언어로 자리매김하고 있다.
