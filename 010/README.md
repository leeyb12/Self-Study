# 010 - 풀스택 웹 기초

풀스택 학습을 위한 HTML/CSS와 JavaScript 기초 실습을 정리하는 폴더입니다.

## 폴더 구조

```text
010/
├─ fullstack-htmlcss/
│  └─ css/
│     └─ css/
│        └─ style.css
└─ fullstack-javascript/
```

## 학습 내용

| 폴더 | 내용 |
| --- | --- |
| `fullstack-htmlcss/` | CSS 파일 구조와 스타일 분리 실습 |
| `fullstack-javascript/` | JavaScript 풀스택 기초 실습을 분리해 보관할 폴더 |

## 풀스택 학습 관점

- 프론트엔드는 화면과 사용자 상태를 관리하고 백엔드는 데이터 규칙과 영속성을 담당합니다.
- HTTP 요청과 응답은 두 영역을 연결하며 URL, 메서드, 상태 코드와 JSON 구조가 API 계약이 됩니다.
- CSS와 JavaScript를 기능별 파일로 분리하면 화면 규모가 커져도 변경 범위를 찾기 쉽습니다.
- 이후 서버 예제가 추가되면 입력 검증, 오류 처리와 데이터 저장 흐름을 함께 기록합니다.

## 정리 기준

- HTML/CSS와 JavaScript를 주제별 폴더로 분리합니다.
- 예제 파일이 늘어나면 기능 단위 또는 장 단위로 하위 폴더를 나눕니다.
- 브라우저에서 확인 가능한 예제는 실행 방법을 README에 함께 기록합니다.
