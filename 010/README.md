# 010 - 풀스택 웹 기초

풀스택 학습을 위한 HTML/CSS와 JavaScript 기초 실습을 정리하는 폴더입니다.

## 폴더 구조

```text
010/
├─ fullstack-htmlcss/
│  └─ css/
│     └─ css/
│        └─ style.css
└─ fullstack-javascript/
```

## 학습 내용

| 폴더 | 내용 |
| --- | --- |
| `fullstack-htmlcss/` | CSS 파일 구조와 스타일 분리 실습 |
| `fullstack-javascript/` | JavaScript 풀스택 기초 실습을 정리할 공간 |

## 정리 기준

- HTML/CSS와 JavaScript를 주제별 폴더로 분리합니다.
- 예제 파일이 늘어나면 기능 단위 또는 장 단위로 하위 폴더를 나눕니다.
- 브라우저에서 확인 가능한 예제는 실행 방법을 README에 함께 기록합니다.
