## VM 워크스테이션 프로 설치 실습 
> "VM 워크스테이션 프로 설치 과정은 윈도우즈 사용자 대상이며, 교재와 동일한 버전을 설치하여 이후 학습의 일관성을 유지한다."

### 1. 다운로드 경로 및 준비
| 항목 | 내용 |
|------|------|
| 다운로드 위치 | 네이버 카페 'this is 리눅스' 교재 자료실 -> VM 워크스테이션 및 퓨전 버전별 다운로드 |
| 교재 버전과 설치 권장 | 교재와 동일한 버전(예: 25H2) 설치 권장, 이후 버전도 가능하나 일관성을 위해 교재 버전 추천 |
| 다운로드 파일 구성 | 총 5개 파일 다운로드 후 실행 시 원하는 VM 워크스테이션 프로 25H2 버전 설치 파일 생성 |
| 파일 문제 시 대체 파일 | 마지막 exe 파일에 문제가 있으면 압축된 파일로 대체 가능 |

### 2. 설치 과정
| 단계 | 설명 |
|------|------|
| 압축 해제 | 다운로드한 5개 파일을 실행하여 자동으로 압축 해제 진행 |
| 설치 시작 | 압축 풀린 설치 파일 실행 -> 설치 프로그램 실행 |
| 라이선스 동의 | 설치 중 라이선스 동의 필요 |
| 하이퍼 V 설정 확인 및 권장사항 | 하이퍼 V 기능이 켜져 있으면 VM 워크스테이션 프로가 느려질 수 있어 하이퍼 V 비활성화 권장 (교재 14페이지 참고) |
| 기본 설정 유지 | 설치 과정 중 별도 변경 없이 기본값으로 진행 |
| 설치 완료 | 약 1~2분 소요 후 설치 완료, 바탕화면에 아이콘 생성 |

### 3. 설치 후 초기 실행 
| 항목 | 내용 |
|------|------|
| 첫 실행 화면 구성 | 왼쪽 라이브러리 창은 필요 없으면 닫기 가능 |
| 업데이트 알림 | 설치한 25H2 버전 이후 소규모 업데이트 안내, 로그인 후 다운로드 가능 |
| 업데이트 파일 다운로드 권장 경로 | 카페에서 업데이트 파일 다운로드 권장 (가입 및 로그인 필요 없음) |
| 업데이트 적용 여부 | 필요 없으면 스킵 가능 (교재 버전과 동일하게 유지 권장) |

### 4. 참고 및 주의사항
- 하이퍼 V 기능: 윈도우의 가상화 기능 중 하나로, 활성화 시 VM 워크스테이션 성능 저하 가능성 존재
- 다운로드 경로: 공식 브로드컴 사이트보다 카페에서 미리 준비된 파일을 받는 것이 편리하며, 교재와 버전 일치 유지에 유리함
- 설치 파일 문제: 마지막 exe 파일 경고 메시지 발생 시 압축 파일 사용 가능
- 설치 시 시스템 재부팅: 설치 도중 재부팅 안내가 나올 수 있으며, 재부팅 후 설치 재개 권장
