## 가상 머신의 개념과 역할
> "가상 머신은 한 대의 실제 컴퓨터(호스트 컴퓨터) 위에 여러 대의 가상 컴퓨터를 만들어 각기 다른 운영 체제(게스트 OS)를 설치하고 운영할 수 있도록 하는 소프트웨어 환경이다."

| 구분 | 설명 |
|------|------|
| 호스트 OS | 실제 컴퓨터에 설치된 운영 체제 (윈도우즈, 맥OS 등) |
| 게스트 OS | 가상 머신 소프트웨어 내에 설치된 운영 체제 (리눅스, 윈도우즈 등) |
| 가상 머신 소프트웨어 | 호스트 OS 위에서 가상의 컴퓨터 환경을 만들어 주는 프로그램 (예: VMware Workstation, VMware Fusion) |

- 한 대의 PC에서 여러 대의 가상 컴퓨터를 동시에 구동 가능
- 실제 컴퓨터가 여러 대인 것처럼 네트워크 서버 운영 환경 구성 가능
- 멀티부팅과 달리, 가상 머신은 여러 OS를 동시에 실행하는 방식임

## 가상 머신 소프트웨어 구조와 네트워크
- 호스트 OS(윈도우즈, 맥OS)는 변경 없이 그대로 유지됨
- 가상 머신 소프트웨어가 설치되면 내부에 가상의 네트워크 장치(게이트웨이, 라우터 등)가 생성됨
- 가상 머신 소프트웨어 내에 다수의 가상 컴퓨터(책상에 비유 가능)가 생성되고 각각 독립된 네트워크 케이블이 연결된 상태와 유사함
- 가상 네트워크를 통해 게스트 OS들이 외부 네트워크와 통신 가능

| 구성 요소 | 역할 및 설명 |
|-----------|--------------|
| 가상 게이트웨이 | 가상 컴퓨터들을 외부 네트워크와 연결하는 네트워크 장치 역할 |
| 가상 컴퓨터(책상) | 각각 독립된 가상 컴퓨터 환경을 구축하는 단위 |
| 네트워크 케이블 | 가상 컴퓨터들을 네트워크에 연결하는 가상의 케이블선 |

- 회사 내 전산실 구축을 비유로 이해 가능: 한 공간(호스트 컴퓨터)에 여러 컴퓨터(게스트 OS)를 배치하고 네트워크 연결을 완성한 상태

## 주요 가상 머신 소프트웨어와 호환성
| 운영체제 환경 | 가상 머신 소프트웨어 | 특징 및 주의 사항 |
|---------------|----------------------|-------------------|
| 윈도우즈 | VMware Workstation Pro | 윈도우즈 환경 전용, 다양한 리눅스 및 윈도우 게스트 OS 지원 |
| 맥OS | VMware Fusion Pro | 맥 전용, ARM용 윈도우즈 11 설치 가능 (실리콘 CPU 지원) |

- VMware Fusion Pro는 맥 실리콘 CPU (M1, M2)에서 ARM 기반 윈도우즈 11 설치 가능
- 최신 버전 사용 권장 (예: VMware Fusion Pro 15 이상)
- 라이선스는 개인/회사/학교 모두 무료로 사용 가능

## 가상 머신 설치 및 하드웨어 요구 사항
| 하드웨어 요소 | 최소 사양 (권장 사양) | 설명 및 권고사항 |
|---------------|-----------------------|------------------|
| CPU | 인텔/AMD x86 계열 2015년 이후 모델 | 맥은 Apple Silicon (M1 이상 권장) |
| 메모리 (RAM) | 윈도우즈 16GB 이상 / 맥 8GB 이상 가능 | 윈도우즈는 8GB로 실습 어렵고 16GB 이상 권장 | 
| 저장 공간 | SSD 50GB 이상 확보 | 가상 머신과 게스트 OS 설치 공간 확보 필요 | 
| 디스플레이 해상도 | 1920x1080 (Full HD) 이상 | 게스트 OS는 1280x800 해상도 사용 예정 |
| 운영체제 | 윈도우즈 10/11 64비트, 맥OS 15 이상 | 최신 OS 권장 |

- 최소 사양을 맞춰드 원활한 실습은 어려움
- 맥 8GB RAM은 실습 가능하지만 불편할 수 있음

## 가상 머신과 멀티부팅의 차이점
| 구분 | 가상 머신 | 멀티부팅 |
|------|-----------|----------|
| OS 실행 방식 | 여러 OS를 동시에 실행 가능 | 한 번에 한 OS만 부팅하여 실행 |
| 하드웨어 공유 | 한 대 컴퓨터의 자원을 여러 OS가 나눠 사용 | 각 OS가 부팅 시 하드웨어 독점 사용 |
| 사용 목적 | 여러 서버 환경 동시 운영, 테스트 환경 구축 | 한 대에 OS 여러 개 설치, 필요할 때 OS 선택 |

- 가상 머신은 효율적인 서버 운영 및 개발 환경에 적합 
- 멀티부팅은 성능을 극대화해야 할 때 유리

## 가상 머신 실습 준비 및 진행 절차
1. 가상 머신 소프트웨어 설치 (VMware Workstation Pro 또는 VMware Fusion Pro)
2. 가상 네트워크 구성 및 가상 게이트웨어 자동 생성 확인
3. 가상 컴퓨터(게스트 OS) 생성
4. 리눅스 또는 윈도우즈 등 게스트 OS 설치
5. 실습 환경에 맞게 네트워크, 스냅샷 등 부가 기능 활용

- 실습 중 문제 발생 시 교재 참조(해당 강의 페이지 우측 상단 표시)
- 맥과 윈도우즈 각 환경별 설치 동영상 제공, 순차적으로 따라할 것

## 가상 머신 활용의 의미
- 한 대의 물리적 컴퓨터에서 여러 운영 체제를 자유롭게 운영함으로써 자원 활용 극대화
- 네트워크 서버 구축, 소프트웨어 개발 및 테스트 환경을 손쉽게 구현 가능
- 실무 환경과 유사한 조건에서 효율적인 학습과 실습 가능

<br>
<hr>

가상 머신은 호스트 OS 위에서 독립적으로 동작하는 게스트 OS들을 네트워크로 연결하고, 효율적인 자원 분배와 관리 메커니즘을 통해 다수의 운영 체제를 동시에 운영할 수 있게 하며, 이를 통해 물리적 장비의 한계를 극복하고 실무 환경을 가상 공간에 재현한다.
