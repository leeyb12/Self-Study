## 22강 합성곱 신경망의 시각화
### 합성곱 신경망(CNN) 가중치와 특성맵 시각화
> "합성곱 신경망의 각 층에서 학습된 가중치(필터)와 출력 특성맵을 시각화하면, 모델이 입력 이미지에서 어떤 패턴을 인식하고 있는지 이해할 수 있다."

#### 1. 합성곱 신경망에서 가중치(필터)의 역할과 시각화
- 합성곱층은 입력 이미지와 필터(가중치)를 합성곱 연산하여 출력을 생성한다.
- 필터는 입력 이미지 내 특정 패턴(예: 가장자리, 텍스처)을 감지하는 역할을 한다.
- 필터는 3차원 텐서(높이 × 너비 × 채널)로 표현되며, 흑백 이미지의 경우 채널 수는 1이다.
- 예시: 3×3×1 크기의 필터 32개 사용 → 필터 가중치 배열은 (3, 3, 1, 32) 형태
- 각 필터에는 편향(bias) 값도 하나씩 존재한다.
- 훈련 전 필터 가중치는 균등분포로 초기화되어 있으나, 훈련 후 특정 픽셀 위치에 민감한 형태로 변화한다.
- 가중치 분포는 대체로 0을 중심으로 한 정규분포 형태를 띠나, 약간 한쪽으로 치우친 경우도 있음.

| 구분 | 내용 |
|------|------|
| 필터 크기 | $3 \times 3 \times 1$ (높이×너비×채널) |
| 필터 개수 | 32개 |
| 편향 개수 | 32개 (필터당 1개) |
| 초기 가중치 분포 | 균등분포 |
| 학습 후 가중치 | 특정 픽셀 위치에 민감한 패턴 학습 |

#### 2. 케라스 모델의 레이어 구조 및 가중치 접근법
- 케라스의 시퀀셜 모델은 <mark>model.layers</mark> 속성으로 층 리스트를 가진다.
- 각 층은 인덱스로 접근 가능하며, 예: 첫 번째 합성곱층은 <mark>model.layers[0]</mark>
- 합성곱층의 가중치는 <mark>layer.get_weights()</mark>로 얻으며, 필터와 편향이 각각 리스트 요소로 존재한다.
- 가중치는 히스토그램으로 시각화 가능하며, 분포 형태를 관찰할 수 있다.
- 모델 구조 예시 (시퀀셜)

| 층 순서 | 층 종류 | 설명 |
|---------|---------|------|
| 0 | Conv2D | 첫 번째 합성곱층 |
| 1 | MaxPooling2D | 첫 번째 맥스 풀링층 |
| 2 | Conv2D | 두 번째 합성곱층 |
| 3 | MaxPooling2D | 두 번째 맥스 풀링층 |
| 4 | Flatten | 1차원으로 펼치는 층 |
| 5 | Dense | 완전연결층 |
| 6 | Dropout | 과적합 방지를 위한 드롭아웃 |
| 7 | Dense (출력층) | 최종 출력층 |

#### 3. 특성맵(feature map) 시각화: 중간층 출력 확인하기
- 특성맵은 합성곱층을 통과한 후의 출력으로, 필터가 감지한 패턴이 반영된 이미지 표현이다.
- 시퀀셜 모델은 중간층 출력을 직접 얻기 어렵다.
- 함수형 API를 사용하면 중간층 출력을 모델의 입력과 출력으로 지정해 쉽게 접근 가능하다.
- 함수형 API 사용법

| 단계 | 설명 |
|------|------|
| 1. 입력 레이어 정의 | <mark>Input()</mark> 클래스로 입력 객체 생성 |
| 2. 층 객체 생성 | 각 층을 변수에 할당 (예: <mark>x = Dense(...)(input_tensor)</mark>) | 
| 3. 모델 생성 | <mark>Model(inputs=입력, outputs=중간층_또는_최종출력)</mark> |
| 4. 중간층 출력 추출 | 중간층의 <mark>outputs</mark> 속성을 모델 출력으로 설정하여 활용 |

- 함수형 API는 복잡한 신경망(다중 입력/출력) 설계에 유리하다.

#### 4. 특성맵 시각화 결과와 해석 
| 층 위치 | 필터 수 | 특성맵 크기 및 특징 |
|---------|---------|---------------------|
| 첫 번째 합성곱층 | 32 | 원본 이미지와 유사한 저수준 패턴(가장자리 등) 감지됨 |
| 두 번째 합성곱층 | 64 | 원본 이미지와 유사성 감소, 점점 추상적인 고차원 패턴 감지 시작 |

- 저수준 층에서는 입력 이미지의 기본적인 패턴(모서리, 선 등)을 인지하는 반면,
- 깊은 층으로 갈수록 고차원적이고 추상적인 패턴(객체의 형태, 특징 등)을 탐지한다.
- 이 과정 때문에 최종 특성맵은 원본과 유사성이 적은 추상적 형태를 띤다.
- 특성맵 시각화는 모델 내부 동작을 이해하는 데 도움을 주지만, 큰 규모 신경망일수록 해석이 어려워질 수 있다. 

#### 5. 모델 내부 데이터 흐름과 객체 호출 방식
- 케라스 및 파이썬 객체 호출 메커니즘을 활용해 층별 출력을 함수처럼 연결한다.
- 예) <mark>hidden1 = Dense1(input_tensor)</mark>, <mark>hidden2 = Dense2(hidden1)</mark>
- 파이썬의 객체 호출 가능(callable) 특성을 이용한 구조
- 이러한 연결을 사슬(chain)처럼 생각할 수 있으며, 입력 -> 중간층 -> 출력의 흐름으로 이어짐.

#### 6. 종합
- 합성곱 신경망은 학습된 필터를 통해 입력 이미지에서 다양한 패턴을 인식한다.
- 필터 가중치와 특성맵 시각화는 신경망이 학습한 정보를 직관적으로 파악할 수 있는 수단이다.
- 케라스의 시퀀셜 모델은 간단하지만 중간층 출력 획득에 제한이 있으므로,
- 함수형 API를 활용하면 중간 특성맵을 쉽게 추출하고 분석할 수 있다.
- 층이 깊어질수록 신경망은 점점 더 추상적이고 고차원적인 특징을 학습한다.
- 이로 인해 신경망 내부 동작 이해 및 해석에 중요한 인사이트를 제공한다.
