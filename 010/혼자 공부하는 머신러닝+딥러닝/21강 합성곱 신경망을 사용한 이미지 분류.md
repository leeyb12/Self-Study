## 21강 합성곱 신경망을 사용한 이미지 분류
### 합성곱 신경망(CNN) 구현 개요
- 8장 1절에서 배운 합성곱 신경망 관련 용어들을 케라스(Keras) 라이브러리의 층으로 실제 구현
- 패션 MNIST 데이터셋 사용: 이미지 크기 $28 \times 28$, 채널 수(댑스) 1
- 케라스 <mark>Conv2D</mark> 층으로 2차원 합성곱 구현
- 합성곱층과 풀링층을 쌓아 특징 맵 생성 및 차원 축소 진행

### 케라스 Conv2D 층 사용법과 매개변수
| 매개변수명 | 설명 | 예시 |
|------------|------|------|
| <mark>filters</mark> | 필터(커널) 개수, 출력 댑스 차원 결정 | 32 |
| <mark>kernel_size</mark> | 필터 크기 (높이, 너비) | 3 또는 (3, 3) |
| <mark>activation</mark> | 활성화 함수 지정 | 'relu' |
| <mark>padding</mark> | 출력 크기를 입력과 동일하게 맞추는 옵션 ('same') | 'same' | 
| 입력 형태 | 3차원 배열 (높이, 너비, 댑스) 기대 | (28, 28, 1) |

- 필터의 댑스 차원은 입력의 댑스 차원과 자동 일치
- <mark>kernel_size</mark>는 보통 정사각형 필터(3x3) 사용, 높이와 너비가 다르게 지정하는 경우는 거의 없음
- 출력 높이와 너비: <mark>padding='same'</mark> 시 입력과 동일, 댑스는 필터 개수와 동일

### 합성곱 및 풀링 층 구조와 출력 크기 변화
| 층 종류 | 입력 크기 | 필터 개수 | 커널 크기 | 출력 크기 | 설명 |
|---------|-----------|-----------|-----------|-----------|------|
| 1차 합성곱층 | $28 \times 28 \times 1$ | 32 | $3 \times 3$ | $28 \times 28 \times 32$ | <mark>padding='same'</mark>로 크기 유지 |
| 1차 맥스 풀링층 | $28 \times 28 \times 32$ | - | $2 \times 2$ | $14 \times 14 \times 32$ | 풀링으로 높이/너비 절반 축소 |
| 2차 합성곱층 | $14 \times 14 \times 32$ | 64 | $ 3 \times 3$ | $14 \times 14 \times 64$ | 입력 댑스 차원에 맞춰 필터 생성 |
| 2차 맥스 풀링층 | $14 \times 14 \times 64$ | - | $2 \times 2$ | $7 \times 7 \times 64$ | 다시 높이/너비 절반 축소 |

- 풀링층은 채널(댑스) 차원 변하지 않음, 각 채널별 독립적으로 적용됨
- 출력 배열 원소 개수 예시: $7 \times 7 \times 64 = 3,136$

### Flatten 층과 밀집층(Dense Layer) 구성
- <mark>Flatten</mark> 층: 3차원 형태의 특성 맵을 1차원 벡터로 변환
  - 학습 파라미터 없음
  - 예: $7 \times 7 \times 64 = 3,136$ -> 1차원 벡터 (길이 3,136)
- 첫 번째 밀집층: 유닛 100개, 활성화 함수는 ReLU
- 드롭아웃 층: 과적합 방지용, 훈련 시 약 40% 뉴런 랜덤 비활성화
- 마지막 밀집층: 클래스 수 10개 (패션 MNIST), 활성화 함수는 Softmax (다중 분류용)

| 층 종류 | 주요 기능 | 파라미터 여부 | 활성화 함수 |
|---------|-----------|---------------|-------------|
| Flatten | 3차원 -> 1차원 변환 | 없음 | - |
| Dense (100 유닛) | 특징 학습, 차원 축소 | 있음 | ReLU |
| Dropout | 과적합 방지 | 없음 (랜덤 비활성화) | - |
| Dense (10 유닛) | 최종 클래스 예측 | 있음 | Softmax |

### 모델 컴파일 및 학습 설정
- 손실함수: <mark>sparse_categorical_crossentropy</mark> (타겟이 정수형 레이블일 때 사용)
- 옵티마이저 및 평가 지표 설정
- 콜백 함수 설정
  - ModelCheckpoint: 가장 성능 좋은 모델 저장
  - EarlyStopping: 검증 점수가 2회 이상 향상되지 않으면 조기 종료
- 훈련 시 검증 데이터 사용, 20 에폭(epoch) 동안 학습
- 조기 종료 시점 예시: 약 5-6번째 에폭에서 검증 점수 향상 멈춤

### 주요 개념 정리 및 이해 도움말
- 합성곱층(Conv2D): 이미지의 공간적 특징을 추출하는 층, 필터가 입력 이미지에서 일정 크기 영역을 스캔하며 특징 맵 생성
- 필터 개수 = 출력 댑스(depth) 크기, 각 필터는 고유한 특징을 학습
- 패딩 'same': 출력 크기가 입력과 같도록 주변에 0으로 채움, 공간 정보 보존
- 맥스 풀링(MaxPooling2D): 다운샘플링 기법, 지역 최대값 추출로 특징 압축 및 계산량 감소
- Flatten 층: 다차원 배열을 1차원 벡터로 변환하여 완전 연결층에 전달
- 드롭아웃(Dropout): 과적합 방지를 위해 학습 시 무작위로 뉴런 비활성화
- 활성화 함수: 비선형성 추가, ReLU는 주로 은닉층, Softmax는 다중 분류 출력층에서 사용
- 모델 체크포인트 및 조기 종료: 효율적인 학습 관리와 과적합 방지에 필수

### 모델 구조 및 파라미터 계산법
- 각 합성곱층 파라미터 수 계산법 예시

| 층 명 | 필터 크기 | 입력 댑스 | 필터 개수 | 파라미터 수 계산식 |
|-------|-----------|-----------|-----------|--------------------|
| 1차 합성곱층 | $3 \times 3$ | 1 | 32 | $(3 \times 3 \times 1 + 1) \times 32 = 320$ |
| 2차 합성곱층 | $3 \times 3$ | 32 | 64 | $(3 \times 3 \times 32 + 1) \times 64 = 18,496$ |

- <mark>+1</mark>은 각 필터마다 있는 바이어스 파라미터
- 밀집층 파라미터는 입력 뉴런 수 x 출력 유닛 수 + 바이어스 수

합성곱 신경망의 구조는 입력 이미지에서 점차 특징을 추출하고 공간 정보를 압축하는 과정을 통해 효율적이고 효과적인 이미지 표현을 생성한다. 필터 개수와 크기, 패딩, 풀링을 적절히 조합하면 다양한 크기와 특성의 특징 맵을 만들 수 있으며, Flatten과 밀집층을 거쳐 최종 분류 결과를 도출한다. 조기 종료와 드롭아웃은 모델의 과적합을 방지하며, 손실 함수와 활성화 함수 설정은 학습 목적에 맞는 최적화에 기여한다.
