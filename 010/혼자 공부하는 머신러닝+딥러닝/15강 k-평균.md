## 15강 K-평균
### K-평균 (K-Means) 군집 알고리즘 이해
- "K-평균 알고리즘은 데이터를 사전에 레이블 없이 여러 클러스터(cluster)로 자동 분류하는 대표적인 비지도 학습 알고리즘이다."

#### 비지도 학습과 군집 (Clustering)
- 비지도 학습은 데이터의 정답(레이블)이 없는 상태에서 데이터 구조를 파악하는 학습 방법
- 대표적인 비지도 학습 종류
  - 군집 (Clustering)
  - 차원 축소 (Dimensionality reduction; 6장 3절에서 다룸)
- 군집은 비슷한 데이터끼리 묶는 작업 -> 데이터의 내재적 구조 파악

#### K-평균 알고리즘 개요
- K-평균은 가장 널리 사용되는 군집 알고리즘 중 하나
- 사전에 군집 개수 $K$를 정해 놓고, 데이터 샘플들을 $K$개의 클러스터로 분할
- 각 클러스터는 **센터로이드(centroid)**라 부르는 중심점(평균)으로 대표
- 알고리즘의 핵심 절차는 반복적인 클러스터 중심 이동과 샘플 재할당

#### K-평균 알고리즘 동작 과정
| 단계 | 설명 |
|------|------|
| 1. 초기화 | $K$개의 클러스터 중심(센터로이드)을 데이터 내 랜덤하게 초기 설정 |
| 2. 할당 | 각 데이터 샘플을 가장 가까운 클러스터 중심에 할당 (예: 유클리드 거리 기준) |
| 3. 업데이트 | 각 클러스터 내 데이터의 평균을 다시 계산해 클러스터 중심을 이동 |
| 4. 반복 | 클러스터 할당 결과가 변하지 않을 때까지 2~3단계 반복 |

- 중심점이 이동하며 점차 데이터가 최적의 클러스터에 할당됨
- 종료 조건은 클러스터 구성이 더 이상 변하지 않을 때

#### K-평균 알고리즘 특징 및 단점 
| 장점 | 단점 |
|------|------|
| - 구현이 쉽고 계산이 빠름 <br> - 대용량 데이터에도 효율적 <br> - 센터로이드 중심 이동으로 직관적 이해 가능 | - 클러스터 개수 $K$를 사전에 지정해야 함 <br> - 초기 중심값 랜덤 설정에 따라 결과가 달라질 수 있음 (무작위성 존재) <br> - 클러스터 형태가 구형(구조 단순)일 때 성능이 좋음; 복잡한 데이터 구조에는 부적합 |

- $K$값 결정 문제: 최적의 군집 개수를 모르는 상황에서 $K$를 정하는 것이 가장 큰 난제
- $K$값을 정하는 대표적 방법 -> 엘보(Elbow) 방법

#### 엘보 (Elbow) 방법을 통한 $K$값 결정
- 여러 $K$값을 시도하며 K-평균을 반복 수행해 이너셜(Inertia) 값(클러스터 내 거리 제곱합)을 기록
- 이너셜 값은 클러스터 개수가 늘어날수록 감소하나, 감소폭이 급격히 완만해지는 지점이 존재
- 이 변곡점(elbow)을 최적 $K$로 판단

| $K$ 증가 | 이너셜 값 변화 | 의미 |
|----------|----------------|------|
| 작음 | 큰 폭 감소 | 클러스터가 조밀해지고 있음 |
| 변곡점 | 완만해짐 | 클러스터 수 증가가 큰 개선을 만들지 못함 -> 최적 $K$ |

- 완벽한 방법은 아니며 경험적 판단 필요

### 사이킷런(sklearn)에서 K-평균 활용
- <mark>sklearn.cluster</mark> 모듈의 <mark>KMeans</mark> 클래스로 사용 가능
- 필수 매개변수: <mark>n_clusters</mark> (클러스터 수 $K$ 지정)
- 선택 매개변수: <mark>random_state</mark> (초기 중심 랜덤성 고정용)
- 데이터 입력: 2차원 배열 (샘플 수 x 특성 수)

#### 사이킷런 KMeans 주요 속성 및 메소드
| 속성/메소드 | 설명 |
|-------------|------|
| <mark>.fit(X)</mark> | 데이터 $X$를 이용해 모델 훈련 (클러스터링 수행) |
| <mark>.labels_</mark> | 각 샘플의 클러스터 할당 결과 (레이블) |
| <mark>.cluster_centers_</mark> | 각 클러스터의 센터로이드 위치 (평균값) |
| <mark>.inertia_</mark> | 클러스터 내 거리 제곱합 (이너셜 값) |
| <mark>.n_iter_</mark> | 반복 수행한 횟수 |
| <mark>.predict(X_new)</mark> | 새로운 데이터 샘플에 대해 클러스터 예측 |
| <mark>.transform(X_new)</mark> | 각 샘플에서 클러스터 중심까지의 거리(특성 변환) 반환 |

#### 예시: 과일 이미지 군집화
- 이미지 데이터를 픽셀 단위로 변환해 각 샘플로 사용 (예: 100x100 픽셀 -> 10,000차원)
- $K$ = 3으로 설정 (사과, 파인애플, 바나나 3종류 가정)
- 초기 중심은 랜덤 선택 -> 반복 수행으로 중심 이동
- 최종적으로 3개의 클러스터로 데이터 분할
- 각 클러스터 중심은 해당 과일의 평균 이미지와 유사

#### 군집 결과 해석 주의점
- 레이블 숫자(0, 1, 2 등)는 의미가 없음 (무작위 초기화와 라이브러리 버전에 따라 달라짐)
- 숫자는 단순히 군집 구분용 인덱스일 뿐, 어떤 과일인지는 별도 분석 필요
- 군집은 데이터의 유사성 기반 그룹화이므로 실제 레이블과 100% 일치하지 않을 수 있음

#### transform() 함수 활용
- 각 샘플과 클러스터 중심 간 거리를 계산해 새로운 특성 벡터 생성 (길이 $K$)
- 이 거리 벡터를 다른 머신러닝 모델에 입력 특성으로 활용 가능
- 예를 들어, 새로운 과일 이미지가 들어올 경우 각 클러스터 중심과의 거리를 구해 가장 가까운 클러스터를 예측

<br>
<hr>
K-평균 알고리즘은 군집 중심을 반복적으로 이동시키며 데이터를 클러스터로 묶는 방식으로, 사전 정보 없이도 데이터의 내재적 구조를 파악하는 데 효과적이다. 클러스터 개수 $K$의 결정이 알고리즘 성능을 좌우하며, 엘보 방법과 같은 경험적 접근법으로 적절한 $K$를 찾아낸다. 사이킷런의 KMeans 구현은 직관적인 인터페이스와 다양한 속성을 제공하여 실제 데이터 분석에 적합하며, transform 메소드를 통해 클러스터 중심과의 거리를 특성으로 변환하여 후속 분석에 활용할 수 있다.
