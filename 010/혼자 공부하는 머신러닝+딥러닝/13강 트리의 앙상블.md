## 13강 트리의 앙상블
### 트리 기반 앙상블 알고리즘 개요
> "앙상블(Ensemble) 알고리즘은 여러 개의 모델을 결합해 단일 모델보다 더 높은 성능과 일반화 능력을 발휘한다."
- 트리 모델은 앙상블 알고리즘의 기본 단위로 사용됨
- 머신러닝 데이터는 크게 정형 데이터와 비정형 데이터로 구분
  - 정형 데이터: CSV, 엑셀 등 행과 열이 명확한 데이터 (관계형 데이터베이스 포함)
  - 비정형 데이터: 이미지, 텍스트, 사운드 등 구조가 명확하지 않은 데이터
- 전통적 머신러닝 모델(선형 회귀, KNN, 로지스틱 회귀, 결정트리 등)은 주로 정형 데이터에 적합
- 딥러닝(신경망)은 비정형 데이터 처리에 강점

### 랜덤 포레스트(Random Forest)
| 특징 | 설명 |
|------|------|
| 부트스트랩 샘플링 | 원본 훈련 세트에서 중복 허용 랜덤 샘플링하여 다수의 샘플 집합 생성 (부스트래핑) |
| 다수결 예측 | 여러 트리의 예측을 합쳐 다수결 또는 평균으로 최종 예측 결정 |
| 특성 무작위 선택 | 각 노드 분할 시 전체 특성 중 $\sqrt{p}$개만 랜덤 선택하여 분할 기준 탐색 (p는 특성 개수) |
| 트리 개수 | 보통 100개 이상의 트리를 생성하여 앙상블 효과 극대화 |
| 일반화 성능 | 개별 트리보다 낮은 편이지만 앙상블 효과로 전체 모델은 테스트 세트에서 높은 성능 발휘 |
| OOB(Out-Of-Bag) 샘플 활용 | 부트스트랩에 포함되지 않은 샘플로 검증 점수 산출 가능, 교차 검증 대체 가능 |

- 비유: 여러 명의 전문가가 독립적으로 의견을 낸 뒤 다수결로 최종 판단하는 과정과 유사
- 특성 무작위 선택은 각 트리가 서로 다른 패턴을 학습하도록 하여 다양성을 높임

### 엑스트라 트리(Extra Trees)
| 특징 | 설명 |
|------|------|
| 샘플링 방식 | 부트스트랩 샘플링 없이 전체 훈련 데이터를 그대로 사용 |
| 노드 분할 기준 | 최적 분할이 아닌, 특성의 임계값을 무작위로 선택하여 노드 분할 |
| 특성 무작위 선택 | 랜덤 포레스트와 동일하게 $\sqrt{p}$개 특성을 랜덤 선택 |
| 학습 속도 | 무작위 분할로 인해 트리 생성이 빠름 | 
| 필요 트리 개수 | 무작위성 증가로 더 많은 트리 필요 |
| OOB 점수 | 전체 데이터 사용으로 OOB 점수 산출 불가 |

- 무작위 분할이 성능을 저하시킬 것 같지만, 다양성 증가와 앙상블 효과가 일반화 성능 향상에 기여
- 랜덤 포레스트보다 빠른 학습과 효율적 병렬 처리 가능

### 그래디언트 부스팅(Gradient Boosting)
| 특징 | 설명 |
|------|------|
| 학습 방식 | 이진 트리의 오차(잔차)를 줄이도록 순차적으로 트리를 추가해 모델을 점진적으로 개선 |
| 손실 함수 | 특정 손실 함수를 최소화하는 방향으로 모델 업데이트 |
| 병렬 처리 제한 | 순차적 학습 구조로 병렬 실행 어려움 |
| 러닝 레이트 (learning rate) | 손실 함수 감소량 조절, 너무 크면 최적값을 넘고, 너무 작으면 트리 수 증가 필요 |
| 과대적합 관리 | 러닝 레이트 조절과 트리 개수 조합으로 과대적합 방지 가능 |
| 성능 | 다양한 문제에서 뛰어난 예측력과 안정성 제공 |

- 러닝 레이트는 경사 하강법(gradient descent)에서 학습률과 유사한 개념으로, 모델의 보폭 크기를 조절
- 많은 트리를 사용하지만, 각 트리는 약한 학습기(weak learner)로 작동

### 히스토그램 기반 그래디언트 부스팅(Histogram-based Gradient Boosting)
| 특징 | 설명 |
|------|------|
| 히스토그램 이산화 | 연속형 특성값을 256개 구간으로 분할하여 구간 단위로 특성값 취급 |
| 학습 속도 향상 | 구간화로 계산량 감소, 빠른 트리 생성 가능 |
| 일반화 성능 개선 | 데이터 단순화가 모델의 과대적합 완화에 도움 |
| 특성 중요도 | 사이킷런 구현에서는 기본 피처 임포턴스 제공 안함 | 
| 대안 특성 중요도 | 퍼뮤테이션 임포턴스(permutation importance)를 사용하여 중요도 평가 가능 |

- 히스토그램 기반 방법은 데이터 분포를 막대그래프처럼 구간화하는 것으로, 고해상도 값 대신 구간 대표값 사용
- 퍼뮤테이션 임포턴스는 특성 하나씩 무작위로 섞어 모델 성능 저하 정도로 중요도 판단

### 퍼뮤테이션 임포턴스(Permutation Importance)
| 단계 | 설명 |
|------|------|
| 1. 원본 모델 성능 측정 | 원본 데이터로 예측 후 성능 기록 |
| 2. 특성 랜덤 섞기 | 특정 특성 열의 값을 무작위로 섞어 원래 특성 정보 파괴 |
| 3. 성능 재측정 | 특성 섞은 데이터로 모델 예측 후 성능 측정 |
| 4. 중요도 평가 | 성능 저하 크기가 큰 특성이 더 중요하다고 판단 |

- 특성 중요도 산출 시 모델 재훈련 불필요, 기존 훈련된 모델 그대로 적용 가능
- 여러 번 반복하여 안정적 중요도 산출

### 앙상블 알고리즘 주요 패키지 및 사용법
| 패키지명 | 설명 | 특징 및 인터페이스 |
|----------|------|--------------------|
| 사이킷런(sklearn) | 기본 앙상블 모델 포함 (RandomForest, ExtraTrees, GradientBoosting, HistGradientBoosting) | 교차 검증, OOB 점수, 피처 임포턴스 제공, 사용 용이 |
| XGBoost | Microsoft 개발, 강력한 부스팅 라이브러리 | 히스토그램 기반 지원 가능, 높은 성능, sklearn 유사 인터페이스 |
| LightGBM | Microsoft 개발, 히스토그램 기반 부스팅 | 빠른 학습, 메모리 효율성 뛰어남, sklearn 유사 인터페이스 |

- 모두 GPU 및 병렬 처리 지원 가능
- 사이킷런과 비슷한 API 제공으로 학습과 적용이 용이
- 교차 검증과 하이퍼파라미터 튜닝에 

### 앙상블 알고리즘 학습 요약
- 앙상블 알고리즘은 여러 약한 학습기(주로 트리)를 결합하여 강력한 예측 모델 생성
- 랜덤 포레스트는 부트스트랩 샘플링과 특성 무작위 선택으로 다양성 확보, 다수결 예측
- 엑스트라 트리는 전체 데이터 사용, 무작위 분할로 빠르게 학습하며 더 많은 트리 필요
- 그래디언트 부스팅은 순차적 오차 보정 방식으로 높은 성능과 안정성을 제공하나 병렬화 어려움
- 히스토그램 기반 그래디언트 부스팅은 데이터 이산화로 학습 속도와 과대적합 완화에 효과적
- 퍼뮤테이션 임포턴스를 통해 특성 중요도를 더욱 신뢰성 있게 평가 가능
- XGBoost, LightGBM 등 고성능 부스팅 라이브러리는 실무에서 널리 활용됨
