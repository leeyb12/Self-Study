## 16강 주성분 분석
### 차원 축소와 주성분 분석(PCA)
> "차원 축소는 고차원 데이터의 특성 벡터를 저차원으로 줄여 저장 공간과 계산 효율을 개선하는 기법이며, 주성분 분석은 대표적인 차원 축소 방법이다."

#### 차원과 차원 축소 개념 이해
- 차원(dimension)
  - 데이터 배열에서 축(axis)의 개수를 의미: 1차원(벡터), 2차원(행렬), 3차원 이상(텐서)
  - 예: 1차원 벡터는 원소가 나열된 형태, 5차원 벡터는 원소가 5개인 1차원 배열
  - 주의: 3차원 벡터와 3차원 배열은 다름 (벡터는 1차원 배열, 배열은 축이 3개)
- 차원 축소
  - 고차원 특성 벡터(예: 100차원)를 저차원 벡터(예: 2차원)로 변환
  - 저장해야 할 값이 줄어들어 효율성 향상
  - 예시: 고객 이미지 데이터의 픽셀 수(특성 수)를 줄여 저장 공간 절감

#### 주성분 분석(PCA)의 핵심 아이디어
- 데이터에서 분산(variance)이 가장 큰 방향을 찾는 것
- 데이터셋의 특성 공간 내에서 가장 널리 퍼진(변동성이 큰) 축을 주성분이라고 함
- 데이터 평균을 원점으로 맞추고(평균 0), 각 점을 주성분 축에 투영하여 차원을 줄임
- 예시: 2차원 데이터에서 첫 번째 주성분은 분산이 가장 큰 방향, 두 번째 주성분은 첫 번째와 직교하면서 분산이 두 번째로 큰 방향

| 주성분 번호 | 설명 | 성질 | 비고 |
|-------------|------|------|------|
| 1번째 | 분산 최대 방향 | 원점 중심, 데이터 투영 | 화살표 방향, 기울기 중요 |
| 2번째 | 1번째 주성분과 수직, 두 번째로 분산이 큰 방향 | 직교성 유지 | 2차원 평면에선 방향 하나뿐임 |
| ... | 이후 주성분도 같은 방식으로 찾음 | 각각 직교하며 분산 감소 | 최대 주성분 개수 = 원본 특성 개수 |

#### PCA의 차원 축소 과정 비유
- 여러 방향으로 흩어진 점들의 구름을 생각하면, 가장 길게 퍼진 방향에 선을 긋고 점들을 그 선 위에 수직 투영하여 1차원 값으로 표현하는 과정
- 복수 방향으로 투영하여 2차원, 3차원 등 원하는 차원까지 줄임 가능

#### PCA의 사이킷런(Scikit-learn) 구현
- <mark>PCA</mark> 클래스 사용 (모듈: <mark>decomposition</mark>)
- 주요 파라미터: <mark>n_components</mark> (추출할 주성분 개수 또는 분산 비율)
  - 정수: 추출할 주성분 개수 지정 (예: 50)
  - 실수 (0~1): 설명할 분산 비율 지정 (예: 0.5는 50% 분산 확보)
- 주요 메서드
  - <mark>fit()</mark> 또는 <mark>fit_transform()</mark>: 학습 및 변환
  - <mark>transform()</mark>: 학습된 PCA로 데이터 변환
  - <mark>inverse_transform()</mark>: 차원 축소된 데이터를 원본 차원으로 복원 (모든 알고리즘에서 제공되지는 않음)

#### PCA 결과 해석
| 속성명 | 의미 | 예시 설명 |
|--------|------|-----------|
| <mark>components_</mark> | 추출된 주성분 벡터들 (원본 특성 공간의 벡터) | 50차원 주성분은 각각 100차원 원본 벡터로 표현 |
| <mark>explained_variance_ratio_</mark> | 각 주성분이 설명하는 데이터 분산 비율 | 50개 주성분이 전체 데이터 분산의 약 92% 설명 |
| 변환된 데이터 모양 | (샘플 수) x (주성분 개수) | 원본 300x10000 -> PCA 변환 후 300x50 |

- 주성분을 적게 써도 원본 데이터의 대부분 정보를 압축해서 보존함을 확인 가능
- 역변환한 이미지는 원본과 유사하게 식별 가능 (배경은 흐릿해도 주요 형태 유지)

#### PCA 차원 축소의 장점
- 저장 공간 절감
- 모델 학습 시간 및 성능 향상 (특성 수 감소로 연산량 감소)
- 노이즈 감소 및 데이터 시각화 용이 (2차원, 3차원으로 표현 가능)

#### PCA를 활용한 분류 및 군집 예시
| 적용 대상 | 데이터 차원 | 학습 방법 | 성능 및 특징 |
|-----------|-------------|-----------|--------------|
| 원본 데이터 | 10000개 특성 | 로지스틱 회귀 | 높은 정확도 (0.99), 느린 학습 속도 | 
| PCA 50개 특성 | 50개 특성 | 로지스틱 회귀 | 비슷한 정확도 유지, 학습 속도 획기적 향상 (0.02) |
| PCA 2개 특성 | 2개 특성 | 로지스틱 회귀 | 거의 동일한 정확도, 시각화 가능 |
| PCA 50개 특성 | 50개 특성 | K-means 군집화 | 군집화 성능 양호, 시각화 가능 |

- 차원 축소 후에도 분류 및 군집화 성능 유지 또는 향상
- 시각화를 통해 데이터 분포 및 군집 결과 직관적으로 이해 가능
- 예: 과일 이미지 데이터(바나나, 파인애플, 사과)에서 PCA 2차원 변환 후 군집 시각화

#### PCA 적용 시 유의점
| 내용 | 설명 |
|------|------|
| 주성분 개수 설정 | 너무 많으면 차원 축소 효과 감소, 너무 적으면 정보 손실 가능 |
| 역변환 기능 지원 여부 | PCA는 지원하지만 모든 차원 축소 알고리즘이 역변환 지원하지 않음 |
| 입력 데이터 전처리 | 평균 0 중심화 필요 (자동 수행 가능) |
| 분산 비율 기반 선택 | 원하는 정보 보존 수준에 따라 <mark>n_components</mark> 실수 설정 가능 |

#### 시각화 예시: PCA 축소 데이터 산점도
- 2차원 PCA 데이터로 변환 후 산점도 그리기
- 군집 또는 분류 레이블별 색상 구분
- 데이터가 잘 구분되어 선형 분류기 및 군집 알고리즘 적용 용이성 확인

주성분 분석은 고차원 데이터에서 분산이 최대인 방향을 찾아 데이터를 저차원으로 투영함으로써 저장 공간과 계산 효율을 크게 개선한다. 이를 통해 원본 데이터의 주요 정보를 압축하여 유지하면서도 머신러닝 모델의 성능과 속도를 향상시키고, 시각화와 군집화에도 효과적으로 활용할 수 있다. PCA의 주성분 벡터와 설명 분산 비율은 데이터 구조를 이해하는 중요한 지표이며, 적절한 주성분 개수 선택과 역변환 활용으로 실제 적용에서 실용적인 이점을 제공한다.
