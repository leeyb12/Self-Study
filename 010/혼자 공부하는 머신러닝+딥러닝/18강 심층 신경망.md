## 18강 심층 신경망
### 심층 신경망 개념 및 구조
- 심층 신경망은 입력층과 출력층 사이에 하나 이상의 은닉층(hidden layer)을 포함한 신경망 모델이다.
- 은닉층은 입력층과 출력층 사이에 위치하며, 각 층의 유닛(뉴런)들은 선형 함수 계산 후 비선형 활성 함수(activation function)를 적용한다.
- 은닉층에 비선형 활성 함수를 적용하지 않으면 여러 층을 쌓아도 전체가 하나의 선형 함수와 동일해진다.
- 출력층은 다중 분류 문제에서 보통 소프트맥스(softmax) 활성 함수를 사용하여 출력값을 확률로 변환한다.
> "은닉층의 활성 함수는 선형 방정식을 비선형 출력으로 변환하여 신경망이 복잡한 패턴을 학습할 수 있게 한다."

### 활성 함수 (Activation Functions)
| 함수명 | 설명 | 특징 및 그래프 형태 |
|--------|------|---------------------|
| 시그모이드 (sigmoid) | $f(z) = \frac{1}{1 + e^{-z}}$ <br> 0과 1 사이 출력값 생성 | 0 무한대 -> 1, 음의 무한대 -> 0, 0일 때 0.5 출력 |
| 렐루 (ReLU) | $f(z) = \max(0, z)$ <br> 0 이하 입력은 0, 0 초과는 그대로 출력 | 단순하고 계산 효율 높음, 최근 많이 사용됨 |
| 소프트맥스 (softmax) | 출력 벡터를 확률 분포로 변환 | 다중 분류 출력층에서 사용, 출력값 합 1 유지 |

- 시그모이드는 과거 로지스틱 회귀에서 사용된 함수로, 은닉층 활성화로도 쓰였으나 현재는 렐루가 더 많이 사용됨.
- 렐루는 음수 입력을 모두 0으로 자르는 함수로, 신경망 학습 성능 향상에 기여.

### 신경망 층 구성과 하이퍼파라미터
- 은닉층은 완전 연결층(Dense layer)으로 구성, 각 층의 유닛 수는 하이퍼파라미터로 조정 가능.
- 예시: 은닉층 1개, 유닛 100개, 출력층 10개 (클래스 10개 분류 문제).
- 층 수, 유닛 수 모두 하이퍼파라미터로서 실험을 통해 최적값을 찾아야 함.
- 입력층은 데이터 크기에 맞게 정의하며, 입력의 차원은 배치 사이즈에 따라 변할 수 있다.

### 모델 파라미터 수 계산
| 층 | 입력 크기 | 출력 유닛 수 | 파라미터 계산법 | 총 파라미터 수 계산 |
|----|-----------|--------------|-----------------|---------------------|
| 첫 번째 Dense 층 | 784 (28x28 이미지) | 100 | 가중치: $784 \times 100$ <br> 절편: 100 | $784 \times 100 + 100 = 78,500$ |
| 두 번째 Dense 층 | 100 | 10 | 가중치: $100 \times 10$ <br> 절편: 10 | $100 \times 10 + 10 = 1,010$ |

- 절편(bias)은 각 유닛마다 하나씩 존재한다.
- 파라미터 수를 이해하면 모델의 복잡도와 학습 난이도를 가늠할 수 있다.

### 입력 데이터 전처리: Flatten 층
- 2차원 이미지 (28x28)를 1차원 벡터 (784)로 펼쳐주는 역할.
- Flatten 층은 파라미터가 없으며 단순 차원 변환만 수행한다.
- 이미지 데이터를 Dense 층에 입력할 때 자주 사용된다.

### 모델 구축 방법 (케라스 기준)
| 방법 | 설명 | 장점 및 특징 |
|------|------|--------------|
| 변수에 층 객체 생성 후 리스트 전달 | Input, Dense 객체를 변수로 만들고 Sequential에 리스트로 전달 | 각 층을 별도로 관리 가능 |
| 클래스 인스턴스 바로 생성 후 리스트 전달 | 변수 없이 바로 Sequential에 층 객체 생성 및 전달 | 코드 간결, 빠른 모델 정의 |
| Sequential 객체 생성 후 add 메소드로 층 추가 | 빈 Sequential 객체 생성 후 add()로 층을 하나씩 추가 | 층 개수가 많거나 동적으로 층 추가 시 유용 |

- 세 가지 방법 모두 동일한 모델을 생성한다.
- 프로젝트 상황에 따라 적합한 방식을 선택 가능.

### 모델 요약 (summary 메소드)
- 모델 구조를 시각적으로 보기 쉽게 출력해 준다.
- 각 층 이름, 출력 크기, 파라미터 수를 확인할 수 있다.
- 입력층은 데이터 크기만 표시되며 파라미터는 없다. 

### 경사 하강법과 옵티마이저
| 용어 | 설명 | 특징 및 사용 방법 |
|------|------|-------------------|
| 확률적 경사하강법 (SGD) | 전체 데이터가 아닌 일부 샘플(미니배치)을 사용해 파라미터 업데이트 | 기본 옵티마이저, 학습률 조절 가능 |
| 모멘텀 최적화 | 이전 그라디언트 방향을 가속도처럼 반영하여 업데이트 가속화 | 모멘텀 값(보통 0.9) 설정 가능 |
| 네스테로프 모멘텀 | 모멘텀의 변형으로 두 단계의 그라디언트 정보를 이용해 더 효율적 업데이트 | 네스테로프가 모멘텀보다 더 빠른 수렴 효과 |
| 적용형 학습률 옵티마이저 | 학습 중 학습률을 자동으로 조절하여 최적점 근처에서 천천히 접근 | RMSProp, Adam 등이 대표적, 학습률 튜닝 부담 감소 |

- 미니배치 크기는 기본 32이며, 실험적으로 16, 64 등 조절 가능.
- 학습률은 손실 함수 최적점 근처에서 지나치게 진동하는 문제를 막기 위해 중요하게 조정해야 한다.
- 케라스에서는 문자열 또는 옵티마이저 클래스 객체로 옵티마이저 지정 가능. 

### 비유: 활성 함수의 중요성
- 선형 함수만 쌓은 신경망은 여러 층을 쌓아도 결국 하나의 선형 함수와 같다. -> 복잡한 문제 해결 불가
- 비선형 활성 함수는 층을 쌓을 때마다 새로운 비선형 변환을 만들어내며, 이를 통해 신경망이 복잡한 패턴을 학습하는 '입체적인' 형태가 된다.
- 이는 마치 여러 층을 쌓은 필터가 다양한 각도와 깊이로 빛을 굴절시키는 광학 장치와 같아, 더 정교한 정보 변환과 해석이 가능해지는 것과 같다.
