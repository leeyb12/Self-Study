## 17강 인공 신경망 
### 인공신경망 개념과 머신러닝과의 관계
- 인공신경망은 머신러닝 알고리즘 중 하나이며, 과거에는 단일 층 구조만 있었으나 층을 깊게 쌓아 딥러닝으로 발전함 <br>
인공신경망은 뇌의 뉴런에서 영감을 받았으나, 실제 생물학적 뉴런과는 매우 다름
  > "인공신경망은 뇌를 모방하거나 복제한 것이 아니라, 문제 해결을 위해 영감을 얻은 형태일 뿐이다"
- 인공신경망의 구성 단위를 뉴런(neuron) 대신 유닛(unit) 또는 로짓(logit unit)으로 부르기도 함
- 다층구조를 통해 입력 데이터에 비선형 변환을 반복 적용하여 복잡한 패턴을 학습 가능

### 데이터셋 소개: 패션 MNIST와 MNIST
| 데이터셋 | 클래스 수 | 이미지 크기 | 이미지 타입 | 훈련 세트 크기 | 테스트 세트 크기 | 특징 및 난이도 |
|----------|-----------|-------------|-------------|----------------|------------------|----------------|
| MNIST | 10 | 28 x 28 픽셀 | 흑백 | 60,000 | 10,000 | 손글씨 숫자 (0~9) |
| 패션 MNIST | 10 | 28 x 28 픽셀 | 흑백 | 60,000 | 10,000 | 의류 이미지 (티셔츠, 바지 등), MNIST보다 난이도 높음 |

- 두 데이터셋 모두 10개의 클래스로 구성되어 있으며, 각 클래스별 훈련 샘플은 약 6,000개, 테스트 샘플은 약 1,000개임
- 이미지 배경은 0(검은색)에 가깝고, 객체(숫자나 의류)는 255(밝은색)에 가까운 픽셀값으로 반전 처리됨
- 패션 MNIST는 MNIST보다 난이도가 높아 기본 이미지 분류 학습에 적합 

### 데이터 전처리 및 형태 변환
- 원본 데이터는 28x28 2D 배열(흑백 이미지) 형태이나, 로지스틱 회귀 등 전통 머신러닝 알고리즘에 적용하려면 1D 벡터로 변환 필요
  - 예: 28x28 = 784차원 벡터로 펼침 (reshape)
- 픽셀 값은 0~255 사이 정수 -> 255로 나누어 0~1 사이의 실수값으로 정규화(스케일링)
  - 딥러닝에서는 표준화 대신 0~1 스케일링을 주로 사용
- 타깃 데이터는 0~9 정수 레이블 형태로 유지 가능하며, 다중 분류시에는 이를 원-핫 인코딩으로 변환하거나 스파스 카테고리컬 크로스 엔트로피(sparse categorical crossentropy) 손실함수 사용

### 로지스틱 회귀 모델과 인공신경망의 유사성
| 구분 | 로지스틱 회귀 모델 | 간단한 인공신경망 |
|------|--------------------|-------------------|
| 입력 | 784차원 벡터 (28x28 픽셀 펼침) | 동일 (입력층) |
| 가중치 곱셈 | 각 입력 픽셀에 대해 클래스별 가중치 곱셈, 절편 더함 | 동일 (입력과 각 뉴런 간 완전 연결) |
| 출력 | 10개 클래스별 선형 방정식 결과 $Z_i$ 계산 | 10개 뉴런의 출력 $Z_i$ | 
| 활성화 함수 | 소프트맥스 함수로 다중 클래스 확률 계산 | 소프트맥스 활성 함수 사용 |
| 분류 결정 | 가장 큰 $Z_i$ 값의 클래스를 예측 | 동일 |

- 인공신경망의 가장 단순한 형태는 로지스틱 회귀와 구조적으로 매우 유사함
- 입력층은 계산 없이 입력 데이터 자체를 의미하며, 그 다음 층부터 계산 수행
- 각 뉴런(유닛)은 입력값과 가중치의 선형 결합 결과에 절편을 더해 출력값 $Z_i$ 생성

### 인공신경망의 기본 구조와 용어
| 구성 요소 | 설명 | 비고 |
|-----------|------|------|
| 입력층 (Input Layer) | 입력 데이터 자체, 계산하지 않음 | 784차원 벡터 형태 (28x28 픽셀 펼침) |
| 은닉층 (Hidden Layer) | 입력층과 출력층 사이의 계산 층, 여러 층 쌓이면 딥러닝됨 | 이번 강의에서는 단일 출력층만 사용 |
| 출력층 (Output Layer) | 최종 출력값 생성, 분류할 클래스 수만큼 뉴런 존재 | 10개 뉴런, 소프트맥스 활성화 함수 사용 |
| 뉴런(유닛) | 입력값과 가중치의 선형 결합을 계산하는 기본 단위 | 로짓(logit unit)이라고도 함 |
| 완전 연결층 (Dense Layer) | 각 뉴런이 이전 층 모든 입력에 연결되어 있음 | 밀집 층(Dense layer), 선형층(Linear layer)이라고도 함 |
| 피드포워드 신경망 (Feedforward NN) | 데이터가 한 방향(입력 -> 출력)으로만 전달되는 구조 | 역전파(Backpropagation)는 학습 시 별도 처리 |

- 은닉층이 추가될수록 모델의 표현력이 증가하며 딥러닝으로 불림
- 인공신경망은 층마다 가중치와 절편을 학습하여 입력과 출력 간 관계를 모델링
- 뉴런의 출력값은 선형 방정식 계산 결과이며, 활성화 함수 적용으로 비선형성 부여 가능

### 머신러닝, 인공신경망, 딥러닝의 관계
- 머신러닝은 컴퓨터가 데이터를 통해 학습하는 알고리즘들의 총칭
- 인공신경망은 머신러닝 알고리즘 중 하나
- 딥러닝은 인공신경망의 층을 여러 개 쌓아 깊게 만든 모델을 의미
- 용어상 딥러닝과 인공신경망을 엄격히 구분하지 않는 경우도 많음
- 인공신경망의 발전은 여러 층을 쌓을 수 있는 기술 발전에 기인

### 케라스(Keras) 라이브러리 개요 및 인공신경망 구현
| 내용 | 설명 |
|------|------|
| 케라스 개발자 | 프랑수아 숄레(Francois Chollet), 2015년 최초 개발 |
| 초기 백엔드 | 시아노(Theano), 텐서플로우(TensorFlow), CNTK 등 여러 백엔드 지원 |
| 텐서플로우 통합 | 텐서플로 2.0부터 공식 API로 통합되어 텐서플로 전용 백엔드 사용 |
| 최신 버전(케라스 3) | 다시 멀티백엔드 지원 시작(TensorFlow, PyTorch, JAX 등) |
| 특징 | 고수준 API로 복잡한 신경망 구조를 간단히 코드로 구현 가능 |
| 주요 모듈 | <mark>keras.layers</mark> (입력층, Dense층 등 다양한 층 제공), <mark>keras.Sequential</mark> (순차적 모델 정의) |
| 활성화 함수 지정 | Dense층의 <mark>activation</mark> 매개변수에 <mark>"softmax"</mark> 등 지정하여 출력층 확률화 가능 |
| 손실 함수 | 다중 분류 문제에서는 <mark>sparse_categorical_crossentropy</mark> 사용 (정수 레이블 그대로 사용 가능) |
| 모델 컴파일 | 손실함수, 최적화 알고리즘, 평가 지표(metrics) 지정하여 학습 준비 |
| 모델 학습 | <mark>fit()</mark> 메서드로 입력 및 타깃 데이터 전달, 에폭(epoch) 수 지정하여 반복 학습 |
| 평가 | <mark>evaluate()</mark> 메서드로 검증 데이터셋에 대한 성능 측정 가능 |

### 인공신경망 모델 생성 및 학습 과정 요약
| 단계 | 설명 |
|------|------|
| 1. 입력층 정의 | <mark>keras.layers.Input(shape=(784,))</mark>로 784차원 벡터 입력층 생성 |
| 2. 출력층 정의 | <mark>keras.layers.Dense(10,activation='softmax)</mark>으로 10개 뉴런(클래스) 출력층 생성 |
| 3. 모델 구성 | <mark>keras.Sequential([입력층, 출력층])</mark>으로 순차적 모델 생성 |
| 4. 컴파일 | <mark>model.compile(loss='sparse_categorical_crossentropy', optimizer='sgd', metrics=['accuracy']) |
| 5. 학습 | <mark>model.fit(train_input, train_target, epochs=5)</mark>으로 5회 반복 학습 |
| 6. 평가 | <mark>model.evaluate(val_input, val_target)</mark>으로 검증 데이터셋 성능 확인 | 

- 입력 데이터는 2차원 배열(샘플 수 x 784) 형태이어야 하며, 타깃은 정수 레이블 배열
- 손실 함수는 다중 클래스 분류에 적합한 스파스 카테고리컬 크로스 엔트로피 사용
- 활성화 함수 소프트맥스는 출력층에서 각 클래스에 대한 확률 분포 생성
- 옵티마이저로 경사하강법(SGD) 사용, 반복(epoch)을 조정하여 학습 지속

### 용어 정리 및 추가 설명
| 용어 | 설명 |
|------|------|
| 뉴런(Neuron) | 인공신경망의 기본 계산 단위, 입력과 가중치의 선형 결합으로 출력값 생성 |
| 로짓(Logit) | 뉴런의 선형 결합 결과값, 소프트맥스 전의 클래스별 점수 |
| 완전 연결층(Dense Layer) | 모든 입력과 출력 뉴런이 연결된 층, 선형 방정식 계산 수행 |
| 활성화 함수(Activation Function) | 뉴런의 출력에 비선형성을 부여하여 모델의 표현력 향상, 대표적 함수: ReLU, Softmax 등 |
| 소프트맥스(Softmax) | 다중 클래스 분류 시 각 클래스에 대한 확률값을 계산하는 함수 |
| 스파스 카테고리컬 크로스 엔트로피 | 정수 레이블을 그대로 사용할 수 있는 다중 클래스 분류용 손실 함수 |
| 피드포워드 신경망 | 데이터가 입력에서 출력 방향으로만 흐르는 신경망 구조 |

- 입력층은 계산하지 않고 데이터를 그대로 전달하는 데이터 포맷 지정 층임
- 역슬래시(\) 문자는 Python 코드에서 한 줄을 여러 줄로 나누어 작성할 때 사용하는 연결 기호
- 각 층의 뉴런 수, 활성화 함수 종류 등은 하이퍼파라미터로 모델 성능에 큰 영향

### 인공신경망과 기존 머신러닝 모델의 본질적 차이
- 로지스틱 회귀는 선형 분류기이며, 단일 층 신경망과 동일한 수학적 구조
- 인공신경망은 다중 층을 쌓아 비선형 변환을 반복 적용함으로써 비선형 문제 해결 가능
- 인공신경망은 학습할 가중치와 절편이 많아 복잡하고 데이터 요구량이 큼
- 딥러닝은 인공신경망의 심층화된 형태로 복잡한 데이터 패턴을 자동으로 학습할 수 있음

### 신경망 학습 과정 개념
- 모델 구조를 먼저 정의(층 구성, 뉴런 수, 활성화 함수 등)
- 손실 함수와 최적화 알고리즘을 지정하여 학습 준비
- 입력 데이터와 타깃 레이블을 사용해 반복적으로 가중치 업데이트
- 학습 중 손실 값 감소 및 정확도 향상을 관찰
- 학습 완료 후 테스트 또는 검증 데이터셋으로 성능 평가

인공신경망은 로지스틱 회귀와 유사한 선형 방정식을 기반으로 입력을 처리하되, 다수의 뉴런과 층이 완전 연결되어 있고 소프트맥스 활성화 함수를 통해 다중 분류 문제를 해결한다. 입력층은 원본 데이터를 전달하는 역할을 하며, 출력층은 클래스별 확률을 산출한다. 케라스는 이러한 신경망 모델을 간단한 코드로 구현할 수 있게 하며, 모델 컴파일 시 적절한 손실 함수와 평가 지표를 설정하여 학습을 진행한다. 인공신경망은 머신러닝 알고리즘의 한 종류로, 여러 층을 깊게 쌓아 딥러닝으로 확장되며, 복잡한 데이터 패턴 학습에 강점을 가진다.
