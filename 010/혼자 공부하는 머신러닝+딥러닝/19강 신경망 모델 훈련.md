## 19강 신경망 모델 훈련
### 신경망 모델 훈련 과정과 히스토리 객체 활용
- 모델의 <mark>fit</mark> 메소드를 호출하면 히스토리(History) 객체가 반환됨
- 히스토리 객체는 에포크(epoch)마다 기록된 손실(loss), 정확도(accuracy) 등의 값을 딕셔너리 형태로 저장
- 기본 키: <mark>"loss"</mark> (훈련 손실), 매트릭스에 따라 <mark>"accuracy"</mark> 등 추가 가능
- 훈련 과정 시각화를 위해 matplotlib 등으로 히스토리 속성의 값을 그래프로 표현 가능
  - 손실은 에포크가 진행될수록 감소
  - 정확도는 에포크가 진행될수록 증가

### 과대적합과 검증 세트 손실 모니터링
- 훈련 세트 손실은 계속 감소하지만, 검증 세트 손실은 어느 시점부터 다시 증가하는 현상 관찰 가능
- 이 구간이 과대적합(overfitting) 영역임
- 반대로 손실이 줄어들지 않는 구간은 과소적합(underfitting) 영역으로 판단
- 이를 확인하기 위해 <mark>fit</mark> 함수 호출 시 <mark>validation_data</mark> 매개변수에 검증 세트 입력과 타깃 데이터 튜플을 전달
- 히스토리 딕셔너리에 <mark>val_loss</mark>, <mark>val_accuracy</mark> 등의 검증 세트 지표가 추가 기록됨
- 검증 손실이 갑자기 증가하면 모델이 과대적합되었다고 판단 가능

### 과대적합 방지 기법: 드롭아웃(Dropout)
| 개념 | 설명 |
|------|------|
| 드롭아웃 | 학습 중 일부 뉴런을 랜덤하게 끄는 기법 (활성화하지 않음) |
| 목적 | 특정 뉴런에 과도하게 의존하는 현상을 방지, 모델의 일반화 성능 향상 |
| 적용 위치 | 은닉층 사이에 드롭아웃 층을 삽입하여 뉴런 출력을 랜덤하게 마스킹함 |
| 비율 조절 | 끄는 뉴런의 비율을 하이퍼파라미터로 설정 (예: 30%, 50%) |
| 훈련과 테스트 차이 | 훈련 시에만 적용, 테스트 시에는 모든 뉴런을 사용하여 예측 수행 |

- 드롭아웃은 제프리 힌튼(Geoffrey Hinton)이 제안한 과대적합 방지 아이디어
- 매 배치마다 무작위로 다른 뉴런을 끄므로 다양한 뉴런 조합으로 학습 효과
- 일부 뉴런만 사용해 학습하므로 특정 뉴런에 의존하는 과적합 현상 완화
- 합성곱 신경망(CNN), 순환 신경망(RNN), 대규모 언어 모델 등 다양한 신경망에서 활용됨

### 모델 저장과 가중치 저장
| 저장 방법 | 설명 | 사용 메소드 | 파일 확장자 예시 |
|-----------|------|-------------|------------------|
| 전체 모델 저장 | 모델 구조 + 가중치 + 컴파일 설정 모두 저장 | <mark>model.save('filename.keras')</mark> | <mark>.keras</mark> |
| 가중치만 저장 | 모델의 학습된 가중치만 저장 | <mark>model.save_weights('filename.h5')</mark> | <mark>.h5</mark> |
| 가중치 로드 | 미리 생성한 동일 구조 모델에 가중치만 불러오기 | <mark>model.load_weights('filename.h5')</mark> | <mark>.h5</mark> |
| 전체 모델 로드 | 저장된 모델 파일에서 모델 객체와 가중치, 컴파일 상태 모두 복원 | <mark>keras.models.load_model('filename.keras')</mark> | <mark>.keras</mark> |

- 모델 저장은 훈련 완료 후 재사용과 배포에 필수적
- 가중치만 저장하면 모델 구조는 코드로 다시 작성해야 함
- 전체 모델 저장 시 컴파일 상태도 복원되어 <mark>evaluate</mark> 등 사용 가능

### 예측과 평가 방법
- <mark>model.predict()</mark>는 클래스 인덱스가 아닌 각 클래스에 대한 확률값을 반환함
- 예측 클래스 인덱스는 NumPy의 <mark>argmax</mark> 함수로 확률이 가장 높은 인덱스를 추출
  - <mark>axis=-1</mark>: 각 샘플별 마지막 차원(클래스별 확률)에서 최대값 인덱스 추출
- <mark>model.evaluate()</mark>는 입력 데이터와 타깃 데이터로 손실과 정확도 등 평가 지표 계산
- 전체 모델을 로드한 경우 컴파일 상태까지 복원되어 바로 <mark>evaluate</mark> 사용 가능
- 가중치만 로드한 경우 <mark>compile</mark> 메소드를 호출해야 <mark>evaluate</mark> 사용 가능

### 콜백(Callbacks)과 조기 종료(Early Stopping)
| 콜백 종류 | 역할 | 주요 매개변수 및 특징 |
|-----------|------|-----------------------|
| ModelCheckpoint | 검증 점수가 가장 좋을 때의 모델 가중치를 파일로 저장 | <mark>save_best_only=True</mark>: 최상의 모델만 저장 |
| EarlyStopping | 검증 손실이 개선되지 않으면 조기 종료, 과대적합 방지 | <mark>restore_best_weights=True</mark>: 최고 성능 가중치 복원 |

- 훈련 중간에 검증 성능이 가장 좋은 시점의 모델을 저장해 최적 모델 관리 가능
- 조기 종료는 검증 손실이 일정 에포크 동안 개선되지 않으면 훈련을 멈춤
- 조기 종료 시 최고 성능 가중치로 모델 파라미터 복원 가능해 재학습 없이 최적 사용 가능
- 콜백은 리스트 형태로 <mark>fit</mark> 메소드에 전달 가능해 여러 콜백 동시 적용 가능

### 신경망 훈련의 핵심 흐름 요약
| 단계 | 설명 |
|------|------|
| 모델 정의 | 은닉층, 출력층, 필요한 경우 드롭아웃 층 추가 |
| 컴파일 | 손실 함수, 옵티마이저, 평가 지표 지정 |
| 훈련 | <mark>fit</mark> 메소드 호출, 검증 데이터 포함, 콜백 리스트 전달 |
| 히스토리 확인 | 반환된 히스토리 객체로 손실과 정확도 등 훈련 경과 시각화 |
| 모델 저장 | 훈련 완료 후 전체 모델 또는 가중치 저장 |
| 모델 로드 | 저장된 모델/가중치 파일 불러오기, 필요 시 컴파일 |
| 예측 및 평가 | <mark>predict</mark>로 확률 출력, <mark>argmax</mark>로 클래스 인덱스 결정, <mark>evaluate</mark>로 성능 평가 |

<hr>
신경망 훈련 과정은 모델이 학습 데이터에 점진적으로 적응하면서 손실을 최소화하고 정확도를 높이는 과정을 체계적으로 관리한다. 검증 세트 손실 모니터링과 드롭아웃 같은 규제 기법은 과대적합을 억제하여 모델의 일반화 능력을 향상시키며, 콜백과 조기 종료는 훈련 시간을 효율화하고 최적 모델을 자동으로 관리한다. 저장과 복원 과정은 학습한 모델을 지속해서 재사용할 수 있게 해 실전 적용에 필수적이다.
