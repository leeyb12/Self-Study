## 14강 군집 알고리즘
### 비지도 학습과 군집 알고리즘 개요
> 비지도 학습은 입력 데이터만 가지고 학습하며, 타겟(label) 없이 유용한 패턴이나 구조를 찾는 머신러닝의 한 분야이다. 
- 5장까지는 주로 지도학습 알고리즘(입력과 타겟 존재) 중심으로 다룸
- 6장부터는 비지도 학습 소개 (타겟 없이 입력 데이터만 활용)
- 비지도 학습은 현실 문제에서 라벨링이 힘들거나 불가능할 때 중요
- 여러 비지도 학습 알고리즘 중에서 군집(Clustering) 알고리즘에 초점을 맞춤

### 데이터 준비아 이미지 데이터 특징
#### 과일 이미지 데이터셋
- 데이터는 bit.ly 주소에서 다운로드한 NPY 파일 형식
- NPY 파일은 넘파이(NumPy) 배열 저장 포맷으로, 다차원 배열을 효율적으로 저장
- 과일 사진 300장, 각 이미지는 100 x 100 픽셀 크기의 3차원 배열 형태
  - 첫 번째 축: 샘플 수 (300개)
  - 두 번째, 세 번째 축: 이미지 가로, 세로 픽셀 수 (100, 100)

#### 픽셀 값과 이미지 표현
| 픽셀 값 범위 | 의미 | 색상 표현 |
|--------------|------|-----------|
| 0 | 가장 낮은 밝기 | 검은색 (배경 영역) |
| 255 | 가장 높은 밝기 | 흰색 (과일 영역) |

- 데이터는 일반 이미지와 달리 배경이 낮은 값(0)이고 과일이 높은 값(밝은 픽셀)으로 반전되어 있음
- 신경망에서 0인 값은 연산에 영향이 없으므로, 관심 영역(과일)을 높은 값으로 표현한 것
- 시각적으로 확인하려면 Matplotlib에서 <mark>cmap='gray_r</mark> 옵션을 사용하여 반전된 색상을 자연스럽게 표시

### 데이터 전처리: 차원 변환과 평균 연산
#### 1차원 배열 변환
- 머신러닝 도구들은 대부분 2차원 이상의 배열을 직접 처리하지 못함
- 따라서 각 이미지의 100 x 100 픽셀 데이터를 1차원 벡터(10000차원)로 펼침(flatten)
- 변환 방법: 넘파이의 <mark>reshape</mark> 함수 사용, 샘플 수 유지(300)하고 각 샘플의 픽셀 차원만 변환

#### 평균 계산과 시각화
| 구분 | 계산 방법 | 결과 해석 |
|------|-----------|-----------|
| 샘플별 평균 (axis=0) | 같은 픽셀 위치에서 300개 샘플의 평균 계산 | 각 픽셀 위치별 평균 밝기 값 획득 |
| 픽셀별 평균 (axis=1) | 한 이미지 내 모든 픽셀의 평균 계산 | 이미지 전체 밝기의 평균 값 산출 |

- 샘플별 평균값을 히스토그램으로 그려 과일 종류 간 밝기 분포 차이 확인
- 바나나는 평균 픽셀값이 낮고, 애플과 파인애플은 유사한 분포로 구분 어려움 시사
- 픽셀별 평균값을 다시 100 x 100 이미지 형태로 재구성하여 각 과일의 평균 이미지 시각화 가능
  - 흐릿하지만 전체적인 형태 인식 가능 (100개 이미지의 합산 평균)

### 비지도 학습을 통한 군집화 접근
#### 단순 평균 기반 분류 시도
- 각 과일 종류별 평균 이미지(벡터)를 구한 뒤,
- 새로운 데이터 샘플과 평균 이미지 간의 차이 절댓값을 계산 (ABSD)
- 차이 절댓값의 평균을 구해 가장 작은 값을 가진 평균 이미지와 비교하여 분류 유추

#### 한계점 및 문제 제기
| 단계 | 설명 | 문제점 |
|------|------|--------|
| 평균 이미지 계산 | 각 과일별 100개 샘플을 이미 알고 있어 평균 계산 | 실제 비지도 학습에서는 정답(라벨) 미존재 |
| 차이 절댓값 계산 | 샘플과 평균 이미지 간 차이 비교 | 사전에 과일 종류를 알고 있어 군집화 의미 감소 |
| 실제 비지도 학습 적용 | 라벨 없이 데이터 군집화 필요 | 자동으로 데이터 그룹화하는 알고리즘 필요 |

- 예시에서는 이미 과일별로 100개씩 라벨이 정해진 상태에서 평균을 계산해 분류했음
- 실제 비지도 학습 문제는 라벨 없이 데이터 내에서 구조를 찾아내는 것이 목적
- 다음 강의에서 군집 알고리즘을 통해 이 문제를 자동화하는 방법 탐구 예정

### 이미지 데이터 분석 요약
| 데이터 특징 | 처리 방법 | 결과 및 해석 |
|-------------|-----------|--------------|
| 3차원 과일 이미지 데이터 | NPY 파일 -> 넘파이 배열 로드 | 샘플별 1차원 벡터 변환(300, 10000) |
| 픽셀값 반전 | 배경 0, 과일 영역 밝은 값으로 변환 | 신경망 입력 시 의미 있는 값 유지 |
| 평균값 계산 | axis=0: 샘플별 픽셀 평균 <br> axis=1: 이미지 내 모든 픽셀 평균 | 과일별 밝기 분포 차이 <br> 각 이미지 밝기 대표값 산출 |
| 평균 이미지 시각화 | 10000차원 -> 100 x 100 이미지 재구성 | 흐릿하지만 과일 모양인지 가능 |
| 단순 평균 기반 분류 시도 | 새로운 샘플과 평균 이미지 차이 계산 | 라벨 알고 있어 실제 비지도 학습과 다름 |

과일 이미지 데이터는 픽셀 값의 반전과 1차원 배열 변환을 통해 머신러닝 모델 입력에 적합한 형태로 가공되며, 샘플과 픽셀 단위 평균값을 분석하여 데이터 내 분포 차이를 탐색한다. 단순 평균 기반 분류는 라벨 정보를 사전에 알고 수행하므로 진정한 비지도 학습 문제의 해결책이 될 수 없으며, 라벨 없이 데이터 구조를 자동으로 인식하는 군집 알고리즘의 필요성을 제기한다.
