## 24강 순환 신경망으로 IMDB 리뷰 분류하기
### IMDB 리뷰 분류를 위한 순환 신경망 모델링
> "IMDB 리뷰 데이터셋을 활용하여 순환 신경망(RNN)으로 영화 리뷰의 긍정/부정을 분류하는 과정과 관련 용어, 데이터 전처리, 인코딩 및 임베딩 방법을 학습한다."

#### 1. IMDB 리뷰 데이터셋 개요
- IMDB 데이터셋
  - 영화 리뷰 텍스트가 담긴 데이터셋
  - 긍정적 리뷰 25,000개, 부정적 리뷰 25,000개로 구성
  - 각 단어는 고유 정수 인덱스로 매핑되어 있음 (케라스가 토큰화 및 인덱싱 처리 완료)
- 용어 설명
  - 토큰화 (Tokenization): 텍스트 데이터를 분석 가능한 최소 단위(토큰)로 나누는 과정입니다.
  - 어휘사전 (Vocabulary): 데이터셋에 등장하는 고유 단어들의 집합으로, 각 단어는 고유한 인덱스로 매핑됩니다.
  - 패딩 (Padding): 서로 길이가 다른 텍스트 시퀀스를 동일한 길이로 맞추기 위해 특정 값(보통 0)을 추가하여 길이를 통일하는 기술입니다.
  - 임베딩 (Embedding): 단어를 고차원의 희소 벡터가 아닌, 의미를 내포한 저차원의 밀집된 실수 벡터로 표현하는 방법입니다.
  - 시그모이드 함수 (Sigmoid Function): 입력값ㅇ르 0과 1 사이의 확률값으로 변환해 주는 활성화 함수로, 주로 이진 분류 문제의 출력층에서 사용됩니다.
  - 과적합 (Overfitting): 모델이 훈련 데이터에 너무 과도하게 맞춰져서, 새로운 데이터에 대한 성능이 떨어지는 현상입니다.

#### 2. 데이터셋 구조 및 특징
- 케라스 IMDB 데이터셋은 이미 토큰화 및 인덱싱이 완료된 정수 시퀀스로 제공됨
- 리뷰 길이 다양성: 리뷰마다 길이가 다름
- 데이터 형태
  - 훈련 입력: 파이썬 리스트(서로 길이가 다름)
  - 타겟(정답): 0 또는 1 (부정/긍정) 이진 분류 문제
- 리뷰 길이 통계
  - 평균 약 200 토큰
  - 중앙값 178 토큰
  - 분포는 짧은 리뷰가 많고 긴 리뷰는 적은 편(우측 치우침)

#### 3. 시퀀스 길이 맞추기: 패딩 (Padding)
- 이유: RNN 입력은 3차원 텐서로, 각 배치 샘플의 시퀀스 길이가 동일해야 함
- 처리 방법
  - 긴 리뷰는 자름 (max length 초과 시)
  - 짧은 리뷰는 0으로 패딩 (제로 패딩)
  - 패딩 위치는 시퀀스 앞부분에 채우는 pre-padding 방식 사용
    - 이유: RNN의 마지막 타임스텝 출력이 중요 -> 실제 텍스트가 뒤쪽에 위치하도록 하기 위함
- 케라스 함수 <mark>pad_sequences</mark> 사용
  - 예: <mark>pad_sequences(train_input, maxlen=100, padding='pre')</mark>
  - 결과: 모든 시퀀스 길이가 100으로 통일됨 (2만 개 샘플 x 100 타임스텝)

#### 4. 순환 신경망 모델 구성 (케라스 활용)
| 구성요소 | 설명 |
|----------|------|
| 입력층(Input layer) | 시퀀스 길이 100, 각 타임스텝은 단어 인덱스(정수)로 표현 |
| 임베딩 차원 | 단어마다의 벡터 크기(초기에는 무작위 실수로 초기화, 학습을 통해 단어 의미를 담은 임베딩 벡터로 최적화) |
| RNN 층 (SimpleRNN) | 유닛 수 8, 순환층으로 시퀀스 처리 |
| 출력층 | 뉴런 1개, 활성화 함수 시그모이드 -> 이진 분류 결과 출력 |

- 모델은 <mark>Sequential</mark> API 또는 함수형 API로 구성 가능
- 출력값은 긍정(1) / 부정(0) 확률로 해석 가능

#### 5. 텍스트 데이터 인코딩 방법
##### 5-1. 원-핫 인코딩 (One-hot encoding)
- 각 단어를 고유 인덱스에 대응하는 벡터로 변환
- 벡터 크기 = 어휘사전 크기 (예: 200)
- 단어가 인덱스 10이라면 10번째 위치만 1이고 나머지는 0인 200차원 벡터 생성
- 결과 텐서 크기: (샘플 수) x (시퀀스 길이) x (어휘 크기)
- 단점: 매우 큰 메모리 사용, 희소 벡터(sparse vector) 발생
- 케라스 함수: <mark>to_categorical</mark> 사용

##### 5-2. 임베딩 (Embedding)
- 단어를 고정 크기 실수 벡터로 표현하는 방법
- 예: 500개의 단어를 16차원 벡터로 매핑 -> 500x16 크기의 임베딩 행렬
- 임베딩 벡터는 학습 과정에서 최적화
- 단어 간 의미적 유사도(예: <mark>cat</mark>과 <mark>dog</mark> 벡터가 가깝게 위치)를 계산 가능
- 메모리 효율이 높고, 단어 의미 표현에 효과적
- 케라스의 <mark>Embedding</mark> 층 사용
- 초기 임베딩 행렬은 랜덤 초기화되고 학습에 따라 개선됨

#### 6. 인코딩과 임베딩 비교 및 활용 
| 구분 | 원-핫 인코딩 | 임베딩 |
|------|--------------|--------|
| 벡터 형태 | 희소 백터 (0과 1만 존재) | 밀집된 실수 벡터 |
| 차원 수 | 어휘 크기만큼(예: 200) | 임베딩 차원 수 (예: 16~200) 선택 가능 |
| 메모리 사용 | 매우 큼 | 상대적으로 작음 |
| 의미 표현력 | 단어 간 관계 반영 불가 | 단어 의미 유사도 반영 가능 |
| 구현 방법 | <mark>to_categorial</mark> 함수 사용 | 케라스 <mark>Embedding</mark> 층 사용 |

#### 7. 모델 훈련 및 평가
- 옵티마이저, 손실 함수 설정
  - 이진 분류이므로 손실 함수는 <mark>binary_crossentropy</mark> 사용
- 콜백 함수로 조기 종료(Early Stopping) 적용 가능
- 훈련 과정에서 검증 세트를 분리하여 과적합 여부 확인
- 임베딩 층을 사용하면 메모리 효율이 좋아지고, 성능 향상 가능
- 훈련 후 정확도 및 손실 곡선으로 모델 성능 평가

#### 8. 자연어 처리와 순환 신경망의 역사적 맥락
- NLP 분야에서 과거에는 순환 신경망이 대표적인 텍스트 처리 방법이었음
- 10장 이후 트랜스포머 모델이 등장하면서 NLP의 주류가 크게 변화됨
- 임베딩 기술은 트랜스포머 모델의 근간을 이루는 핵심 개념임
- 초기에는 이러한 계산적 접근법이 기존 언어학적 전통과 달라 저항이 있었으나, 뛰어난 실용성과 성능을 바탕으로 점차 인정받게 됨
