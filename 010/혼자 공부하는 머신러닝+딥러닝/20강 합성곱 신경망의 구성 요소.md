## 20강 합성곱 신경망의 구성 요소
### 컨볼루션 신경망(Convolutional Neural Networks, CNN) 주요 개념
> "컨볼루션 신경망은 이미지 등의 2D 데이터 처리에 특화된 신경망 구조로, 입력 데이터의 일부 영역에만 가중치 연산을 수행해 효율적이고 효과적인 특징 추출을 가능하게 한다."

#### 1. Dense Layer와 Convolutional Layer 차이
| 구분 | Dense Layer | Convolutional Layer (CNN) |
|------|-------------|---------------------------|
| 입력과 가중치 매핑 | 모든 입력(feature)에 각각 가중치 곱셈 | 입력 일부 영역에만 가중치 곱셈 (부분적 연산) |
| 가중치 수 | 입력 수와 동일 (예: 10 입력 -> 10 가중치) | 가중치 수 적음 (예: 10 입력 중 3 가중치만 사용) |
| 출력 생성 방식 | 입력 전체에 가중치 곱 후 합산 | 가중치(필터)를 입력에 슬라이딩하며 합산 |
| 용도 | 일반적인 피드포워드 신경망 | 이미지, 시계열 등 국소 특징 추출에 적합 |

#### 2. 컨볼루션 연산 (Convolution Operation)
- 1D 컨볼루션: 3개의 가중치(W1, W2, W3)를 입력 배열에 슬라이딩하며 곱셈-합산 수행
- 입력 10개, 가중치 3개 -> 출력 8개 생성 (슬라이딩 위치마다 1개 출력)
- 2D 컨볼루션: 4x4 입력 이미지에 3x3 필터(커널)를 적용
  - 필터가 겹치는 3x3 영역과 곱한 후 합산해 한 개의 출력 생성
  - 필터를 오른쪽으로 한 칸씩 이동하며 출력 생성 -> 2x2 출력 생성
- 필터(Weights)는 Dense Layer의 가중치와 동일 개념이나, CNN에서는 Filter 또는 Kernel이라 부름

| 용어 | 의미 및 설명 |
|------|--------------|
| 필터(Filter) | 입력 데이터에 슬라이딩되며 곱해지는 가중치 집합 전체 |
| 커널(Kernel) | 필터 내부의 가중치 배열, 보통 2D 혹은 3D 배열 |
| 피처 맵(Feature Map) | 필터 적용 결과로 생성되는 출력 배열, 입력과 크기 관계 있음 |

- 필터 여러 개 사용 -> 각 필터는 다른 특징 감지 (예: 색상, 모양, 선 등)
- 필터 수가 출력 피처 맵의 길이(depth)를 결정 (예: 3개 필터 -> 출력 2x2x3)

#### 3. 패딩(Padding)
- 입력 가장자리 주변에 0으로 채운 픽셀 추가 (zero padding)
- 목적
  - 필터가 입력 경계를 벗어나지 않고도 더 많이 슬라이딩 가능
  - 출력 크기를 조절해 입력과 동일 크기로 만들거나 크기 유지
- 예: 4x4 입력에 1픽셀 패딩 -> 6x6 입력처럼 처리 가능
- 0으로 채워 곱셈 결과에 영향 없도록 설계
- 딥러닝 라이브러리(Keras 등)에서 자동으로 패딩 조절 가능

#### 4. 스트라이드(Stride)
- 필터가 입력 위를 움직이는 간격(칸 수)
- 기본값은 1 (한 칸씩 이동)
- 2 이상일 경우 필터가 띄엄띄엄 이동 -> 출력 크기 감소
- 예: 4x4 입력, 3x3 필터, 스트라이드 2 -> 2x2 출력 생성
- 실무에서는 보통 스트라이드 1 사용 빈도 높음

#### 5. 풀링(Pooling)
- 특징 맵의 공간적 크기(가로, 세로)를 줄여 계산량 감소 및 특징 요약 목적
- 보통 스트라이드 크기 = 풀링 영역 크기 (예: 2x2 영역, 스트라이드 2 -> 겹치지 않음)
- 종류
  - 최대 풀링(Max Pooling): 영역 내 최대값 추출 (특징 강조에 효과적)
  - 평균 풀링(Average Pooling): 영역 내 평균값 추출 (평균적 특징 표현)
- 풀링은 곱셈 없이 단순 값 선택/계산 -> 가중치 없음
- CNN에서는 풀링 레이어 별도 구성

| 툭징 | 설명 |
|------|------|
| 역할 | 공간 크기 축소, 특징 요약 및 잡음 제거 |
| Max Pooling | 영역 내 최대값 선택, 패턴 검출에 유리 |
| Average Pooling | 영역 내 평균값 계산, 특징의 일반화 도움 |

#### 6. CNN 기본 구조 예시
| 단계 | 설명 |
|------|------|
| 입력 | 4x4 이미지 + 1픽셀 패딩 -> 5x5 입력 |
| 컨볼루션 | 3개의 3x3 필터 적용 -> 4x4 크기, 3채널(feature maps) 출력 |
| 활성화 함수 | ReLU 등 비선형 함수 적용 |
| 풀링 | 2x2 영역, 스트라이드 2 풀링 -> 2x2x3 크기 축소된 출력 |
| 평탄화(Flatten) | 3D 배열(2x2x3) -> 1D 배열(12개 요소) 변환 |
| Dense Layer | 10개 뉴런(클래스) 출력, Softmax 활성화 함수 적용 |

#### 7. 컬러 이미지와 3D 컨볼루션
- 컬러 이미지는 높이, 너비, 깊이(채널, 예: RGB 3채널)로 구성된 3D 배열
- 입력 깊이에 맞춰 필터(커널)도 3D 생성 (예: 3x3x3)
- 필터 깊이는 입력 깊이와 자동 매칭
- 흑백 이미지는 2D지만, CNN 입력으로 3D(28x28x1) 형태로 변환 후 처리
- 필터는 깊이 방향으로 슬라이딩하며 곱셈과 합산 수행 -> 단일 출력 생성

### 주요 용어 정리
| 용어 | 정의 및 설명 |
|------|--------------|
| Dense Layer | 모든 입력에 가중치 곱하고 합산해 출력 생성하는 완전연결층 |
| Convolution | 가중치 필터를 입력 데이터에 슬라이딩하며 곱셈-합산 수행 |
| Filter | CNN에서 커널을 포함한 가중치 집합, 여러 개 존재 가능 |
| Kernel | 필터 내 2D 또는 3D 가중치 배열 |
| Feature Map | 필터 적용 결과로 생성된 출력 배열 |
| Padding | 입력 주변에 0을 추가해 공간 확장, 출력 크기 조절 목적 |
| Stride | 필터가 입력 위를 움직이는 간격 |
| Pooling | 특징 맵 크기 축소, 대표값 추출 (Max/Average) |
| Activation Function | ReLU 등 비선형 변환 함수, 특징 추출 후 적용 |

<hr>
컨볼루션 신경망은 입력 데이터의 공간적 구조를 보존하며 국소 영역에 집중해 가중치를 공유하는 방식을 통해 효율성을 극대화한다. 필터들은 서로 다른 특징을 감지하도록 학습되고, 이를 통해 입력 데이터 내에서 다양한 패턴을 효과적으로 추출한다. 패딩과 스트라이드 조절로 출력 크기를 세밀하게 관리하며, 풀링 레이어를 통해 공간적 차원을 축소함으로써 모델의 계산량과 과적합 위험을 줄인다. 컬러 이미지의 다중 채널 구조와 이에 적합한 3D 필터 설계는 CNN이 복잡한 시각 정보도 효과적으로 처리할 수 있게 한다.
