## 1강 데이터베이스 알아보기
### 데이터베이스와 DBMS 개념 이해
> "데이터베이스는 데이터의 집합이며, 일상 속 다양한 정보(교통카드, 인스타그램 사진, 카카오톡 메시지 등)를 포함한다."
- 데이터베이스: 여러 데이터가 모여 체계적으로 저장된 집합
- DBMS (Database Management System): 데이터베이스를 관리하는 소프트웨어
  - 엑셀 등은 데이터 관리를 하긴 하나, 대용량 관리와 다중 사용자 공유가 어려워 DBMS로 보지 않음
  - 은행 시스템은 다수 사용자가 동시에 데이터베이스에 접근 가능 (예: 인터넷 뱅킹, ATM)

### DBMS 종류 및 특징
| DBMS 종류 | 특징 및 설명 | 현재 사용 여부 |
|-----------|--------------|----------------|
| 계층형 DBMS | 트리 구조로 데이터 저장, 형제 노드 간 직접 연결 불가 (비효율적) | 과거에 사용, 현재는 거의 사용되지 않음 |
| 망형 DBMS | 계층형 단점 해결, 노드 간 복잡한 연결 가능 (망 구조) | 과거 사용, 현재는 많이 사용되지 않음 |
| 관계형 DBMS (RDBMS) | 테이블(행과 열) 형태로 데이터 저장, 현재 대부분 DBMS가 관계형 | 현재 주류, MySQL 등 대표적 사용 |

- 관계형 DBMS의 테이블은 행(row)과 열(column)로 구성된 표 형태
- MySQL, MariaDB, Oracle, SQL 서버 등이 대표적인 관계형 DBMS
